理解热拉尔·热奈特（Gérard Genette）的理论，关键在于学会区分文学经验中经常混在一起的关系：一件事何时发生，与它何时被讲到，是两回事；谁负责讲述，与谁的经验限制着我们获得的信息，是两回事；一个文本被归入文学，与它是否优秀，也是两回事。将这些关系拆开，才可能说明它们如何共同作用，使同一组事件成为不同的作品。

例如，一位女儿发现母亲留下的一封旧信。由女儿多年后回忆、由母亲当天写日记、由一个不参与事件的叙述者跟随女儿的意识呈现，这三个版本可以保留相近的事件，却分别产生追悔、未知与贴近当下的效果。进一步说，同一个版本被题为《母亲的秘密》或《未寄出的信》，被标注为“小说”或“家族实录”，被放进不同的文学传统，也会改变阅读的起点。热奈特的研究逐步从讲述的内部结构，扩展到文本的关系、文学的边界与艺术的存在方式。

这里所说的“理论体系”，是根据其主要研究重建的学习框架。热奈特并未以一本总论建立封闭体系，各时期的概念也并非毫无变化。本文覆盖其主要理论领域与实际分析所需的核心分支，不将每篇评论中的零散判断都编成独立学说。表中的次序是学习路径，不等同于著作出版顺序。

| 研究领域 | 所处理的关系 | 分析时可以提出的问题 |
| --- | --- | --- |
| 叙事话语理论 | 故事、叙事文本与讲述行为 | 相同事件为何能形成不同的叙事经验？ |
| 跨文本关系与体裁理论 | 一个文本与其他文本、类型及附属材料 | 一部作品怎样借助既有文学和出版安排获得意义？ |
| 修辞、文体与语言拟仿研究 | 语言的形式、意义和被感知的性质 | 某种表达为什么显得简洁、庄重、急促或仿佛贴合事物？ |
| 虚构与文学性理论 | 文本的交际身份与文学身份 | 什么使文本被当作虚构或文学来阅读？ |
| 艺术本体论与审美理论 | 作品、呈现形式与接受活动 | 同一作品怎样存在于多个版本中，又怎样成为审美对象？ |

这些领域相互贯通。例如，自由间接引语既是话语呈现方式，也涉及文体；封面上的“回忆录”既是副文本，又影响虚构性判断；一个改写本既可以作为超文本研究，也可以引出作品同一性问题。学习时应保留这些交叉，不能把表格误当成互不往来的学科分区。

**热奈特的基本工作方式，是先区分关系，再解释关系的组合。** 这与结构主义诗学（Structuralist Poetics）的取向有关。诗学在这里指文学形式、惯例与构成条件的一般研究，范围不限于诗歌。对某部作品的解释可以问“这封信象征什么”；诗学则进一步问，信件作为嵌入文本可以怎样组织时间、限制信息、改变人物之间的知识分配。前一个问题需要后一个问题提供工具，但工具本身不会自动给出唯一解释。

这种区分也可以约束分析中的过度推论。说“作品采用倒叙”是形式判断；说“倒叙使母亲早年的行动直到女儿成年后才获得解释”是机制判断；说“这一安排表现了家庭记忆对女性经验的遮蔽”则是意义解释。第三步应由前两步和具体文本支持。单独一个术语，不能证明一个主题。

《叙事话语》的重要实验场是普鲁斯特的《追忆似水年华》（À la recherche du temps perdu）。这使它兼有一般理论与特定作品研究的性质：概念从具体阅读中产生，又在复杂文本面前接受检验。普鲁斯特式的时间交错和叙事变化并不总是安稳地落进分类，因此，学习这些范畴时也应注意其边缘、混合与修订，而不只记住定义最整齐的例子。[1]

下面使用的《未寄出的信》及其片段均为教学自拟，不是实际出版作品。不同片段是对同一素材的改写实验，并不假定它们同时存在于一个自洽版本中。基本事件为：1998年夏天，母亲写下一封打算离家的信，父亲把它锁进抽屉；母亲最终没有离开，2008年去世；2020年父亲去世后，女儿林岚发现这封信；2025年，她向弟弟讲述发现旧信的经过。

**进入叙事学，首先要把“发生了什么”“文本怎样呈现”和“谁在什么情境下讲述”分开。** 这分别对应故事（histoire / story）、叙事话语（récit / narrative discourse）与叙述行为（narration / narrating）。《叙事话语》以这三个对象之间的关系组织分析；其五个主要项目是顺序、时长、频率、语式与语态，前三项归在时间这一上位范畴之下。[1]

“故事”是从叙事中重建的事件及其时空联系。在我们的例子中，写信、藏信、母亲去世、发现旧信，可以排成时间线。不过，故事并不等于一个能够脱离文本而完全确定的“真实底稿”。如果小说只提供相互冲突的证词，分析者可能无法确认父亲究竟藏了信，还是母亲自己放弃寄出。遇到这种情况，应保留不同版本，不能为了画出整齐的时间线而替作品裁定真相。

“叙事话语”是读者实际遇到的呈现。小说可以从2020年发现旧信写起，随后转入1998年，再返回2020年。也可以始终不直接呈现1998年，只让人物根据纸张、笔迹和记忆推测。两者即使指向相同的过去，也提供了不同的证据条件。

“叙述行为”是故事被讲出的活动及其情境。2025年的林岚写下一段回忆，就具有自己的时间位置、听众和目的。她是在解释误会、请求弟弟原谅，还是为自己辩护，会影响她怎样选择材料。现实作者在电脑前创作小说的行为，与小说设置的林岚写回忆的行为，需要分别处理。

| 上位范畴 | 主要项目 | 核心比较 |
| --- | --- | --- |
| 时间（Tense） | 顺序（Order） | 事件发生顺序与文本呈现顺序 |
| 时间（Tense） | 时长／速度（Duration / Speed） | 事件持续时间与叙述所占篇幅 |
| 时间（Tense） | 频率（Frequency） | 同类事件发生次数与叙述次数 |
| 语式（Mood） | 距离与聚焦 | 信息怎样被表达，以及受什么范围限制 |
| 语态／叙述声音（Voice） | 叙述时间、叙述层、人物关系等 | 讲述行为怎样与故事、叙述者和受述者联系 |

Tense、Mood、Voice借用了语法术语，但并不等同于语法中的时态、语气和主动／被动语态。尤其是“叙述时间”这个中文说法容易混淆。下文把事件的时间称为“故事时间”，把文本的次序和篇幅组织称为“话语时间”，把讲述活动发生的时间称为“叙述行为时间”。

**时间分析首先关心，信息为什么在这个位置出现。** 顺序研究比较故事时间线与文本的排列。设写信为A、藏信为B、母亲去世为C、发现旧信为D，按事件顺序是A—B—C—D。文本若采用D—A—B—C，就把结果放在前面，并要求读者逐步回溯原因。

回叙／倒叙（Analepsis）是在叙事推进到某一点时，返回此前发生的事情。例如：“林岚展开信纸。二十二年前，母亲曾在这张桌子前坐了整夜。”预叙（Prolepsis）则提前涉及相对于当前叙事位置尚未发生的事情，例如：“她把信放进口袋，还不知道两年后它会使兄妹彻底决裂。”二者属于时间倒错（Anachrony）。这里的“当前”是叙事的局部参照点，不是现实读者所在的年份。[2]

不能把所有涉及过去的句子都算作回叙。“2020年，她回到旧屋”可以只是故事的起点；只有相对于已经建立的叙事时序发生返回，才有回叙关系。同样，人物说“我明天可能离开”，首先是当前发生的一次设想或言语行为，不能直接当成对未来事实的预叙。若文本随后明确保证她第二天确实离开，性质才有所不同。伏笔也不等于预叙：桌上的车票可以暗示出走，却没有实际讲述未来的出走。

分析时间倒错时，两个尺度很有用：距离／跨度（Reach / Portée）说明离开当前时点有多远；幅度（Extent / Amplitude）说明那次跳转覆盖多长的事件时间。从2020年返回1998年的一个晚上，距离约二十二年，幅度却只有一晚。小说完全可以用很大的时间距离，聚焦很小的一段经历。这样一来，短暂事件的持久影响就会突出出来。

还可以区分外部、内部与混合回叙。假设某个版本的主要叙事时段是2020年至2025年，那么1998年的往事处在这段范围之前，是外部回叙；从2025年返回2021年，则是内部回叙；从1998年一直讲到2021年，则跨过起点，构成混合回叙。“内部／外部”在这里以主要故事的时间范围为标准，与内外叙述层、内外聚焦都不是同一分类。

主要叙事时段也需要从作品中辨认。如果小说开篇只有一句2025年的提示，主体却持续讲述1998年的夏天，就不能机械地把整部小说都视为相对于第一句的巨大插叙。应说明叙事实际建立了怎样的基准线，以及基准线是否发生移动。

回叙还可能执行不同任务。补充性回叙填补先前没有叙述的内容；重复性回叙重新讲述已出现的事件，但可能改变细节、语境或解释。第一次写父亲锁上抽屉，林岚以为他只是保管文件；第二次返回同一动作，才出现他藏起母亲来信的情境。这里的重点是同一动作获得了新意义。若先前根本没交代藏信行为，后来的揭示则首先是补充。

顺序改变的是阅读中的认识进程。先写藏信，再写女儿发现，读者会提前知道她尚不知道的事实；先写发现，再逐步补出藏信，读者则与她一起追索。前者可能使等待和误认变得紧张，后者可能强化调查和重释。这些是具体安排可以产生的效果，不是“预叙必然制造宿命”“倒叙必然制造悬念”的固定公式。

**时长分析关注另一件事：哪些经历被给予时间，哪些被迅速越过。** 故事中的一年与文本中的一页不能直接当成同一种时间单位。印刷文字首先具有长度，阅读速度也因人而异。因此，热奈特讨论叙事速度时，实际上以篇幅与故事时长建立近似关系。可以把它理解为“每一段文字推进多少故事时间”，不必假装能作精确的物理测量。[2]

| 基本运动 | 自拟表达 | 时间与篇幅的关系 |
| --- | --- | --- |
| 停顿（Pause） | 事件暂不推进，叙述转而长篇议论家族对沉默的理解 | 话语继续，故事时间暂时停住 |
| 场景（Scene） | 逐句呈现林岚与弟弟围绕信件的争论 | 事件过程相对充分展开，常以对话作为参照 |
| 概述（Summary） | “此后的十年，她只在春节回家。” | 较长的故事时间压缩进较短篇幅 |
| 省略（Ellipsis） | 从1998年直接跳到2008年，其间生活不予叙述 | 一段故事时间被跳过 |

场景中的“时长近似相等”是一种分析约定。读一段对话需要多久，与人物实际说话多久，不可能严格一致。省略则既可能显式标出，如“十年以后”，也可能只通过人物年龄、环境变化等线索使人推知。概述与省略的区别在于：前者仍告诉你这段时间里发生了什么，后者跳过这段经历。

描写也不自动等于停顿。“她沿着桌面摸索，指尖越过一道裂缝，终于碰到抽屉把手”，虽然写了物体细节，人物的行动与感知仍在持续。只有叙述的展开不再对应故事时间的推进，才适合判为停顿。如果一次几秒钟的犹豫被写得极长，则可以进一步讨论减速或延展（Stretch）；这一实用补充不必被冒充为原著四种基本运动中另一个并列的原始类别。

运用时长理论，不应只说“节奏快慢交替”。更有价值的是比较篇幅分配的差异：十年母女关系只用一段概述，拆信的三分钟却用了数页，这使旧日生活退居背景，发现真相的瞬间成为经验中心。不过，文字少也可能是在表现某种生活被压抑或无法言说，不能立即等同于“不重要”。需要考察被省略的部分是否在后文反复召回。

**频率分析把注意力从“一次经历写多长”转向“一次经历被写几次”。** 单次叙述（Singulative Narrative）通常是发生一次、讲述一次；发生三次而分别讲述三次，也属于这种逐次对应的方式。重复叙述（Repeating Narrative）是同一事件被叙述多次。迭述（Iterative Narrative）则用一次表述概括多次发生的同类事件，例如“每逢雷雨，母亲都会检查那只抽屉”。

区分这三类时，要先确定事件的计数单位。林岚在第一章拆信，弟弟在第四章重述她拆信的动作，是同一事件的重复叙述。若她每天都把信拆开再读，故事中本来就发生了多次阅读；分别叙述这些阅读，不是把同一次阅读讲了多遍。反复出现“信”这个意象，也不等于叙事频率上的重复。

迭述尤其适合表现惯例、持续的压力和生活模式。一句“整个夏天，她每天都写信，却从不寄出”，把许多天组织成共同的状态。若其中某一天被转为详细场景，就会从惯常生活中突出一个差异点。热奈特还讨论伪迭述（Pseudo-iterative）：文本表面上说“每个星期天都是这样”，却插入细节极其独特、似乎不可能原样重复的长对话。它可以使一个具体场面承担整段生活的代表性，而不必被简单斥为事实错误。[1]

顺序、时长和频率能够同时作用。父亲藏信的一个晚上，可以在二十二年后被回叙，以很长篇幅呈现，并被不同人物讲述三次。这里分别发生了时间位置的移动、叙事速度的减缓和叙述次数的增加。若只用“倒叙”概括，就会漏掉其余两种机制。

**语态分析把问题转向讲述者所处的位置。** 这里的叙述声音（Voice）首先关心发出叙述的实例及其关系，而不是声音洪亮、语气亲切这类日常意义。分析小说时，现实作者、叙述者和人物需要分别识别。现实作者可以设置一个自私、误解他人甚至蓄意撒谎的叙述者；人物或叙述者说出一句话，并不足以证明现实作者赞同它。

叙述层（Narrative Level）描述讲述行为在嵌套关系中的位置。外叙述层（Extradiegetic Level）是产生第一层故事的讲述位置；第一层故事世界本身是故事内层面的世界。当其中一个人物再讲出一段故事，他就以故事内叙述者（Intradiegetic Narrator）的身份实施讲述，其所讲内容构成次级／元故事叙事（Metadiegetic Narrative）。这里的meta-指嵌入层次，不应被自动理解为“反思叙事”。[3]

例如，某个版本直接以“2025年，我终于决定把发现旧信的经过告诉你”开篇，由林岚承担整部第一层故事的讲述。她的讲述处于外叙述层。若另一个版本先写记者在2025年拜访林岚，再由林岚向记者讲述2020年的事情，那么记者来访属于第一层故事，林岚的讲述行为属于内叙述层，她的回忆内容则是嵌入故事。两次讲述可以使用完全相同的话语，叙述层却不同，因为包围它们的结构变了。

“外叙述层”不等于现实世界，也不等于叙述者没有参与事件。林岚既可以是第一层故事的讲述者，又是被讲述事件的参与者。判断时应问：她的这次讲述，是否已经被另一个叙述当作故事中的事件来呈现？这比“她在故事里面还是外面”更精确。

同故事叙述（Homodiegetic Narration）与异故事叙述（Heterodiegetic Narration）描述另一组关系：叙述者是否作为人物参加自己正在讲述的故事。林岚讲述自己发现信的经过，是同故事叙述；一个从未参与这些事件的叙述者讲述她的经历，是异故事叙述。叙述者同时是主要主人公时，可进一步称为自叙故事叙述（Autodiegetic Narration）；见证者或配角讲述则不因此成为自叙。

| 讲述位置与参与关系 | 自拟情境 |
| --- | --- |
| 外叙述层—同故事 | 小说直接由林岚回顾自己发现旧信的经历 |
| 外叙述层—异故事 | 小说的基本叙述者不参与林家的故事 |
| 内叙述层—同故事 | 记者来访的故事中，林岚讲述自己当年的发现 |
| 内叙述层—异故事 | 记者来访的故事中，林岚讲述自己出生前、未曾参与的一段独立往事 |

这里需要说明分类的尺度。同故事叙述者可以在自己的长篇回忆里转述出生前的事情，不会因此使整部作品突然变成异故事叙述。只有明确了正在分析哪一段叙事、哪一个故事单位，分类才有意义。

语法人称与这种参与关系也不能等同。异故事叙述者可以插入“我必须提醒读者”而仍不参加所讲事件；同故事叙述者也可能以姓名或第三人称谈论过去的自己。人称保留其文体和修辞价值，但无法独自代替叙述者关系的分析。

叙述层的增加同样不能根据引号机械判断。人物说“把信给我”，通常只是被呈现的一次对话；人物开始讲述“那年夏天，我怎样发现父亲锁上抽屉”，才承担了嵌入讲述的功能。信件、梦境、回忆或心理片段是否形成独立层次，要看具体结构，不能因为排版改变、出现第一人称或涉及过去，就一律判为次级叙事。

嵌入故事还需要分析它对外层故事做了什么。它可以解释当下处境，形成与外层故事相似或相反的主题关系，也可以通过讲述行为本身改变外层行动。例如，林岚讲述母亲的过去，可能使弟弟放弃焚毁信件。此时，嵌入故事既传达信息，又作为一次劝说发挥作用。分析重点就从“这里有故事套故事”，推进到“讲故事怎样成为故事中的行动”。

**讲述的位置还包括它与事件之间的时间关系。** 后置叙述（Subsequent Narrating）发生在所讲事件之后，如2025年的林岚讲述2020年的发现。前置叙述（Prior Narrating）发生在所讲事件之前，如一个预言式声音叙述尚未发生的经历。同时叙述（Simultaneous Narrating）将讲述设置为与事件大体同步。插入式叙述（Interpolated Narrating）则由穿插在行动过程中的多次讲述构成，持续的日记和往返信件是常见情境。[4]

前置叙述与预叙尤其容易混淆。2025年的林岚叙述2020年的发现，期间提前交代2022年的争执，这是后置叙述中的预叙：对于叙述者而言，两件事都已经发生；对于文本当前推进到的2020年而言，2022年的争执仍在未来。前置叙述则要求讲述行为本身先于所讲事件。这两个判断比较的时间项不同。

语法上的现在时也不足以证明同时叙述。一个多年后回忆的人可以为了增强现场感，写“我推开门，屋里没有人”。应结合“如今”“当时”“后来才知道”等线索，判断讲述情境。日记中的单篇记录又往往是对当天事情的短距离后置叙述，而整组日记形成插入式结构；局部和整体可以有不同描述。

这一区分引出叙述之我（Narrating I）与经历之我（Experiencing I）。2020年的林岚可能相信父亲，2025年的林岚已经知道更多。句子“我那时还不知道，抽屉里藏着母亲未寄出的信”，把过去的无知放在现在的知识之下。若文本始终严格贴近当时的感知，后来的知识就暂时被压住；若不断穿插后来判断，回忆便带有解释、反省或自我辩护的色彩。第一人称提供的不是一个天然统一的认识中心，而可能是过去与现在两个自我之间的持续对话。

叙述还面向某个受述者（Narratee）。这指叙述在文本中设定或预设的接受位置，不等同于拿着书的现实读者。“弟弟，我知道你仍然相信父亲”把弟弟置于明确的受述位置；现实读者则是在旁听这次讲述。弟弟具有某些已有知识、情感和立场，林岚因此可能略过双方熟知的事情，也可能反复解释一件普通读者不觉得有争议的事。没有被点名的受述者，也可以通过解释的多少、称呼和预设知识被间接构造。[5]

受述者与故事世界中实际听到或读到叙述的人，还可能发生偏离。一封给弟弟的解释信被记者读到，预定接受者和实际接受者便不相同。运用这一点，可以分析信息为何失效、为什么出现误解，以及亲密表达怎样被重新当成公共证词。不要把所有“你”都认作现实读者，也不要将受述者与其他理论中的隐含读者直接合并。

叙述者的活动也不限于交代事件。热奈特区分叙事、组织、交流、见证和意识形态等功能：讲述发生了什么；提示文本接下来怎样展开；维系与受述者的联系；交代消息来源、记忆精确度或情感关系；对行为作出概括和判断。这些功能可以在一句话里重叠。例如“你大概不信，但那句话我至今记得清清楚楚”，既面向受述者，又对记忆作出担保。[1][4]

这种功能分析适合检验叙述权威怎样建立。“我亲眼看见”是一种权威声明，并非其内容必然真实的证明；“家家都有不能说的事”则可能把一个家庭的行为包装成普遍规律。分析时应分别记录事实陈述、证据声明与价值判断，再看后文是否支持或瓦解它们。

**语式分析关心，事件和人物的话语怎样成为我们能够接触的信息。** 热奈特在语式（Mood）之下讨论距离（Distance）与聚焦（Focalization）。前者侧重呈现的中介方式，后者侧重信息选择的范围。两者会互动，却不能互相代替。

距离最容易从言语呈现开始理解。比较下面四种写法：

| 写法 | 自拟文本 | 读者获得了什么 |
| --- | --- | --- |
| 叙述化话语（Narratized Discourse） | “她拒绝交出那封信。” | 言语行为被概括，具体措辞不可见 |
| 间接引语（Indirect Discourse） | “她说，她第二天不会把信交给他。” | 内容被转述，语法嵌入叙述者的表达 |
| 直接引语（Direct Discourse） | “‘我明天绝不会把信交给你。’她说。” | 人物话语以相对独立的形式出现 |
| 自由间接话语（Free Indirect Discourse） | “她明天绝不会把信交给他。凭什么？他以为自己是谁？” | 第三人称叙述中浮现人物的语气与判断 |

这些常用名称和自由间接话语的研究传统并非都由热奈特创立；他将相关问题纳入叙事距离分析。叙述化、转述和引述体现出不同程度的中介，但不构成严格的文学优劣等级。直接引语看似让人物自己说话，仍由整体叙事决定何时引用、引用多久、前后配上怎样的说明。虚构对话也没有一个必须真实存在的原始录音。因此，“展示”（Showing）与“讲述”（Telling）可以描述效果差异，却不宜被理解成一种完全无中介的再现与一种有中介的再现之间的绝对分界。[6][7]

自由间接话语尤其需要结合上下文判断。“凭什么”可能是人物的反应，也可能是叙述者的评论。中文缺少某些欧洲语言中显著的时态变换线索，更应观察用词、语气、指示中心，以及句子与前后意识活动的联系。没有引号的第一人称内心独白，并不会因此自动成为自由间接话语；自由直接话语（Free Direct Discourse）也是可能的形式。

自由间接话语的意义，不只在“深入内心”。它可以让叙述者的语法框架容纳人物的评价用语，使两种声音接近、混合，或形成讽刺性的距离。假如父亲心想“不过是一封没有寄出的信，有什么值得大惊小怪”，文本可能只是呈现他的自我辩护，而没有替他认证这种判断。必须继续观察词语是否与事实冲突、其他人物是否受到伤害、叙事是否留下反驳线索。

距离也不能和情感距离直接划等号。一句极其克制的概述，可能比长篇直接引语更令人难过；大量对话，也可能使人物显得空洞而疏远。形式上的中介程度、心理上的接近程度和伦理上的赞同程度，是三个需要分别论证的关系。

**聚焦则追问信息为什么限于这些内容，以及这些内容与谁的经验有关。** “谁在说”与“谁在看”是便于入门的区分，但“看”还包括知道、感觉、推测和评价。更精确的表述是：这段叙事依照什么信息规范运作？人物的认识范围怎样参与限制它？[8]

零聚焦（Zero Focalization）指叙事不受某个特定人物的认知范围持续约束。它可以同时交代各方互不知晓的事情、历史背景或未来结果。内部聚焦（Internal Focalization）则使信息与某个人物的经验范围保持对应。外部聚焦（External Focalization）主要呈现行动、言语等外部迹象，保留人物内部知识和意识。所谓“叙述者知道得更多、同样多或更少”，应理解为叙事提供的信息关系；不能据此替一个没有被具体塑造的叙述者编造心理档案。

比较三个版本：

> 林岚拿起信。她以为父亲从未读过，却不知道他二十二年前已经将它藏起；住在城另一端的弟弟，此时也正隐瞒着一件与母亲有关的事。

> 林岚拿起信。封口的折痕太旧了。父亲读过吗？她记得他总说，这个家从来没有秘密。

> 林岚拿起信，翻到背面，停了片刻。她没有拆开，只把它放进外套口袋。

第一个版本自由进入分属不同人物的信息范围，体现零聚焦的组织可能。第二个版本贴近林岚的感知、记忆和疑问，是内部聚焦。第三个版本暂时不给出她的思想，可以作为外部聚焦的局部示例。不过，仅凭一个短段落没有写心理，不能据此判定全篇实行外部聚焦；需要观察更大范围中是否形成稳定限制。

内部聚焦还分为固定、变换与多重三种组织方式。固定内部聚焦（Fixed Internal Focalization）持续以同一人物为主要经验中心。变换内部聚焦（Variable Internal Focalization）在不同部分依次转移到不同人物。多重内部聚焦（Multiple Internal Focalization）则从不同人物的位置反复呈现同一事件。小说第一章跟随林岚发现旧信，第二章跟随弟弟在另一个城市生活，属于变换；两章各自重述同一次家庭争吵，才构成多重聚焦的典型情形。

因此，**能够进入多个人物的内心，并不足以单独证明零聚焦。** 如果每个章节都严格受其当前聚焦人物的经验限制，整体可能采用变换内部聚焦。反过来，零聚焦也不必每段都无所不知；某些部分可以暂时停留在一个人物身边。分析要同时描述局部规范与全篇组织，不应为追求单一标签而抹去变化。

热奈特还用信息增越（Paralepsis）和信息缺略（Paralipsis）讨论对既定聚焦规范的偏离。前者提供超出原有限制的信息，后者省去按照既定规范本应能够呈现的重要信息。假设小说一直贴近林岚的当下经验，却突然不经来源说明而确认弟弟独处时的秘密思想，可以考察是否发生增越。假设小说始终详细呈现她在争执中的思想，却直到结尾才揭示她当时明知信是伪造的，则可以考察是否发生缺略。[8]

这种判断必须以作品已建立的规范为依据。内部聚焦并不承诺报告人物每秒钟的全部意识；暂未告诉读者某件事，也不自动构成缺略。稳定地转移到另一个人物，更可能是聚焦模式的变化，不能一概叫作“违规”。这些术语首先用于描述差异，而不预先裁定写作失误。

聚焦与不可靠叙述（Unreliable Narration）也有交叉，却不相同。一个人不知道父亲藏过信，属于认识限制；一个叙述者反复声称“母亲从无离开的念头”，而文本持续提供相反证据，才需要讨论其陈述或判断是否不可靠。此概念主要关联韦恩·布斯（Wayne C. Booth）及后续修辞叙事学的发展，不能全算成热奈特的原创理论。可靠性又可以在事实报告、解释和价值判断上分别表现：事件可能讲对了，原因却解释错了；事情可能没有隐瞒，对伤害的评价却值得怀疑。[9]

如果第三人称叙述紧贴父亲的意识，呈现他对妻子的轻蔑，也应先判断轻蔑属于谁的声音。人物的偏见与叙述者的失实是不同命题。读者能够接近一个人的意识，不意味着作品要求读者赞同这个人。

**各个维度只有重新组合起来，才构成有解释力的分析。** 比如，一个回忆体版本可以同时是外叙述层、同故事、后置叙述，并主要限制在过去林岚的内部经验中；另一个版本则可以是外叙述层、异故事、以现在时呈现，并采用相同的内部聚焦。两者都可能让读者暂时不知道藏信的真相，但第一种形式额外引入了“如今的她为什么这样回忆”的问题。

这也说明传统的第一人称、第三人称、限知、全知等说法不会简单失效。它们有表达上的便利，但常把不同维度打包。热奈特的贡献在于允许我们拆开检验：同样是第三人称，两段文本可能具有不同的信息限制；同样是第一人称，一段可能严守当时经验，另一段却不断提前揭示后来结果。

**叙事越界研究的，则是上述层次的边界怎样被突破。** 叙事越界（Narrative Metalepsis）在这里不是人物违背伦理规范，而是讲述的世界与被讲述的世界、外层故事与嵌入故事之间发生了不符合通常层级关系的侵入。[10]

设想林岚读母亲的日记，日记记载1998年的一场雨。这是正常的嵌入关系。如果她听见日记中的母亲说：“正在读这页纸的林岚，别再往下翻”，而文本进一步让1998年的母亲直接回应2020年林岚的动作，就可能形成越界。被讲述世界中的人物似乎能够认识并干预外层阅读活动。

这与现实作者通过创作决定人物命运不同。现实写作本来就创造虚构人物；只有作品把这种跨层的干预戏剧化，造成层级短路，才构成这里要分析的现象。小说中出现名叫“作者”的人物，也不够：这个人物可能只是故事里另一个普通角色。必须证明他跨越了原来区分讲述者与被讲述者的边界。

同样，一部小说讨论写作，是元小说（Metafiction）的常见方式，却未必发生叙事越界。嵌入故事与外层故事互相映照，可以构成镜像式结构，也未必跨层。角色“看向镜头”或向读者说话是否属于越界，要结合媒介和作品建立的接受位置判断，不能把所有自我指涉都收进一个标签。

越界可以产生喜剧，也可以产生不安。旧日母亲能反过来读懂女儿的阅读，会破坏“过去已经结束、记录只是记录”的安全感。形式识别之后，还要追问：究竟哪条边界被打破，谁因此取得原本没有的行动能力，作品是否维持这种不可能性，还是最后给出普通解释。

**当我们追问一部作品如何依靠其他文本而成立，研究就进入跨文本关系。** 跨文本性（Transtextuality）是热奈特用来统摄文本与其他文本之间多种关系的概念。《隐迹稿本》（Palimpsestes）区分五种主要关系，随后尤其深入研究改写与模仿。它们是可以交叉的关系类型，并非一部作品只能选择一个的归类箱。[11]

| 关系 | 判定重心 | 用旧信故事说明 |
| --- | --- | --- |
| 互文性（Intertextuality） | 另一文本在此文本中的共现，如引文、典故或可识别的暗示 | 母亲的信引用一首既有诗歌 |
| 副文本性（Paratextuality） | 标题、署名、序言等怎样呈现正文 | 封面题为《一个母亲的真实出走》 |
| 元文本性（Metatextuality） | 一个文本对另一个文本的评论关系 | 一篇评论分析母亲书信中的自我辩护 |
| 超文本性（Hypertextuality） | 后来文本对先前文本的转换或模仿 | 新小说系统重写一部既有出走故事 |
| 类属文本性（Architextuality） | 文本与体裁、话语类型和表达模式等一般类别的关系 | 小说借用书信体、家族小说或侦探小说的惯例 |

“类属文本性”有时译成“原型文本性”，但这里的architext不等于某一部作为原型的旧作品，也不是荣格意义上的原型。为了避免把具体底本与一般类型混淆，本文采用“类属文本性”。同样，超文本性在这里不是网页超链接技术；元文本性也不是“小说反思自身写作”的元小说概念。

互文性的判定需要可核查的关联，而不能止于“让我想起另一部作品”。两部小说都有一封信，可能只是共享常见母题；出现独特的措辞、情节配置或文化上足够明确的暗示，才有更扎实的关联证据。暗示不必完整引述原句，但需要说明识别依据。热奈特的这一用法比克里斯蒂娃（Julia Kristeva）传统中较广义的互文性狭窄，使用术语时应说明所采用的范围。

元文本性关注评论，而不要求被评论文本一定被完整引用。评论可以公开讨论前作，也可以通过明显的批判关系与它相连。一篇书评若引用小说原句，又解释其偏见，就同时具有互文关系和元文本关系。它们描述的不是两个互斥身份，而是同一文本间联系的不同方面。

**超文本分析最有价值的步骤，是说明后作究竟对前作做了什么。** 被转换或模仿的先前文本称为底本（Hypotext），由此派生的后作称为超文本／派生文本（Hypertext）。其中，转换（Transformation）直接作用于既有文本的材料或结构；模仿（Imitation）则从某种风格、写法中提取模式，再据此产生新的表达。

把旧作“女儿出走”的情节改成“母亲出走”，保留主要关系，却调整人物身份和结局，是转换的例子。另写一个与旧作情节无关的故事，但持续模仿其句式、叙述口吻和修辞习惯，则是模仿的例子。换言之，前者要问“这一个故事怎样被改造”，后者要问“这套写法怎样被再生产”。实际作品可以兼有两者。

热奈特进一步把这一区分与游戏性、讽刺性、严肃性等功能倾向交叉，形成六种基本位置。[11]

| 对前作的操作 | 游戏性（Playful） | 讽刺性（Satirical） | 严肃性（Serious） |
| --- | --- | --- | --- |
| 转换 | 戏仿（Parody / Parodie） | 滑稽改写（Travesty / Travestissement） | 严肃转换（Transposition） |
| 模仿 | 风格仿作（Pastiche） | 讽刺性仿作（Caricature / Charge） | 严肃仿作（Forgery / Forgerie） |

可以把它们理解为两条判断轴线的交叉，而不是六种天然分明的作品物种。把庄严故事的具体措辞或情境作游戏性变动，与以夸张方式模仿某人的写作习惯，就处在不同位置；严肃地改写旧故事，与依照某种古老风格续写新故事，也不相同。这里的forgerie不能不加区分地当成现实中的欺诈行为，它涵盖以严肃方式延续既有文学写作的拟作实践。具体文本的功能倾向又可以混合或变动。

因此，不能把所有“parody”都理解成有意嘲笑前作，或把所有“pastiche”都理解成简单拼贴：它们在这一分类中有比日常批评用语更特定的位置。实际分析仍应先明确转换还是模仿、主要处理了什么、产生何种态度，再决定更细的名称。

可实际检查的变化包括：篇幅的删减或扩展，诗体与散文等形式的转换，叙述与戏剧呈现之间的转换，故事时空与人物身份的迁移，以及动机和价值评价的改变。后一组尤其重要：原作把母亲的离开归为自私，改写可能保留她离开的行动，却增补其长期承受的压迫，使同一行为得到不同解释。这时变化的不只是结局，而是行动何以成立、谁有资格评价它。

一种有效的比较写法是：“后作保留了前作的X，改变了Y，因此原先建立在Z之上的判断受到动摇。”例如，保留母亲出走，却把叙述中心从丈夫转向女儿，并逐步提供母亲的书信，就可能改变读者能够接近的证据和声音。这个推论仍须通过两部作品的具体对照来验证，不能仅靠“女性视角”四字完成。

**类属文本性则把具体作品放回一般形式的历史。** 《类属文本导论》（Introduction à l’architexte）追问文学分类的来历，并区分表达模式与历史形成的体裁。抒情、史诗、戏剧的三分法不能简单当作亚里士多德已经完整制定的永恒分类。某些今天看来理所当然的类别，是后世逐步整理出来的。[12]

这一点影响实际阅读。把《未寄出的信》当作侦探小说，读者容易追问谁藏了信、证据是否公平、结尾是否解释谜团；把它当作家族小说，读者可能更关注代际记忆与关系延续。文本可以同时调动这些期待，并使它们发生冲突。它也可能借用调查结构，却让关键真相永远无法确认，从而使“追索”本身成为主题。

因此，体裁分析不能止于列出“这是一部书信体心理小说”。需要说清它调用了哪些惯例，这些惯例使人期待什么，作品在哪些地方满足、混合或改变了期待。封面上的“长篇小说”是一个副文本标识；作品与小说这一类别之间的关系才是类属文本关系。标识与实际形式可以吻合，也可以发生张力。

**副文本理论说明，进入正文之前，阅读已经受到组织。** 副文本（Paratext）包括围绕文本、使其被呈现和接受的材料。内副文本（Peritext）与正文处于同一出版物，如标题、作者署名、封面、题词、序言和注释；外副文本（Epitext）则在书外流通，例如与作品有关的作者访谈或出版宣传。同一访谈后来被收入新版附录，它的空间位置与功能也会改变。[13]

副文本不是无关紧要的装饰，也不一定提供正文的最终解释。《未寄出的信》将注意力引向信息没有抵达；《母亲的秘密》容易强化隐瞒；《她为什么留下》则预先把留下变成需要解释的问题。即使正文完全相同，三个标题也可能引导不同的提问。这是副文本分析的一种可操作办法：设想替换标题，检验哪些期待随之改变，再回到实际版本提供证据。

研究副文本时，可以追踪五个方面：它位于哪里，何时出现，由谁负责，面向谁，以及试图产生什么作用。作者初版序言、出版社后来添加的腰封、译者的说明，不能被当成同一个发言者的声音。某篇独立评论也不因为在书外谈论作品，就自动成为外副文本；在热奈特的原始框架中，应尤其注意它与作者、出版及作品呈现机制的联系。若评论中的一句赞语被出版社摘到封底，那一摘录便取得了新的副文本功能。

副文本还会改变我们怎样理解“事实”。假设封面标注“小说”，而前言声称材料来自一箱真实书信；它可能让作品在虚构契约和见证效果之间摆动。分析者需要记录这种摆动，不能自行替作品消除它。版本也是证据的一部分：若两个版本的序言不同，就不能把某一版产生的阅读预设说成作品始终不变的性质。

**在叙事结构之外，热奈特还持续追问语言的形式怎样进入文学经验。** 早期修辞研究提醒我们，不宜把修辞学（Rhetoric）逐渐收缩成辞格学，再把辞格缩成隐喻研究。《受限的修辞学》（La rhétorique restreinte）所诊断的，正是研究范围不断变窄的问题。[14]

这一提醒可以用于纠正一种常见阅读习惯：发现“抽屉像一张闭紧的嘴”，便认出比喻，接着宣称完成了语言分析。实际上，同一段文字的词序、句长、停顿、重复、语体、论证方式和接受对象，也都可能决定表达如何起作用。辞格是可分析的一个方面，并不穷尽语言形式。

早期关于逼真性（Verisimilitude / Vraisemblance）与动机化（Motivation）的研究，还揭示了“令人相信”与“确实发生”之间的差别。某种行为即使历史上真实发生，也可能违背一个时代对身份、性别和体面的期待，而被批评为不合情理。“她不可能这样做”有时是在表达经验判断，有时却将“她不应该这样做”伪装成经验判断。[15]

动机化则可以帮助考察，作品如何赋予行动或构造一种看似自然的理由。父亲藏信可以被解释为嫉妒、恐惧失去家人或维护名誉；这些解释既在故事中建立因果，也影响读者能否接受情节。分析应区分人物自己给出的理由、叙述者提供的理由，以及为了使情节成立而设置的条件。三者可能一致，也可能互相拆穿。

在我们的例子中，若叙述不断重复“一个母亲怎么会愿意离开孩子”，就值得追问：这句话是否把社会规范当成了心理事实？倘若母亲的书信提供了不同经验，作品就可能使原先被视为“不可能”的行动重新变得可理解。这是形式分析与性别、伦理或社会批评建立联系的一个入口，但具体历史规范仍需另行考证。

《拟仿论》（Mimologiques）处理另一条常被叙事学概览遗漏的线索：人为什么希望语言的声音、形状或结构能够像它所指的事物？这一问题可追溯到柏拉图《克拉底鲁篇》（Cratylus）中名称与事物的关系。热奈特追踪关于语言拟仿的各种思想和文学想象，而不是简单主张所有词语天然模仿对象。[16]

设想一个段落用连续短句描写拆信：“她停住。伸手。又缩回去。”分析时可以讨论断裂的句法怎样与犹豫的动作形成可感的对应。但这与宣称“短句在任何语言中都天然代表恐惧”不同。前者立足于具体文本建立的关系，后者将局部效果变成了未经证明的普遍定律。对于拟声、音韵、字形和句法象似性的分析，同样应区分作品制造的感受、文化约定和关于语言起源的强断言。

文体（Style）在后期研究中又与语言的例示功能（Exemplification）相联系。语言不仅指称某件事情，也能呈现并让人注意它自身具有的性质。这一思路受纳尔逊·古德曼（Nelson Goodman）的符号理论启发。[17]

“她终于知道父亲藏过那封信”与“信是父亲藏的。一直都是”，可以指向相近的信息，后一种表达却通过停顿、重复和补充，呈现认识突然凝固的过程。这里不能只罗列“用了短句”，而应解释短句与前文的速度、人物的意识及信息揭示的位置怎样共同作用。例示也不等于语言只要具有某种性质，就必然把它突出为审美对象；需要看具体阅读关系中哪些性质被选择并变得显著。

这使“平淡”不再等于“没有文体”。省去修饰、持续使用简短陈述，依然是可以描述的表达方式。也不能先确定内容完全不变，再把文体当成随意更换的包装：语气、节奏、语体和指示方式本身可能改变判断的力度、责任的归属及人物的形象。文体分析应说明表达所做的事情，而不仅是为表达贴上“优美”“冷峻”的形容词。

**从表达形式继续向前，就会遇到什么使文本成为文学的问题。** 《虚构与措辞》（Fiction et diction）中的diction，不宜只理解成挑选了哪些词；它涉及文本作为语言形式的性质及其审美可感性。这里必须区分三个命题：“这是虚构”“这属于文学”“这是优秀文学”。三者不能互相替代。

虚构（Fiction）涉及文本怎样设置想象的对象与情境；措辞／语言形式（Diction）涉及表达自身怎样成为注意和欣赏的对象。与此同时，构成性文学性（Constitutive Literariness）与条件性文学性（Conditional Literariness）区分文学身份如何成立。前者指在所讨论的文学惯例中，文本凭其类型与性质而取得文学身份；后者则依赖某种审美接受，一个本来承担其他用途的文本，也可能被当作文学阅读。[17]

| 文学性来源与成立方式 | 典型情形 | 需要保留的区别 |
| --- | --- | --- |
| 虚构性作为构成性来源 | 虚构叙事进入文学范围 | 写得差的小说仍可能是小说 |
| 语言形式作为构成性来源 | 诗歌依其形式和文学惯例取得身份 | 属于诗歌不等于具有很高价值 |
| 语言形式作为条件性来源 | 书信、历史叙述、随笔等因表达而被审美地接受 | 文学性可以随阅读方式与历史处境而变化 |

这是一种关于文学性来源与制度化认识的理论区分，并非不受争议的、适用于一切文化的自然定义。“构成性”也不表示某部作品在历史之外永远具有同一身份。更不能把所有想象、错误或谎言都叫作构成性的文学；虚构话语的交际情境需要单独辨认。

在旧信的例子中，母亲原本写信是为了表达离开的决定，它具有具体的交际用途。多年后，女儿注意到信中反复出现的停顿、克制的称呼和欲言又止的句子，可能开始把它作为值得反复阅读的语言作品来对待。它并未因为这次阅读而失去书信身份，却获得了审美接受的可能。这说明条件性文学性不是给非文学文本发放一个永恒等级证书，而是描述一种成立条件。

虚构性与真实性的关系，也不能靠“有没有写实细节”判断。“1998年夏天，一位母亲准备离家”既可以出现在小说中，也可以出现在调查报道中。作为事实叙述，它通常承担关于现实事件的真实性承诺；作为虚构，它邀请接受者在一个被设定的情境中理解人物与事件。小说使用真实城市，不使它自动变成报道；报道用了回叙、对话和细节，也不使它自动变成小说。[18]

热奈特关于虚构行为的研究，进入了言语行为理论（Speech Act Theory）的范围：看似断言事件发生的句子，在虚构交际中可以同时执行建构并提出一个想象世界的活动。因此，虚构不宜被简单定义为欺骗性的陈述。谎言试图让人把某个不实断言当成事实；通常的虚构交际则不以掩盖其虚构身份为成立条件。当然，伪造回忆录、假文献和混合写作会使边界复杂化，必须考察具体出版承诺与文本策略。[17][18]

叙事形式提供线索，却很少独自决定虚构身份。无来源地进入许多人物的意识，常与虚构叙事的惯例相容；事实叙述若作同类陈述，则需要特别解释其依据。但不能把“使用第三人称”或“存在内部聚焦”当成虚构的充分条件。历史研究和传记也会根据书信、访谈等材料重建思想，只是它们的证据义务不同。

作者与叙述者的关系在这里也发生变化。小说中的叙述者通常不能与现实作者直接等同；事实性自传则可以承诺两者身份相同，作者为叙述承担相应责任。热奈特把这一关系纳入虚构与事实叙述的讨论，但它更适合作为分析轴线，不能脱离匿名、编辑、代笔和虚构自传等复杂情境，变成一眼判别所有文本的公式。

**艺术本体论提出的问题更进一步：我们究竟把什么叫作同一部作品？** 一册书被烧毁，通常不意味着那部小说消失；一幅独一的画作被毁，其损失却不能简单通过重新印一张解决。艺术本体论（Ontology of Art）考察这类存在与同一性问题，而不是首先判断哪件作品更好。

《艺术作品》第一卷以内在性（Immanence）与超越性（Transcendence）组织讨论。这里的内在性涉及作品具体以何种对象或结构成立；超越性涉及作品怎样超出它与某一内在对象之间的简单一一对应。这不是“内在思想”与“超越现实精神”的对立，也不能简化为“实体”与“感受”。[19]

热奈特继承并调整古德曼关于自笔性／原作性（Autographic）与他笔性／记谱性（Allographic）的区分。在典型绘画中，制作历史与具体物件的真实性关系到作品身份，外观极其相似的复制品并不因此成为原作。在典型文学文本中，符合其语言构成的不同印本可以承载同一文本；一本由他人排印的书，不会仅因不是作家亲手写成，就成为文本意义上的赝品。

这一区分不是“只有一件”与“可以有很多件”的简单对照。版画等艺术可以有多个经认可的原始印本，仍涉及自笔性制度；文学作品也可能留下独一的手稿，但手稿这一物件的收藏身份，不等于文学文本的全部身份。应问的是哪些性质对作品的识别具有构成作用，哪些只属于某一次呈现。

用旧信故事举例：同一段文字印在两本不同颜色封面的书里，可以仍是同一个文本；把结尾改成“母亲其实寄出了信”，则不只是更换纸张。若更换字体改变了诗歌的视觉结构，又不能想当然地把字体视为不重要的外观。构成性与偶然性需要依据作品和媒介的具体规范判断。

“超越性”处理的，是这种同一性关系中的进一步复杂性。一部作品可以有彼此不同的版本；我们也可能只接触它的片段、复制或间接呈现；同一构成又可能在不同历史情境中取得不同的作品功能。对文学来说，这意味着文本、具体印本、修订状态和作品整体需要分别说明。原作与译本是否被视为同一作品的不同呈现，或具有相对独立身份，不能靠一句“意思一样”解决。[19]

这一理论的实际价值，在版本研究中尤其明显。比较删节本、初刊本、作者修订本和译本时，首先要说明比较的是文本差异、物质呈现差异，还是读者将这些材料归为同一作品的方式。两个印本的排版不同，与两个版本删改了人物动机，是不同层次的变化。若将某个译本的语气当作原作语言的固有性质，也会混淆作品身份与具体呈现。

**审美关系则把作品的存在问题，转向我们怎样注意和评价它。** 《艺术作品》第二卷《审美关系》（La relation esthétique）研究的不是一张可机械使用的“艺术质量评分表”。审美注意（Aesthetic Attention）关注对象如何显现、怎样组织并被经验；在文学中，所注意的性质可以包括声音、节奏、句法、意义和结构，而不局限于视觉外表。对象也不必先具有艺术身份：一段普通书信，甚至自然景物，都可能成为审美注意的对象。[20]

读母亲的信，首先可以是寻找她是否买过车票；也可以是关注她怎样始终不直接说出“我要离开”。前者主要追踪事实信息，后者使表达方式本身成为注意中心。两种活动可以同时发生，并不要求人先丢掉事实问题，才能进入审美关系。

在艺术作品的接受中，意识到对象是以某种艺术意图被制作或呈现的，以及理解它所处的历史与体裁关系，也会影响评价。这里的“意图”不是要求读者先知道作者脑中的所有计划，更不意味着作者对作品意义拥有最终裁决权。它首先涉及我们为何把对象当作值得以艺术方式理解的对象。

热奈特强调审美评价的主体依赖性。觉得一个结尾动人，涉及某个人在某种处境中的感受；它不是像页数一样可以直接测定的属性。但主观并不等于论证没有意义。批评可以让别人注意以前忽略的重复、结构或语气，纠正事实误读，改变作品被经验的方式，却不能保证所有人在获得同样信息后必然产生同样的愉悦。

例如，“这个结尾令人窒息”是一种评价；“最后五句连续撤去人物可以采取的行动，最后只剩无法寄出的信”则提供可检查的形式依据。后者使评价能够被讨论。另一个人可以承认这个结构，却觉得它过度设计。双方的分歧不必都归结为一方没有读懂，也不能因为审美依赖主体，就把对文本的任何错误陈述都免于检验。

**现在可以把这些工具放进一次完整的阅读。** 以下片段仍为自拟，它的作用是示范怎样从证据逐步形成论点：

> 弟弟，直到2025年的今天，我仍不敢说自己终于懂了母亲。父亲去世那晚，我才打开那只抽屉。此后二十二个月，我每天都把信摊在桌上，却一次也没有给你看。
>
> 你还记得1998年的夏天吗？母亲每逢下雨就坐在门边，等水从屋檐落尽。我当时只觉得她怕冷。直到2020年读到信，我才知道她曾准备在那个夏天离开。
>
> 我拆开信。她竟然要走？把我们留在这里？纸上只有一行字让我反复看了许久：“明天我会离开。至于为什么留下过这么多年，我现在还说不清。”
>
> 我把信折回原样。那时我并不知道，两年后你会说，真正隐瞒了这件事的人是我。

先确定讲述情境。文本开头给出2025年的叙述行为时间，明确向弟弟说话；“父亲去世那晚”与2020年相联系。讲述发生在事件之后，是后置叙述。若这就是小说的基本开篇，且没有更外层框架，讲述者属于外叙述层；她参加拆信与隐瞒的事件，是同故事叙述。是否进一步称为自叙故事叙述，需要看全篇的主要行动究竟围绕女儿，还是围绕经由女儿讲述的母亲，不能仅凭第一人称决定。

再整理事件与话语的顺序。片段从2025年的反思转入2020年的发现，又越过一段时间概述反复读信，随后返回1998年，最后重新呈现2020年拆信，并提前涉及2022年的冲突。这说明回叙和预叙可以嵌入同一段后置讲述。母亲信中的“明天我会离开”则首先是一项当时的计划或宣告，片段本身没有证明她后来真的离开，不能把它直接计入已实现的未来事件。

频率和时长共同区分了两种经验。“此后二十二个月，我每天都把信摊在桌上”是迭述，并以概述压缩较长时段；“我拆开信”之后则转入一个较充分展开的具体场面。重复阅读使发现旧信不再只是单次震惊，而成为持续的隐瞒行为。句中的“却一次也没有给你看”又把日常习惯与弟弟的受述位置联系起来：眼前这次讲述，正在补偿一种拖延已久的交流。

聚焦需要区分时间中的两个自我。“我当时只觉得她怕冷”保留过去的误解，“直到2020年……才知道”则从后来的知识重释过去。“她竟然要走？把我们留在这里？”直接浮现当时的情绪性内言，更适合讨论为自由直接的意识呈现，而不能因为没有“我想”就判为自由间接话语。此处没有出现第一人称思想被转入第三人称语法框架的明显结构。

母亲的信以直接引语出现，暂时使她的表达进入女儿控制的叙述。但引文仍经女儿选择；“只有一行字让我反复看了许久”提醒我们，她没有提供信的全部内容。不能由这一点立即断定她蓄意歪曲，却可以据此提出问题：她为什么选出这一行？它支持了怎样的母亲形象？是否存在被略去的理由？此外，这一句主要是未来决定与自我说明，未展开一个相对独立的往事叙述，因而仅凭信件被引用，还不足以宣布这里已经构成完整的次级故事。

到这里，可以形成一个有证据的论点：片段通过成年叙述者对过去经验的回溯、长期读信的迭述和明确面向弟弟的解释，将发现真相逐步转化为对自身隐瞒的审视。母亲起初是被怀疑“要抛下孩子”的人，女儿随后也进入了信息控制者的位置。这个解释来自时间、频率、受述关系和话语选择的共同作用，而不是来自任何一个术语的固定含义。

进一步的判断仍需谨慎。结尾提前出现弟弟的指责，不证明指责必然公正；女儿有所隐瞒，也不自动证明她与父亲出于相同动机。全文若交代弟弟当时病重，或母亲要求保密，就会改变伦理评价。好的解释需要说明自己依赖哪些证据，也说明什么新证据会促使它被修正。

如果再给这个片段加上《母亲的秘密》这一标题，可以提出一个副文本假设：标题先把秘密归给母亲，而正文逐步让父女都成为隐瞒者，阅读由此修正最初的归责。但在没有看到既有底本的情况下，不能凭家庭题材就补出超文本关系；在没有不同版本的情况下，也不必硬套作品同一性研究。系统掌握理论，意味着能够选择与问题相关的工具，而不是强迫每篇分析用遍全部概念。

**把方法迁移到其他小说，可以从一个具体的阅读困难开始。** 例如：“为什么我很了解这个人物的想法，却越来越不信任他的解释？”这个问题可能要求同时分析内部聚焦、自由间接话语和不可靠判断。“为什么母亲的经历只出现几页，却决定了全书？”则可能要求分析省略、补充性回叙及篇幅与因果重要性的错位。研究问题决定工具选择；术语的数量不决定分析深度。

一个可反复使用的工作次序是：

1. **确定材料与范围。** 记录版本、译本、章节和所分析的具体段落；保留引文的位置。
2. **重建必要的故事关系。** 只整理与问题有关的事件；将确定事实、人物说法和未决处分别标记。
3. **定位形式安排。** 指出顺序、时长、频率、声音或聚焦等方面的可观察证据。
4. **解释局部机制。** 说明安排怎样分配信息、时间、发言机会或判断权威。
5. **联系较大的意义。** 检查这一机制是否在其他段落重复、变化或受到反驳，再讨论主题和价值。
6. **检验替代解释。** 设想换一种写法会改变什么，并检查原论点是否把相关性误当成必然性。

改写实验尤其有帮助。把一个内部聚焦段落改为零聚焦，如果人物误解随即被提前解释，就能观察原来的信息限制承担了什么作用；把反复拆信的迭述改成三次各不相同的场景，可以比较“生活模式”与“逐次变化”怎样形成。实验不是用自己写得更差的版本证明原作伟大，而是使形式选择的后果更容易辨认。

还有几条边界需要始终保留。叙述者并不因第三人称而自动可靠；聚焦人物并不因获得篇幅而必然受到赞同；作品也不因混合多种手法而必然复杂或优秀。热奈特式分析首先提供描述的精度，文学价值还需要具体论证。其基本模型又主要从文学叙事、尤其是小说中发展出来；转用于电影、游戏、戏剧或口述时，应检验镜头、表演、声音和交互分别承担了哪些功能，不宜把印刷文本的范畴原样搬过去。

这套方法也有自己的限度。性别权力如何形成、某种行为在特定历史条件下为何被认可、读者实际上产生何种情绪，都不能仅凭形式分类得到完整答案。可以从信息分配发现谁长期无法直接发言，再结合相应历史与社会研究解释其意义。后续叙事学对聚焦、叙述者是否必然存在、非自然叙事等问题也提出了修订，因此热奈特应被学成一套能讨论、能校正的理论，而不是一套禁止作品超出的规则。

**可以用下面几道问题检查自己是否真正分清了这些关系。** 先自行判断，再看随后给出的解释。

| 情境 | 需要判断的问题 |
| --- | --- |
| 第三人称小说，每一章严格跟随一个不同人物 | 是否因为进入多人内心，就属于零聚焦？ |
| 2025年回忆2020年时，提前讲到2022年发生的争吵 | 是前置叙述，还是后置叙述中的预叙？ |
| 主人公回想童年，但没有承担另一段独立讲述 | 是否必然增加叙述层？ |
| 相同争吵由三个人各讲一次 | 频率与聚焦可以怎样分别描述？ |
| 人物被大段直接引述，却在上下文中不断暴露偏见 | 直接引语是否意味着作品认可其话语？ |
| 书外访谈后来被编入新版附录 | 副文本的哪一种关系发生了改变？ |
| 同一小说换了纸张，另一版本却改了结局 | 这两种变化是否属于相同层次？ |

第一种情境通常应先考虑变换内部聚焦，再检查是否存在突破各章限制的信息。第二种是后置叙述中的预叙，因为讲述者在2025年时，两次事件都已经发生。第三种不必然增加叙述层，回忆首先涉及时间和意识，只有具体结构建立了新的讲述关系，才进一步讨论层次。第四种在频率上是重复叙述；若每次都围绕相应人物的经验呈现同一争吵，则同时具有多重内部聚焦。第五种不意味着认可，引文的框架仍可产生反讽。第六种是外副文本被收入内副文本，同时其读者与持久性可能改变。第七种需要区分具体呈现与文本构成；改变结局通常比更换普通纸张更直接触及作品的文本身份。

接下来读原著，可以用问题来组织次序。先读《叙事话语》，把时间、语式和语态连接起来；随后读《新叙事话语》（Nouveau Discours du récit），观察概念如何在批评中被澄清和调整。研究改写与体裁时转向《隐迹稿本》和《类属文本导论》，研究出版与接受入口时读《门槛》（Seuils）。若问题转为“这种语言为什么成为审美对象”，再进入《虚构与措辞》《拟仿论》和《艺术作品》两卷。每次阅读都可以带上一小段小说作检验材料，使理论定义与文本判断保持往返。

写出分析时，可以尝试把一句话补完整：“这段文本通过……的形式安排，使……信息／经验以……方式出现，因此在这里改变了……；这一解释由……支持，但仍需考虑……。”其中最难、也最有学习价值的部分，是把“因此”前后的关系说明白。只要这个关系能够被文本检查、被其他读者质疑并据证据修正，术语就已经转化成了研究能力。
