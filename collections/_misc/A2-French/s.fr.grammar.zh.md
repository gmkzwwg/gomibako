## 0. 法语语法总览（Vue d'ensemble）

法语语法的核心不是把每条规则孤立背下来，而是理解几个系统怎样同时工作：**名词有性数，限定词和形容词要配合；动词要按人称、时态和语式变位；代词位置高度固定；从句常常决定语式；介词和搭配不能逐词翻译**。本章是全书地图，用来建立查表顺序和判断框架。

### 0.1 法语语法地图

| 层级 | 研究对象 | 关键问题 | 对应章节 |
| ---- | -------- | -------- | -------- |
| 书写和发音接口 | accent, élision, liaison, h muet | 拼写、连音、省音是否影响语法形式 | 1 |
| 词类和成分 | nom, verbe, adjectif, pronom, COD, COI | 一个词或短语在句中做什么 | 2, 3 |
| 名词系统 | genre, nombre, groupe nominal | 名词是阳性还是阴性，单数还是复数 | 4 |
| 限定系统 | articles, déterminants, quantificateurs | 名词前用 le, un, du, ce, mon 还是 de | 5, 6 |
| 修饰系统 | adjectifs, adverbes, compléments | 形容词/副词放哪里，是否配合 | 7, 8, 9 |
| 代词系统 | pronoms personnels, y, en, relatifs | 代词替代什么，放在什么位置 | 10, 11, 12 |
| 动词系统 | conjugaison, temps, modes, voix | 动词如何变位，用什么时态和语式 | 13-18 |
| 否定疑问强调 | négation, interrogation, mise en relief | 句子如何否定、提问、强调 | 19, 20 |
| 介词和搭配 | prépositions, régimes | 为什么是 à/de/en/pour，动词要求什么介词 | 21, 22, 31 |
| 从句系统 | complétives, relatives, circonstancielles | 从句作什么成分，用 indicatif 还是 subjonctif | 23-26 |
| 一致配合 | accords | 形容词、动词、过去分词和谁配合 | 27 |
| 语篇和实际使用 | registre, politesse, erreurs | 正式/口语如何选择，如何综合改错 | 28-32 |

**最小直觉**：法语句子不是只按意思排列，而是同时检查“名词组是否完整、动词是否变位、代词位置是否正确、介词是否固定、配合是否一致”。

### 0.2 法语与英语、汉语的关键差异

| 问题 | 法语 | 英语 | 汉语学习者易错点 |
| ---- | ---- | ---- | ---------------- |
| 名词性别 | 每个名词通常有阳性/阴性 | 基本无语法性别 | 忘记把名词连同 le/la 或 un/une 记 |
| 冠词使用 | 名词前通常需要冠词或限定词 | 也有冠词，但系统不同 | 说成 J'aime café 而不是 J'aime le café |
| 形容词配合 | 形容词随名词性数变化 | 基本不变 | une maison blanc -> une maison blanche |
| 形容词位置 | 多数后置，少数前置 | 多数前置 | un français étudiant -> un étudiant français |
| 动词变位 | 人称、时态、语式变化丰富 | 变化较少 | nous va -> nous allons |
| 复合时态 | avoir/être + participe passé | have/be + participle | être 动词和过去分词配合易错 |
| 语式 | indicatif/subjonctif/conditionnel 对立明显 | 虚拟较弱 | Il faut que tu viens -> viennes |
| 代词位置 | 宾语代词多在变位动词前 | 多在动词后 | Je vois le -> Je le vois |
| 介词搭配 | 动词/名词/形容词强制搭配 | 也固定但系统不同 | dépendre de, penser à 不能互换 |
| 否定 | 标准书面 ne...pas 双成分 | not 单成分 | Je pas sais -> Je ne sais pas |

### 0.3 法语句子的构造层级

| 层级 | 法语术语 | 例子 | 说明 |
| ---- | -------- | ---- | ---- |
| 词 | mot | livre, parler, beau | 最小词汇单位 |
| 短语 | groupe | un vieux livre | 没有完整主谓，可作句子成分 |
| 从句/分句 | proposition | que tu as acheté | 有主谓，但可能依附主句 |
| 句子 | phrase | J'ai lu le livre que tu as acheté. | 完整表达 |
| 段落/语篇 | texte, discours | email, récit, article | 多句之间有逻辑和语体 |

**从词到句的扩展**：

| 扩展 | 例子 | 增加的信息 |
| ---- | ---- | ---------- |
| 名词 | livre | 名词核心 |
| 加冠词 | un livre | 可数单数名词需要限定 |
| 加前置形容词 | un vieux livre | vieux 前置并配合阳性单数 |
| 加后置形容词 | un vieux livre français | 国籍/关系形容词后置 |
| 加介词短语 | un vieux livre de grammaire | de 引出名词补语 |
| 加关系从句 | un vieux livre que j'ai acheté | que 作从句直接宾语 |
| 完整句 | J'ai lu un vieux livre de grammaire que j'ai acheté hier. | 主谓宾完整，关系从句修饰 livre |

### 0.4 性、数、人称、时态、语式：五个核心维度

| 维度 | 要问的问题 | 影响什么 | 例子 |
| ---- | ---------- | -------- | ---- |
| 性 genre | 名词是阳性还是阴性 | 冠词、形容词、部分代词、过去分词 | le livre, la table |
| 数 nombre | 单数还是复数 | 冠词、形容词、动词、代词 | les livres intéressants |
| 人称 personne | 谁作主语 | 动词变位、命令式、代词 | je parle, nous parlons |
| 时态 temps | 动作何时发生、是否完成 | 动词形式、叙事关系 | je parle, j'ai parlé, je parlerai |
| 语式 mode | 事实、愿望、假设、命令还是评价 | indicatif, subjonctif, conditionnel, impératif | il faut que tu viennes |

**同一句中多个系统会同时工作**：

| 句子 | 需要检查的语法点 |
| ---- | ---------------- |
| Les petites filles sont arrivées. | les 复数；petites 阴性复数；filles 阴性复数；sont 3复；arrivées 与主语配合 |
| Je ne les ai pas vues. | 否定包住助动词；les 在助动词前；vues 与前置 COD les 配合 |
| Il faut que tu sois prudent. | il faut que 触发 subjonctif；sois 是 être 虚拟式；prudent 配合 tu 的性数 |

### 0.5 法语语法速查方法

遇到一个句子不会判断时，按下面顺序查，比直接从中文翻译更可靠。

| 步骤 | 要检查什么 | 典型问题 | 查哪章 |
| ---- | ---------- | -------- | ------ |
| 1 | 主句动词在哪里 | 是简单时态、复合时态还是动词链 | 13-18 |
| 2 | 主语是谁 | 动词是否按主语变位 | 2, 13, 27 |
| 3 | 名词组是否完整 | 名词前有没有冠词/限定词 | 4-6 |
| 4 | 名词性数是否带动配合 | 形容词、过去分词、代词是否一致 | 7, 27 |
| 5 | 宾语是 COD 还是 COI | 用 le/la/les 还是 lui/leur | 2, 10, 11 |
| 6 | y/en 是否适用 | 替代 à + 物/地点，还是 de + 物/数量 | 11 |
| 7 | 介词是否固定 | 是 à, de, en, pour, par 还是无介词 | 21, 22 |
| 8 | 从句类型是什么 | que, qui, dont, si, quand 的功能 | 24-26 |
| 9 | 是否需要 subjonctif | 意愿、必要、情感、疑虑、目的、让步 | 16, 24, 26 |
| 10 | 语体是否合适 | tu/vous, on/nous, 口语/书面 | 30 |

**例句演示**：

| 句子 | 分析路径 |
| ---- | -------- |
| Je voudrais vous poser une question. | voudrais 是 conditionnel 礼貌；vous 是间接/礼貌对象；poser une question 是固定搭配 |
| Les lettres que j'ai écrites sont importantes. | que 指 lettres 作 COD，位于 avoir 过去分词前，所以 écrites 配合阴性复数 |
| Je n'en ai jamais entendu parler. | ne...jamais 包住 ai；en 替代 de + 内容；entendu parler 是动词链 |

### 0.6 全书表格和例句使用规则

| 标记 | 含义 | 例子 |
| ---- | ---- | ---- |
| COD | 直接宾语，不带介词 | Je vois Marie. -> Je la vois. |
| COI | 间接宾语，通过 à/de 等连接 | Je parle à Marie. -> Je lui parle. |
| GN | 名词短语 groupe nominal | un très bon livre |
| GV | 动词短语 groupe verbal | a déjà fini |
| indicatif | 陈述事实或认为真实 | Je pense qu'il vient. |
| subjonctif | 愿望、必要、情感、疑虑等非事实视角 | Je veux qu'il vienne. |
| conditionnel | 假设、礼貌、传闻 | Je voudrais partir. |
| impératif | 命令或建议 | Parlez plus lentement. |

### 0.7 本章常见误区速查

| 误区 | 不够好的做法 | 更稳的做法 | 原因 |
| ---- | ------------ | ---------- | ---- |
| 只背中文意思 | livre = 书 | le livre, un livre, des livres 一起记 | 法语名词离不开性数和限定词 |
| 只背动词原形 | aller = 去 | je vais, tu vas, nous allons, ils vont | 高频动词常不规则 |
| 忽略介词 | dépendre = 取决于 | dépendre de quelque chose | 介词是搭配的一部分 |
| 把英语语序搬来 | Je vois le. | Je le vois. | 法语宾语代词位置不同 |
| 看到 que 就固定翻译 | que = that | 判断 que 是连词、关系代词还是比较结构 | 同形词功能不同 |
| 只按“过去”选时态 | j'ai été petit | j'étais petit | 背景状态常用 imparfait |
| 把 subjonctif 当高级装饰 | Il faut que tu viens. | Il faut que tu viennes. | 很多结构强制触发虚拟式 |

## 1. 书写、发音与语法接口（Orthographe, prononciation et grammaire）

法语拼写和发音不是单独的发音知识，它们直接影响冠词、省音、连读、性数判断、动词词尾识别和书面语拼写。本章只讲和语法判断有关的书写/发音接口：**哪些字母不发音但必须写，哪些音变会改变冠词和代词形式，哪些拼写标记会区分词义或语法功能**。

### 1.1 字母、重音符号与拼写标记

| 标记 | 名称 | 功能 | 例子 |
| ---- | ---- | ---- | ---- |
| é | accent aigu | 常标 /e/，区分词形 | été, parlé |
| è | accent grave | 常标 /ɛ/，也区分词义 | mère, très, où |
| ê | accent circonflexe | 常标历史脱落字母或音质 | être, forêt, sûr |
| ë | tréma | 表示相邻元音分开读 | Noël, naïf |
| ç | cédille | 让 c 在 a/o/u 前读软音 /s/ | français, garçon |
| ' | apostrophe | 省音后连接下一个词 | l'homme, j'aime |
| - | trait d'union | 倒装、复合词、命令代词 | Parlez-vous ? Donne-le-moi. |

| 易混 | 区别 |
| ---- | ---- |
| ou / où | ou = 或者；où = 哪里/在其中 |
| a / à | a = avoir 第三人称；à = 介词 |
| du / dû | du = de + le 或部分冠词；dû = devoir 的过去分词 |
| sur / sûr | sur = 在……上；sûr = 确定的 |

**速查原则**：重音符号不是装饰。正式书写中，é/è/ê/à/ù/ç 等都应保留；缺失可能造成词义、时态或语法功能误判。

### 1.2 省音 élision：je -> j', le -> l'

省音是指某些以元音结尾的短词，在下一个词以元音或 h muet 开头时，去掉元音并加 apostrophe。省音影响冠词、代词、否定和连词。

| 原形 | 省音形式 | 例子 |
| ---- | -------- | ---- |
| je | j' | j'aime, j'habite |
| me | m' | il m'appelle |
| te | t' | je t'écoute |
| se | s' | elle s'appelle |
| le | l' | l'homme, je l'aime |
| la | l' | l'eau, je l'attends |
| de | d' | d'accord, beaucoup d'amis |
| ne | n' | je n'ai pas |
| que | qu' | je pense qu'il vient |
| jusque | jusqu' | jusqu'à demain |
| lorsque / puisque | lorsqu' / puisqu' | lorsqu'il arrive, puisqu'elle est là |

| 不省音 | 例子 | 说明 |
| ------ | ---- | ---- |
| h aspiré 前 | le héros, la haine | h aspiré 阻止省音 |
| onze, oui 等少数词前 | le onze, le oui | 传统上不省音 |
| si 通常只在 il/ils 前省音 | s'il vient, s'ils viennent | si elle vient 不省音 |

### 1.3 省音与语法判断

| 表面形式 | 展开 | 语法身份 | 例句 |
| -------- | ---- | -------- | ---- |
| j' | je | 主语代词 | J'aime Paris. |
| l' | le/la | 定冠词或宾语代词 | L'homme arrive. / Je l'aime. |
| d' | de | 介词、数量 de、否定 de | beaucoup d'eau, pas d'argent |
| n' | ne | 否定第一部分 | Je n'ai rien vu. |
| qu' | que | 连词、关系代词或疑问结构一部分 | Je sais qu'il vient. |

| 判断方法 | 例子 | 说明 |
| -------- | ---- | ---- |
| l' 后接名词，多半是冠词 | l'idée est bonne | l' = la |
| l' 在动词前，多半是宾语代词 | je l'ai vue | l' = la/le，可能影响过去分词配合 |
| d' 后接名词，不一定都是“的” | pas d'amis, beaucoup d'idées | 可能是否定或数量结构 |
| qu' 要看从句缺什么成分 | le livre qu'il lit / je pense qu'il lit | 前者关系代词，后者连词 |

### 1.4 连读 liaison 与语法边界

连读是指一个词末通常不发音的辅音，在下一个词以元音或 h muet 开头时读出来。连读常让书面上的复数、限定词、人称词尾在口语中显现。

| 类型 | 例子 | 连读音 | 说明 |
| ---- | ---- | ------ | ---- |
| 限定词 + 名词 | les amis | /z/ | les 的 s 连读 |
| 形容词 + 名词 | petits enfants | /z/ | 复数 s 连读 |
| 代词 + 动词 | nous avons | /z/ | nous 与 avons 连读 |
| être 后 | ils sont arrivés | /t/ | sont 的 t 连读 |
| très + 形容词 | très important | /z/ | 常见必需/自然连读 |
| quand + 元音 | quand il vient | /t/ | 常见固定连读 |

| 连读类型 | 场景 | 例子 |
| -------- | ---- | ---- |
| 必需 liaison obligatoire | 限定词+名词、代词+动词、固定短语 | les amis, vous avez |
| 可选 liaison facultative | 较正式或慢速语流 | pas encore, trop important |
| 禁止 liaison interdite | 单数名词后、et 后、h aspiré 前 | un enfant et un ami, les héros |

### 1.5 连读和语法信息

| 听到/看到 | 可能提示 | 例子 |
| -------- | -------- | ---- |
| /z/ | 复数限定词或代词边界 | les amis, ils ont |
| /t/ | 动词或固定连接 | quand il, est-il |
| /n/ | un/mon/son/on 等词尾 | un ami, mon idée |
| 不发音的 -s | 书面复数仍然必须写 | les livres rouges |
| 不发音的 -ent | 第三人称复数动词词尾 | ils parlent |

| 易错 | 正确理解 |
| ---- | -------- |
| ils parlent 和 il parle 发音常相同 | 书面必须按主语写 parle / parlent |
| livre 和 livres 发音常相同 | 冠词 le/les 或上下文显示数 |
| grande amie 中 d 连读 | grande 的 -e 仍显示阴性 |
| les héros 不连读 | héros 是 h aspiré |

### 1.6 h muet / h aspiré 与冠词、连读、省音

法语 h 本身通常不发音，但分为 **h muet** 和 **h aspiré**。区别不在 h 是否发音，而在它是否允许省音和连读。

| 类型 | 是否省音 | 是否连读 | 例子 |
| ---- | -------- | -------- | ---- |
| h muet | 允许 | 允许 | l'homme, les hommes |
| h aspiré | 不允许 | 不允许 | le héros, les héros |

| h muet 常见词 | 例子 |
| ------------- | ---- |
| homme | l'homme, les hommes |
| heure | l'heure, deux heures |
| histoire | l'histoire |
| hôtel | l'hôtel |
| habitude | l'habitude |
| hiver | l'hiver |

| h aspiré 常见词 | 例子 |
| --------------- | ---- |
| héros | le héros, les héros |
| haricot | le haricot, des haricots |
| hasard | le hasard |
| honte | la honte |
| haine | la haine |
| hauteur | la hauteur |

| 错误 | 正确 | 原因 |
| ---- | ---- | ---- |
| l'héros | le héros | héros 是 h aspiré |
| les-z-héros | les héros，不连读 | h aspiré 阻止连读 |
| le homme | l'homme | homme 是 h muet |

### 1.7 阴阳性和复数在发音中的可见/不可见差异

法语很多性数变化在书面上可见，但口语中不一定明显。因此阅读和写作时不能只凭发音判断形式。

| 书面差异 | 发音是否常有差异 | 例子 |
| -------- | ---------------- | ---- |
| 名词复数 -s | 通常不发音 | un livre / des livres |
| 形容词复数 -s | 通常不发音 | petit / petits |
| 动词第三复数 -ent | 通常不发音 | il parle / ils parlent |
| 阴性 -e | 有时改变前面辅音是否发音 | petit / petite |
| 阴性双写辅音 | 常影响发音 | bon / bonne |
| 过去分词配合 -e/-s | 多数不发音，但书面必须写 | allé / allée / allés / allées |

| 对比 | 说明 |
| ---- | ---- |
| Il parle. / Ils parlent. | 发音可能相同，主语决定动词拼写 |
| Elle est arrivée. / Il est arrivé. | 发音可能接近，但书面配合不同 |
| un ami / une amie | 发音相同，冠词显示性别 |
| petit / petite | petite 的 t 通常发音，性别可听出 |

### 1.8 大写、标点和法语排版空格

| 项目 | 法语规则 | 例子 |
| ---- | -------- | ---- |
| 语言名 | 小写 | le français, l'anglais |
| 国籍形容词 | 小写 | un étudiant français |
| 国籍名词 | 可大写 | un Français, une Française |
| 星期、月份 | 小写 | lundi, juillet |
| 书名/标题 | 大写规则依风格 | Le Petit Prince |
| 冒号、分号、问号、感叹号前 | 法式排版常有窄不换行空格 | Bonjour ! Pourquoi ? |
| 引号 | 法式引号可用 « ... » | « Bonjour ! » |

| 易错 | 推荐 |
| ---- | ---- |
| J'apprends le Français. | J'apprends le français. |
| un étudiant Français | un étudiant français |
| Lundi, Juillet | lundi, juillet |

### 1.9 常见拼写-语法错误速查

| 错误类型 | 不自然/错误 | 推荐表达 | 原因 |
| -------- | ----------- | -------- | ---- |
| 重音遗漏导致混淆 | a Paris | à Paris | à 是介词，a 是 avoir |
| ou/où 混淆 | la ville ou j'habite | la ville où j'habite | où 表地点 |
| 省音缺失 | je aime | j'aime | je 在元音前省音 |
| 不该省音 | l'héros | le héros | h aspiré 阻止省音 |
| 连字符缺失 | Parlez vous français ? | Parlez-vous français ? | 倒装疑问用连字符 |
| 复数只按发音写 | les livre | les livres | -s 不发音但必须写 |
| 动词复数词尾遗漏 | ils parle | ils parlent | 第三人称复数 -ent |
| 过去分词书面配合遗漏 | elles sont allé | elles sont allées | être 复合时态与主语配合 |
| ç 遗漏 | nous commencons | nous commençons | c 在 o 前需 ç 保持 /s/ |
| 大小写照搬英语 | en Juillet | en juillet | 月份小写 |

## 2. 词性、短语与句子成分（Parties du discours et fonctions）

本章解决“一个词或短语在句子里做什么”的问题。法语语法分析要区分三层：**词性**说明词本身的类型，**短语**说明一组词构成的单位，**句子成分**说明这个单位在句子中的功能。后面的冠词、代词、动词、从句和配合规则都依赖这套判断。

### 2.1 词性总览

| 词性 | 法语术语 | 作用 | 例子 |
| ---- | -------- | ---- | ---- |
| 名词 | nom | 指人、物、地点、概念 | livre, ville, liberté |
| 限定词 | déterminant | 放在名词前，限定名词 | le, une, ce, mon, trois |
| 形容词 | adjectif | 修饰名词或作表语 | grand, rouge, français |
| 代词 | pronom | 替代名词、短语或从句 | je, le, lui, y, en, qui |
| 动词 | verbe | 表动作、状态、变化 | être, avoir, parler, venir |
| 副词 | adverbe | 修饰动词、形容词、副词或全句 | bien, très, souvent |
| 介词 | préposition | 引出介词短语，表示关系 | à, de, dans, pour, avec |
| 连词 | conjonction | 连接词、短语、从句或句子 | et, mais, que, parce que |
| 感叹词 | interjection | 表回应、情绪、呼喊 | oh, bravo, merci |

| 同形词 | 可能词性 | 例句 |
| ------ | -------- | ---- |
| le | 定冠词 / COD 代词 | **Le** livre est ici. / Je **le** vois. |
| la | 定冠词 / COD 代词 | **La** porte est ouverte. / Je **la** ferme. |
| leur | COI 代词 / 物主限定词 | Je **leur** parle. / **Leur** maison est grande. |
| bien | 副词 / 名词 | Il parle **bien**. / C'est un **bien** public. |
| que | 连词 / 关系代词 / 疑问词一部分 | Je pense **que** oui. / le livre **que** je lis |

### 2.2 短语类型：groupe nominal, verbal, adjectival, prépositionnel

| 短语类型 | 法语术语 | 核心 | 例子 | 可充当的成分 |
| -------- | -------- | ---- | ---- | ------------ |
| 名词短语 | groupe nominal, GN | 名词 | le vieux livre rouge | 主语、宾语、表语等 |
| 动词短语 | groupe verbal, GV | 动词 | a déjà fini son travail | 谓语核心 |
| 形容词短语 | groupe adjectival | 形容词 | très fier de son fils | 表语、定语 |
| 副词短语 | groupe adverbial | 副词 | très souvent | 状语 |
| 介词短语 | groupe prépositionnel | 介词 | dans la maison, à Paris | 状语、补语、名词修饰 |
| 从句 | proposition subordonnée | 变位动词 | que tu connais | 名词性、定语、状语 |

| 例子 | 短语边界 | 功能 |
| ---- | -------- | ---- |
| **Le frère de Marie** arrive. | le frère de Marie | 主语 |
| Je lis **un livre de grammaire**. | un livre de grammaire | COD |
| Elle est **très contente de son résultat**. | très contente de son résultat | 主语表语 |
| Il travaille **dans une petite entreprise**. | dans une petite entreprise | 地点状语 |

### 2.3 主语 sujet

主语通常回答“谁/什么执行动作或处于状态”。法语主语大多数情况下不能省略，动词必须和主语在人称和数上配合。

| 主语形式 | 例句 | 说明 |
| -------- | ---- | ---- |
| 名词短语 | **Marie** arrive. | 人名作主语 |
| 代词 | **Elle** arrive. | 主语代词 |
| 不定式 | **Partir maintenant** serait une erreur. | 动作作主语 |
| 从句 | **Ce que tu dis** est vrai. | 从句作主语 |
| ce / il | **C'est** important. / **Il** faut partir. | 形式或非人称主语 |

| 判断方法 | 例子 |
| -------- | ---- |
| 问“谁/什么 + 动词？” | **Les enfants** jouent. |
| 看动词配合 | Les enfants **jouent**，不是 joue |
| 注意 qui 可继承先行词 | C'est moi qui **suis** responsable. |

| 易错 | 推荐 | 原因 |
| ---- | ---- | ---- |
| Est important. | C'est important. / Il est important de... | 法语通常需要显性主语 |
| Moi suis prêt. | Moi, je suis prêt. | 重读代词不能单独作普通主语 |
| C'est moi qui est responsable. | C'est moi qui suis responsable. | qui 指 moi |

### 2.4 谓语和动词组 groupe verbal

动词组是句子的核心，决定这个句子需要什么宾语、补语或介词结构。分析时先找变位动词，再看是否有助动词、不定式或代词。

| 动词组结构 | 例句 | 说明 |
| ---------- | ---- | ---- |
| 简单变位动词 | Elle **parle**. | présent 等简单时态 |
| 助动词 + 过去分词 | Elle **a parlé**. | passé composé 等复合时态 |
| 半助动词 + 不定式 | Elle **va partir**. | futur proche / 动词链 |
| 情态动词 + 不定式 | Elle **peut venir**. | pouvoir, devoir, vouloir |
| 代词式动词 | Elle **se lève**. | se 是动词结构一部分 |
| 否定动词组 | Elle **ne parle pas**. | ne...pas 包住变位动词 |

| 动词要求 | 结构 | 例子 |
| -------- | ---- | ---- |
| 不及物 | V | dormir -> Il dort. |
| 直接及物 | V + COD | lire quelque chose -> Elle lit un livre. |
| 间接及物 à | V + à + COI | parler à quelqu'un -> Elle parle à Paul. |
| 间接及物 de | V + de + COI | parler de quelque chose -> Elle parle du projet. |
| 系动词 | V + attribut | être fatigué -> Elle est fatiguée. |

### 2.5 直接宾语 COD

COD（complément d'objet direct）直接接在动词后，不由介词 à/de/pour 等引出。它回答“动词作用于谁/什么”。

| 名词宾语 | COD 代词 | 例句 |
| -------- | -------- | ---- |
| Je vois **Paul**. | le | Je **le** vois. |
| Je vois **Marie**. | la | Je **la** vois. |
| Je vois **les enfants**. | les | Je **les** vois. |
| Je lis **ce livre**. | le | Je **le** lis. |
| J'aime **la musique**. | l' / la | Je **l'**aime. |

| COD 判断 | 例子 |
| -------- | ---- |
| 动词后无介词 | regarder un film |
| 可被 le/la/les 替代 | Je regarde le film -> Je le regarde |
| 在 avoir 复合时态前置时影响过去分词配合 | les lettres que j'ai écrites |

| 易错 | 推荐 | 原因 |
| ---- | ---- | ---- |
| Je regarde à la télé. | Je regarde la télé. | regarder 是直接及物 |
| Je cherche pour mes clés. | Je cherche mes clés. | chercher 直接接 COD |
| Je l'ai parlé. | Je lui ai parlé. | parler à quelqu'un 是 COI |

### 2.6 间接宾语 COI

COI（complément d'objet indirect）通过介词，最常见是 à 或 de，与动词连接。不要把所有“对象”都当 COD。

| 结构 | 例句 | 代词替换 |
| ---- | ---- | -------- |
| parler à quelqu'un | Je parle à Marie. | Je lui parle. |
| téléphoner à quelqu'un | Je téléphone à Paul. | Je lui téléphone. |
| répondre à quelqu'un | Je réponds au professeur. | Je lui réponds. |
| penser à quelque chose | Je pense à ce problème. | J'y pense. |
| parler de quelque chose | Je parle de ce livre. | J'en parle. |
| avoir besoin de quelque chose | J'ai besoin de ce document. | J'en ai besoin. |

| COI 类型 | 人 | 物/事情 |
| -------- | -- | -------- |
| à + 名词 | à Marie -> lui | à ce problème -> y |
| de + 名词 | de Marie -> d'elle | de ce problème -> en |

| 易错 | 推荐 | 原因 |
| ---- | ---- | ---- |
| Je téléphone Marie. | Je téléphone à Marie. | téléphoner à |
| Je lui regarde. | Je la/le regarde. | regarder 是 COD |
| J'y pense à Marie. | Je pense à elle. | à + 人通常用重读代词 |

### 2.7 表语 attribut du sujet / attribut du COD

表语说明主语或宾语的身份、性质、状态。主语表语常跟在 être, sembler, devenir, rester, paraître 等系动词后。

| 类型 | 结构 | 例句 | 说明 |
| ---- | ---- | ---- | ---- |
| 主语表语 | sujet + verbe attributif + attribut | Elle est médecin. | 说明主语身份 |
| 主语表语 | sujet + être + adjectif | Elle est fatiguée. | 形容词与主语配合 |
| 宾语表语 | V + COD + attribut du COD | Je trouve ce film intéressant. | intéressant 说明 film |
| 命名/任命 | nommer/élire + COD + attribut | On l'a élue présidente. | présidente 说明 l' |

| 常见系动词 | 例句 |
| ---------- | ---- |
| être | Il est calme. |
| sembler / paraître | Elle semble inquiète. |
| devenir | Il devient impatient. |
| rester | Elle reste silencieuse. |
| avoir l'air | Elle a l'air fatiguée. |

| 易错 | 推荐 | 原因 |
| ---- | ---- | ---- |
| Elle est un médecin. | Elle est médecin. / C'est un médecin. | 职业表身份时 il/elle est 后通常无冠词 |
| Elle est fatigué. | Elle est fatiguée. | 表语形容词与主语配合 |
| Je trouve intéressant ce film，普通语序 | Je trouve ce film intéressant. | COD + attribut du COD |

### 2.8 状语 complément circonstanciel

状语说明动作发生的时间、地点、方式、原因、目的、条件等。它通常比宾语更自由，可以移动或删除而不破坏核心句型。

| 类型 | 问题 | 例句 |
| ---- | ---- | ---- |
| 时间 | quand ? combien de temps ? | Elle part demain. |
| 地点 | où ? d'où ? vers où ? | Il travaille à Lyon. |
| 方式 | comment ? | Elle parle lentement. |
| 原因 | pourquoi ? | Il est absent à cause de la pluie. |
| 目的 | pour quoi faire ? | Elle étudie pour réussir. |
| 条件 | à quelle condition ? | En cas de pluie, on reste ici. |
| 伴随 | avec qui/quoi ? | Il est venu avec sa soeur. |
| 让步 | malgré quoi ? | Malgré la fatigue, elle continue. |

| 位置 | 例句 | 说明 |
| ---- | ---- | ---- |
| 句首 | Demain, je pars. | 强调时间或设置背景 |
| 句末 | Je pars demain. | 中性位置 |
| 动词附近 | Il parle souvent français. | 频率副词位置较固定 |

### 2.9 名词补语 complément du nom

名词补语修饰名词，通常由介词短语或从句构成。它是名词短语内部成分，不是动词的宾语。

| 结构 | 例子 | 关系 |
| ---- | ---- | ---- |
| N + de + N | le livre de Marie | 所属 |
| N + de + N | un cours de français | 内容/类型 |
| N + à + N | une tasse à café | 用途 |
| N + en + N | une bague en or | 材料 |
| N + pour + N/infinitif | une salle pour les réunions | 目的 |
| N + relative | le livre que j'ai acheté | 定语从句修饰 |

| 对比 | 说明 |
| ---- | ---- |
| une tasse de café | 一杯咖啡，de 表内容 |
| une tasse à café | 咖啡杯，à 表用途 |
| un professeur de français | 法语老师 |
| un professeur français | 法国老师/法国籍老师 |

### 2.10 同位语、插入语和补充说明

| 类型 | 法语术语 | 例句 | 功能 |
| ---- | -------- | ---- | ---- |
| 同位语 | apposition | Paris, capitale de la France, est célèbre. | 用名词短语补充说明 |
| 插入语 | incise / parenthèse | Il viendra, je crois, demain. | 插入说话态度 |
| 补充说明 | complément détaché | Fatiguée, elle est rentrée tôt. | 句首/句中补充状态 |
| 呼语 | apostrophe | Marie, viens ici. | 直接呼唤对象 |

| 标点 | 例句 |
| ---- | ---- |
| 逗号隔开补充信息 | Mon frère, médecin, habite à Lyon. |
| 不加逗号时可能变成限制信息 | les étudiants français |
| 插入语不参与主谓配合 | Les enfants, je crois, sont partis. |

### 2.11 常见句子成分误判速查

| 错误类型 | 不自然/错误 | 推荐判断/表达 | 原因 |
| -------- | ----------- | ------------- | ---- |
| 把 COI 当 COD | Je la téléphone. | Je lui téléphone. | téléphoner à quelqu'un |
| 把 COD 当 COI | Je lui vois. | Je le/la vois. | voir quelqu'un |
| 把名词补语当宾语 | le livre de Marie 中 de Marie 是宾语 | de Marie 是 complément du nom | 它修饰 livre，不受动词支配 |
| 忽略表语配合 | Elle est intelligent. | Elle est intelligente. | 表语形容词与主语配合 |
| 重读代词当普通主语 | Moi suis d'accord. | Moi, je suis d'accord. | moi 需配合主语代词 je |
| 状语位置照搬中文 | Demain je à Paris vais. | Demain, je vais à Paris. | 核心语序仍是 je vais |
| 误判 qui 的人称 | C'est moi qui est prêt. | C'est moi qui suis prêt. | qui 继承 moi |
| 缺形式主语 | Faut partir.，标准书面 | Il faut partir. | 标准法语需要 il |

## 3. 基本句型、语序与句子类型（Ordre des mots et types de phrases）

本章解决“法语句子怎样排”的问题。法语的基本语序是 **主语 + 变位动词 + 补语**，但否定、疑问、命令式、宾语代词、强调结构都会改变表面顺序。学习时要先抓住**变位动词的位置**，再判断主语、宾语、状语和代词围绕它怎样排列。

### 3.1 法语基本语序 SVO

法语陈述句的默认顺序是 **S + V + O / C / CC**：主语在前，变位动词紧随其后，宾语、表语、状语通常在后。

| 结构 | 法语公式 | 例句 | 说明 |
| ---- | -------- | ---- | ---- |
| 主语 + 不及物动词 | S + V | Le train arrive. | arrive 不带宾语 |
| 主语 + 直接宾语 | S + V + COD | Marie lit un roman. | un roman 是 COD |
| 主语 + 间接宾语 | S + V + COI | Je parle à Paul. | à Paul 是 COI |
| 主语 + 双宾语 | S + V + COD + COI | Elle donne un livre à son frère. | 名词宾语通常 COD 在 COI 前 |
| 主语 + 表语 | S + V + attribut | Il est fatigué. | fatigué 说明主语状态 |
| 主语 + 动词 + 状语 | S + V + CC | Nous partons demain. | demain 是时间状语 |

**核心判断**：先找变位动词，再问“谁做动作”“动作作用到谁/什么”“句子还补充了什么时间、地点、方式、原因”。

| 中文想表达 | 自然法语 | 不自然/错误 | 原因 |
| ---------- | -------- | ----------- | ---- |
| 我每天学习法语。 | J'étudie le français tous les jours. | Tous les jours j'étudie le français 也可，但更有强调感 | 状语可前置，但默认放句末更中性 |
| 他给我打电话。 | Il me téléphone. | Il téléphone moi. | 宾语是代词时，位置变到动词前 |
| 这本书很有趣。 | Ce livre est intéressant. | Ce livre intéressant. | 法语句子通常需要变位动词 |
| 我喜欢咖啡。 | J'aime le café. | J'aime café. | 泛指类别名词通常要冠词 |

### 3.2 简单句、并列句、复合句

法语句子可以按 **proposition**（分句/从句）数量和关系来分析。每个 proposition 通常至少有自己的主语和变位动词。

| 类型 | 法语术语 | 结构 | 例句 | 重点 |
| ---- | -------- | ---- | ---- | ---- |
| 简单句 | phrase simple | 一个 proposition | Je travaille. | 一个主谓核心 |
| 并列句 | phrase composée / coordination | proposition + et/mais/ou/donc + proposition | Je travaille et il lit. | 两个分句地位并列 |
| 复合句 | phrase complexe / subordination | 主句 + 从句 | Je pense qu'il a raison. | 一个分句依附另一个分句 |
| 嵌套句 | phrase avec plusieurs subordonnées | 主句 + 多个从句 | Je sais que tu connais la personne qui parle. | 需要逐层找主干 |

常见连接方式：

| 连接方式 | 连接词/标记 | 例句 | 功能 |
| -------- | ----------- | ---- | ---- |
| 并列 | et, mais, ou, donc, car | Il est tard, donc je pars. | 连接同等级分句 |
| 名词性从句 | que, si, ce que, ce qui | Je crois qu'il viendra. | 从句作宾语、主语或表语 |
| 关系从句 | qui, que, dont, où | C'est le livre que j'ai acheté. | 修饰名词 |
| 状语从句 | quand, parce que, si, bien que | Je reste parce qu'il pleut. | 表时间、原因、条件、让步等 |

**实用拆句法**：

| 步骤 | 问题 | 例句：Je sais que tu as vu le film dont il parle. |
| ---- | ---- | ----------------------------------------------- |
| 1 | 找所有变位动词 | sais, as vu, parle |
| 2 | 找主句主谓 | Je sais |
| 3 | 找从句边界 | que tu as vu le film / dont il parle |
| 4 | 判断从句功能 | que 从句作 sais 的宾语；dont 从句修饰 film |
| 5 | 还原成分关系 | tu as vu le film；il parle de ce film |

### 3.3 陈述句

陈述句用于说明事实、状态、习惯、计划或判断。中性语序通常不倒装，主语不省略，动词必须变位。

| 用途 | 结构 | 例句 | 说明 |
| ---- | ---- | ---- | ---- |
| 事实 | S + V | Le magasin ouvre à neuf heures. | 客观陈述 |
| 状态 | S + être/devenir/rester + attribut | Elle est médecin. | 表语说明身份/状态 |
| 习惯 | S + V au présent | Je prends le métro tous les jours. | présent 可表习惯 |
| 计划 | S + aller + infinitif | Nous allons partir demain. | futur proche |
| 判断 | S + trouver/penser que... | Je pense que c'est utile. | que 从句作宾语 |

陈述句里的状语位置比较灵活，但每种位置的语感不同：

| 状语位置 | 例句 | 语感/用法 |
| -------- | ---- | -------- |
| 句末 | Je travaille à Paris maintenant. | 最中性，常用 |
| 句首 | Maintenant, je travaille à Paris. | 设置话题或对比 |
| 动词后 | Il parle souvent de son travail. | 频率副词常靠近动词 |
| 助动词与过去分词之间 | Il a déjà fini. | déjà, bien, mal, beaucoup 等常在这里 |
| 句中插入 | Elle, en général, répond vite. | 书面或强调，需注意逗号 |

陈述句常见骨架：

| 骨架 | 例句 | 可替换部分 |
| ---- | ---- | ---------- |
| Il y a + 名词 | Il y a un problème. | 表“有/存在” |
| C'est + 名词/形容词 | C'est une bonne idée. | 识别、评价、强调 |
| Il est + 形容词 + de/que | Il est difficile de choisir. | 非人称评价 |
| Ça/Cela + 动词 | Ça dépend. | 口语/中性指代整个情况 |
| On + 动词 | On commence ? | 口语中常代 nous 或泛指“人们” |

### 3.4 否定句基本框架

标准法语否定的基本框架是 **ne + 变位动词 + pas**。口语里 ne 常被省略，但书面语、正式表达和考试中应掌握完整形式。

| 肯定句 | 否定句 | 说明 |
| ------ | ------ | ---- |
| Je comprends. | Je ne comprends pas. | ne...pas 夹住变位动词 |
| Il aime le café. | Il n'aime pas le café. | 元音前 ne -> n' |
| Nous sommes prêts. | Nous ne sommes pas prêts. | être 也同样被夹住 |
| Elle a fini. | Elle n'a pas fini. | 复合时态中夹住助动词 |
| Il va partir. | Il ne va pas partir. | 近将来中夹住 aller |

否定范围取决于被否定的成分：

| 否定对象 | 例句 | 含义 |
| -------- | ---- | ---- |
| 整个谓语 | Je ne sais pas. | 我不知道 |
| 不定式 | Je préfère ne pas répondre. | 我宁愿不回答 |
| 名词宾语 | Je n'ai pas de voiture. | 我没有车 |
| 数量 | Il n'y a pas assez de temps. | 时间不够 |
| 形容词/副词 | Ce n'est pas très clair. | 不是很清楚 |

否定词基本表：

| 否定结构 | 含义 | 例句 | 注意 |
| -------- | ---- | ---- | ---- |
| ne...pas | 不 | Je ne viens pas. | 最基础 |
| ne...plus | 不再 | Il ne travaille plus ici. | 表变化 |
| ne...jamais | 从不 | Elle ne fume jamais. | jamais 可单独回答 |
| ne...rien | 什么也不 | Je ne vois rien. | rien 可作宾语 |
| ne...personne | 没有人 | Je ne connais personne. | personne 可作宾语/主语 |
| ne...que | 只 | Je n'ai que dix euros. | 不是否定意义，而是限制 |

### 3.5 疑问句基本框架

法语提问有三种常用层级：**语调提问**最口语，**est-ce que** 中性可靠，**倒装**更书面或正式。

| 方式 | 结构 | 例句 | 使用场景 |
| ---- | ---- | ---- | -------- |
| 语调 | 陈述句 + ? | Tu viens ? | 口语、熟人 |
| est-ce que | Est-ce que + 陈述语序 | Est-ce que tu viens ? | 中性、安全 |
| 倒装 | V-sujet + ? | Viens-tu ? | 书面、正式、文学 |
| 疑问词 + 语调 | Mot interrogatif + 陈述语序 | Tu vas où ? | 口语 |
| 疑问词 + est-ce que | Mot interrogatif + est-ce que + 陈述语序 | Où est-ce que tu vas ? | 中性 |
| 疑问词 + 倒装 | Mot interrogatif + V-sujet | Où vas-tu ? | 正式 |

常见疑问词：

| 疑问词 | 问什么 | 例句 | 说明 |
| ------ | ------ | ---- | ---- |
| qui | 谁 | Qui vient ? / Tu vois qui ? | 可问主语或宾语 |
| que / quoi | 什么 | Que fais-tu ? / Tu fais quoi ? | que 多用于句首，quoi 多在介词后或口语句末 |
| où | 哪里 | Où habites-tu ? | 问地点 |
| quand | 什么时候 | Quand pars-tu ? | 问时间 |
| comment | 怎样 | Comment ça marche ? | 问方式/状态 |
| pourquoi | 为什么 | Pourquoi tu dis ça ? | 问原因 |
| combien | 多少 | Combien ça coûte ? | 问数量/价格 |
| quel | 哪个/什么样的 | Quel livre veux-tu ? | 形容词性，随名词性数变化 |

是非问句回答：

| 问句 | 肯定回答 | 否定回答 | 说明 |
| ---- | -------- | -------- | ---- |
| Tu viens ? | Oui, je viens. | Non, je ne viens pas. | 普通肯否 |
| Tu ne viens pas ? | Si, je viens. | Non, je ne viens pas. | 否定问句中，反驳否定用 si |
| Il n'est pas là ? | Si, il est là. | Non, il n'est pas là. | si = “不，他在/是的，他在” |

### 3.6 命令句基本框架

命令式用于命令、请求、建议、邀请。常用形式只有 **tu, nous, vous** 三个人称，通常省略主语。

| 陈述式 | 命令式 | 含义 | 注意 |
| ------ | ------ | ---- | ---- |
| Tu viens. | Viens ! | 来！ | 无主语 tu |
| Nous partons. | Partons ! | 我们走吧！ | 表建议 |
| Vous écoutez. | Écoutez ! | 请听！ | 可礼貌也可命令 |
| Tu regardes. | Regarde ! | 看！ | 第一组动词 tu 命令式通常去 -s |
| Tu vas. | Va ! | 去！ | aller 特殊 |

命令式与代词的位置：

| 类型 | 结构 | 例句 | 说明 |
| ---- | ---- | ---- | ---- |
| 肯定命令 | V-pronom | Regarde-le. | 代词放动词后，用连字符 |
| 肯定双代词 | V-COD-COI | Donne-le-moi. | me/te 变 moi/toi |
| 否定命令 | Ne + pronom + V + pas | Ne le regarde pas. | 否定命令回到普通代词前置 |
| y/en 肯定命令 | V-y / V-en | Vas-y. / Prends-en. | 某些形式保留或添加 -s 便于发音 |
| 礼貌请求 | Veuillez + infinitif | Veuillez patienter. | 正式书面/公告 |

命令句常用缓和方式：

| 直接命令 | 缓和表达 | 语感 |
| -------- | -------- | ---- |
| Fermez la porte. | Pouvez-vous fermer la porte ? | 更礼貌 |
| Donne-moi ton adresse. | Tu peux me donner ton adresse ? | 口语请求 |
| Répondez avant vendredi. | Merci de répondre avant vendredi. | 邮件/通知常用 |
| Attends. | Attends un instant, s'il te plaît. | 加 s'il te plaît 更自然 |

### 3.7 感叹句基本框架

感叹句表达强烈评价、惊讶、赞叹或抱怨。常见标记有 **quel**, **comme**, **que**, **ce que**。

| 结构 | 例句 | 含义/语感 |
| ---- | ---- | -------- |
| Quel(le)(s) + 名词 ! | Quelle surprise ! | 多么令人惊讶！ |
| Quel(le)(s) + 名词 + 形容词 ! | Quelle belle journée ! | 多么美好的一天！ |
| Comme + 句子 ! | Comme c'est beau ! | 多么美！ |
| Que + 句子 ! | Que c'est difficile ! | 较书面或正式 |
| Ce que + 句子 ! | Ce que tu es impatient ! | 口语感叹，很强 |
| Qu'est-ce que + 句子 ! | Qu'est-ce qu'il fait chaud ! | 口语强烈感叹 |

quel 的配合：

| 名词 | 感叹形式 | 例句 |
| ---- | -------- | ---- |
| 阳性单数 | quel | Quel courage ! |
| 阴性单数 | quelle | Quelle idée ! |
| 阳性复数 | quels | Quels livres intéressants ! |
| 阴性复数 | quelles | Quelles belles maisons ! |

注意：感叹结构里 **quel** 是限定词，后面接名词；**comme/que/ce que** 后面接完整句子。

### 3.8 代词导致的语序变化

名词宾语通常在动词后，但宾语变成代词后，多数情况下移到**变位动词前**。这是法语语序最容易出错的地方。

| 名词宾语 | 代词句 | 说明 |
| -------- | ------ | ---- |
| Je vois Marie. | Je la vois. | COD 代词在动词前 |
| Il parle à Paul. | Il lui parle. | COI 代词在动词前 |
| Tu penses à ce problème. | Tu y penses. | à + 事物常用 y |
| Elle revient de Paris. | Elle en revient. | de + 地点/来源可用 en |
| Nous avons acheté trois livres. | Nous en avons acheté trois. | en 替代 de/数量相关名词 |

复合时态和动词链：

| 结构 | 例句 | 位置规则 |
| ---- | ---- | -------- |
| 复合时态 | Je l'ai vu. | 代词在助动词前 |
| 近将来 | Je vais le voir. | 代词在不定式前 |
| 情态/半助动词 | Je peux le faire. | 代词在真正支配宾语的不定式前 |
| 否定 + 代词 | Je ne le vois pas. | ne + 代词 + 动词 + pas |
| 双代词 | Je le lui donne. | 顺序固定，详见代词章 |

基本代词语序模板：

| 句型 | 模板 | 例句 |
| ---- | ---- | ---- |
| 陈述句 | S + pronom + V | Je le comprends. |
| 否定句 | S + ne + pronom + V + pas | Je ne le comprends pas. |
| 复合时态 | S + pronom + auxiliaire + participe | Je l'ai compris. |
| 不定式 | S + V1 + pronom + infinitif | Je veux le comprendre. |
| 肯定命令 | V-pronom | Comprends-le. |
| 否定命令 | Ne + pronom + V + pas | Ne le comprends pas. |

### 3.9 倒装、书面语语序和强调语序

法语有一些非默认语序，用来提问、保持书面风格、连接上下文或突出信息。

| 类型 | 结构 | 例句 | 使用场景 |
| ---- | ---- | ---- | -------- |
| 主谓倒装提问 | V-sujet | Parlez-vous français ? | 正式疑问 |
| 疑问词倒装 | Mot interrogatif + V-sujet | Où habitez-vous ? | 正式疑问 |
| 名词主语复杂倒装 | Nom sujet + V-pronom | Paul viendra-t-il ? | 书面/正式；名词主语保留，再加代词倒装 |
| 引语倒装 | Citation, dit-il. | « Je pars », dit-elle. | 书面叙事 |
| 某些状语前置后倒装 | Adverbe initial + V-sujet | Peut-être viendra-t-il. | 书面语，较正式 |
| 强调结构 | C'est...qui/que... | C'est Marie qui a appelé. | 强调主语或宾语 |

倒装中的 -t-：

| 普通形式 | 倒装 | 原因 |
| -------- | ---- | ---- |
| Il parle. | Parle-t-il ? | 动词元音结尾 + il 元音开头，中间加 -t- |
| Elle arrive. | Arrive-t-elle ? | 避免两个元音相接 |
| On commence. | Commence-t-on ? | 同理 |
| Il est prêt. | Est-il prêt ? | est 已以 t 音结尾，不另加 -t- |

强调结构速查：

| 想强调 | 普通句 | 强调句 | 说明 |
| ------ | ------ | ------ | ---- |
| 主语 | Marie a appelé. | C'est Marie qui a appelé. | qui 作从句主语 |
| 直接宾语 | J'ai vu Marie. | C'est Marie que j'ai vue. | que 作 COD；注意过去分词可能配合 |
| 时间 | Je pars demain. | C'est demain que je pars. | que 引出被强调状语 |
| 地点 | Il travaille à Lyon. | C'est à Lyon qu'il travaille. | 介词保留 |
| 原因 | Je reste pour toi. | C'est pour toi que je reste. | 强调介词短语 |

### 3.10 常见语序错误速查

| 错误句 | 推荐改法 | 错因 | 记忆点 |
| ------ | -------- | ---- | ------ |
| Je français parle. | Je parle français. | 把宾语/补语放到动词前 | 默认 SVO |
| Moi parle français. | Je parle français. | 用重读代词 moi 作普通主语 | 普通主语用 je |
| Je pas comprends. | Je ne comprends pas. | 否定词位置错误 | ne...pas 夹变位动词 |
| Je ne veux le voir pas. | Je ne veux pas le voir. | pas 放错位置 | 否定夹住变位动词 veux，代词在不定式 voir 前 |
| Je le veux voir. | Je veux le voir. | 把代词放在错误动词前 | 代词靠近支配它的动词 |
| Tu vas où ? | 正确，口语 | 不是错误 | 口语可疑问词后置 |
| Où tu vas ? | Où vas-tu ? / Où est-ce que tu vas ? | 口语可用，但正式写作不推荐 | 正式用倒装或 est-ce que |
| Est-ce que viens-tu ? | Est-ce que tu viens ? | est-ce que 后仍用陈述语序 | 不要双重倒装 |
| Pourquoi est-ce que tu pars ? | 正确 | 中性疑问 | 疑问词 + est-ce que + 陈述语序 |
| Pourquoi pars-tu ? | 正确 | 正式疑问 | 疑问词 + 倒装 |
| Ne regarde-le pas. | Ne le regarde pas. | 否定命令中代词位置错误 | 否定命令代词前置 |
| Regarde le ! | Regarde-le ! | 肯定命令代词需连字符 | V-pronom |
| C'est Marie que a appelé. | C'est Marie qui a appelé. | 强调主语时关系词错 | 主语用 qui |
| C'est Marie qui j'ai vue. | C'est Marie que j'ai vue. | 强调直接宾语时关系词错 | COD 用 que |
| Il y a beaucoup des gens. | Il y a beaucoup de gens. | 数量表达后介词错误 | beaucoup de + 名词 |

## 4. 名词：性、数与名词短语（Noms, genre, nombre et groupe nominal）

法语名词的核心难点是 **性 genre** 和 **数 nombre**。名词本身决定阳性/阴性，冠词、限定词、形容词、某些代词和过去分词都要跟着它配合。实际学习时，不要只背 `table = 桌子`，而要把名词当成一个小短语来记：**une table**, **le problème**, **des informations importantes**。

### 4.1 名词分类总览

| 分类角度 | 类型 | 例子 | 语法影响 |
| -------- | ---- | ---- | -------- |
| 性 | 阳性 masculin | un livre, le temps | 冠词和形容词用阳性形式 |
| 性 | 阴性 féminin | une table, la vie | 冠词和形容词用阴性形式 |
| 数 | 单数 singulier | une idée | 限定词、形容词、动词按单数配合 |
| 数 | 复数 pluriel | des idées | 限定词、形容词、动词按复数配合 |
| 可数性 | 可数 nom comptable | un livre, deux livres | 可直接数，常用 un/deux/des |
| 可数性 | 不可数 nom non comptable | du lait, de l'eau | 常用部分冠词或数量结构 |
| 指称 | 普通名词 nom commun | ville, étudiant | 通常小写，需要限定词 |
| 指称 | 专有名词 nom propre | Paris, Marie, la France | 多数首字母大写，冠词规则特殊 |
| 意义 | 具体名词 nom concret | chaise, pomme | 指可感知对象 |
| 意义 | 抽象名词 nom abstrait | liberté, patience | 表概念、品质、状态 |
| 结构 | 简单名词 nom simple | maison | 一个词 |
| 结构 | 复合名词 nom composé | arc-en-ciel, grand-mère | 复数规则需单独判断 |

名词不是孤立出现，而是构成 **groupe nominal**：

| 名词短语 | 结构 | 说明 |
| -------- | ---- | ---- |
| un livre | 限定词 + 名词 | 最小可用名词短语 |
| un bon livre | 限定词 + 形容词 + 名词 | 前置形容词 |
| un livre intéressant | 限定词 + 名词 + 形容词 | 后置形容词 |
| un livre de grammaire | 限定词 + 名词 + de 短语 | 名词补语 |
| le livre que tu as acheté | 限定词 + 名词 + 关系从句 | 从句修饰名词 |

**实用原则**：看见一个法语名词，要同时问四件事：它的性是什么、数是什么、前面需要什么限定词、后面的修饰成分是否要配合或用介词连接。

### 4.2 阳性与阴性：规律、后缀和高频例外

名词性别必须记忆，但很多后缀有强倾向。下面是速查规律，不是绝对规则。

常见阳性后缀：

| 后缀/类型 | 常见性别 | 例子 | 注意 |
| --------- | -------- | ---- | ---- |
| -age | 多为阳性 | le village, le fromage, le voyage | la page, la plage, la cage 例外 |
| -ment | 阳性 | le gouvernement, le changement | 基本稳定 |
| -isme | 阳性 | le tourisme, le capitalisme | 学说、制度、倾向 |
| -eau | 阳性 | le bureau, le bateau | 复数多为 -eaux |
| -phone | 阳性 | le téléphone, le microphone | 工具/设备常见 |
| -scope | 阳性 | le microscope | 工具名 |
| -oir | 多为阳性 | le miroir, le couloir | la mémoire 是例外且意义不同 |
| -teur | 多为阳性 | le moteur, le facteur | 抽象名词 -tion 通常阴性 |
| 星期、月份、季节 | 多为阳性 | le lundi, janvier, le printemps | 月份通常不加冠词，但语法上按阳性处理 |
| 语言名 | 阳性 | le français, l'anglais | 学语言通常用阳性单数 |
| 树木名 | 多为阳性 | le chêne, le pommier | 少数需单独记 |
| 金属和化学元素 | 多为阳性 | le fer, l'or, le carbone | l'or 为阳性 |

常见阴性后缀：

| 后缀/类型 | 常见性别 | 例子 | 注意 |
| --------- | -------- | ---- | ---- |
| -tion, -sion | 阴性 | la nation, la décision | 极高频规律 |
| -té | 多为阴性 | la liberté, la beauté | le côté, l'été 例外 |
| -ette | 阴性 | la cigarette, la recette | 小称/物名常见 |
| -ie | 多为阴性 | la vie, la philosophie | le génie 例外 |
| -ure | 阴性 | la culture, la voiture | le murmure 例外 |
| -ence, -ance | 阴性 | la différence, la confiance | 基本稳定 |
| -esse | 阴性 | la jeunesse, la vitesse | 抽象品质 |
| -ade | 阴性 | la promenade, la salade | 有例外 |
| -aison | 阴性 | la maison, la saison | 基本稳定 |
| -oire | 多为阴性 | la mémoire, l'histoire | le territoire 例外 |
| 科学/学科名 -ique | 多为阴性 | la physique, la politique | le graphique 例外 |

高频性别必须单独记：

| 阳性名词 | 含义 | 阴性名词 | 含义 |
| -------- | ---- | -------- | ---- |
| le problème | 问题 | la solution | 解决办法 |
| le système | 系统 | la méthode | 方法 |
| le modèle | 模型、模范 | la règle | 规则 |
| le programme | 程序、计划 | la langue | 语言 |
| le monde | 世界 | la personne | 人 |
| le travail | 工作 | la question | 问题 |
| le choix | 选择 | la chose | 事情 |
| le temps | 时间、天气 | la fois | 次、回 |
| le pays | 国家 | la ville | 城市 |
| le cours | 课程 | la classe | 班级、课堂 |

### 4.3 人和职业名词的阴阳性

表示人和职业的名词通常可以按自然性别变化，但现代法语中职业阴性化有多种形式，实际使用受地区、正式程度和行业习惯影响。

| 阳性 | 阴性 | 例句 | 说明 |
| ---- | ---- | ---- | ---- |
| un étudiant | une étudiante | Elle est étudiante. | 常规加 -e |
| un ami | une amie | C'est une amie. | 发音可能不变，书写变化 |
| un employé | une employée | une employée expérimentée | 加 -e，形容词也配合 |
| un vendeur | une vendeuse | une vendeuse très connue | -eur -> -euse |
| un acteur | une actrice | une actrice française | -teur -> -trice 常见 |
| un directeur | une directrice | la directrice de l'école | 职务名 |
| un serveur | une serveuse | une serveuse sympathique | -eur -> -euse |
| un boulanger | une boulangère | une boulangère du quartier | -er -> -ère |
| un infirmier | une infirmière | une infirmière compétente | -ier -> -ière |
| un chanteur | une chanteuse | une chanteuse célèbre | 职业/身份 |

不变或特殊的人名词：

| 名词 | 性别用法 | 例句 | 注意 |
| ---- | -------- | ---- | ---- |
| une personne | 永远阴性 | C'est une personne très gentille. | 即使指男性，语法上仍阴性 |
| une victime | 永远阴性 | La victime est arrivée. | 指男性也用阴性 |
| un témoin | 通常阳性，也可按实际用法变化 | Elle est témoin. | 用法有变化，需看语境 |
| un médecin | 传统上常不变，现代可见 une médecin | Elle est médecin. | 法语区差异明显 |
| un professeur | 可见 une professeure / une professeur | Ma professeure est suisse. | 正式写作可按当地规范 |
| un auteur | 可见 une auteure / une autrice | une autrice contemporaine | autrice 越来越常见 |
| un écrivain | 可见 une écrivaine | une écrivaine connue | 现代常用 |
| un chef | 可见 une cheffe | la cheffe du projet | 法国现代用法常见 |

职业作表语时通常不加不定冠词，除非带修饰或强调身份：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| être + 职业 | Elle est médecin. | 中性说明职业 |
| être + un/une + 修饰名词 | C'est une médecin très connue. | 有形容词、关系从句等修饰时常加冠词 |
| devenir + 职业 | Il veut devenir ingénieur. | devenir 后职业也常无冠词 |
| travailler comme + 职业 | Elle travaille comme avocate. | comme 表“作为” |

### 4.4 名词复数规则

法语名词复数通常在书写上加 **-s**，但很多复数 -s 不发音，真正可听见复数常靠限定词、连音或形容词判断。

| 单数 | 复数 | 例子 | 说明 |
| ---- | ---- | ---- | ---- |
| 一般情况 | + -s | un livre -> des livres | 最常见 |
| -e 结尾 | + -s | une idée -> des idées | 只加 s |
| -s, -x, -z 结尾 | 不变 | un pays -> des pays | 书写不变 |
| -au, -eau, -eu | 多加 -x | un bateau -> des bateaux | pneu -> pneus 例外 |
| -al | 多变 -aux | un journal -> des journaux | bal -> bals 例外 |
| -ail | 多加 -s，少数 -aux | un détail -> des détails | travail -> travaux |
| -ou | 多加 -s，少数 -x | un trou -> des trous | bijoux, cailloux 等加 x |

常见不规则复数：

| 单数 | 复数 | 含义 | 记忆点 |
| ---- | ---- | ---- | ------ |
| un œil | des yeux | 眼睛 | 极高频特殊 |
| monsieur | messieurs | 先生们 | 称谓特殊 |
| madame | mesdames | 女士们 | 称谓特殊 |
| mademoiselle | mesdemoiselles | 小姐们 | 称谓特殊 |
| un ciel | des cieux / des ciels | 天空 | cieux 较文学或宗教，ciels 可指天空状态 |
| un aïeul | des aïeux / des aïeuls | 祖先/祖父母 | 意义有差别 |

复数发音提示：

| 形式 | 发音特点 | 例子 | 说明 |
| ---- | -------- | ---- | ---- |
| 名词末尾 -s | 通常不发音 | livres | 单靠名词听不出复数 |
| 限定词 les/des | 可听出复数 | les livres | 限定词承担复数标记 |
| 连音 | 可听出复数 | les amis | les amis 中 s 连成 z 音 |
| 形容词变化 | 有时可听出 | petits amis | petit/petits 多数听不出，beau/beaux 也需看限定词 |

### 4.5 不规则复数和单复数同形

有些名词单复数书写相同，因为单数已经以 -s, -x, -z 结尾。

| 单数 | 复数 | 说明 |
| ---- | ---- | ---- |
| un pays | des pays | -s 结尾不变 |
| un prix | des prix | -x 结尾不变 |
| une voix | des voix | -x 结尾不变 |
| un nez | des nez | -z 结尾不变 |
| un choix | des choix | -x 结尾不变 |
| un cours | des cours | -s 结尾不变 |
| un mois | des mois | -s 结尾不变 |

七个常见 -ou -> -oux：

| 单数 | 复数 | 含义 |
| ---- | ---- | ---- |
| un bijou | des bijoux | 首饰 |
| un caillou | des cailloux | 石子 |
| un chou | des choux | 卷心菜 |
| un genou | des genoux | 膝盖 |
| un hibou | des hiboux | 猫头鹰 |
| un joujou | des joujoux | 玩具 |
| un pou | des poux | 虱子 |

常见 -al -> -aux 与例外：

| 单数 | 复数 | 类型 |
| ---- | ---- | ---- |
| un journal | des journaux | 常规 -al -> -aux |
| un animal | des animaux | 常规 |
| un hôpital | des hôpitaux | 常规 |
| un cheval | des chevaux | 常规 |
| un travail | des travaux | -ail 特殊 |
| un bal | des bals | 例外，加 -s |
| un festival | des festivals | 例外，加 -s |
| un carnaval | des carnavals | 例外，加 -s |

### 4.6 复合名词复数

复合名词的复数取决于组成成分。现代拼写改革放宽了一些形式，但实际阅读中仍要掌握传统规则。

| 结构 | 复数倾向 | 例子 | 说明 |
| ---- | -------- | ---- | ---- |
| 名词 + 名词 | 两个可变或核心可变 | un chou-fleur -> des choux-fleurs | 视意义而定 |
| 名词 + 介词 + 名词 | 主要名词变 | un arc-en-ciel -> des arcs-en-ciel | 介词后的名词通常不变 |
| 形容词 + 名词 | 两者可变 | une grand-mère -> des grands-mères | 现代常见 grands-mères |
| 动词 + 名词 | 动词不变，名词按意义 | un porte-clés -> des porte-clés | porte 不变 |
| 副词/介词 + 名词 | 名词可变 | une arrière-boutique -> des arrière-boutiques | arrière 不变 |
| 固定外来词 | 常按普通名词加 s | un week-end -> des week-ends | 现代用法常规化 |

常见复合名词：

| 单数 | 复数 | 含义 | 注意 |
| ---- | ---- | ---- | ---- |
| un chef-d'œuvre | des chefs-d'œuvre | 杰作 | chef 变复数 |
| un arc-en-ciel | des arcs-en-ciel | 彩虹 | ciel 不变 |
| un timbre-poste | des timbres-poste | 邮票 | poste 作补语不变 |
| un porte-monnaie | des porte-monnaie | 钱包 | 传统不变 |
| un porte-clés | des porte-clés | 钥匙扣 | clés 本身复数 |
| une grand-mère | des grands-mères | 祖母 | 常见现代写法 |
| un après-midi | des après-midi | 下午 | 常不变，也可见 après-midis |

实用处理：遇到不确定的复合名词，优先查词典；写作中避免临时推导高风险形式。

### 4.7 可数、不可数与集合名词

法语比汉语更依赖“可数/不可数”区分。不可数名词不能直接用 `un/deux/des` 表示数量，常用部分冠词或数量短语。

| 类型 | 例子 | 自然表达 | 错误倾向 |
| ---- | ---- | -------- | -------- |
| 可数具体物 | livre, chaise, pomme | un livre, deux pommes | 可直接数 |
| 不可数物质 | eau, lait, pain, riz | de l'eau, du lait, un morceau de pain | 不能说 deux pains 表示“两片面包”，除非指两条/两份 |
| 抽象概念 | courage, patience, liberté | du courage, beaucoup de patience | 冠词选择随泛指/特指变化 |
| 集合名词 | famille, équipe, groupe | une famille, un groupe de touristes | 语法上可单数 |
| 总称类别 | les enfants, le français | Les enfants aiment jouer. | 法语常用冠词表类别 |

数量结构：

| 表达 | 后接形式 | 例句 | 说明 |
| ---- | -------- | ---- | ---- |
| beaucoup de | 名词 | beaucoup de travail | de 不随名词性数变化 |
| peu de | 名词 | peu d'argent | 元音前 de -> d' |
| un peu de | 不可数名词 | un peu de café | 一点 |
| assez de | 名词 | assez de temps | 足够 |
| trop de | 名词 | trop de bruit | 太多 |
| un morceau de | 物质/整体的一部分 | un morceau de fromage | 一块 |
| une bouteille de | 容器量 | une bouteille d'eau | 一瓶 |
| un groupe de | 集合 | un groupe d'étudiants | 一群 |

### 4.8 专有名词、国家城市名和语言名

专有名词通常首字母大写。人名和城市名多数不带冠词，国家名多带冠词并有性别。

| 类型 | 例子 | 冠词/性别 | 说明 |
| ---- | ---- | --------- | ---- |
| 人名 | Marie, Paul | 通常无冠词 | Marie arrive. |
| 城市名 | Paris, Tokyo, Lyon | 通常无冠词 | J'habite à Paris. |
| 国家阴性 | la France, la Chine | la | 多数 -e 结尾国家为阴性 |
| 国家阳性 | le Japon, le Canada | le | 非 -e 结尾常为阳性 |
| 国家复数 | les États-Unis, les Pays-Bas | les | 复数国家 |
| 大洲 | l'Europe, l'Asie | 多为阴性 | 用法近国家名 |
| 语言名 | le français, le japonais | 阳性 | J'apprends le français. |
| 国籍形容词 | français, japonaise | 配合名词 | une étudiante japonaise |

国家名性别和介词会影响表达：

| 地点 | 在/去 | 从……来 | 例句 |
| ---- | ----- | -------- | ---- |
| 阴性国家 | en | de | Elle va en France. / Elle vient de France. |
| 阳性元音开头国家 | en | d' | Il habite en Iran. / Il vient d'Iran. |
| 阳性辅音开头国家 | au | du | Je vais au Japon. / Je viens du Japon. |
| 复数国家 | aux | des | Il travaille aux États-Unis. / Il vient des États-Unis. |
| 城市 | à | de | Nous allons à Lyon. / Ils viennent de Lyon. |

语言、国籍、居民名：

| 中文 | 法语 | 说明 |
| ---- | ---- | ---- |
| 法语 | le français | 语言名，阳性 |
| 一个法国人 | un Français / une Française | 居民名，通常大写 |
| 法国的学生 | un étudiant français / une étudiante française | 形容词，小写并配合 |
| 日本 | le Japon | 国家名，阳性 |
| 日语 | le japonais | 语言名，小写 |
| 一个日本人 | un Japonais / une Japonaise | 居民名，大写 |

### 4.9 名词短语内部结构

名词短语以名词为中心，前后可以有多种修饰成分。分析时先找核心名词，再看限定词、形容词、介词短语、从句。

| 结构位置 | 成分 | 例子 | 功能 |
| -------- | ---- | ---- | ---- |
| 名词前 | 限定词 | ce livre, mon ami | 标记指称、所有、数量等 |
| 名词前 | 少数形容词 | un petit appartement | 常见短形容词可前置 |
| 核心 | 名词 | appartement | 短语中心 |
| 名词后 | 多数形容词 | un appartement moderne | 描述性质、类别 |
| 名词后 | 介词短语 | un appartement à Paris | 补充关系 |
| 名词后 | 关系从句 | un appartement qui donne sur la rue | 具体限定或补充说明 |

名词短语扩展示例：

| 层级 | 法语 | 说明 |
| ---- | ---- | ---- |
| 核心名词 | idée | 名词 |
| 加限定词 | une idée | 阴性单数 |
| 加形容词 | une bonne idée | bonne 前置并配合 |
| 加后置形容词 | une bonne idée simple | simple 后置 |
| 加介词短语 | une bonne idée de projet | de projet 说明类型 |
| 加从句 | une bonne idée que nous pouvons tester | que 从句进一步限定 |

名词短语中的配合：

| 被配合对象 | 需要配合的成分 | 例句 | 说明 |
| ---------- | -------------- | ---- | ---- |
| 名词性别 | 冠词 | la table, le bureau | 冠词体现性别 |
| 名词性数 | 形容词 | des idées intéressantes | intéressantes 阴性复数 |
| 名词数量 | 限定词 | ce livre, ces livres | ce/ces 随数变化 |
| 名词前置 COD | 过去分词 | les lettres que j'ai écrites | 高级配合，详见一致章 |

### 4.10 名词补语：de, à, en, pour

名词后面的介词短语常用来说明所属、内容、用途、材料、地点或关系。不要把所有“的”都机械翻成 de。

| 介词 | 常见关系 | 例子 | 说明 |
| ---- | -------- | ---- | ---- |
| de | 所属/来源 | le livre de Marie | Marie 的书 |
| de | 内容/主题 | un cours de français | 法语课 |
| de | 材料 | une table de bois | 木桌，较书面；也常用 en bois |
| de | 数量/整体 | un verre d'eau | 一杯水 |
| à | 用途/功能 | une machine à laver | 洗衣机 |
| à | 特征/配料 | une tarte aux pommes | 苹果派 |
| à | 地点/关联 | un appartement à Paris | 巴黎的一套公寓 |
| en | 材料/状态 | une robe en soie | 真丝连衣裙 |
| pour | 目的/对象 | un cadeau pour Marie | 给 Marie 的礼物 |
| avec | 附带特征 | une chambre avec balcon | 带阳台的房间 |
| sans | 缺少特征 | un café sans sucre | 不加糖的咖啡 |

de 与 à 的常见区别：

| 中文想法 | 推荐法语 | 说明 |
| -------- | -------- | ---- |
| 法语课 | un cours de français | de 表内容/学科 |
| 法国课 | un cours sur la France | sur 表主题“关于法国”更清楚 |
| 咖啡杯 | une tasse à café | à 表用途：用来喝咖啡的杯子 |
| 一杯咖啡 | une tasse de café | de 表内容物 |
| 洗衣机 | une machine à laver | à + infinitif 表用途 |
| 写字桌 | une table à écrire / un bureau | à 表用途，但 bureau 更自然 |
| 木桌 | une table en bois | en 表材料最常用 |
| Marie 的书 | le livre de Marie | de 表所属 |

### 4.11 名词性别改变意义的词

少数名词阳性和阴性都存在，但意义不同。它们不是简单的“男/女”变化，必须作为不同词记。

| 阳性 | 含义 | 阴性 | 含义 |

| le poste | 职位、岗位、设备 | la poste | 邮局、邮政 |
| le manche | 柄、把手 | la manche | 袖子，英吉利海峡 |
| le mémoire | 硕士论文、报告 | la mémoire | 记忆 |
| le critique | 评论家 | la critique | 批评、评论 |
| le physique | 体格、外貌 | la physique | 物理学 |
| le politique | 政治人物、政治领域 | la politique | 政治、政策 |
| le voile | 面纱、帆 | la voile | 帆船运动、帆 |
| le garde | 守卫 | la garde | 看守、监护、值班 |
| le capital | 资本 | la capitale | 首都 |

高频易混名词：

| 词 | 正确性别 | 例句 | 错误提醒 |
| -- | -------- | ---- | -------- |
| problème | 阳性 | un problème important | 不是 une problème |
| solution | 阴性 | une solution simple | 不是 un solution |
| information | 阴性 | une information utile | 英语 influence 易误导 |
| travail | 阳性 | un travail difficile | 复数 travaux 特殊 |
| personne | 阴性 | une personne âgée | 指男性也用阴性 |

| exemple | 阳性 | un exemple clair | 不是 une exemple |
| image | 阴性 | une image nette | 元音开头用 une image |
| argent | 阳性 | de l'argent | 不可数，阳性 |
| eau | 阴性 | de l'eau froide | eau 阴性，形容词阴性 |

### 4.12 名词常见错误速查

| 错误句 | 推荐改法 | 错因 | 记忆点 |
| ------ | -------- | ---- | ------ |
| J'ai problème. | J'ai un problème. | 可数单数名词缺限定词 | 法语普通名词通常不能裸用 |
| Une problème important. | Un problème important. | problème 是阳性 | 记 un problème |
| Le solution est simple. | La solution est simple. | solution 是阴性 | -tion 多阴性 |
| Des information importantes. | Des informations importantes. | 可数复数缺 -s | une information, des informations |
| Beaucoup des étudiants sont là. | Beaucoup d'étudiants sont là. | 数量表达后误用 des | beaucoup de + 名词 |
| Deux pains, s'il vous plaît. | Deux baguettes / deux morceaux de pain, s'il vous plaît. | pain 可表示面包整体或物质，需看实际单位 | 用具体单位更准确 |
| Je vais à France. | Je vais en France. | 国家介词错误 | 阴性国家用 en |
| Je viens de le Japon. | Je viens du Japon. | de + le 缩合 | de + le = du |
| J'apprends français. | J'apprends le français. | 语言名作宾语常带定冠词 | le français |
| Un étudiant Japonais. | Un étudiant japonais. | 国籍形容词不大写 | 居民名大写，形容词小写 |
| Une Français habite ici. | Une Française habite ici. | 居民名需按性别变化 | un Français, une Française |
| Les livre sont chers. | Les livres sont chers. | 复数名词缺 -s | 限定词、名词、动词一起看 |
| Des journals. | Des journaux. | -al 复数错误 | journal -> journaux |
| Des travails. | Des travaux. | travail 复数特殊 | un travail, des travaux |
| Une tasse à café pleine de thé. | Une tasse de thé / une tasse à café | à 表用途，de 表内容 | tasse à café 是咖啡杯，tasse de café 是一杯咖啡 |
| Une robe avec soie. | Une robe en soie. | 材料介词错误 | en + 材料最常用 |
| Le personne est gentil. | La personne est gentille. | personne 语法上阴性 | 即使指男性也按阴性配合 |
| Un bonne idée. | Une bonne idée. | idée 阴性，冠词和形容词都要配合 | une idée intéressante |

## 5. 冠词系统（Articles）

冠词是法语名词短语的入口。普通名词多数不能像汉语一样裸用，必须先说明它是**特指还是泛指、可数还是不可数、首次提及还是已知信息、肯定还是否定**。冠词错误会连带影响名词性数、缩合、代词替代和句子自然度。

### 5.1 冠词总览：défini, indéfini, partitif

法语核心冠词有三组：定冠词、不定冠词、部分冠词。它们不是简单对应中文“这个/一个/一些”，而是标记说话者怎样看待这个名词。

| 类型 | 形式 | 基本含义 | 典型场景 | 例句 |
| ---- | ---- | -------- | -------- | ---- |
| 定冠词 article défini | le, la, l', les | 已知、特指、类别整体 | 已提过、唯一对象、泛指类别 | J'aime le café. |
| 不定冠词 article indéfini | un, une, des | 一个/某个/一些 | 首次提及、非特指可数名词 | J'ai acheté un livre. |
| 部分冠词 article partitif | du, de la, de l', des | 一些/若干不可数部分 | 食物、液体、抽象量 | Je bois du café. |
| 零冠词 absence d'article | 无 | 不用冠词 | 职业表语、固定介词短语、标题 | Elle est médecin. |
| 否定后的 de | de, d' | 不再保留 un/des/du 等 | 否定数量或存在 | Je n'ai pas de voiture. |

冠词形式总表：

| 名词 | 定冠词 | 不定冠词 | 部分冠词 | 例子 |
| ---- | ------ | -------- | -------- | ---- |
| 阳性单数辅音开头 | le | un | du | le pain, un pain, du pain |
| 阴性单数辅音开头 | la | une | de la | la soupe, une soupe, de la soupe |
| 单数元音/h muet 开头 | l' | un/une | de l' | l'eau, une eau minérale, de l'eau |
| 复数 | les | des | des | les livres, des livres, des épinards |

**最重要的判断**：

| 问题 | 如果答案是 | 常用冠词 | 例句 |
| ---- | ---------- | -------- | ---- |
| 听话人知道是哪一个吗？ | 知道/已提过/唯一 | le, la, l', les | Ferme la porte. |
| 第一次提到一个可数对象吗？ | 是 | un, une, des | Il y a un problème. |
| 说的是不可数的一部分吗？ | 是 | du, de la, de l' | Je voudrais de l'eau. |
| 说的是一整个类别吗？ | 是 | le, la, l', les | Le français est difficile. |
| 是否定“有/吃/买”等数量吗？ | 是 | de, d' | Je ne bois pas de café. |

### 5.2 定冠词 le, la, l', les

定冠词用于说话人认为对象已经可识别：前文提过、情境中唯一、常识中唯一、或表示整个类别。

| 形式 | 用于 | 例子 | 说明 |
| ---- | ---- | ---- | ---- |
| le | 阳性单数 | le livre, le problème | 辅音或 h aspiré 前 |
| la | 阴性单数 | la table, la question | 辅音或 h aspiré 前 |
| l' | 元音/h muet 开头单数 | l'homme, l'idée, l'eau | 阳性/阴性都可省音 |
| les | 复数 | les livres, les idées | 阴阳性复数同形 |

定冠词常见用法：

| 用法 | 例句 | 说明 |
| ---- | ---- | ---- |
| 已提过 | J'ai acheté un livre. Le livre est cher. | 第二次提到变已知 |
| 情境中唯一 | Ferme la fenêtre. | 房间里双方知道是哪扇窗 |
| 世界/常识唯一 | le soleil, la lune | 唯一对象 |
| 类别整体 | Le café est amer. | 咖啡这种东西 |
| 抽象概念泛指 | La liberté est importante. | 抽象名词整体 |
| 语言名 | J'apprends le français. | 语言作名词常用定冠词 |
| 身体部位 | Il a mal à la tête. | 法语常不用物主限定词 |
| 日期/周期习惯 | Le lundi, je travaille à la maison. | 每周一；具体日期另讲 |

定冠词 vs 指示限定词：

| 想表达 | 法语 | 说明 |
| ------ | ---- | ---- |
| 那本/这本双方已知的书 | le livre | 定冠词只标记可识别 |
| 这本书、那本书 | ce livre | 指示限定词有指向性 |
| 我喜欢这部电影 | J'aime ce film. | 强调“这部” |
| 我喜欢电影 | J'aime le cinéma. / J'aime les films. | 泛指类别 |

### 5.3 不定冠词 un, une, des

不定冠词用于首次提及、非特指、可数对象。单数是 `un/une`，复数是 `des`。

| 形式 | 用于 | 例子 | 说明 |
| ---- | ---- | ---- | ---- |
| un | 阳性单数可数名词 | un livre, un étudiant | 一个/某个 |
| une | 阴性单数可数名词 | une idée, une voiture | 一个/某个 |
| des | 复数可数名词 | des livres, des idées | 一些；英语 often 无对应词 |

不定冠词常见用法：

| 用法 | 例句 | 说明 |
| ---- | ---- | ---- |
| 首次提及 | Il y a un problème. | 先引入一个对象 |
| 非特指对象 | Je cherche un appartement. | 不指定哪一套 |
| 分类身份 | C'est un ami. | “是一个……” |
| 复数若干 | J'ai acheté des pommes. | 买了一些苹果 |
| 评价中的例子 | C'est une bonne idée. | idea 是可数单数，需要 une |

`des` 的两个常见来源：

| 形式 | 来源 | 例句 | 说明 |
| ---- | ---- | ---- | ---- |
| des = 不定冠词复数 | de + les 不是这里的来源 | J'ai des amis. | “一些朋友” |
| des = de + les 缩合 | 介词 de + 定冠词 les | Je parle des amis de Paul. | “Paul 的那些朋友” |

不定冠词与数量词：

| 表达 | 例句 | 说明 |
| ---- | ---- | ---- |
| un/une | une question | 一个可数单数 |
| deux/trois 等数字 | deux questions | 数字本身作限定，不再用 des |
| plusieurs | plusieurs questions | “好几个”，不加 des |
| quelques | quelques questions | “几个”，不加 des |
| beaucoup de | beaucoup de questions | 数量副词后用 de |

### 5.4 部分冠词 du, de la, de l', des

部分冠词用于不可数名词或当作不可数使用的名词，表示“取其中一部分/一些量”。它常见于食物、饮料、物质、天气、抽象品质和活动。

| 形式 | 用于 | 例子 | 说明 |
| ---- | ---- | ---- | ---- |
| du | 阳性单数不可数 | du pain, du café | de + le 缩合成 du |
| de la | 阴性单数不可数 | de la soupe, de la musique | 不缩合 |
| de l' | 元音/h muet 开头单数 | de l'eau, de l'argent | 阳性/阴性都可 |
| des | 复数名词作部分/若干 | des épinards, des pâtes | 形式同不定复数 |

部分冠词常见用法：

| 语义 | 例句 | 说明 |
| ---- | ---- | ---- |
| 食物/饮料 | Je bois du thé. | 喝一些茶 |
| 物质 | Il y a de l'eau sur la table. | 有一些水 |
| 抽象品质 | Elle a du courage. | 有勇气 |
| 活动 | Il fait du sport. | 做运动 |
| 天气/自然现象 | Il y a du vent. | 有风 |
| 音乐/乐器活动 | Elle écoute de la musique. | 听音乐 |

部分冠词 vs 定冠词：

| 句子 | 含义 | 说明 |
| ---- | ---- | ---- |
| Je bois du café. | 我喝咖啡/喝一些咖啡。 | 当前摄入或非特定量 |
| J'aime le café. | 我喜欢咖啡。 | 咖啡作为类别 |
| Elle mange du fromage. | 她吃一些奶酪。 | 一部分 |
| Elle aime le fromage. | 她喜欢奶酪。 | 类别整体 |
| Il fait du piano. | 他弹钢琴/学钢琴。 | 活动 |
| Le piano est difficile. | 钢琴这种乐器很难。 | 类别 |

部分冠词 vs 不定冠词：

| 名词用法 | 例句 | 说明 |
| -------- | ---- | ---- |
| 可数一个 | Je voudrais un café. | 一杯咖啡，点单中常用 |
| 不可数量 | Je voudrais du café. | 一些咖啡 |
| 可数一条/一个面包 | J'achète un pain. | 一条面包或一种面包 |
| 不可数面包 | Je mange du pain. | 吃面包这种食物的一部分 |

### 5.5 否定后的 de / d'

否定句中，如果否定的是数量、存在或宾语名词，`un/une/des/du/de la/de l'` 通常变成 `de/d'`。

| 肯定句 | 否定句 | 说明 |
| ------ | ------ | ---- |
| J'ai une voiture. | Je n'ai pas de voiture. | un/une -> de |
| Il y a des problèmes. | Il n'y a pas de problèmes. | des -> de |
| Je bois du café. | Je ne bois pas de café. | du -> de |
| Elle mange de la viande. | Elle ne mange pas de viande. | de la -> de |
| Nous avons de l'argent. | Nous n'avons pas d'argent. | 元音前 de -> d' |

不变成 de 的重要情况：

| 情况 | 例句 | 说明 |
| ---- | ---- | ---- |
| 否定的是定冠词类别 | Je n'aime pas le café. | “不喜欢咖啡”不是“没有咖啡” |
| être 后表身份/定义 | Ce n'est pas un problème. | être 后通常保留 un/une/des |
| 对比强调“不是一个，而是另一个” | Ce n'est pas une erreur, c'est un choix. | 保留不定冠词 |
| ne...que 限制 | Je n'ai qu'un frère. | ne...que 不是普通否定 |
| 固定数量 | Il n'a pas les trois livres. | 指那三本，不是零数量 |

否定后 de 的判断：

| 问题 | 例句 | 冠词 |
| ---- | ---- | ---- |
| 是否表示“没有任何一个/一些”？ | Je n'ai pas de stylo. | de |
| 是否表示“不吃/不喝某种量”？ | Je ne bois pas de lait. | de |
| 是否表示“不喜欢这个类别”？ | Je n'aime pas le lait. | le |
| 是否是 être 后定义？ | Ce n'est pas une solution. | une |
| 是否有形容词导致语义仍需冠词？ | Ce n'est pas un petit problème. | un 常保留 |

### 5.6 泛指、特指和首次提及

冠词选择的核心不是中文有没有“一个/这个”，而是信息状态：这个名词是**第一次出现**、**已知特指**，还是**整个类别**。

| 信息状态 | 冠词 | 例句 | 说明 |
| -------- | ---- | ---- | ---- |
| 首次提及可数单数 | un/une | J'ai vu un chien. | 引入新对象 |
| 再次提及 | le/la/l' | Le chien était noir. | 已知对象 |
| 首次提及复数 | des | J'ai acheté des fleurs. | 一些花 |
| 再次提及复数 | les | Les fleurs sont pour toi. | 那些花 |
| 泛指类别单数 | le/la/l' | Le chien est fidèle. | 狗这种动物 |
| 泛指类别复数 | les | Les chiens sont fidèles. | 狗这一类，复数角度 |
| 泛指不可数 | le/la/l' | Le lait est bon pour la santé. | 牛奶这种东西 |
| 部分数量 | du/de la/de l' | Je bois du lait. | 喝一些牛奶 |

同一名词的冠词变化：

| 法语 | 中文近似 | 语义 |
| ---- | -------- | ---- |
| J'ai acheté un livre. | 我买了一本书。 | 首次提及，可数单数 |
| Le livre est intéressant. | 这本/那本书很有趣。 | 已知特指 |
| J'aime les livres. | 我喜欢书。 | 泛指复数类别 |
| Le livre est un objet culturel. | 书是一种文化物品。 | 泛指单数类别 |
| Je lis des livres français. | 我读一些法语书。 | 不定复数 |

### 5.7 抽象名词、语言、学科和类别泛指

抽象名词、语言名、学科名和类别名在泛指时常用定冠词。汉语学习者容易省略冠词。

| 类型 | 泛指表达 | 例句 | 说明 |
| ---- | -------- | ---- | ---- |
| 抽象概念 | la liberté, le courage | La liberté a un prix. | 概念整体 |
| 品质 | la patience, l'intelligence | La patience est nécessaire. | 抽象品质 |
| 语言 | le français, l'anglais | Le français est une langue romane. | 语言作名词 |
| 学科 | la physique, la grammaire | La grammaire aide à écrire clairement. | 学科整体 |
| 艺术/活动 | la musique, le cinéma | J'aime le cinéma. | 类别/艺术形式 |
| 动物/植物类别 | le chat, les chats | Le chat est indépendant. | 单数或复数泛指都可 |

抽象名词也可以用部分冠词，表示“某种量/表现”：

| 泛指整体 | 部分/表现 | 说明 |
| -------- | --------- | ---- |
| Le courage est important. | Il a du courage. | 有勇气 |
| La patience est utile. | Il faut de la patience. | 需要一些耐心 |
| La chance joue un rôle. | Elle a de la chance. | 她有运气 |
| L'imagination est essentielle. | Il a de l'imagination. | 有想象力 |

语言名常见结构：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| apprendre + le/la langue | J'apprends le français. | 学法语 |
| parler + 语言 | Je parle français. | parler 后语言常裸用 |
| en + 语言 | écrire en français | 用法语写 |
| cours de + 语言 | un cours de français | 法语课 |
| traduction en/de | une traduction en français | 译成法语 |

### 5.8 身体部位与定冠词

法语说身体部位时，常用定冠词而不是物主限定词，因为所有者通常由主语、间接宾语代词或上下文表达。

| 中文 | 法语 | 说明 |
| ---- | ---- | ---- |
| 我头疼。 | J'ai mal à la tête. | à + la |
| 他洗手。 | Il se lave les mains. | 反身代词 se 已说明是谁的手 |
| 她闭上眼睛。 | Elle ferme les yeux. | 用 les，不用 ses |
| 我摔断了腿。 | Je me suis cassé la jambe. | me 说明所有者 |
| 医生检查我的喉咙。 | Le médecin me regarde la gorge. | me 表“我的” |

身体部位结构：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| avoir mal à + 定冠词 | J'ai mal au dos. | à + le = au |
| se laver + 定冠词 | Elle se lave le visage. | 反身动作 |
| se casser + 定冠词 | Il s'est cassé le bras. | 身体损伤 |
| fermer/ouvrir + 定冠词 | Ouvre les yeux. | 身体部位作 COD |
| prendre par + 定冠词 | Il l'a pris par la main. | 抓住某人某部位 |

什么时候用物主限定词：

| 用法 | 例句 | 说明 |
| ---- | ---- | ---- |
| 强调所属 | Mes mains sont froides. | 主语就是身体部位 |
| 对比 | Elle a levé sa main, pas la mienne. | 强调“她的” |
| 非动作对象 | Ses yeux sont bleus. | 描述特征 |
| 歌词/文学/强调 | Mon cœur est triste. | 风格性选择 |

### 5.9 职业、身份和国籍前的冠词

职业、身份、国籍在法语中有两套常见用法：作名词时常有冠词，作表语说明职业/身份时通常无冠词。

| 结构 | 例句 | 冠词规则 |
| ---- | ---- | -------- |
| être + 职业 | Elle est médecin. | 通常无冠词 |
| devenir + 职业 | Il veut devenir ingénieur. | 通常无冠词 |
| travailler comme + 职业 | Il travaille comme serveur. | 通常无冠词 |
| c'est + 职业名词 | C'est un médecin. | 常有冠词 |
| être + 修饰职业名词 | Elle est une excellente médecin. | 有形容词评价时可加冠词 |
| 职业作普通名词 | Le médecin arrive. | 指某个医生，有冠词 |

国籍表达：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| être + 国籍形容词 | Elle est française. | 形容词，小写，无冠词 |
| c'est + 居民名词 | C'est une Française. | 名词，大写，有冠词 |
| un/une + 居民名词 | un Japonais, une Japonaise | 指一个人 |
| 国籍形容词修饰名词 | un étudiant japonais | 小写，配合 |

身份名词是否加冠词：

| 场景 | 例句 | 说明 |
| ---- | ---- | ---- |
| 说明职业 | Je suis professeur. | 无冠词常见 |
| 具体识别 | C'est le professeur de Paul. | 特指，用定冠词 |
| 首次介绍某人身份 | C'est un ami. | 名词性识别，用不定冠词 |
| 亲属/身份特指 | C'est mon frère. | 物主限定词代替冠词 |

### 5.10 à/de 与定冠词缩合：au, aux, du, des

介词 `à` 和 `de` 遇到定冠词 `le/les` 必须缩合。遇到 `la/l'` 不缩合。

| 组合 | 结果 | 例句 | 说明 |
| ---- | ---- | ---- | ---- |
| à + le | au | Je vais au cinéma. | 必须缩合 |
| à + les | aux | Il parle aux étudiants. | 必须缩合 |
| à + la | à la | Elle va à la banque. | 不缩合 |
| à + l' | à l' | Il va à l'école. | 不缩合 |
| de + le | du | Je viens du Japon. | 必须缩合 |
| de + les | des | Il parle des étudiants. | 必须缩合 |
| de + la | de la | Je viens de la gare. | 不缩合 |
| de + l' | de l' | Il vient de l'école. | 不缩合 |

`du/des` 可能有不同来源：

| 形式 | 来源 | 例句 | 判断 |
| ---- | ---- | ---- | ---- |
| du | 部分冠词 | Je bois du café. | 表一些量 |
| du | de + le | Je viens du café près de la gare. | 表介词 de + 定冠词 |
| des | 不定冠词复数 | J'ai des amis. | 一些 |
| des | de + les | Je parle des amis de Paul. | 特指那些朋友 |

地名缩合：

| 名词 | 介词结构 | 例句 | 说明 |
| ---- | -------- | ---- | ---- |
| le Japon | au / du | Je vais au Japon. / Je viens du Japon. | 阳性辅音国家 |
| les États-Unis | aux / des | Il habite aux États-Unis. | 复数国家 |
| la France | en / de | Elle va en France. | 国家名不总用 à/de + 冠词 |
| le cinéma | au / du | Je vais au cinéma. | 普通地点名词 |

### 5.11 零冠词场景

零冠词不是“随便省略”，而是某些结构中名词不需要 article。要把这些结构作为固定模式记。

| 场景 | 例句 | 说明 |
| ---- | ---- | ---- |
| être/devenir + 职业 | Elle est avocate. | 说明职业 |
| parler + 语言 | Je parle chinois. | parler 后语言常裸用 |
| en + 材料/语言/交通方式 | en bois, en français, en train | en 结构常无冠词 |
| sans + 抽象/不可数/泛指名词 | sans sucre, sans difficulté | 表“无……” |
| avec + 抽象方式 | avec plaisir, avec attention | 固定表达 |
| de + 学科/内容 | un cours de français | 内容名词无冠词 |
| 标题、标签、菜单 | Entrée, Sortie, Grammaire française | 标题式省略 |
| 固定搭配 | avoir faim, avoir peur, prendre soin | 需逐个记 |

常见固定零冠词表达：

| 表达 | 含义 | 例句 |
| ---- | ---- | ---- |
| avoir faim | 饿 | J'ai faim. |
| avoir soif | 渴 | Tu as soif ? |
| avoir peur | 害怕 | Elle a peur. |
| avoir besoin de | 需要 | J'ai besoin d'aide. |
| faire attention | 注意 | Fais attention. |
| prendre soin de | 照顾 | Il prend soin de sa mère. |
| par hasard | 偶然 | Je l'ai rencontré par hasard. |
| en général | 一般来说 | En général, c'est vrai. |
| à pied | 步行 | Je vais au bureau à pied. |
| sans doute | 也许/无疑 | Il viendra sans doute. |

零冠词 vs 有冠词：

| 无冠词 | 有冠词 | 区别 |
| ------ | ------ | ---- |
| Elle est médecin. | C'est un médecin. | 表语职业 vs 名词识别 |
| Je parle français. | J'apprends le français. | parler + 语言 vs apprendre + 语言名 |
| un cours de français | le français est utile | 内容补语 vs 语言整体 |
| sans sucre | le sucre est cher | 无糖 vs 糖这种东西 |
| en train | dans le train | 交通方式 vs 在火车里 |

### 5.12 冠词选择流程

实际写句子时，可以按下面顺序判断。不要先问中文有没有“的/一个/一些”，要先问法语名词的语法环境。

| 步骤 | 问题 | 选择 | 例句 |
| ---- | ---- | ---- | ---- |
| 1 | 名词是否在固定零冠词结构中？ | 零冠词 | Elle est médecin. |
| 2 | 是否已有其他限定词？ | 不再加冠词 | mon livre, ce livre, trois livres |
| 3 | 是否是介词 à/de + 定冠词？ | 缩合 au/aux/du/des | au cinéma, des enfants de Paul |
| 4 | 是否是否定数量/存在？ | de/d' | pas de problème |
| 5 | 是否泛指整个类别？ | le/la/l'/les | J'aime le café. |
| 6 | 是否特指/已知？ | le/la/l'/les | La porte est ouverte. |
| 7 | 是否首次提及可数对象？ | un/une/des | J'ai une question. |
| 8 | 是否不可数的一部分？ | du/de la/de l' | Je voudrais de l'eau. |

快速对照：

| 想表达 | 法语模板 | 例句 |
| ------ | -------- | ---- |
| 有一个问题 | il y a + un/une | Il y a un problème. |
| 没有问题 | il n'y a pas de | Il n'y a pas de problème. |
| 喜欢某类别 | aimer + le/la/les | J'aime les chats. |
| 吃/喝一些 | manger/boire + du/de la/de l' | Je bois de l'eau. |
| 学某语言 | apprendre + le/la | J'apprends le japonais. |
| 说某语言 | parler + 零冠词 | Je parle japonais. |
| 职业身份 | être + 零冠词 | Je suis étudiant. |
| 具体某职业者 | un/le + 职业名词 | C'est un étudiant. |

### 5.13 冠词常见错误速查

| 错误句 | 推荐改法 | 错因 | 记忆点 |
| ------ | -------- | ---- | ------ |
| J'aime café. | J'aime le café. | 泛指类别缺定冠词 | 喜欢某类东西用 le/la/les |
| Je bois le café. | Je bois du café. | 把部分量误作类别/特指 | 喝一些咖啡用 du |
| J'ai acheté livre. | J'ai acheté un livre. | 可数单数缺冠词 | 单数普通名词通常要限定 |
| J'ai des trois livres. | J'ai trois livres. | 数字前误加 des | 数字本身限定名词 |
| Beaucoup des gens sont ici. | Beaucoup de gens sont ici. | 数量表达后误用 des | beaucoup de + 名词 |
| Je n'ai pas une voiture. | Je n'ai pas de voiture. | 否定数量未变 de | pas de + 名词 |
| Je n'aime pas de café. | Je n'aime pas le café. | 否定喜好类别误用 de | aimer 否定仍可用定冠词 |
| Ce n'est pas de problème. | Ce n'est pas un problème. | être 后定义误用 de | être 后常保留 un/une |
| Je vais à le cinéma. | Je vais au cinéma. | à + le 未缩合 | à + le = au |
| Je parle de les enfants. | Je parle des enfants. | de + les 未缩合 | de + les = des |
| Je vais en le Japon. | Je vais au Japon. | 国家介词错误 | 阳性辅音国家用 au |
| J'apprends français. | J'apprends le français. | 学语言缺定冠词 | apprendre le français |
| Je parle de français. | Je parle français. | 把语言名误放进 de 短语 | parler + 语言通常零冠词 |
| Elle est une médecin. | Elle est médecin. | 职业表语多余冠词 | être + 职业常无冠词 |
| C'est médecin. | C'est un médecin. | c'est 后名词识别缺冠词 | c'est + un/une + 名词 |
| Il se lave ses mains. | Il se lave les mains. | 身体部位误用物主 | 反身代词 + 定冠词 |
| J'ai mal à ma tête. | J'ai mal à la tête. | 身体疼痛结构错误 | avoir mal à + 定冠词 |
| Une tasse à café. | Une tasse de café. | 若想说“一杯咖啡”，介词错 | à 表用途，de 表内容 |
| Un cours du français. | Un cours de français. | 内容补语误用定冠词缩合 | cours de + 学科/语言 |
| Sans le sucre, s'il vous plaît. | Sans sucre, s'il vous plaît. | 固定零冠词结构 | sans + 泛指名词 |

## 6. 限定词与数量表达（Déterminants et quantificateurs）

限定词放在名词前，决定这个名词短语的指称、数量、所属或范围。它们和冠词一样占据名词前的“限定位置”，所以很多限定词不能和冠词直接叠加：可以说 **mon livre**, **ce livre**, **trois livres**, **beaucoup de livres**，不能说 **le mon livre** 或 **ce mon livre**。

### 6.1 限定词总览

| 类型 | 法语名称 | 常见形式 | 功能 | 例子 |
| ---- | -------- | -------- | ---- | ---- |
| 冠词 | article | le, un, du | 标记特指、不定、部分量 | le livre, un livre |
| 指示限定词 | déterminant démonstratif | ce, cet, cette, ces | 这/那，指向对象 | ce livre, cette idée |
| 物主限定词 | déterminant possessif | mon, ton, son, notre, votre, leur | 我的、你的、他的等 | mon livre, leurs enfants |
| 数词限定词 | déterminant numéral | un, deux, trois, premier | 数量或顺序 | deux jours, le premier jour |
| 不定限定词 | déterminant indéfini | chaque, tout, plusieurs, quelques | 每个、所有、几个、若干 | chaque jour, plusieurs idées |
| 否定限定词 | déterminant négatif | aucun, nul, pas un | 没有任何一个 | aucun problème |
| 数量表达 | quantificateur | beaucoup de, peu de, assez de | 多、少、足够 | beaucoup de temps |

限定词的基本位置：

| 结构 | 例子 | 说明 |
| ---- | ---- | ---- |
| 限定词 + 名词 | ce livre | 最小名词短语 |
| 限定词 + 形容词 + 名词 | ces petits livres | 前置形容词在限定词后 |
| 限定词 + 名词 + 形容词 | trois livres intéressants | 后置形容词跟名词配合 |
| 数量表达 + de + 名词 | beaucoup de livres | 数量表达后通常用 de |
| 限定词 + 名词 + de 短语 | mon livre de grammaire | de 短语在名词后 |

互斥原则：

| 错误叠加 | 正确表达 | 原因 |
| -------- | -------- | ---- |
| le mon livre | mon livre | 物主限定词已经限定名词 |
| ce le livre | ce livre | 指示限定词和定冠词不能直接并列 |
| des plusieurs idées | plusieurs idées | plusieurs 本身限定复数名词 |
| les tous étudiants | tous les étudiants | tout 作总量词时位置特殊 |
| beaucoup des livres | beaucoup de livres | 数量表达后用 de |

### 6.2 指示限定词 ce, cet, cette, ces

指示限定词相当于“这/那”，用于把对象指给听话人、承接上下文、或表达评价色彩。形式随名词性数和发音环境变化。

| 形式 | 用于 | 例子 | 说明 |
| ---- | ---- | ---- | ---- |
| ce | 阳性单数辅音或 h aspiré 前 | ce livre, ce héros | 这个/那个 |
| cet | 阳性单数元音或 h muet 前 | cet homme, cet ami | 便于发音 |
| cette | 阴性单数 | cette idée, cette femme | 不因元音变 cet |
| ces | 复数 | ces livres, ces idées | 阴阳性复数同形 |

用法速查：

| 用法 | 例句 | 说明 |
| ---- | ---- | ---- |
| 指现场对象 | Regarde cette voiture. | 看这辆车 |
| 承接上文 | Ce problème est important. | 上文提到的问题 |
| 对比选择 | Je prends ce livre, pas celui-là. | 这个而不是那个 |
| 时间表达 | ce matin, cette semaine, cette année | 今天早上、本周、今年 |
| 评价色彩 | Cette histoire est incroyable. | 可带情绪评价 |

指示限定词 vs 指示代词：

| 类型 | 例子 | 说明 |
| ---- | ---- | ---- |
| 指示限定词 | ce livre | 后面必须接名词 |
| 指示代词 | celui-ci, celle-là | 自己代替名词 |
| 错误 | ce est intéressant | ce 不能直接作这种主语 |
| 正确 | C'est intéressant. | ce 在 c'est 中作代词 |

常见搭配：

| 表达 | 含义 | 例句 |
| ---- | ---- | ---- |
| ce matin | 今天早上 | Je pars ce matin. |
| cet après-midi | 今天下午 | On se voit cet après-midi. |
| ce soir | 今晚 | Je travaille ce soir. |
| cette nuit | 今夜、昨夜，视语境 | Il a plu cette nuit. |
| ces jours-ci | 最近这些天 | Je suis occupé ces jours-ci. |

### 6.3 物主限定词 mon, ton, son, notre, votre, leur

物主限定词表达所属关系，但形式首先由**被拥有的名词**的性数决定，不由拥有者的自然性别决定。

| 拥有者 | 阳性单数 | 阴性单数 | 复数 | 例子 |
| ------ | -------- | -------- | ---- | ---- |
| je | mon | ma | mes | mon livre, ma table, mes amis |
| tu | ton | ta | tes | ton idée, ta voiture, tes livres |
| il/elle/on | son | sa | ses | son frère, sa sœur, ses enfants |
| nous | notre | notre | nos | notre maison, nos voisins |
| vous | votre | votre | vos | votre nom, vos questions |
| ils/elles | leur | leur | leurs | leur fils, leurs filles |

元音或 h muet 前，阴性单数也用 `mon/ton/son`：

| 中文 | 法语 | 说明 |
| ---- | ---- | ---- |
| 我的朋友，女性 | mon amie | amie 阴性，但元音开头 |
| 你的想法 | ton idée | idée 阴性元音开头 |
| 他的/她的学校 | son école | école 阴性元音开头 |
| 我的历史 | mon histoire | h muet，按元音处理 |

`son/sa/ses` 不等于英语 his/her：

| 法语 | 可能含义 | 如何消除歧义 |
| ---- | -------- | ------------ |
| son livre | 他的书、她的书、它的书 | le livre de Paul / le livre de Marie |
| sa maison | 他的房子、她的房子 | sa maison à elle, sa maison à lui |
| ses enfants | 他的孩子、她的孩子 | ses enfants à lui / à elle |

物主限定词常见用法：

| 用法 | 例句 | 说明 |
| ---- | ---- | ---- |
| 所有关系 | C'est mon ordinateur. | 我的电脑 |
| 亲属关系 | Son père est médecin. | 他的/她的父亲 |
| 身体特征描述 | Ses yeux sont bleus. | 描述特征时可用物主 |
| 固定个人信息 | votre nom, votre adresse | 表格、礼貌询问 |
| 习惯性所有 | Je prends mon petit déjeuner. | 固定说法 |

### 6.4 数词限定词

数词可以直接限定名词。基数词表示数量，序数词表示顺序。数字细节会在第 29 章展开，本节只处理它们作为限定词时的语法。

| 类型 | 形式 | 例子 | 说明 |
| ---- | ---- | ---- | ---- |
| 基数词 | un, deux, trois | deux livres | 表数量 |
| 序数词 | premier, deuxième, troisième | le premier jour | 表顺序 |
| 倍数/分数 | double, moitié, tiers | la moitié du temps | 数量结构 |
| 大约数量 | une dizaine de, une centaine de | une dizaine de personnes | 约十个/约一百个 |

基数词用法：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| 数字 + 复数名词 | trois livres | 不加 des |
| un/une + 单数名词 | un jour, une heure | un/une 同时是数字和不定冠词 |
| zéro + 名词 | zéro faute / zéro défaut | 常见固定式，名词可单数 |
| 数字 + ans | Elle a vingt ans. | 年龄用 avoir |
| 数字 + heures | Il est trois heures. | 时间表达 |

序数词用法：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| le/la + 序数词 + 名词 | le premier jour | 通常有定冠词 |
| premier/première | la première fois | premier 随性数变化 |
| deuxième / second | le deuxième chapitre | second 常用于两者中的第二个 |
| 序数词作名词 | le premier, la troisième | 可代替名词 |

数字后不用冠词：

| 错误 | 正确 | 原因 |
| ---- | ---- | ---- |
| des deux livres | deux livres | 表数量时数字已限定名词 |
| les trois livres | les trois livres | 正确，但含义是“那三本书” |
| mes deux amis | mes deux amis | 物主 + 数字可以共现 |
| ces trois questions | ces trois questions | 指示 + 数字可以共现 |

### 6.5 chaque, tout, tous, toute, toutes

`chaque` 表“每一个”，只接单数名词；`tout` 系列可表“全部、整个、每个”，形式和位置要特别注意。

`chaque`：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| chaque + 单数名词 | chaque jour | 每一天 |
| chaque + 名词作主语 | Chaque étudiant doit répondre. | 动词用单数 |
| chaque + fois | chaque fois | 每次 |
| chacun/chacune | Chacun a son avis. | 这是代词，不直接接名词 |

`tout` 作限定词：

| 形式 | 用于 | 例子 | 含义 |
| ---- | ---- | ---- | ---- |
| tout | 阳性单数 | tout le monde, tout le temps | 整个、全部 |
| toute | 阴性单数 | toute la journée | 一整天 |
| tous | 阳性复数 | tous les jours | 每天、所有日子 |
| toutes | 阴性复数 | toutes les semaines | 每周、所有周 |

`tout` 的三种常见结构：

| 结构 | 例句 | 含义 |
| ---- | ---- | ---- |
| tout + 定冠词 + 名词 | tout le livre | 整本书 |
| tous/toutes + 定冠词 + 复数名词 | tous les étudiants | 所有学生 |
| tout + 无冠词固定表达 | tout à fait, tout de suite | 固定副词短语 |

易混对比：

| 表达 | 含义 | 例句 |
| ---- | ---- | ---- |
| chaque jour | 每一天，强调逐个 | Chaque jour est différent. |
| tous les jours | 每天，强调频率 | Je travaille tous les jours. |
| tout le jour | 整个白天，较少用 | Il a plu tout le jour. |
| toute la journée | 一整天 | J'ai travaillé toute la journée. |
| tout le monde | 大家、所有人 | Tout le monde est là. |

### 6.6 plusieurs, quelques, certain, divers

这些限定词表达不精确数量或不确定范围，通常直接放在复数名词前，不再加冠词。

| 限定词 | 含义 | 例句 | 说明 |
| ------ | ---- | ---- | ---- |
| plusieurs | 好几个、若干 | plusieurs questions | 数量多于 quelques，直接接复数 |
| quelques | 几个、一些 | quelques minutes | 数量少，不精确 |
| certains / certaines | 某些 | certains étudiants | 表部分成员 |
| divers / diverses | 各种、若干 | diverses raisons | 书面语较常见 |
| différents / différentes | 不同的、若干 | différentes solutions | 可作形容词，也有不定限定意味 |
| quelques-uns / quelques-unes | 一些人/物 | Quelques-uns sont partis. | 代词，不接名词 |

`quelque` 的常见形式：

| 形式 | 例句 | 说明 |
| ---- | ---- | ---- |
| quelques + 复数名词 | quelques jours | 几天 |
| quelque + 单数名词 | quelque chose, quelque part | 固定不定表达 |
| quelque + 数字 | quelque deux cents personnes | 大约，较书面 |
| quel que soit | Quel que soit le problème... | 让步结构，另作从句表达 |

`certain` 的两类用法：

| 用法 | 例句 | 含义 |
| ---- | ---- | ---- |
| 不定限定词 | certains étudiants | 某些学生 |
| 形容词 | une réponse certaine | 确定的答案 |
| 单数不定 | un certain courage | 某种勇气、相当的勇气 |

### 6.7 aucun, nul, pas un

否定限定词表达“没有任何一个”。它们通常和 `ne` 配合，名词多用单数，但语义上是否定整个集合。

| 形式 | 用法 | 例句 | 说明 |
| ---- | ---- | ---- | ---- |
| aucun | 阳性单数 | Je n'ai aucun doute. | 没有任何疑问 |
| aucune | 阴性单数 | Elle n'a aucune idée. | 没有任何想法 |
| aucuns/aucunes | 少数复数固定场景 | aucuns frais | 名词只用复数或语义要求复数时 |
| nul/nulle | 书面、正式 | Nul doute que... | 较书面 |
| pas un / pas une | 强调一个也没有 | Pas un bruit. | 可省略完整句 |

`aucun` 句法：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| ne + V + aucun + nom | Je n'ai aucun problème. | 标准结构 |
| aucun + nom + ne + V | Aucun étudiant n'est venu. | aucun 短语作主语 |
| sans aucun + nom | sans aucun doute | 无需 ne |
| aucune de + 定冠词/代词 | Aucune de ces solutions ne marche. | aucun 作代词性结构 |

否定限定词 vs 否定后的 de：

| 表达 | 例句 | 语感 |
| ---- | ---- | ---- |
| pas de + 名词 | Je n'ai pas de question. | 普通否定 |
| aucun/aucune + 名词 | Je n'ai aucune question. | 更强，强调一个也没有 |
| pas un/pas une + 名词 | Il n'y avait pas un bruit. | 强烈、常用于叙述 |

### 6.8 beaucoup de, peu de, assez de, trop de

数量表达通常不是普通形容词，而是“数量词 + de + 名词”的结构。`de` 后的名词一般不加冠词，除非后面是特指的定冠词短语。

| 表达 | 含义 | 例句 | 说明 |
| ---- | ---- | ---- | ---- |
| beaucoup de | 很多 | beaucoup de travail | 可数/不可数都可 |
| peu de | 很少 | peu de temps | 数量少 |
| un peu de | 一点 | un peu d'eau | 常接不可数 |
| assez de | 足够 | assez d'argent | 元音前 d' |
| trop de | 太多 | trop de bruit | 负面或超量 |
| plus de | 更多 | plus de détails | 比较数量 |
| moins de | 更少 | moins de stress | 比较数量 |
| autant de | 同样多 | autant de questions | 与某数量相等 |
| tant de | 如此多 | tant de problèmes | 强调，多用于书面/感叹 |

可数和不可数：

| 名词类型 | 例句 | 说明 |
| -------- | ---- | ---- |
| 可数复数 | beaucoup de livres | 很多书 |
| 可数单数 | beaucoup de questions | 通常用复数名词表示很多个 |
| 不可数 | beaucoup de café | 很多咖啡 |
| 抽象名词 | trop de patience | 太多耐心，语义视上下文 |

有定冠词时的区别：

| 结构 | 例句 | 含义 |
| ---- | ---- | ---- |
| beaucoup de + 名词 | beaucoup d'étudiants | 很多学生，非特指 |
| beaucoup des + 名词 | beaucoup des étudiants de cette classe | 这个班学生中的很多人 |
| la plupart de + 定冠词 | la plupart des étudiants | 大多数学生 |
| trop de + 名词 | trop de livres | 太多书 |
| trop des + 名词 | trop des livres que tu as achetés | 你买的那些书中太多一部分，较少见 |

### 6.9 数量表达后的 de

数量词后通常用 `de/d'`，这是汉语学习者最容易写成 `des/du/de la` 的地方。

| 数量表达 | 后接 | 例句 | 说明 |
| -------- | ---- | ---- | ---- |
| beaucoup de | 名词 | beaucoup de gens | 不说 beaucoup des gens，除非特指 |
| peu de | 名词 | peu de chances | 很少机会 |
| un peu de | 不可数名词 | un peu de sucre | 一点糖 |
| assez de | 名词 | assez de place | 足够空间 |
| trop de | 名词 | trop de bruit | 太吵 |
| combien de | 名词 | combien de temps | 多少 |
| plus de / moins de | 名词 | plus de liberté | 更多自由 |
| une bouteille de | 名词 | une bouteille d'eau | 容器量 |
| un kilo de | 名词 | un kilo de pommes | 度量 |
| une sorte de | 名词 | une sorte de problème | 种类 |

`de` 变 `d'`：

| 环境 | 例句 | 说明 |
| ---- | ---- | ---- |
| 元音前 | beaucoup d'argent | de -> d' |
| h muet 前 | trop d'histoires | 按元音处理 |
| h aspiré 前 | beaucoup de héros | 不省音 |

数字和数量词的区别：

| 表达 | 例句 | 说明 |
| ---- | ---- | ---- |
| 具体数字 | trois livres | 不用 de |
| 大约数量名词 | une dizaine de livres | 用 de |
| 度量单位 | deux kilos de pommes | 单位后用 de |
| 容器 | trois verres d'eau | 容器后用 de |
| 百分比 | 30 % des étudiants | 百分比后常接 de + 定冠词，表示某集合中的比例 |

### 6.10 物主和指示限定词的互斥

一个普通名词前通常只能有一个核心限定词。物主、指示、冠词不能直接并排；需要同时表达“我的”和“这个”时，要改用 `à moi`, `de`, 或其他结构。

| 想表达 | 错误 | 推荐 | 说明 |
| ------ | ---- | ---- | ---- |
| 我的书 | le mon livre | mon livre | 物主限定词已足够 |
| 这本书 | ce le livre | ce livre | 指示限定词已足够 |
| 我的这本书 | ce mon livre | ce livre à moi / mon livre ici | 需换结构 |
| Paul 的这本书 | ce livre de Paul | ce livre de Paul | 指示 + 名词 + de 所属 |
| 我的三个朋友 | mes trois amis | mes trois amis | 物主 + 数字可共现 |
| 这三个问题 | ces trois questions | ces trois questions | 指示 + 数字可共现 |
| 所有我的朋友 | tous mes amis | tous mes amis | tout 可放在物主前 |

可以共现的顺序：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| tout + 定冠词 | tout le livre | 整本书 |
| tous/toutes + 定冠词复数 | tous les jours | 每天 |
| tous/toutes + 物主 | tous mes amis | 我所有朋友 |
| 指示/物主 + 数字 | ces deux livres, mes trois idées | 可共现 |
| 指示/物主 + 形容词 | ce beau livre, mon ancien professeur | 形容词在限定词后 |
| 数量表达 + de + 指示/定冠词 | beaucoup de ces livres | 这些书中的很多 |

表达“其中一些/很多”：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| certains de + 定冠词/指示/物主 | certains de mes amis | 我的某些朋友 |
| plusieurs de + 定冠词/指示/物主 | plusieurs de ces livres | 这些书中的几本 |
| beaucoup de + 指示/物主 | beaucoup de mes collègues | 我的许多同事 |
| aucun de + 定冠词/指示/物主 | aucun de ces exemples | 这些例子中没有一个 |

### 6.11 限定词常见错误速查

| 错误句 | 推荐改法 | 错因 | 记忆点 |
| ------ | -------- | ---- | ------ |
| Le mon livre est ici. | Mon livre est ici. | 冠词和物主限定词叠用 | mon 已经限定名词 |
| Ce le problème est grave. | Ce problème est grave. | 指示限定词和定冠词叠用 | ce 后直接接名词 |
| Cet idée est intéressante. | Cette idée est intéressante. | 阴性名词误用 cet | cet 只用于阳性元音开头 |
| Cette homme est gentil. | Cet homme est gentil. | 阳性元音开头应用 cet | homme 是阳性 h muet |
| Ma amie arrive. | Mon amie arrive. | 阴性元音开头需 mon | mon amie 便于发音 |
| Son mère est médecin. | Sa mère est médecin. | 形式由被拥有名词决定 | mère 阴性辅音开头 |
| Sa école est loin. | Son école est loin. | 阴性元音开头用 son | son école |
| Des plusieurs questions. | Plusieurs questions. | plusieurs 前不加 des | plusieurs 本身限定名词 |
| Beaucoup des gens sont là. | Beaucoup de gens sont là. | 数量表达后误用 des | 非特指用 beaucoup de |
| Beaucoup de les étudiants de ma classe sont là. | Beaucoup des étudiants de ma classe sont là. | de + les 必须缩合 | 特指集合中很多人用 des |
| Trop du travail. | Trop de travail. | 数量表达后误用部分冠词 | trop de + 名词 |
| J'ai trois des livres. | J'ai trois livres. | 数字后误加 des | 数字直接限定名词 |
| Tous étudiants sont venus. | Tous les étudiants sont venus. | tous 后普通名词需定冠词 | tous les + 复数名词 |
| Chaque étudiants doit répondre. | Chaque étudiant doit répondre. | chaque 后用单数 | chaque + 单数名词 |
| Chaque jours, je travaille. | Chaque jour, je travaille. | chaque 后误用复数 | chaque + 单数名词 |
| Je n'ai pas aucun problème. | Je n'ai aucun problème. | 双重否定式误叠 | ne...aucun，不加 pas |
| Aucun étudiants ne sont venus. | Aucun étudiant n'est venu. | aucun 作主语通常单数 | aucun + 单数名词 |
| Je veux ce mon livre. | Je veux ce livre à moi. | 指示和物主不能直接叠用 | 改用 à moi 或 de |
| Tous mes les amis sont là. | Tous mes amis sont là. | 物主和定冠词叠用 | tous + mes + 名词 |
| Une dizaine des personnes. | Une dizaine de personnes. | 约数表达后误用 des | une dizaine de + 名词 |

## 7. 形容词（Adjectifs）

法语形容词有两个核心问题：**是否和名词性数配合**，以及**放在名词前还是名词后**。多数形容词后置并随名词性数变化；少数高频短形容词前置；有些形容词前后位置不同会改变意义。颜色、国籍、复合形容词和不变形容词还各有特殊规则。

### 7.1 形容词总览

| 功能 | 位置 | 是否配合 | 例句 | 说明 |
| ---- | ---- | -------- | ---- | ---- |
| 修饰名词 | 多数在名词后 | 是 | une maison blanche | blanche 配合 maison |
| 少数常前置 | 名词前 | 是 | un petit appartement | petit 是常前置形容词 |
| 作主语表语 | être 等动词后 | 是 | Elle est fatiguée. | fatiguée 配合 elle |
| 作宾语表语 | 宾语后或补语位置 | 是 | Je trouve cette idée intéressante. | intéressante 配合 idée |
| 不变形容词 | 名词后 | 否 | des robes orange | orange 作颜色名词时不变 |
| 复合形容词 | 名词后 | 视结构 | des yeux bleu clair | 复合颜色通常不变 |

形容词要回答三个问题：

| 问题 | 判断 | 例子 |
| ---- | ---- | ---- |
| 修饰谁？ | 找它对应的名词或代词 | une idée intéressante |
| 是否配合？ | 看被修饰词的性数 | des idées intéressantes |
| 放哪里？ | 多数后置，少数前置，位置可改义 | un ancien professeur |

形容词与其他词类的区别：

| 词类 | 修饰对象 | 例句 | 说明 |
| ---- | -------- | ---- | ---- |
| 形容词 | 名词/代词 | un livre intéressant | intéressant 修饰 livre |
| 副词 | 动词/形容词/句子 | Il parle lentement. | lentement 修饰 parle |
| 限定词 | 名词范围 | ce livre, mon livre | 放在名词短语最前 |
| 名词补语 | 名词 | un livre de grammaire | 介词短语补充名词 |

### 7.2 形容词性数配合

形容词通常和它修饰的名词或代词在**性 genre** 和 **数 nombre** 上一致。

| 名词 | 形容词 | 例句 | 说明 |
| ---- | ------ | ---- | ---- |
| 阳性单数 | 原形 | un livre intéressant | 基本形式 |
| 阴性单数 | 常加 -e | une histoire intéressante | 阴性 |
| 阳性复数 | 常加 -s | des livres intéressants | 复数 |
| 阴性复数 | 常加 -es | des histoires intéressantes | 阴性复数 |

表语形容词也要配合：

| 主语 | 句子 | 说明 |
| ---- | ---- | ---- |
| il | Il est prêt. | 阳性单数 |
| elle | Elle est prête. | 阴性单数 |
| ils | Ils sont prêts. | 阳性复数 |
| elles | Elles sont prêtes. | 阴性复数 |
| 混合性别复数 | Paul et Marie sont prêts. | 传统语法中阳性复数作混合复数 |

多个名词共用一个形容词：

| 结构 | 例句 | 配合 |
| ---- | ---- | ---- |
| 两个阳性名词 | un livre et un cahier neufs | 阳性复数 |
| 两个阴性名词 | une table et une chaise neuves | 阴性复数 |
| 阳性 + 阴性 | un livre et une table neufs | 阳性复数 |
| 意义上各自修饰 | une chemise blanche et bleue | 一件白蓝相间的衬衫 |
| 两个独立对象 | une chemise blanche et une chemise bleue | 两件不同衬衫 |

### 7.3 阴性形式构成

多数形容词阴性加 `-e`，但词尾变化很多。拼写变化往往也影响发音。

| 阳性词尾 | 阴性变化 | 例子 | 说明 |
| -------- | -------- | ---- | ---- |
| 一般情况 | + -e | grand -> grande | 最常见 |
| 已以 -e 结尾 | 不变 | jeune -> jeune | 书写不变 |
| -eux | -euse | heureux -> heureuse | 高频 |
| -if | -ive | actif -> active | f -> v |
| -er | -ère | cher -> chère | 加重音 |
| -et | -ète 或 -ette | complet -> complète, net -> nette | 需记具体词 |
| -el | -elle | naturel -> naturelle | 双写 l |
| -eil | -eille | pareil -> pareille | 双写 l |
| -en | -enne | ancien -> ancienne | 双写 n |
| -on | -onne | bon -> bonne | 双写 n |
| -s | -se | français -> française | s 发 z 音 |
| -x | -se | faux -> fausse | 特殊 |
| -c | -que 或 -che | public -> publique, blanc -> blanche | 需记具体词 |
| -f | -ve | neuf -> neuve | f -> v |

高频不规则阴性：

| 阳性 | 阴性 | 例句 |
| ---- | ---- | ---- |
| beau | belle | une belle maison |
| nouveau | nouvelle | une nouvelle idée |
| vieux | vieille | une vieille voiture |
| fou | folle | une folle histoire |
| mou | molle | une pâte molle |
| sec | sèche | une chemise sèche |
| frais | fraîche | de l'eau fraîche |
| long | longue | une longue journée |
| doux | douce | une voix douce |
| favori | favorite | mon équipe favorite |

元音前的特殊阳性形式：

| 普通阳性 | 元音前阳性 | 阴性 | 例句 |
| -------- | ---------- | ---- | ---- |
| beau | bel | belle | un bel homme |
| nouveau | nouvel | nouvelle | un nouvel appartement |
| vieux | vieil | vieille | un vieil ami |
| fou | fol | folle | un fol espoir |
| mou | mol | molle | un mol oreiller，较少见 |

### 7.4 复数形式构成

形容词复数通常加 `-s`，但也有和名词类似的特殊变化。

| 单数词尾 | 复数变化 | 例子 | 说明 |
| -------- | -------- | ---- | ---- |
| 一般情况 | + -s | petit -> petits | 最常见 |
| 已以 -s 或 -x 结尾 | 不变 | gris -> gris, heureux -> heureux | 阳性复数不变 |
| -eau | -eaux | beau -> beaux | 常见 |
| -al | 多为 -aux | national -> nationaux | 阳性复数 |
| -al 例外 | + -s | fatal -> fatals, banal -> banals | 需记 |
| 阴性形式 | 通常 + -s | belle -> belles | 阴性复数 |

四格速查：

| 阳性单数 | 阴性单数 | 阳性复数 | 阴性复数 |
| -------- | -------- | -------- | -------- |
| petit | petite | petits | petites |
| grand | grande | grands | grandes |
| heureux | heureuse | heureux | heureuses |
| beau | belle | beaux | belles |
| nouveau | nouvelle | nouveaux | nouvelles |
| national | nationale | nationaux | nationales |
| ancien | ancienne | anciens | anciennes |
| blanc | blanche | blancs | blanches |

### 7.5 形容词位置：前置与后置

法语形容词多数放在名词后，尤其是颜色、国籍、形状、宗教、关系、分类性质和较长形容词。

| 常后置类型 | 例子 | 说明 |
| ---------- | ---- | ---- |
| 颜色 | une robe rouge | 颜色后置 |
| 国籍/地区 | un étudiant japonais | 国籍形容词后置 |
| 宗教 | une église catholique | 宗教形容词后置 |
| 形状 | une table ronde | 形状后置 |
| 分类/关系 | une décision politique | 表类别或关系 |
| 分词形容词 | un problème compliqué | 来自动词分词 |
| 较长形容词 | une situation extrêmement difficile | 后置更自然 |

常前置的多为短、高频、主观评价形容词：

| 常前置 | 例子 | 说明 |
| ------ | ---- | ---- |
| beau | une belle journée | 美丽/美好 |
| bon | un bon repas | 好 |
| mauvais | une mauvaise idée | 坏 |
| grand | une grande maison | 大、伟大 |
| petit | un petit problème | 小 |
| jeune | un jeune homme | 年轻 |
| vieux | un vieux livre | 老、旧 |
| nouveau | une nouvelle voiture | 新 |
| autre | une autre question | 另一个 |
| même | la même chose | 同一个 |

位置带来的语感：

| 位置 | 例句 | 语感 |
| ---- | ---- | ---- |
| 后置 | un livre intéressant | 客观描述、分类 |
| 前置 | un intéressant livre | 文学、强调或较书面，不是普通说法 |
| 后置 | une voiture rouge | 客观颜色 |
| 前置 | une rouge voiture | 很不自然，除文学风格外避免 |

### 7.6 BAGS 类常前置形容词

英语教学中常用 BAGS 记忆法：Beauty, Age, Goodness, Size。法语中这些类别的短形容词常前置，但不是机械规则。

| 类别 | 常见形容词 | 例子 | 说明 |
| ---- | ---------- | ---- | ---- |
| Beauty | beau, joli | une jolie fleur | 美丑评价 |
| Age | jeune, vieux, nouveau | un vieux quartier | 年龄、新旧 |
| Goodness | bon, mauvais, excellent | une bonne réponse | 好坏评价 |
| Size | grand, petit, gros, long | un petit village | 大小长短 |

高频前置形容词：

| 形容词 | 例句 | 注意 |
| ------ | ---- | ---- |
| bon | un bon film | 阴性 bonne |
| mauvais | une mauvaise nouvelle | 阴性加 -e |
| beau | un beau paysage | 元音前 bel |
| joli | une jolie robe | 常前置 |
| grand | une grande ville | 可表大小或重要性 |
| petit | un petit café | 可表小、亲切、轻微 |
| vieux | un vieux monsieur | 元音前 vieil |
| nouveau | un nouveau projet | 元音前 nouvel |
| jeune | une jeune femme | 常前置 |
| autre | un autre exemple | 必须常在名词前 |
| même | la même question | 放名词前 |

不要过度套 BAGS：

| 不自然 | 自然 | 原因 |
| ------ | ---- | ---- |
| une rouge robe | une robe rouge | 颜色后置 |
| un français étudiant | un étudiant français | 国籍后置 |
| une politique décision | une décision politique | 关系/分类形容词后置 |
| un intéressant livre | un livre intéressant | intéressant 通常后置 |

### 7.7 位置改变意义的形容词

有些形容词前置时意义更主观、抽象或评价性，后置时意义更具体、字面或分类性。

| 形容词 | 前置意义 | 后置意义 | 例子 |
| ------ | -------- | -------- | ---- |
| ancien | 以前的 | 古老的 | mon ancien professeur / un meuble ancien |
| cher | 亲爱的 | 昂贵的 | mon cher ami / un livre cher |
| grand | 伟大的、重要的 | 高大的、大的 | un grand homme / un homme grand |
| pauvre | 可怜的 | 贫穷的 | un pauvre homme / un homme pauvre |
| propre | 自己的 | 干净的 | ma propre chambre / une chambre propre |
| seul | 唯一的 | 单独的、孤独的 | mon seul ami / un homme seul |
| brave | 好心的、可敬的 | 勇敢的 | un brave homme / un homme brave |
| curieux | 奇怪的 | 好奇的 | une curieuse histoire / un enfant curieux |
| certain | 某个 | 确定的 | un certain problème / une réponse certaine |
| simple | 只不过的、普通的 | 简单的 | un simple employé / une question simple |
| même | 同一个 | 本人、甚至 | la même personne / la personne même |

实用判断：

| 后置倾向 | 前置倾向 |
| -------- | -------- |
| 客观、可观察、分类 | 主观、评价、抽象 |
| 颜色、国籍、形状 | 大小、好坏、年龄、美丑 |
| un étudiant français | un bon étudiant |
| une table ronde | une vieille table |

### 7.8 颜色形容词

颜色形容词多数后置。简单颜色通常配合；由名词转成的颜色、复合颜色通常不变。

简单颜色配合：

| 阳性单数 | 阴性单数 | 阳性复数 | 阴性复数 | 例句 |
| -------- | -------- | -------- | -------- | ---- |
| blanc | blanche | blancs | blanches | des chemises blanches |
| noir | noire | noirs | noires | des robes noires |
| vert | verte | verts | vertes | des pommes vertes |
| bleu | bleue | bleus | bleues | des yeux bleus |
| gris | grise | gris | grises | des vestes grises |
| rouge | rouge | rouges | rouges | des fleurs rouges |
| jaune | jaune | jaunes | jaunes | des murs jaunes |

名词来源的颜色通常不变：

| 颜色 | 例句 | 说明 |
| ---- | ---- | ---- |
| orange | des robes orange | 来源于水果名，不变 |
| marron | des chaussures marron | 来源于栗子名，不变 |
| crème | des murs crème | 名词作颜色，不变 |
| olive | des vestes olive | 名词作颜色，不变 |
| kaki | des vestes kaki | 外来颜色名，通常不变 |

复合颜色通常不变：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| 颜色 + 颜色 | des yeux bleu-vert | 蓝绿色，不变 |
| 颜色 + 形容词 | des chemises bleu clair | 浅蓝色，不变 |
| 颜色 + 名词 | des robes rouge cerise | 樱桃红，不变 |
| 深浅表达 | des murs vert foncé | 深绿色，不变 |

例外和提醒：

| 表达 | 说明 |
| ---- | ---- |
| rose, mauve, pourpre, écarlate | 这些虽源于名词，但常作为普通形容词配合 |
| des robes roses | rose 常配合 |
| des tissus mauves | mauve 常配合 |
| des chaussures marron | marron 通常不变 |
| des fleurs orange | orange 通常不变 |

### 7.9 国籍、宗教、关系形容词

国籍、地区、宗教、政治、学科等关系形容词通常后置，并随名词性数配合。作形容词时小写；作居民名词时大写。

| 类型 | 例子 | 说明 |
| ---- | ---- | ---- |
| 国籍 | un étudiant français | 后置，小写，配合 |
| 地区 | la cuisine lyonnaise | 后置，配合 |
| 宗教 | une tradition catholique | 后置，配合 |
| 政治 | une décision politique | 后置，配合 |
| 学科 | une analyse linguistique | 后置，配合 |
| 材料/用途关系 | une crise économique | 后置，分类关系 |

国籍形容词速查：

| 阳性单数 | 阴性单数 | 阳性复数 | 阴性复数 | 例句 |
| -------- | -------- | -------- | -------- | ---- |
| français | française | français | françaises | des étudiantes françaises |
| japonais | japonaise | japonais | japonaises | une entreprise japonaise |
| chinois | chinoise | chinois | chinoises | des villes chinoises |
| anglais | anglaise | anglais | anglaises | une université anglaise |
| allemand | allemande | allemands | allemandes | des produits allemands |
| italien | italienne | italiens | italiennes | une chanson italienne |
| américain | américaine | américains | américaines | des films américains |
| suisse | suisse | suisses | suisses | une banque suisse |

大小写区别：

| 用法 | 例句 | 说明 |
| ---- | ---- | ---- |
| 居民名词 | un Français, une Japonaise | 大写 |
| 国籍形容词 | un étudiant français | 小写 |
| 语言名 | le français, le japonais | 小写，阳性 |
| 国家名 | la France, le Japon | 首字母大写 |

### 7.10 复合形容词和不变形容词

复合形容词由两个或多个词组成，配合规则取决于结构。实际写作中最稳妥的是掌握高频类型。

| 类型 | 例子 | 是否配合 | 说明 |
| ---- | ---- | -------- | ---- |
| 颜色复合 | des robes bleu clair | 不变 | 整体表示一种颜色 |
| 副词 + 形容词 | des enfants très jeunes | 形容词配合 | très 是副词不变 |
| 形容词 + 形容词 | des relations franco-allemandes | 后一部分常配合 | 需看固定用法 |
| 学科复合 | des études socio-économiques | 后一部分配合 | 常见于书面语 |
| demi + 名词 | une demi-heure | demi 不变 | demi 在名前不变 |
| 名词 + demi | deux heures et demie | demi 可配合 | demi 在名后配合阴性 |
| nu + 名词 | nu-pieds, nu-tête | 多不变 | 固定表达，多不变 |

常见不变形容词：

| 类型 | 例子 | 说明 |
| ---- | ---- | ---- |
| 外来颜色/名词颜色 | des vestes kaki, des robes orange | 常不变 |
| 副词化形容词 | des places debout | debout 不变 |
| 固定形容词短语 | des robes bon marché | bon marché 不变 |
| 作为副词使用 | Elles chantent faux. | faux 修饰动词时不配合 |

`demi` 速查：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| demi + 名词 | une demi-heure | 名词前不变，连字符 |
| 名词 + et demi | une heure et demie | 在阴性名词后配合 |
| 名词 + et demi | deux ans et demi | 阳性名词后 demi |
| à demi | à demi ouvert | 副词短语，不变 |

### 7.11 形容词作名词

形容词可以名词化，前面加冠词或限定词，表示一类人、一个抽象概念、或省略掉的名词。

| 类型 | 例句 | 含义 |
| ---- | ---- | ---- |
| 表人群 | les jeunes, les riches | 年轻人、富人 |
| 表抽象 | le vrai, le possible | 真实、可能之事 |
| 省略名词 | la bleue | 蓝色那件，需上下文 |
| 中性结构 | quelque chose de nouveau | 某个新东西 |
| 最高级名词化 | le plus important | 最重要的事 |

名词化时仍要注意性数：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| les + 形容词复数 | les pauvres | 一类人 |
| le + 形容词阳性单数 | le nécessaire | 抽象整体 |
| la + 形容词阴性单数 | la première | 第一位女性或第一项，依上下文 |
| ceux/celles + 形容词 | ceux qui sont prêts | 代词化表达更清楚 |

常见结构：

| 表达 | 例句 | 说明 |
| ---- | ---- | ---- |
| quelque chose de + adjectif | quelque chose d'intéressant | de 后形容词常用阳性单数 |
| rien de + adjectif | rien de spécial | 没什么特别的 |
| quelqu'un de + adjectif | quelqu'un de fiable | 某个可靠的人 |
| le plus + adjectif | le plus difficile | 最难的部分/事情 |

### 7.12 形容词补足语：content de, prêt à 等

很多形容词后面要求固定介词，再接名词或不定式。介词不能按中文意思随意替换。

| 形容词结构 | 含义 | 例句 | 说明 |
| ---------- | ---- | ---- | ---- |
| content de | 对……满意 | Je suis content de ce résultat. | de + 名词 |
| heureux de | 高兴做某事 | Elle est heureuse de vous voir. | de + infinitif |
| fier de | 为……自豪 | Il est fier de son fils. | 固定 de |
| sûr de | 确信 | Je suis sûr de ma réponse. | de + 名词 |
| responsable de | 负责 | Elle est responsable du projet. | de + 名词 |
| capable de | 有能力 | Il est capable de réussir. | de + infinitif |
| prêt à | 准备好 | Nous sommes prêts à partir. | à + infinitif |
| facile à | 容易…… | Ce texte est facile à lire. | à + infinitif |
| difficile à | 难以…… | Cette règle est difficile à comprendre. | à + infinitif |
| utile à | 对……有用 | C'est utile aux débutants. | à + 人或事 |
| bon pour | 对……有益 | C'est bon pour la santé. | pour + 受益对象 |
| nécessaire pour | 对……必要 | C'est nécessaire pour réussir. | pour + infinitif 或名词 |

形容词 + de/à 的常见差异：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| 非人称评价 | Il est facile de comprendre cette règle. | 真正动作是 comprendre |
| 名词主语 + 形容词 | Cette règle est facile à comprendre. | 形容词修饰 règle，后接 à + infinitif |
| content de | Je suis content de partir. | content de + infinitif |
| prêt à | Je suis prêt à partir. | prêt à + infinitif |
| important de | C'est important de vérifier. | 非人称评价后常用 de |
| important pour | C'est important pour moi. | 对我来说重要，用 pour |

### 7.13 形容词常见错误速查

| 错误句 | 推荐改法 | 错因 | 记忆点 |
| ------ | -------- | ---- | ------ |
| Une maison blanc. | Une maison blanche. | 阴性未配合 | maison 阴性，blanche |
| Des idées intéressant. | Des idées intéressantes. | 阴性复数未配合 | -e + -s |
| Elle est prêt. | Elle est prête. | 表语形容词未配合主语 | elle -> prête |
| Ils sont heureuse. | Ils sont heureux. | 性数错误 | ils 阳性复数 |
| Une rouge robe. | Une robe rouge. | 颜色形容词位置错误 | 颜色通常后置 |
| Un français étudiant. | Un étudiant français. | 国籍形容词位置错误 | 国籍后置 |
| Un intéressant livre. | Un livre intéressant. | 普通描述形容词误前置 | intéressant 通常后置 |
| Une beau maison. | Une belle maison. | beau 阴性形式错误 | beau -> belle |
| Un beau homme. | Un bel homme. | 元音前阳性特殊形式 | beau -> bel |
| Une vieux voiture. | Une vieille voiture. | vieux 阴性形式错误 | vieux -> vieille |
| Des robes oranges. | Des robes orange. | orange 作颜色通常不变 | 名词来源颜色不变 |
| Des chaussures marrones. | Des chaussures marron. | marron 通常不变 | marron 不加 -s |
| Des yeux bleus clairs. | Des yeux bleu clair. | 复合颜色误配合 | 复合颜色通常不变 |
| Une étudiante Française. | Une étudiante française. | 国籍形容词误大写 | 形容词小写 |
| Une Française étudiante. | Une étudiante française. | 居民名和形容词混用 | 名词大写，形容词小写 |
| Je suis content pour te voir. | Je suis content de te voir. | 形容词介词搭配错误 | content de |
| Ce texte est facile de lire. | Ce texte est facile à lire. | 形容词补足语介词错误 | 名词主语 + facile à |
| Il est capable à réussir. | Il est capable de réussir. | capable 搭配错误 | capable de |
| Quelque chose intéressant. | Quelque chose d'intéressant. | quelque chose 后缺 de | quelque chose de + adjectif |
| Les nouveau projets. | Les nouveaux projets. | nouveau 阳性复数错误 | nouveau -> nouveaux |

## 8. 比较、最高级与程度表达（Comparaison et degré）

比较结构不是只把中文“更、最、一样、太”逐词翻译成法语。法语要先判断比较对象是**形容词、副词、名词数量还是动词程度**，再选择 `plus/moins/aussi`, `plus de/moins de/autant de`, 或 `plus/moins/autant`。本章也处理 `meilleur/mieux`、最高级、倍数、程度副词和高频错误。

### 8.1 比较结构总览

| 比较对象 | 优势比较 | 劣势比较 | 同等比较 | 例句 |
| -------- | -------- | -------- | -------- | ---- |
| 形容词 | plus + adj + que | moins + adj + que | aussi + adj + que | Elle est plus rapide que moi. |
| 副词 | plus + adv + que | moins + adv + que | aussi + adv + que | Il parle plus vite que moi. |
| 名词数量 | plus de + nom + que | moins de + nom + que | autant de + nom + que | J'ai plus de temps que toi. |
| 动词程度/次数 | verbe + plus que | verbe + moins que | verbe + autant que | Il travaille plus que moi. |
| 质量“更好” | meilleur / mieux | pire / plus mal | aussi bon / aussi bien | Ce livre est meilleur. |

比较结构的基本公式：

| 含义 | 公式 | 例句 | 注意 |
| ---- | ---- | ---- | ---- |
| 更…… | plus + adj/adv + que | plus intéressant que prévu | que 引出比较基准 |
| 不如…… | moins + adj/adv + que | moins cher que l'autre | moins 不是否定 |
| 和……一样 | aussi + adj/adv + que | aussi clair que possible | 同等比较用 aussi |
| 更多…… | plus de + nom + que | plus de livres que moi | 名词前用 de |
| 更少…… | moins de + nom + que | moins de temps que toi | de 后不加冠词，除非特指 |
| 同样多…… | autant de + nom + que | autant de questions que nous | 名词数量 |
| 做得更多 | verbe + plus que | Il lit plus que moi. | 比较动词程度/频率 |

比较对象必须平行：

| 不平行 | 推荐改法 | 原因 |
| ------ | -------- | ---- |
| Paris est plus cher que vivre à Lyon. | Vivre à Paris est plus cher que vivre à Lyon. | 动作和动作比较 |
| Ce livre est plus intéressant que hier. | Ce livre est plus intéressant que celui d'hier. | 书和书比较 |
| Il travaille plus que son frère travaille. | Il travaille plus que son frère. | 后半可省略重复动词 |

### 8.2 plus / moins / aussi ... que

`plus/moins/aussi ... que` 用于形容词和副词比较。`que` 后面可以接名词短语、代词、从句或省略的结构。

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| plus + adjectif + que | Ce film est plus long que l'autre. | 形容词比较 |
| moins + adjectif + que | Cette solution est moins chère que prévu. | 比预想便宜 |
| aussi + adjectif + que | Elle est aussi sérieuse que lui. | 同等程度 |
| plus + adverbe + que | Il court plus vite que moi. | 副词比较 |
| moins + adverbe + que | Elle parle moins clairement qu'avant. | que + 元音前 qu' |
| aussi + adverbe + que | Tu écris aussi bien que lui. | bien 是副词 |

`que` 后常见形式：

| 形式 | 例句 | 说明 |
| ---- | ---- | ---- |
| 名词短语 | plus rapide que le train | 比火车快 |
| 重读代词 | plus grand que moi | 代词用 moi/toi/lui 等重读形式 |
| 从句 | plus difficile que je ne pensais | 比我想的更难 |
| 省略结构 | plus tôt que prévu | 比预定更早 |
| 时间/地点 | plus calme qu'à Paris | 介词保留 |

`ne explétif` 提示：在较正式书面语中，`plus/moins/autre` 等比较后可出现不表示否定的 `ne`：

| 句子 | 含义 | 说明 |
| ---- | ---- | ---- |
| C'est plus difficile que je ne pensais. | 这比我想的难。 | ne 不翻译成“不” |
| Il est moins naïf qu'il ne paraît. | 他不像看起来那么天真。 | 书面语常见 |
| Elle est autre que je ne l'imaginais. | 她和我想象的不一样。 | 较书面 |

### 8.3 meilleur, mieux, pire, moindre

`bon` 的比较级通常是 `meilleur`，`bien` 的比较级是 `mieux`。这是本章最高频错误点。

| 原级 | 词类 | 比较级 | 例句 | 说明 |
| ---- | ---- | ------ | ---- | ---- |
| bon | 形容词 | meilleur | Ce vin est meilleur. | 修饰名词，需配合 |
| bonne | 形容词 | meilleure | Cette idée est meilleure. | 阴性 |
| bons | 形容词 | meilleurs | Ces résultats sont meilleurs. | 阳性复数 |
| bonnes | 形容词 | meilleures | Ces solutions sont meilleures. | 阴性复数 |
| bien | 副词 | mieux | Il travaille mieux. | 修饰动词，不配合 |
| bien | 表状态/感觉 | mieux | Je vais mieux. | 身体/状态更好 |

`meilleur` vs `mieux`：

| 想表达 | 正确 | 错误 | 判断 |
| ------ | ---- | ---- | ---- |
| 这本书更好。 | Ce livre est meilleur. | Ce livre est mieux. | 评价名词品质，用 meilleur |
| 他唱得更好。 | Il chante mieux. | Il chante meilleur. | 修饰动词，用 mieux |
| 这个方案更好。 | Cette solution est meilleure. | Cette solution est mieux. | solution 阴性 |
| 我感觉好多了。 | Je vais mieux. | Je vais meilleur. | aller mieux |
| 这是更好的选择。 | C'est un meilleur choix. | C'est un mieux choix. | 形容词修饰 choix |

`pire`, `plus mauvais`, `plus mal`, `moindre`：

| 表达 | 用法 | 例句 | 说明 |
| ---- | ---- | ---- | ---- |
| pire | 更坏/更糟 | La situation est pire. | 常作形容词或名词化 |
| plus mauvais | 更差，较字面 | Ce film est plus mauvais que l'autre. | 也可用 pire |
| plus mal | 做得更糟 | Il travaille plus mal qu'avant. | mal 的比较 |
| moindre | 更小、更少、较轻微 | le moindre doute | 书面/固定表达多 |
| meilleur marché | 更便宜 | C'est meilleur marché. | 固定表达，不说 plus bon marché 通常也可见但较不优 |

### 8.4 最高级 le plus / le moins

最高级表示“最……”。形容词最高级通常需要定冠词，且冠词和形容词要按被修饰名词配合。

| 类型 | 结构 | 例句 | 说明 |
| ---- | ---- | ---- | ---- |
| 形容词最高级 | le/la/les plus + adj | C'est le plus grand musée. | 冠词配合名词 |
| 形容词最低级 | le/la/les moins + adj | C'est la moins chère. | “最不……” |
| 副词最高级 | le plus + adv | Il court le plus vite. | 副词最高级 le 通常不变 |
| 名词数量最高级 | le plus de + nom | C'est lui qui a le plus de temps. | “最多……” |
| 动词程度最高级 | verbe + le plus | C'est elle qui travaille le plus. | 动词后 le plus |

形容词最高级配合：

| 名词 | 最高级 | 例句 |
| ---- | ------ | ---- |
| 阳性单数 | le plus / le moins | le plus grand problème |
| 阴性单数 | la plus / la moins | la plus grande ville |
| 阳性复数 | les plus / les moins | les plus grands pays |
| 阴性复数 | les plus / les moins | les plus grandes villes |

位置规则：

| 普通形容词位置 | 最高级位置 | 例句 |
| -------------- | ---------- | ---- |
| 后置形容词 | 名词 + le plus + adj | le livre le plus intéressant |
| 前置形容词 | le plus + adj + 名词 | le plus beau jour |
| 表语 | le/la/les plus + adj | Cette ville est la plus grande. |
| 副词 | le plus + adv | Il répond le plus rapidement. |

`meilleur` 的最高级：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| le meilleur | C'est le meilleur choix. | bon 的最高级 |
| la meilleure | C'est la meilleure solution. | 阴性 |
| les meilleurs | Ce sont les meilleurs résultats. | 复数 |
| le mieux | C'est lui qui travaille le mieux. | bien 的最高级 |

### 8.5 autant / aussi / tant / tellement

这些词都和“同样、这么、那么、多”有关，但词类和结构不同。

| 表达 | 后接 | 含义 | 例句 |
| ---- | ---- | ---- | ---- |
| aussi | 形容词/副词 | 一样、也、这么 | aussi important que |
| autant de | 名词 | 同样多 | autant de temps que toi |
| autant | 动词 | 同样多/同样程度 | Il travaille autant que moi. |
| tant de | 名词 | 如此多 | tant de problèmes |
| tant | 动词 | 如此多、这么 | Il a tant travaillé. |
| tellement | 形容词/副词/动词 | 如此、非常 | tellement difficile, tellement vite |
| tellement de | 名词 | 如此多 | tellement de bruit |

`aussi` vs `autant`：

| 比较对象 | 正确 | 错误 | 说明 |
| -------- | ---- | ---- | ---- |
| 形容词 | aussi grand que | autant grand que | 形容词用 aussi |
| 副词 | aussi vite que | autant vite que | 副词用 aussi |
| 名词数量 | autant de livres que | aussi de livres que | 名词用 autant de |
| 动词程度 | travailler autant que | travailler aussi que | 动词用 autant |

`tant` / `tellement` 的结果结构：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| tellement + adj + que | Il est tellement fatigué qu'il dort. | 如此……以至于 |
| tellement + adv + que | Elle parle tellement vite que je ne comprends pas. | 副词 |
| tellement de + nom + que | Il y a tellement de bruit qu'on ne s'entend pas. | 名词数量 |
| tant + verbe + que | Il a tant travaillé qu'il est épuisé. | 较书面 |
| tant de + nom + que | Il a tant de livres qu'il manque de place. | 书面或强调 |

### 8.6 倍数表达

倍数比较常用 `deux fois / trois fois + plus/moins/aussi... que`，也可用 `le double`, `la moitié`, `deux fois plus de` 等名词数量结构。

| 含义 | 结构 | 例句 | 说明 |
| ---- | ---- | ---- | ---- |
| 两倍大/快 | deux fois plus + adj/adv + que | Cette salle est deux fois plus grande que l'autre. | 字面常表示“是……的两倍程度” |
| 三倍少 | trois fois moins + adj/adv + que | C'est trois fois moins cher. | 价格等常用 |
| 精确两倍数量 | deux fois autant de + nom que | Il a deux fois autant de livres que moi. | 较精确，但日常也常用 deux fois plus de |
| 两倍数量 | deux fois plus de + nom + que | Il a deux fois plus de livres que moi. | 名词数量 |
| 一半 | la moitié de | La moitié des étudiants sont absents. | 半数 |
| 两倍 | le double de | C'est le double du prix. | 名词结构 |
| 三倍 | le triple de | Il gagne le triple de mon salaire. | 名词结构 |

更自然的倍数表达：

| 中文 | 法语 | 说明 |
| ---- | ---- | ---- |
| 这个房间是那个的两倍大。 | Cette pièce est deux fois plus grande que l'autre. | 常用表达 |
| 价格是两倍。 | Le prix est deux fois plus élevé. / C'est le double. | 可用 élevé 或 double |
| 他书比我多一倍。 | Il a deux fois plus de livres que moi. | 名词数量 |
| 这便宜一半。 | C'est moitié moins cher. | 口语常见 |
| 人数增加了一倍。 | Le nombre a doublé. | 动词 doubler 更自然 |

注意：法语 `deux fois plus` 在实际使用中通常对应“是两倍”或“多一倍”，但数学精确表达可能需改写为 `deux fois autant`、`le double` 或直接给数字，避免歧义。

### 8.7 越来越、越...越...

“越来越……”常用 `de plus en plus`；“越来越不……”用 `de moins en moins`；“越……越……”常用 `plus..., plus...` 或 `moins..., moins...`。

| 中文 | 法语结构 | 例句 | 说明 |
| ---- | -------- | ---- | ---- |
| 越来越 + 形容词 | de plus en plus + adj | C'est de plus en plus difficile. | 越来越难 |
| 越来越 + 副词 | de plus en plus + adv | Il parle de plus en plus vite. | 越来越快 |
| 越来越多 + 名词 | de plus en plus de + nom | Il y a de plus en plus de touristes. | 名词数量 |
| 越来越少 | de moins en moins | J'ai de moins en moins de temps. | 越来越少 |
| 越……越…… | plus..., plus... | Plus je lis, plus je comprends. | 两个分句 |
| 越少……越少…… | moins..., moins... | Moins il dort, moins il se concentre. | 相关变化 |

`plus..., plus...` 结构：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| Plus + S + V, plus + S + V | Plus tu pratiques, plus tu progresses. | 越练越进步 |
| Plus + adjectif, plus... | Plus c'est simple, plus c'est utile. | 越简单越有用 |
| Moins + S + V, plus... | Moins tu hésites, plus tu avances. | 越少犹豫越前进 |
| Plus de + nom, plus... | Plus il y a de temps, mieux c'est. | 名词数量 |

高频固定表达：

| 表达 | 含义 | 例句 |
| ---- | ---- | ---- |
| de mieux en mieux | 越来越好 | Elle parle de mieux en mieux français. |
| de pire en pire | 越来越糟 | La situation va de pire en pire. |
| de moins en moins | 越来越少 | Il sort de moins en moins. |
| de plus en plus souvent | 越来越经常 | On en parle de plus en plus souvent. |

### 8.8 程度副词 très, trop, assez, plutôt

程度副词修饰形容词、副词或动词，表达强弱、过量、足够、相当等。不要把 `très`, `trop`, `beaucoup` 混用。

| 副词 | 基本含义 | 例句 | 语感 |
| ---- | -------- | ---- | ---- |
| très | 很 | très important | 中性加强 |
| trop | 太、过于 | trop cher | 常表示超过合适程度 |
| assez | 相当；足够 | assez clair | 可正可负，依语境 |
| plutôt | 相当、倒是 | plutôt intéressant | 温和评价 |
| vraiment | 真地、确实 | vraiment utile | 主观强调 |
| tout à fait | 完全 | tout à fait normal | 完全、正式 |
| complètement | 完全 | complètement faux | 强烈 |
| presque | 几乎 | presque impossible | 接近 |

`très` vs `beaucoup`：

| 修饰对象 | 正确 | 错误 | 说明 |
| -------- | ---- | ---- | ---- |
| 形容词 | très intéressant | beaucoup intéressant | 形容词用 très |
| 副词 | très vite | beaucoup vite | 副词用 très |
| 动词 | J'aime beaucoup ce livre. | J'aime très ce livre. | 动词用 beaucoup |
| 名词数量 | beaucoup de livres | très de livres | 名词数量用 beaucoup de |
| 过去分词形容词化 | très fatigué | beaucoup fatigué | 表状态用 très |

`trop` 的语感：

| 句子 | 含义 | 说明 |
| ---- | ---- | ---- |
| C'est très cher. | 很贵。 | 中性强度 |
| C'est trop cher. | 太贵了。 | 超出可接受范围 |
| C'est trop bien ! | 太好了！ | 口语中可作正面夸张 |
| Il travaille trop. | 他工作过度。 | 动词程度 |
| Il y a trop de bruit. | 噪音太多。 | 名词数量 |

### 8.9 比较结构常见错误速查

| 错误句 | 推荐改法 | 错因 | 记忆点 |
| ------ | -------- | ---- | ------ |
| Elle est plus grande de moi. | Elle est plus grande que moi. | 比较基准介词错误 | 比较用 que |
| Il parle plus vite de moi. | Il parle plus vite que moi. | 副词比较也用 que | plus + adv + que |
| Elle est aussi intelligente comme lui. | Elle est aussi intelligente que lui. | 同等比较误用 comme | aussi...que |
| J'ai plus livres que toi. | J'ai plus de livres que toi. | 名词数量缺 de | plus de + nom |
| Il a aussi de temps que moi. | Il a autant de temps que moi. | 名词数量误用 aussi | autant de + nom |
| Il travaille aussi que moi. | Il travaille autant que moi. | 动词程度误用 aussi | verbe + autant que |
| Ce livre est plus bon. | Ce livre est meilleur. | bon 的比较级错误 | bon -> meilleur |
| Elle chante meilleure. | Elle chante mieux. | bien 的比较级错误 | 修饰动词用 mieux |
| Cette solution est mieux. | Cette solution est meilleure. | 评价名词品质应用 meilleur | solution 阴性 |
| C'est le plus bon choix. | C'est le meilleur choix. | bon 的最高级错误 | le meilleur |
| Il court le mieux vite. | Il court le plus vite. | vite 的最高级错误 | le plus + adv |
| C'est la plus intéressante livre. | C'est le livre le plus intéressant. | 后置形容词最高级位置错误 | 名词 + le plus + 后置形容词 |
| Elle est plus intelligente que moi suis. | Elle est plus intelligente que moi. | 比较后重复结构不自然 | 重读代词即可 |
| Plus je lis, je comprends plus. | Plus je lis, plus je comprends. | “越……越……”结构错误 | plus..., plus... |
| De plus en plus de difficile. | De plus en plus difficile. | 形容词前误加 de | de plus en plus + adj |
| Beaucoup intéressant. | Très intéressant. | 程度副词误用 | très + adj |
| Très de livres. | Beaucoup de livres. | 名词数量误用 très | beaucoup de + nom |
| Beaucoup cher. | Très cher. / Trop cher. | 程度副词误用 | 形容词用 très/trop，不用 beaucoup |
| Deux fois plus de cher. | Deux fois plus cher. | 形容词倍数误加 de | deux fois plus + adj |
| Le prix est deux fois plus grand. | Le prix est deux fois plus élevé. | 价格高低搭配不自然 | prix élevé/bas |

## 9. 副词与状语（Adverbes et compléments circonstanciels）

副词修饰动词、形容词、副词或整个句子；状语可以是副词、介词短语、名词短语或从句。法语副词的难点不是词形本身，而是**放在变位动词前后、助动词和过去分词之间、不定式前后**的选择，以及 `déjà/encore/toujours`, `bien/bon/mieux/meilleur` 等高频词的语义差别。

### 9.1 副词类型总览

| 类型 | 常见副词/状语 | 修饰对象 | 例句 | 说明 |
| ---- | ------------- | -------- | ---- | ---- |
| 方式 | bien, mal, vite, lentement | 动词 | Il parle lentement. | 怎样做 |
| 时间 | aujourd'hui, hier, déjà, bientôt | 动词/句子 | Elle arrive bientôt. | 何时 |
| 频率 | souvent, toujours, parfois, jamais | 动词/习惯 | Je viens souvent ici. | 多常 |
| 地点 | ici, là, partout, ailleurs | 动词/句子 | Il habite ailleurs. | 哪里 |
| 程度 | très, trop, assez, plutôt | 形容词/副词/动词 | C'est très utile. | 强弱程度 |
| 数量 | beaucoup, peu, assez, trop | 动词/名词数量 | Il travaille beaucoup. | 动作程度或数量 |
| 句子副词 | probablement, heureusement, franchement | 整句 | Heureusement, il va bien. | 说话人态度 |
| 连接副词 | donc, pourtant, cependant, ensuite | 句子/语篇 | Il pleut, pourtant je sors. | 逻辑连接 |

副词和状语的区别：

| 项目 | 副词 adverbe | 状语 complément circonstanciel |
| ---- | ------------ | ----------------------------- |
| 词类/功能 | 副词是词类 | 状语是句子成分 |
| 形式 | vite, souvent, ici | à Paris, tous les jours, avec soin |
| 例句 | Il répond vite. | Il répond avec soin. |
| 重点 | 一个词怎样修饰 | 整个成分表达时间、地点、方式等 |

### 9.2 -ment 副词构成

很多方式副词由形容词加 `-ment` 构成，近似英语 `-ly`，但法语通常从阴性形式或特殊词干构成。

| 形容词类型 | 构成 | 例子 | 说明 |
| ---------- | ---- | ---- | ---- |
| 一般形容词 | 阴性形式 + -ment | lente -> lentement | lent -> lente -> lentement |
| 阳性以元音结尾 | 阳性形式 + -ment | vrai -> vraiment | 不另加阴性 e |
| -ant 结尾 | -amment | constant -> constamment | 发音近 -amment |
| -ent 结尾 | -emment | récent -> récemment | 发音也近 -amment |
| 特殊 | 词干变化 + -ment | bref -> brièvement | bref 阴性 brève，词干变化 |
| 特殊 | 特殊副词形式 | gentil -> gentiment | 不按 gentillement |

高频 `-ment` 副词：

| 形容词 | 副词 | 例句 |
| ------ | ---- | ---- |
| rapide | rapidement | Il répond rapidement. |
| lent | lentement | Parle plus lentement. |
| clair | clairement | Explique clairement. |
| sérieux | sérieusement | Il travaille sérieusement. |
| vrai | vraiment | C'est vraiment utile. |
| naturel | naturellement | Elle parle naturellement. |
| général | généralement | Généralement, ça marche. |
| complet | complètement | C'est complètement faux. |
| récent | récemment | Je l'ai vu récemment. |
| prudent | prudemment | Conduis prudemment. |

注意：不是所有副词都来自形容词，也不是所有形容词都适合机械加 `-ment`。口语里常用短副词或介词短语替代。

### 9.3 高频非 -ment 副词

很多最常用副词不是 `-ment` 形式，必须作为基本词记。

| 副词 | 含义 | 例句 | 注意 |
| ---- | ---- | ---- | ---- |
| bien | 好、很、确实 | Il parle bien. | 副词，不配合 |
| mal | 不好、糟 | Il dort mal. | 比较级 plus mal |
| vite | 快 | Va vite. | 不说 vitement |
| tôt | 早 | Je pars tôt. | 反义 tard |
| tard | 晚 | Il rentre tard. | 时间副词 |
| souvent | 经常 | Je viens souvent. | 频率 |
| toujours | 总是、仍然 | Il travaille toujours ici. | 语义依上下文 |
| déjà | 已经 | Il est déjà parti. | 复合时态常在助动词后 |
| encore | 还、再、仍然 | Encore une fois. | 语义复杂 |
| ici | 这里 | Viens ici. | 地点 |
| là | 那里、这儿 | Il est là. | 口语常用 |
| ailleurs | 别处 | Cherche ailleurs. | 地点 |
| beaucoup | 很多、很 | Il travaille beaucoup. | 修饰动词或数量 |
| peu | 少 | Il parle peu. | 修饰动词或数量 |
| assez | 足够、相当 | C'est assez clair. | 程度 |
| trop | 太、多过头 | Tu parles trop. | 过量 |

短副词常放在动词附近：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| 简单时态 | Il parle bien. | 副词在动词后 |
| 复合时态 | Il a bien parlé. | 常在助动词和过去分词之间 |
| 不定式 | Il veut bien parler. | 语义可能是“愿意说”或“说得好”，需看上下文 |

### 9.4 副词位置：简单时态

简单时态中，短副词通常放在变位动词后；较长副词、句子副词、时间地点状语位置更灵活。

| 副词类型 | 常见位置 | 例句 | 说明 |
| -------- | -------- | ---- | ---- |
| 方式短副词 | 动词后 | Il parle bien. | bien, mal, vite |
| 频率副词 | 动词后 | Je vais souvent à Paris. | souvent, toujours, parfois |
| 数量副词 | 动词后 | Il travaille beaucoup. | beaucoup, peu, trop |
| 程度副词 | 被修饰词前 | C'est très important. | très 修饰形容词 |
| 长副词 | 动词后或句末 | Il répond clairement. | -ment 副词常后置 |
| 句子副词 | 句首或插入 | Heureusement, il est là. | 修饰整句 |
| 时间/地点状语 | 句首或句末 | Je pars demain. | 句末中性，句首设话题 |

简单时态模板：

| 模板 | 例句 | 说明 |
| ---- | ---- | ---- |
| S + V + adv | Elle chante bien. | 默认 |
| S + V + adv + complément | Il lit souvent le soir. | 频率副词靠近动词 |
| S + V + complément + adv long | Elle explique la règle clairement. | 长方式副词可后置 |
| Adv de phrase, S + V | Franchement, je ne sais pas. | 话语副词句首 |

### 9.5 副词位置：复合时态

复合时态中，很多短副词放在**助动词和过去分词之间**。长副词或强调时间地点的状语常放句末或句首。

| 副词类型 | 位置 | 例句 | 说明 |
| -------- | ---- | ---- | ---- |
| bien/mal | 助动词后 | Il a bien compris. | 常见 |
| déjà | 助动词后 | Elle est déjà partie. | 已经 |
| beaucoup | 助动词后 | Il a beaucoup travaillé. | 修饰动作程度 |
| trop/assez/peu | 助动词后 | Tu as trop parlé. | 数量/程度 |
| toujours/souvent | 助动词后或句中 | J'ai souvent vu ce film. | 频率 |
| 长方式副词 | 过去分词后或句末 | Il a répondu clairement. | 更自然 |
| 具体时间地点 | 句末/句首 | Je l'ai vu hier. | 不放助动词后 |

位置对比：

| 自然 | 不自然/意义变 | 说明 |
| ---- | ------------ | ---- |
| Il a déjà fini. | Il a fini déjà. | déjà 通常在助动词后 |
| Elle a bien travaillé. | Elle a travaillé bien. | bien 常夹在中间 |
| Il a travaillé longtemps. | Il a longtemps travaillé. | 两者都可，后者更书面/强调持续 |
| Je l'ai vu hier. | Je l'ai hier vu. | 具体时间不夹在助动词后 |

否定中副词位置：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| ne + auxiliaire + pas encore + participe | Il n'a pas encore fini. | 还没 |
| ne + auxiliaire + jamais + participe | Je n'ai jamais vu ça. | 从未 |
| ne + auxiliaire + plus + participe | Elle n'est plus venue. | 不再 |
| ne + auxiliaire + pas beaucoup + participe | Il n'a pas beaucoup travaillé. | 不太多 |

### 9.6 时间、地点、方式、频率状语

状语可以放句首、句末或句中。句末通常最中性；句首常设置话题、对比或强调。

| 状语类型 | 常见形式 | 例句 | 位置倾向 |
| -------- | -------- | ---- | -------- |
| 时间 | demain, hier, le matin | Je pars demain. | 句末或句首 |
| 地点 | à Paris, ici, dans la rue | Il travaille à Paris. | 句末 |
| 方式 | avec soin, lentement | Elle écrit avec soin. | 动词后 |
| 频率 | souvent, tous les jours | Je fais du sport tous les jours. | 副词靠近动词，短语多句末 |
| 原因 | à cause de, parce que | Il reste à cause de la pluie. | 句末或句首 |
| 目的 | pour + infinitif | Je viens pour t'aider. | 句末 |

时间表达速查：

| 表达 | 含义 | 例句 |
| ---- | ---- | ---- |
| aujourd'hui | 今天 | Je travaille aujourd'hui. |
| maintenant | 现在 | Je suis occupé maintenant. |
| en ce moment | 最近/眼下 | Il cherche un travail en ce moment. |
| bientôt | 很快 | On part bientôt. |
| tout de suite | 马上 | Je reviens tout de suite. |
| déjà | 已经 | Tu as déjà fini ? |
| depuis | 自从/已经持续 | J'habite ici depuis deux ans. |
| pendant | 持续了…… | J'ai travaillé pendant deux heures. |
| il y a | ……以前 | Je suis arrivé il y a dix minutes. |

频率表达：

| 表达 | 含义 | 例句 |
| ---- | ---- | ---- |
| toujours | 总是/仍然 | Il est toujours là. |
| souvent | 经常 | Je lis souvent le soir. |
| parfois / quelquefois | 有时 | Parfois, je rentre tard. |
| rarement | 很少 | Il sort rarement. |
| jamais | 从不 | Je ne bois jamais de café. |
| tous les jours | 每天 | Elle court tous les jours. |
| une fois par semaine | 每周一次 | On se voit une fois par semaine. |

### 9.7 déjà, encore, toujours, ne...plus

这组词都和“已经、还、仍然、不再”有关，中文容易混。

| 法语 | 常见含义 | 例句 | 说明 |
| ---- | -------- | ---- | ---- |
| déjà | 已经 | Il est déjà parti. | 动作已发生 |
| encore | 还、仍然 | Il est encore là. | 状态持续 |
| encore | 再、又 | Encore une fois. | 追加 |
| toujours | 总是 | Il arrive toujours en retard. | 习惯 |
| toujours | 仍然 | Il travaille toujours ici. | 状态持续 |
| ne...plus | 不再 | Il ne travaille plus ici. | 过去有，现在无 |
| pas encore | 还没有 | Il n'est pas encore arrivé. | 尚未发生 |

对比速查：

| 中文 | 法语 | 例句 |
| ---- | ---- | ---- |
| 已经完成 | déjà | J'ai déjà fini. |
| 还没完成 | pas encore | Je n'ai pas encore fini. |
| 仍然在这里 | encore / toujours | Il est encore là. / Il est toujours là. |
| 不再在这里 | ne...plus | Il n'est plus là. |
| 再来一次 | encore | Encore une fois. |
| 从不 | ne...jamais | Il ne vient jamais. |

`encore` vs `toujours`：

| 句子 | 语感 |
| ---- | ---- |
| Il est encore là. | 他还在，常带“本来可能离开”的语感 |
| Il est toujours là. | 他仍然在，也可表示一直如此 |
| Il travaille encore. | 他还在工作/又工作了，需语境 |
| Il travaille toujours. | 他仍在工作/总是工作 |

### 9.8 bien, bon, mieux, meilleur

`bon` 是形容词，修饰名词并配合；`bien` 是副词，修饰动词、形容词或整个判断。比较级分别是 `meilleur` 和 `mieux`。

| 词 | 词类 | 用法 | 例句 |
| -- | ---- | ---- | ---- |
| bon/bonne | 形容词 | 修饰名词 | un bon repas, une bonne idée |
| bien | 副词 | 修饰动词 | Il parle bien. |
| bien | 副词/程度 | 修饰形容词 | C'est bien utile. |
| meilleur(e)(s) | 形容词比较级 | 更好的 | une meilleure solution |
| mieux | 副词比较级 | 更好地、状态更好 | Il travaille mieux. |
| mal | 副词/形容词性固定 | 不好 | Je dors mal. |
| mauvais(e) | 形容词 | 坏的 | une mauvaise réponse |

高频结构：

| 想表达 | 法语 | 说明 |
| ------ | ---- | ---- |
| 这是好主意 | C'est une bonne idée. | 形容词配合 idée |
| 他讲得好 | Il parle bien. | 副词修饰 parle |
| 这个更好 | C'est mieux. | 中性指代，mieux 常用 |
| 这个方案更好 | Cette solution est meilleure. | 修饰 solution |
| 我好多了 | Je vais mieux. | 状态 |
| 祝你好运 | Bonne chance ! | 固定祝愿 |
| 很好 | Très bien. | 回答/评价 |

### 9.9 句子副词和话语副词

句子副词不只修饰动词，而是表达说话人对整句的判断、态度、信息来源或语篇组织。常放句首并用逗号隔开。

| 功能 | 副词/短语 | 例句 | 说明 |
| ---- | --------- | ---- | ---- |
| 可能性 | probablement, peut-être | Probablement, il viendra. | 可能 |
| 确定性 | certainement, sans doute | Il viendra sans doute. | sans doute 常表示“很可能” |
| 态度 | malheureusement, heureusement | Heureusement, tout va bien. | 幸好/不幸 |
| 诚实说明 | franchement, honnêtement | Franchement, je ne sais pas. | 话语标记 |
| 逻辑连接 | donc, pourtant, cependant | Il pleut, pourtant je sors. | 连接上下文 |
| 顺序 | d'abord, ensuite, enfin | D'abord, lis le texte. | 组织步骤 |
| 总结 | bref, en résumé | Bref, c'est impossible. | 概括 |

`peut-être` 与倒装：

| 结构 | 例句 | 语体 |
| ---- | ---- | ---- |
| Peut-être que + 陈述句 | Peut-être qu'il viendra. | 中性、口语常用 |
| Peut-être + 陈述句 | Peut-être il viendra. | 口语可见，正式写作避免 |
| Peut-être + 倒装 | Peut-être viendra-t-il. | 书面、正式 |

### 9.10 状语顺序和信息焦点

法语状语顺序没有一个永远固定的公式。中性句中，短副词靠近动词，时间/地点/方式短语常放句末；被放到句首的状语通常成为话题或对比焦点。

| 排列 | 例句 | 语感 |
| ---- | ---- | ---- |
| 中性 | Je travaille à Paris tous les jours. | 地点 + 时间，普通陈述 |
| 时间前置 | Tous les jours, je travaille à Paris. | 强调频率/设定话题 |
| 地点前置 | À Paris, je travaille tous les jours. | 和别处对比 |
| 方式靠后 | Elle a expliqué la règle clairement. | 方式说明 |
| 短副词靠近动词 | Elle explique souvent la règle. | 频率靠近动作 |
| 长状语句首 | Pendant les vacances, je lis beaucoup. | 时间框架 |

多个状语的实用顺序：

| 优先策略 | 例句 | 说明 |
| -------- | ---- | ---- |
| 短副词靠近动词 | Il travaille souvent le soir. | often 类型 |
| 具体地点后置 | Elle habite à Lyon. | 地点补足 |
| 时间框架可前置 | En 2020, il habitait à Lyon. | 设背景 |
| 新信息放句末 | Il a rencontré Marie hier. | 句末承载重点 |
| 对比信息放句首 | Hier, il a rencontré Marie, pas aujourd'hui. | 对比 |

### 9.11 副词常见错误速查

| 错误句 | 推荐改法 | 错因 | 记忆点 |
| ------ | -------- | ---- | ------ |
| Il parle bon français. | Il parle bien français. | 修饰动词应用副词 | bien 修饰 parler |
| C'est une bien idée. | C'est une bonne idée. | 修饰名词应用形容词 | bon/bonne + 名词 |
| Elle chante bonne. | Elle chante bien. | 副词误作形容词 | chanter bien |
| Il travaille beaucoup bien. | Il travaille très bien. | 程度副词搭配错误 | très + bien |
| Il court vitement. | Il court vite. | vite 不是 -ment 形式 | 直接用 vite |
| Je ne viens jamais pas. | Je ne viens jamais. | 否定副词和 pas 误叠 | ne...jamais 不再加 pas |
| Je souvent vais à Paris. | Je vais souvent à Paris. | 副词位置受英语影响 | 简单时态副词多在动词后 |
| Il a fini déjà. | Il a déjà fini. | 复合时态副词位置错误 | déjà 在助动词后 |
| Elle a travaillé bien. | Elle a bien travaillé. | bien 位置错误 | 助动词 + bien + participe |
| Je l'ai hier vu. | Je l'ai vu hier. | 具体时间不能夹在助动词后 | 时间状语常句末 |
| Il n'est encore pas arrivé. | Il n'est pas encore arrivé. | pas encore 顺序错误 | pas encore = 还没 |
| Il ne travaille pas plus ici. | Il ne travaille plus ici. | “不再”结构错误 | ne...plus |
| Il est toujours pas là. | Il n'est toujours pas là. | 标准否定缺 ne | 书面语保留 ne |
| Beaucoup intéressant. | Très intéressant. | 修饰形容词误用 beaucoup | très + adjectif |
| Très de livres. | Beaucoup de livres. | 名词数量误用 très | beaucoup de + nom |
| Je suis meilleur aujourd'hui. | Je vais mieux aujourd'hui. | 表身体状态用 aller mieux | mieux 是副词 |
| Cette réponse est mieux. | Cette réponse est meilleure. | 修饰名词品质用 meilleur | meilleure 配合 réponse |
| Peut-être il viendra. | Peut-être qu'il viendra. / Peut-être viendra-t-il. | 正式写作中结构不稳 | 用 peut-être que 或倒装 |
| Heureusement il est là. | Heureusement, il est là. | 句子副词后缺逗号 | 句首话语副词常加逗号 |
| J'habite ici depuis deux ans passé. | J'habite ici depuis deux ans. | depuis 已表示持续到现在 | 不加 passé |

## 10. 代词系统总览（Pronoms I）

代词用来替代名词短语、从句、地点、数量或整个情况。法语代词系统的难点有三点：**形式按语法功能变化**，主语、重读、直接宾语、间接宾语不是同一套形式；**位置高度固定**，宾语代词通常在动词前；**指代必须清楚**，代词的性数、人称和语义要能回到明确对象。本章先建立地图和基础代词，宾语代词、`y/en`、关系代词在第 11-12 章展开。

### 10.1 代词地图

| 代词类型 | 法语名称 | 常见形式 | 主要功能 | 例句 |
| -------- | -------- | -------- | -------- | ---- |
| 主语代词 | pronoms sujets | je, tu, il, elle, on, nous, vous, ils, elles | 作主语，决定动词变位 | Je parle. |
| 重读代词 | pronoms toniques | moi, toi, lui, elle, nous, vous, eux, elles | 强调、介词后、独立回答 | Moi, je suis prêt. |
| 反身代词 | pronoms réfléchis | me, te, se, nous, vous, se | 代词式动词、反身动作 | Je me lève. |
| 直接宾语代词 | pronoms COD | me, te, le, la, nous, vous, les | 替代直接宾语 | Je le vois. |
| 间接宾语代词 | pronoms COI | me, te, lui, nous, vous, leur | 替代 à + 人 | Je lui parle. |
| y | pronom y | y | 地点、à + 物 | J'y vais. |
| en | pronom en | en | de + 物、部分量、数量 | J'en veux. |
| 中性代词 | pronoms neutres | ce, cela, ça, le | 替代情况、从句、判断 | C'est vrai. |
| 指示代词 | pronoms démonstratifs | celui, celle, ceux, celles | 替代“那个/那些”名词 | Celui-ci est meilleur. |
| 物主代词 | pronoms possessifs | le mien, la tienne | 替代“我的/你的……” | C'est le mien. |
| 不定代词 | pronoms indéfinis | quelqu'un, rien, chacun | 泛指或不定对象 | Quelqu'un arrive. |
| 疑问代词 | pronoms interrogatifs | qui, que, quoi, lequel | 提问 | Qui vient ? |
| 关系代词 | pronoms relatifs | qui, que, dont, où, lequel | 引导关系从句 | Le livre que j'ai lu. |

先区分“限定词”和“代词”：

| 类型 | 后面是否接名词 | 例子 | 说明 |
| ---- | -------------- | ---- | ---- |
| 限定词 | 接名词 | mon livre, ce livre | 不替代名词，只限定名词 |
| 代词 | 不接名词 | le mien, celui-ci | 自己替代名词短语 |
| 形容词 | 修饰名词 | un livre intéressant | 描述性质 |
| 副词 | 修饰动词/形容词 | Il parle bien. | 不替代名词 |

代词选择第一步：判断它在句中做什么。

| 被替代对象 | 句中功能 | 常用代词 | 例句 |
| ---------- | -------- | -------- | ---- |
| Paul | 主语 | il | Paul arrive. -> Il arrive. |
| Marie | 直接宾语 | la | Je vois Marie. -> Je la vois. |
| Paul | à + 人 | lui | Je parle à Paul. -> Je lui parle. |
| Paris | 地点 | y | Je vais à Paris. -> J'y vais. |
| du café | 部分量 | en | Je veux du café. -> J'en veux. |
| cette idée | 指示替代 | celle-ci | Cette idée est meilleure. -> Celle-ci est meilleure. |
| 整个情况 | 中性指代 | ça / ce | Ça m'étonne. / C'est vrai. |

### 10.2 主语代词 je, tu, il, elle, on, nous, vous, ils, elles

主语代词放在变位动词前，决定动词人称和数。法语一般不能像汉语那样随意省略主语。

| 人称 | 主语代词 | 用法 | 例句 |
| ---- | -------- | ---- | ---- |
| 第一人称单数 | je / j' | 我 | Je parle. / J'aime. |
| 第二人称单数 | tu | 你，熟人/非正式 | Tu viens ? |
| 第三人称阳性单数 | il | 他、它、形式主语 | Il arrive. / Il pleut. |
| 第三人称阴性单数 | elle | 她、它 | Elle est prête. |
| 不定/口语第一人称复数 | on | 人们、我们、有人 | On y va ? |
| 第一人称复数 | nous | 我们，较正式或强调 | Nous partons demain. |
| 第二人称复数/礼貌 | vous | 你们、您 | Vous comprenez ? |
| 第三人称阳性复数 | ils | 他们、它们，混合复数 | Ils sont là. |
| 第三人称阴性复数 | elles | 她们、阴性复数物 | Elles sont parties. |

主语代词和动词变位：

| 主语 | parler | être | avoir |
| ---- | ------ | ---- | ----- |
| je | je parle | je suis | j'ai |
| tu | tu parles | tu es | tu as |
| il/elle/on | il parle | il est | il a |
| nous | nous parlons | nous sommes | nous avons |
| vous | vous parlez | vous êtes | vous avez |
| ils/elles | ils parlent | ils sont | ils ont |

主语不能随意省略：

| 中文 | 错误/不完整 | 正确 | 说明 |
| ---- | ----------- | ---- | ---- |
| 我不知道。 | Ne sais pas. | Je ne sais pas. | 标准法语需要主语 |
| 下雨了。 | Pleut. | Il pleut. | 非人称 il |
| 很重要。 | Est important. | C'est important. / Il est important de... | 需要主语 |
| 走吧？ | Va ? | On y va ? | 口语常用 on |

### 10.3 on 的用法

`on` 是法语最高频代词之一。动词按第三人称单数变位，但语义可以是“我们、人们、有人、大家、一般人”。

| 用法 | 例句 | 含义 | 注意 |
| ---- | ---- | ---- | ---- |
| 口语我们 | On part demain. | 我们明天走。 | 动词第三人称单数 |
| 泛指人们 | En France, on mange tard. | 在法国，人们吃饭晚。 | 类似“大家/人们” |
| 不明确主语 | On frappe à la porte. | 有人敲门。 | 不知道是谁 |
| 建议/邀请 | On y va ? | 走吗？ | 高频口语 |
| 被动意味 | On m'a volé mon sac. | 我的包被偷了。 | 法语常用 on 代替被动 |

`on` 和配合：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| 动词变位 | On est prêts. | 动词仍用 est |
| 形容词语义配合 | On est prêts/prêtes. | 如果 on = nous，形容词可按实际人群配合 |
| 过去分词 | On est partis tôt. | on = nous 时，partis 可按实际主语配合 |
| 泛指 on | On est souvent fatigué après ça. | 泛指时常用阳性单数 |

`nous` vs `on`：

| 表达 | 语体 | 例句 |
| ---- | ---- | ---- |
| nous | 正式、强调、书面 | Nous avons décidé de partir. |
| on | 口语、中性日常 | On a décidé de partir. |
| nous + on 同句 | 强调群体 | Nous, on préfère rester. |

### 10.4 tu / vous 的语用差异

`tu` 和 `vous` 不只是单复数差异，还体现礼貌、距离、身份和场合。选错会显得过分亲密或过分疏远。

| 形式 | 用法 | 例句 | 语感 |
| ---- | ---- | ---- | ---- |
| tu | 单数熟人、家人、朋友、儿童 | Tu viens ce soir ? | 亲近、非正式 |
| vous | 复数你们 | Vous venez ce soir ? | 对多人 |
| vous | 单数礼貌“您” | Vous avez une réservation ? | 礼貌、正式 |
| on se tutoie ? | 是否用 tu 相称 | On peut se tutoyer ? | 请求转为 tu |
| vouvoyer | 用 vous 称呼 | Je préfère vous vouvoyer. | 保持距离 |

常见场景：

| 场景 | 常用形式 | 说明 |
| ---- | -------- | ---- |
| 店员、客户、陌生成年人 | vous | 默认礼貌 |
| 老师和学生 | 视地区/学校而定 | 初学写作默认 vous 更稳 |
| 同龄朋友 | tu | 关系确立后 |
| 工作同事 | 视公司文化 | 法国现代职场常见 tu，但不绝对 |
| 邮件正式开头 | vous | Madame, Monsieur, vous... |

动词和物主也要跟着变：

| 含义 | tu | vous |
| ---- | -- | ---- |
| 你叫什么？ | Comment tu t'appelles ? | Comment vous vous appelez ? |
| 你的名字 | ton nom | votre nom |
| 你好吗？ | Tu vas bien ? | Vous allez bien ? |
| 请坐 | Assieds-toi. | Asseyez-vous. |

### 10.5 重读代词 moi, toi, lui, elle, nous, vous, eux, elles

重读代词用于强调、介词后、比较后、独立回答、`c'est` 结构等。它们不能替代普通主语代词的位置。

| 主语代词 | 重读代词 | 例句 | 用法 |
| -------- | -------- | ---- | ---- |
| je | moi | Moi, je suis d'accord. | 强调“我” |
| tu | toi | Et toi ? | 独立使用 |
| il | lui | Je viens avec lui. | 介词后 |
| elle | elle | C'est elle. | c'est 后 |
| nous | nous | Chez nous, c'est différent. | 介词后 |
| vous | vous | Je pense à vous. | 介词后 |
| ils | eux | C'est pour eux. | 介词后 |
| elles | elles | Elle parle d'elles. | 介词后 |

重读代词常见位置：

| 场景 | 结构 | 例句 |
| ---- | ---- | ---- |
| 句首强调 | Moi, je... | Moi, je préfère rester. |
| 介词后 | préposition + pronom tonique | avec toi, pour lui, chez nous |
| 比较后 | que + pronom tonique | Elle est plus grande que moi. |
| c'est 后 | c'est + pronom tonique | C'est moi. |
| 独立回答 | pronom seul | Qui veut venir ? Moi. |
| et/ou 后 | Paul et moi | Paul et moi, nous partons. |

不要把重读代词当普通主语：

| 错误 | 正确 | 说明 |
| ---- | ---- | ---- |
| Moi suis prêt. | Je suis prêt. / Moi, je suis prêt. | moi 不能直接接变位动词 |
| Toi viens ? | Tu viens ? | 普通主语用 tu |
| Lui est français. | Il est français. / Lui, il est français. | 强调时要补主语 il |

### 10.6 反身代词 me, te, se, nous, vous, se

反身代词用于代词式动词或反身动作，位置通常在变位动词前。它和主语人称一致。

| 主语 | 反身代词 | 例句 | 说明 |
| ---- | -------- | ---- | ---- |
| je | me / m' | Je me lève. | 元音前 m' |
| tu | te / t' | Tu te souviens ? | 元音前 t' |
| il/elle/on | se / s' | Elle se repose. | 元音前 s' |
| nous | nous | Nous nous promenons. | 同形 |
| vous | vous | Vous vous appelez comment ? | 同形 |
| ils/elles | se / s' | Ils se connaissent. | 复数 |

反身/代词式动词类型：

| 类型 | 例句 | 说明 |
| ---- | ---- | ---- |
| 真反身 | Elle se regarde. | 她看自己 |
| 相互动词 | Ils se parlent. | 他们互相说话 |
| 固定代词式 | Je me souviens de lui. | se souvenir 必须带反身代词 |
| 被动/自发意味 | Ça se voit. | 看得出来 |
| 日常动作 | se lever, se laver, s'habiller | 起床、洗、穿衣 |

反身代词位置：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| 简单时态 | Je me lève. | 变位动词前 |
| 否定 | Je ne me lève pas. | ne + 反身代词 + 动词 + pas |
| 复合时态 | Je me suis levé. | 反身代词在助动词前 |
| 不定式 | Je vais me lever. | 在不定式前 |
| 肯定命令 | Lève-toi. | 动词后，me/te -> moi/toi |
| 否定命令 | Ne te lève pas. | 回到动词前 |

### 10.7 ce, il, cela, ça 作形式主语或中性指代

`ce`, `il`, `cela`, `ça` 都可以指代情况，但用法不同。`ce/c'` 常用于识别、评价和强调；`il` 常作非人称形式主语；`ça` 是口语中性指代；`cela` 较书面。

| 形式 | 用法 | 例句 | 说明 |
| ---- | ---- | ---- | ---- |
| c'est / ce sont | 识别、定义、介绍 | C'est Marie. / Ce sont mes amis. | 后接名词常用 c'est |
| c'est + adjectif | 整体评价 | C'est important. | 评价整个情况 |
| il est + adjectif + de/que | 非人称评价 | Il est important de vérifier. | 后接不定式/从句 |
| il y a | 有、存在 | Il y a un problème. | 固定存在结构 |
| il fait | 天气/温度 | Il fait froid. | 固定天气结构 |
| ça | 这/那/这件事 | Ça marche. | 口语中性 |
| cela | 这/那件事 | Cela dépend. | 较正式 |

`c'est` vs `il/elle est`：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| c'est + 名词 | C'est un médecin. | 识别身份 |
| il/elle est + 职业 | Elle est médecin. | 说明职业 |
| c'est + 形容词 | C'est intéressant. | 评价整个情况 |
| il/elle est + 形容词 | Elle est intéressante. | 评价具体人/物 |
| c'est + 人名/重读代词 | C'est Paul. / C'est moi. | 介绍/识别 |
| il est + 时间 | Il est trois heures. | 时间表达 |

`ce sont` 与口语 `c'est`：

| 表达 | 语体 | 例句 |
| ---- | ---- | ---- |
| ce sont + 复数名词 | 标准书面 | Ce sont mes amis. |
| c'est + 复数名词 | 口语常见 | C'est mes amis. |
| 写作建议 | 用 ce sont | Ce sont des questions importantes. |

### 10.8 代词指代清晰和性数一致

代词必须能清楚指回前文对象，并在必要时体现性数、人称或语义类别。代词选择不清会导致句子歧义。

| 前文对象 | 推荐代词 | 例句 | 说明 |
| -------- | -------- | ---- | ---- |
| le livre | il / le | Il est intéressant. / Je le lis. | 主语 il，COD le |
| la solution | elle / la | Elle marche. / Je la préfère. | 阴性 |
| les enfants | ils / les / leur | Ils jouent. / Je les vois. / Je leur parle. | 功能不同 |
| cette idée | elle / cela / ça | Elle est utile. / Ça m'intéresse. | 具体名词或整件事 |
| du café | en | J'en veux. | 部分量 |
| à Paris | y | J'y habite. | 地点 |

避免歧义：

| 有歧义 | 更清楚 | 说明 |
| ------ | ------ | ---- |
| Paul a parlé à Marc parce qu'il était inquiet. | Paul a parlé à Marc parce que Paul était inquiet. | il 指谁不清 |
| Marie a vu Sophie avec sa sœur. | Marie a vu Sophie avec la sœur de Marie. | sa sœur 指谁不清 |
| J'ai mis le livre sur le cahier, puis je l'ai pris. | J'ai pris le livre. / J'ai pris le cahier. | le 指代可能不清 |

代词和配合：

| 情况 | 例句 | 说明 |
| ---- | ---- | ---- |
| 主语代词决定动词 | Ils arrivent. | ils -> 复数动词 |
| 形容词配合代词 | Elle est prête. | elle -> 阴性 |
| 前置 COD 影响过去分词 | Les lettres, je les ai écrites. | 详见一致章 |
| 中性 le 不配合 | Je le crois possible. | le 可指整个判断 |

### 10.9 代词系统常见错误速查

| 错误句 | 推荐改法 | 错因 | 记忆点 |
| ------ | -------- | ---- | ------ |
| Moi suis prêt. | Je suis prêt. / Moi, je suis prêt. | 重读代词误作普通主语 | 主语用 je |
| Toi viens demain ? | Tu viens demain ? | 普通主语错误 | tu + 动词 |
| Lui est mon frère. | Il est mon frère. / C'est mon frère. | lui 不能直接作普通主语 | 识别身份常用 c'est |
| Nous on sommes prêts. | Nous, on est prêts. | on 的动词变位错误 | on + 第三人称单数 |
| On sommes partis. | On est partis. | on 后动词错 | on est |
| Je vais avec il. | Je vais avec lui. | 介词后应用重读代词 | avec lui |
| C'est je. | C'est moi. | c'est 后应用重读代词 | C'est moi. |
| Paul et je partons. | Paul et moi, nous partons. | 并列中应用重读代词 | Paul et moi |
| Je se lève. | Je me lève. | 反身代词人称不一致 | je me |
| Elle me repose. | Elle se repose. | 代词式动词反身代词错误 | elle se |
| Je ne me pas lève. | Je ne me lève pas. | 否定位置错误 | ne + pronom + V + pas |
| Je vais lever me. | Je vais me lever. | 不定式前代词位置错误 | me + infinitif |
| Il est important venir. | Il est important de venir. / C'est important de venir. | 非人称评价后缺 de | il est important de + infinitif |
| Il est Marie. | C'est Marie. | 识别人名应用 c'est | c'est + nom/pronom |
| C'est médecin. | C'est un médecin. / Elle est médecin. | c'est 后名词缺冠词 | c'est + un/une + nom |
| Elle est une médecin. | Elle est médecin. | 职业表语多余冠词 | être + profession |
| Ça sont mes amis. | Ce sont mes amis. | 复数识别标准形式错误 | ce sont |
| Il a Marie dans la salle. | Marie est dans la salle. / Il y a Marie dans la salle. | 把 il y a 写成 il a | 存在结构用 il y a |
| Je pense à ça question. | Je pense à cette question. | ça 是代词，不作限定词 | cette + nom |
| Paul a parlé à Marc parce qu'il était malade. | Paul a parlé à Marc parce que Paul/Marc était malade. | 代词指代不清 | 必要时重复名词 |

## 11. 宾语代词、y/en 与代词顺序（Pronoms II）

法语宾语代词的核心不是“把名词换成代词”这么简单，而是先判断被替代成分是 **直接宾语 COD**、**间接宾语 COI**、**地点**、**à + 事物**、**de + 事物** 还是**部分量/数量**，再把代词放到正确位置。多数宾语代词放在变位动词前；不定式结构中放在真正支配它的动词前；肯定命令式中放在动词后。

### 11.1 COD 代词 le, la, l', les

COD（complément d'objet direct）是不带介词直接跟在动词后的宾语。COD 代词替代人或物，形式按被替代名词的性数变化。

| 名词宾语 | COD 代词 | 例句 | 说明 |
| -------- | -------- | ---- | ---- |
| 阳性单数 | le / l' | Je lis le livre. -> Je le lis. | le 在元音前变 l' |
| 阴性单数 | la / l' | Je connais Marie. -> Je la connais. | 人名也可替代 |
| 复数 | les | Je vois les enfants. -> Je les vois. | 阴阳性复数同形 |
| 整个判断 | le | Je crois que c'est vrai. -> Je le crois. | 中性 le，不配合性数 |

COD 判断：

| 动词 + 宾语 | 问题 | COD? | 代词句 |
| ----------- | ---- | ---- | ------ |
| voir Marie | voir qui ? | 是 | Je la vois. |
| lire le livre | lire quoi ? | 是 | Je le lis. |
| attendre Paul | attendre qui ? | 是 | Je l'attends. |
| chercher les clés | chercher quoi ? | 是 | Je les cherche. |
| aimer le café | aimer quoi ? | 是 | Je l'aime. |

注意：有些中文看似“给/对”，法语却是直接宾语；有些中文看似直接宾语，法语却要介词。

| 法语动词 | 结构 | 例句 | 代词 |
| -------- | ---- | ---- | ---- |
| attendre | attendre quelqu'un | J'attends Paul. | Je l'attends. |
| chercher | chercher quelque chose | Je cherche mes clés. | Je les cherche. |
| regarder | regarder quelqu'un/quelque chose | Je regarde ce film. | Je le regarde. |
| écouter | écouter quelqu'un/quelque chose | J'écoute Marie. | Je l'écoute. |
| aider | aider quelqu'un | J'aide mon frère. | Je l'aide. |

### 11.2 COI 代词 me, te, lui, nous, vous, leur

COI（complément d'objet indirect）通常由介词引出。这里先讲最常见的 **à + 人**，对应 `me, te, lui, nous, vous, leur`。

| 间接宾语 | COI 代词 | 例句 | 说明 |
| -------- | -------- | ---- | ---- |
| à moi | me / m' | Il parle à moi. -> Il me parle. | 实际多不用 à moi 作普通宾语 |
| à toi | te / t' | Je téléphone à toi. -> Je te téléphone. | 元音前 t' |
| à lui / à elle | lui | Je parle à Paul/Marie. -> Je lui parle. | lui 可指男或女 |
| à nous | nous | Elle écrit à nous. -> Elle nous écrit. | 同形 |
| à vous | vous | Je réponds à vous. -> Je vous réponds. | 同形 |
| à eux / à elles | leur | Je téléphone aux enfants. -> Je leur téléphone. | 不加 s |

常见 `à + 人` 动词：

| 动词 | 结构 | 例句 | 代词句 |
| ---- | ---- | ---- | ------ |
| parler à | 对……说话 | Je parle à Marie. | Je lui parle. |
| téléphoner à | 给……打电话 | Je téléphone à Paul. | Je lui téléphone. |
| répondre à | 回答…… | Elle répond aux étudiants. | Elle leur répond. |
| écrire à | 给……写信 | J'écris à mes parents. | Je leur écris. |
| demander à | 问/请求某人 | Je demande à Paul. | Je lui demande. |
| obéir à | 服从 | L'enfant obéit à sa mère. | Il lui obéit. |

`leur` 作 COI 代词不加 `s`，和物主限定词 `leur/leurs` 不同：

| 类型 | 例句 | 说明 |
| ---- | ---- | ---- |
| COI 代词 | Je leur parle. | 固定 leur，无 s |
| 物主限定词单数 | leur maison | 他们的房子 |
| 物主限定词复数 | leurs enfants | 他们的孩子 |

### 11.3 COD / COI 判断方法

COD/COI 不能靠中文判断，要看法语动词要求什么结构。判断流程：先查动词结构，再看名词前是否有介词，最后选择代词。

| 法语结构 | 功能 | 代词 | 例句 |
| -------- | ---- | ---- | ---- |
| verbe + quelqu'un/quelque chose | COD | le, la, les | Je le vois. |
| verbe + à + personne | COI | lui, leur | Je lui parle. |
| verbe + à + chose/idée | à + 物 | y | J'y pense. |
| verbe + de + chose/idée | de + 物 | en | J'en parle. |
| verbe + de + personne | de + 人 | de + 重读代词 | Je parle de lui. |
| lieu | 地点 | y | J'y vais. |
| quantité/partitif | 数量/部分量 | en | J'en ai trois. |

高频易错动词：

| 中文 | 法语结构 | 代词 | 例句 |
| ---- | -------- | ---- | ---- |
| 等某人 | attendre quelqu'un | le/la/les | Je l'attends. |
| 找某物 | chercher quelque chose | le/la/les | Je les cherche. |
| 听某人/某物 | écouter quelqu'un/quelque chose | le/la/les | Je l'écoute. |
| 看某人/某物 | regarder quelqu'un/quelque chose | le/la/les | Je le regarde. |
| 给某人打电话 | téléphoner à quelqu'un | lui/leur | Je lui téléphone. |
| 回答某人 | répondre à quelqu'un | lui/leur | Je leur réponds. |
| 想到某事 | penser à quelque chose | y | J'y pense. |
| 想念某人/思考某人 | penser à quelqu'un | à lui/à elle | Je pense à lui. |
| 谈论某事 | parler de quelque chose | en | J'en parle. |
| 谈论某人 | parler de quelqu'un | de lui/d'elle | Je parle de lui. |

实用测试：

| 原句 | 问题 | 判断 | 代词句 |
| ---- | ---- | ---- | ------ |
| Je vois Paul. | voir qui ? | COD | Je le vois. |
| Je parle à Paul. | parler à qui ? | COI 人 | Je lui parle. |
| Je pense à ce problème. | penser à quoi ? | à + 物 | J'y pense. |
| Je parle de ce problème. | parler de quoi ? | de + 物 | J'en parle. |
| Je parle de Paul. | parler de qui ? | de + 人 | Je parle de lui. |

### 11.4 y：地点与 à + 物

`y` 替代地点，或替代 `à + 事物/概念`。它通常不替代 `à + 人`。

| 被替代成分 | 原句 | 代词句 | 说明 |
| ---------- | ---- | ------ | ---- |
| à Paris | Je vais à Paris. | J'y vais. | 地点 |
| dans ce restaurant | Je mange dans ce restaurant. | J'y mange. | 地点 |
| chez Paul | Je vais chez Paul. | J'y vais. | 地点也可用 y |
| à ce problème | Je pense à ce problème. | J'y pense. | à + 事物 |
| à cette idée | Je réfléchis à cette idée. | J'y réfléchis. | à + 概念 |
| à Paul | Je pense à Paul. | Je pense à lui. | à + 人不用 y |

常见 `à + 物` 动词/结构：

| 结构 | 例句 | 代词句 |
| ---- | ---- | ------ |
| penser à quelque chose | Je pense à ce projet. | J'y pense. |
| réfléchir à quelque chose | Elle réfléchit à la question. | Elle y réfléchit. |
| participer à quelque chose | Nous participons à la réunion. | Nous y participons. |
| s'intéresser à quelque chose | Il s'intéresse à l'histoire. | Il s'y intéresse. |
| tenir à quelque chose | Je tiens à cette règle. | J'y tiens. |

`y` 的位置：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| 简单时态 | J'y vais. | 动词前 |
| 否定 | Je n'y vais pas. | ne + y + V + pas |
| 复合时态 | J'y suis allé. | 助动词前 |
| 不定式 | Je vais y aller. | 不定式前 |
| 肯定命令 | Vas-y. | 动词后，连字符 |
| 否定命令 | N'y va pas. | y 回到动词前 |

### 11.5 en：de + 物、部分量、数量

`en` 替代 `de + 事物/概念`，也替代部分冠词、不定冠词复数、数量表达后的名词。它通常不替代 `de + 人`。

| 被替代成分 | 原句 | 代词句 | 说明 |
| ---------- | ---- | ------ | ---- |
| de ce problème | Je parle de ce problème. | J'en parle. | de + 物 |
| de cette idée | Il se souvient de cette idée. | Il s'en souvient. | de + 概念 |
| du café | Je veux du café. | J'en veux. | 部分冠词 |
| des pommes | J'achète des pommes. | J'en achète. | 不定复数 |
| trois livres | J'ai trois livres. | J'en ai trois. | 数字保留 |
| beaucoup de temps | Il a beaucoup de temps. | Il en a beaucoup. | 数量词保留 |
| de Paul | Je parle de Paul. | Je parle de lui. | de + 人不用 en |

数量相关的 `en`：

| 原句 | 代词句 | 说明 |
| ---- | ------ | ---- |
| J'ai un frère. | J'en ai un. | 数字保留 |
| Elle a deux voitures. | Elle en a deux. | 数字保留 |
| Tu veux du thé ? | Tu en veux ? | 部分量 |
| Il a beaucoup d'amis. | Il en a beaucoup. | beaucoup 保留 |
| Je n'ai pas de questions. | Je n'en ai pas. | 否定数量 |

常见 `de + 物` 动词/结构：

| 结构 | 例句 | 代词句 |
| ---- | ---- | ------ |
| parler de quelque chose | Je parle de ce livre. | J'en parle. |
| avoir besoin de quelque chose | J'ai besoin d'aide. | J'en ai besoin. |
| avoir envie de quelque chose | Elle a envie de café. | Elle en a envie. |
| se souvenir de quelque chose | Il se souvient de cette histoire. | Il s'en souvient. |
| être fier de quelque chose | Nous sommes fiers de ce résultat. | Nous en sommes fiers. |

### 11.6 双代词顺序

两个代词同时出现时，顺序固定。先掌握陈述句和否定句中的普通顺序；肯定命令式另有顺序。

普通句中的顺序：

| 顺序位 | 代词 | 例子 |
| ------ | ---- | ---- |
| 1 | me, te, se, nous, vous | Il me le donne. |
| 2 | le, la, les | Je le lui donne. |
| 3 | lui, leur | Je le leur explique. |
| 4 | y | Je l'y mets. |
| 5 | en | Il m'en parle. |

常见组合：

| 名词句 | 代词句 | 说明 |
| ------ | ------ | ---- |
| Je donne le livre à Paul. | Je le lui donne. | COD le + COI lui |
| Elle montre les photos aux enfants. | Elle les leur montre. | les + leur |
| Il me donne des conseils. | Il m'en donne. | me + en |
| Je mets le livre sur la table. | Je l'y mets. | le + y |
| Tu parles de ce problème à Marie. | Tu lui en parles. | lui + en |

不常用或避免的组合：

| 组合 | 问题 | 推荐 |
| ---- | ---- | ---- |
| y + en | 很少自然连用 | 通常改写，保留一个名词短语 |
| lui + y | 罕见/不自然 | 改用 à lui + 地点或重写 |
| 过多代词 | 理解负担大 | 分成两句或保留名词 |

### 11.7 简单时态中的代词位置

简单时态中，宾语代词、`y/en` 放在变位动词前；否定句中放在 `ne` 和动词之间。

| 结构 | 模板 | 例句 |
| ---- | ---- | ---- |
| 肯定 | S + pronom + V | Je le vois. |
| 否定 | S + ne + pronom + V + pas | Je ne le vois pas. |
| 双代词 | S + pronoms + V | Je le lui donne. |
| y | S + y + V | J'y pense. |
| en | S + en + V | J'en veux. |
| 否定 + en | S + n' + en + V + pas | Je n'en veux pas. |

和副词的位置：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| 代词在动词前 | Je le comprends bien. | bien 仍在动词后 |
| 否定 | Je ne le comprends pas bien. | pas bien 在动词后 |
| 频率副词 | Je le vois souvent. | souvent 在动词后 |
| 双代词 + 副词 | Je le lui explique souvent. | 代词组在动词前 |

### 11.8 复合时态中的代词位置

复合时态中，代词放在助动词前，而不是过去分词前。COD 代词前置时，过去分词可能要和 COD 配合。

| 名词句 | 代词句 | 说明 |
| ------ | ------ | ---- |
| J'ai vu Marie. | Je l'ai vue. | la/l' 指 Marie，过去分词配合 |
| J'ai lu les lettres. | Je les ai lues. | les 前置，lues 配合 |
| J'ai parlé à Paul. | Je lui ai parlé. | COI 不引发过去分词配合 |
| Je suis allé à Paris. | J'y suis allé. | y 在助动词前 |
| J'ai acheté des pommes. | J'en ai acheté. | en 在助动词前 |

否定复合时态：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| ne + pronom + auxiliaire + pas + participe | Je ne l'ai pas vu. | 代词在助动词前 |
| ne + y + auxiliaire + pas + participe | Je n'y suis pas allé. | y 同样前置 |
| ne + en + auxiliaire + pas + participe | Je n'en ai pas acheté. | en 同样前置 |
| jamais/plus | Je ne l'ai jamais vu. | jamais 代替 pas |

配合提醒：

| 情况 | 例句 | 说明 |
| ---- | ---- | ---- |
| 前置 COD | Les lettres, je les ai écrites. | 过去分词和 les 配合 |
| COI | Je leur ai écrit. | leur 是 COI，无配合 |
| en | Des lettres, j'en ai écrit. | en 通常不引发配合 |
| 中性 le | Cette histoire, je l'ai cru possible. | le 指整个判断时通常不配合 |

### 11.9 不定式结构中的代词位置

有两个动词时，代词通常放在真正支配它的那个不定式前，而不是第一个变位动词前。

| 名词句 | 代词句 | 说明 |
| ------ | ------ | ---- |
| Je veux voir Marie. | Je veux la voir. | voir 支配 Marie |
| Je vais acheter ce livre. | Je vais l'acheter. | acheter 支配 ce livre |
| Je peux parler à Paul. | Je peux lui parler. | parler à Paul |
| Je dois penser à ce problème. | Je dois y penser. | penser à + 物 |
| Je veux acheter du pain. | Je veux en acheter. | acheter du pain |

否定和不定式：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| ne + V1 + pas + pronom + infinitif | Je ne veux pas le voir. | 否定夹住 V1 |
| ne + V1 + plus + pronom + infinitif | Je ne peux plus y aller. | plus 也在 V1 后 |
| V1 + ne pas + infinitif | Je préfère ne pas le voir. | 否定不定式本身 |
| V1 + ne pas + pronom + infinitif | Je préfère ne pas lui parler. | 代词仍在不定式前 |

例外提醒：

| 动词 | 例句 | 说明 |
| ---- | ---- | ---- |
| faire + infinitif | Je le fais réparer. | faire causatif 结构特殊，后续动词章展开 |
| laisser + infinitif | Je le laisse partir. | laisser 结构也有特殊性 |
| perception verbs | Je la vois arriver. | voir/entendre + infinitif 中代词常在第一个动词前 |

### 11.10 肯定命令式中的代词位置

肯定命令式中，代词放在动词后，用连字符；`me/te` 变成 `moi/toi`。这是和陈述句最大的位置差异。

| 陈述句 | 肯定命令 | 说明 |
| ------ | -------- | ---- |
| Tu le regardes. | Regarde-le. | COD 后置 |
| Tu me regardes. | Regarde-moi. | me -> moi |
| Tu te lèves. | Lève-toi. | te -> toi |
| Tu lui parles. | Parle-lui. | lui 后置 |
| Tu y vas. | Vas-y. | aller tu 命令保留 -s 便于连音 |
| Tu en prends. | Prends-en. | en 后置 |

肯定命令式双代词顺序：

| 名词句 | 命令式 | 说明 |
| ------ | ------ | ---- |
| Donne le livre à Paul. | Donne-le-lui. | le + lui |
| Donne le livre à moi. | Donne-le-moi. | moi 在后 |
| Donne des livres à Paul. | Donne-lui-en. | lui + en |
| Mets le livre là. | Mets-le là. | 地点副词 là 常直接保留 |

实用提醒：肯定命令式双代词形式虽然有规则，但日常表达中太复杂时，常保留名词或改写句子以避免拗口。

### 11.11 否定命令式中的代词位置

否定命令式中，代词回到动词前，顺序和普通陈述句一样；`moi/toi` 也恢复为 `me/te`。

| 肯定命令 | 否定命令 | 说明 |
| -------- | -------- | ---- |
| Regarde-le. | Ne le regarde pas. | 代词前置 |
| Parle-lui. | Ne lui parle pas. | COI 前置 |
| Donne-le-moi. | Ne me le donne pas. | moi -> me，顺序普通化 |
| Vas-y. | N'y va pas. | y 前置 |
| Prends-en. | N'en prends pas. | en 前置 |
| Lève-toi. | Ne te lève pas. | toi -> te |

否定命令模板：

| 模板 | 例句 |
| ---- | ---- |
| Ne + pronom + V + pas | Ne le fais pas. |
| Ne + pronoms + V + pas | Ne me le donne pas. |
| N' + y/en + V + pas | N'y va pas. / N'en parle pas. |
| Ne + te/vous/nous + V + pas | Ne te lève pas. |

### 11.12 代词位置常见错误速查

| 错误句 | 推荐改法 | 错因 | 记忆点 |
| ------ | -------- | ---- | ------ |
| Je vois le. | Je le vois. | COD 代词位置错误 | 代词在变位动词前 |
| Je la téléphone. | Je lui téléphone. | téléphoner à quelqu'un 是 COI | à + 人 -> lui/leur |
| Je lui vois. | Je le vois. | voir quelqu'un 是 COD | 直接宾语 -> le/la |
| Je parle à lui. | Je lui parle. | 普通 à + 人宾语应前置 | parler à Paul -> lui parler |
| Je pense lui. | Je pense à lui. | penser à + 人不能用 lui 作 COI | à + 人保留 à + 重读代词 |
| Je pense à le problème. | Je pense au problème. / J'y pense. | à + le 未缩合，且可用 y 替代 | à + 物 -> y |
| Je parle de le problème. | Je parle du problème. / J'en parle. | de + le 未缩合，且可用 en 替代 | de + 物 -> en |
| J'y parle. | Je lui parle. / J'en parle. | y 不能替代 à + 人，也不能替代 de | 先判断介词和对象 |
| J'en pense. | J'y pense. | penser à quelque chose | à + 物 -> y |
| Je le donne lui. | Je le lui donne. | COI 代词位置错误 | le/la/les 在 lui/leur 前 |
| Je lui le donne. | Je le lui donne. | 双代词顺序错误 | le/la/les + lui/leur |
| Je ne vois pas le. | Je ne le vois pas. | 否定中代词位置错误 | ne + pronom + V + pas |
| Je ne vois le pas. | Je ne le vois pas. | 否定中代词位置错误 | ne + le + V + pas |
| Je veux voir le. | Je veux le voir. | 不定式结构中代词位置错误 | 支配动词前 |
| Je le veux voir. | Je veux le voir. | 代词放错动词前 | voir 支配 le |
| Je n'ai vu le pas. | Je ne l'ai pas vu. | 复合时态位置错误 | 代词在助动词前 |
| J'ai vu la. | Je l'ai vue. | 代词位置和省音错误 | la + ai -> l'ai |
| Donne-moi le. | Donne-le-moi. | 肯定命令双代词顺序错误 | le + moi |
| Ne donne-le-moi pas. | Ne me le donne pas. | 否定命令位置错误 | 否定命令用普通顺序 |
| N'en vas pas. | N'y va pas. | aller à un lieu 用 y | y = 地点 |
| Je n'ai pas trois. | Je n'en ai pas trois. | 替代数量名词时漏掉 en | 数量词保留，名词用 en 替代 |
| J'en ai trois livres. | J'en ai trois. | en 已替代名词 | 数字保留，名词省略 |

## 12. 指示、物主、不定、疑问与关系代词（Pronoms III）

本章处理“不是主语/宾语位置核心表”的其他代词：指示代词、物主代词、不定代词、疑问代词和关系代词预览。它们的共同点是：**代词本身替代名词短语**，不能再直接接同一个名词；如果要继续限定它，通常要接 `de` 短语、关系从句或 `-ci/-là`。

### 12.1 指示代词 celui, celle, ceux, celles

`celui/celle/ceux/celles` 替代前文已知名词，必须按被替代名词的性数变化。它们通常不能单独裸用，后面常接 `de`、关系从句或 `-ci/-là`。

| 被替代名词 | 指示代词 | 例句 | 说明 |
| ---------- | -------- | ---- | ---- |
| 阳性单数 | celui | Ce livre est plus cher que celui de Paul. | celui = le livre |
| 阴性单数 | celle | Cette voiture est plus rapide que celle de Marie. | celle = la voiture |
| 阳性复数 | ceux | Ces livres sont meilleurs que ceux d'hier. | ceux = les livres |
| 阴性复数 | celles | Ces idées sont plus claires que celles du texte. | celles = les idées |

常见补足结构：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| celui/celle + de + nom | celui de Paul | Paul 的那个 |
| celui/celle + qui... | celui qui parle | 正在说话的那个人/那个东西 |
| celui/celle + que... | celle que j'ai choisie | 我选的那个 |
| celui/celle + dont... | celle dont je parle | 我说的那个 |
| celui-ci / celui-là | celui-ci est meilleur | 这个/那个 |

指示限定词 vs 指示代词：

| 类型 | 形式 | 例句 | 说明 |
| ---- | ---- | ---- | ---- |
| 指示限定词 | ce/cet/cette/ces + 名词 | ce livre | 后面接名词 |
| 指示代词 | celui/celle/ceux/celles | celui de Paul | 自己替代名词 |
| 错误 | celui livre | ce livre / celui-ci | celui 后不能直接接名词 |
| 错误 | ce de Paul | celui de Paul | ce 不能这样替代名词 |

### 12.2 celui-ci / celui-là

`-ci` 表“这个/较近者”，`-là` 表“那个/较远者”。现实使用中，`-là` 也常泛指“那个已知对象”，不一定真的很远。

| 形式 | 性数 | 例句 | 含义 |
| ---- | ---- | ---- | ---- |
| celui-ci | 阳性单数 | Je prends celui-ci. | 这个 |
| celle-ci | 阴性单数 | Celle-ci est moins chère. | 这个/这一件 |
| ceux-ci | 阳性复数 | Ceux-ci sont nouveaux. | 这些 |
| celles-ci | 阴性复数 | Celles-ci sont meilleures. | 这些 |
| celui-là | 阳性单数 | Je préfère celui-là. | 那个 |
| celle-là | 阴性单数 | Celle-là est trop grande. | 那个/那一件 |
| ceux-là | 阳性复数 | Ceux-là sont anciens. | 那些 |
| celles-là | 阴性复数 | Celles-là sont rouges. | 那些 |

对比选择：

| 场景 | 例句 | 说明 |
| ---- | ---- | ---- |
| 两个中选一个 | Celui-ci est bon, mais celui-là est meilleur. | 这个 vs 那个 |
| 近远对比 | Prends ces livres-ci, pas ceux-là. | 这些 vs 那些 |
| 承接上文 | Ce problème-là est difficile. | 指前面说过的问题，可带强调 |

注意 `ce ... -ci/-là` 是限定词结构，`celui-ci/celle-là` 是代词结构：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| ce + nom + -ci | ce livre-ci | 这个书，书仍出现 |
| celui-ci | celui-ci | 这个，名词省略 |
| cette + nom + -là | cette idée-là | 那个想法 |
| celle-là | celle-là | 那个，名词省略 |

### 12.3 中性指示 ce, ceci, cela, ça

中性指示代词替代整件事、一个情况、一个判断或后面的从句。它们不按阳性/阴性变化。

| 形式 | 语体 | 用法 | 例句 |
| ---- | ---- | ---- | ---- |
| ce / c' | 中性、固定结构 | c'est, ce sont, ce qui, ce que | C'est important. |
| ceci | 较正式 | 指“这件事/以下内容” | Ceci est difficile à expliquer. |
| cela | 中性偏书面 | 指“那件事/这件事” | Cela dépend. |
| ça | 口语常用 | 这/那/这件事 | Ça marche. |

`ce qui / ce que / ce dont` 预览：

| 结构 | 例句 | 含义 |
| ---- | ---- | ---- |
| ce qui + verbe | Ce qui m'intéresse, c'est la grammaire. | 让我感兴趣的东西/事情 |
| ce que + sujet + verbe | Ce que je veux, c'est du temps. | 我想要的东西/事情 |
| ce dont + sujet + verbe | Ce dont j'ai besoin, c'est de repos. | 我需要的东西/事情 |
| ce à quoi | Ce à quoi je pense est simple. | 我想到的事情，较书面 |

`ça` 的常见口语句型：

| 句型 | 例句 | 说明 |
| ---- | ---- | ---- |
| Ça va. | Ça va ? | 状态/问候 |
| Ça marche. | D'accord, ça marche. | 行、可行 |
| Ça dépend. | Ça dépend du contexte. | 看情况 |
| Ça m'intéresse. | Cette idée, ça m'intéresse. | 这件事让我感兴趣 |
| Ça se voit. | Ça se voit tout de suite. | 看得出来 |

### 12.4 物主代词 le mien, la tienne, les leurs

物主代词替代“我的那个/你的那些”，形式由被替代名词的性数和拥有者共同决定。它前面总带定冠词。

| 拥有者 | 阳性单数 | 阴性单数 | 阳性复数 | 阴性复数 |
| ------ | -------- | -------- | -------- | -------- |
| je | le mien | la mienne | les miens | les miennes |
| tu | le tien | la tienne | les tiens | les tiennes |
| il/elle/on | le sien | la sienne | les siens | les siennes |
| nous | le nôtre | la nôtre | les nôtres | les nôtres |
| vous | le vôtre | la vôtre | les vôtres | les vôtres |
| ils/elles | le leur | la leur | les leurs | les leurs |

例句：

| 原名词短语 | 物主代词 | 说明 |
| ---------- | -------- | ---- |
| mon livre | le mien | livre 阳性单数 |
| ma voiture | la mienne | voiture 阴性单数 |
| mes livres | les miens | 阳性复数 |
| mes idées | les miennes | 阴性复数 |
| votre maison | la vôtre | maison 阴性单数 |
| leurs enfants | les leurs | enfants 复数 |

物主限定词 vs 物主代词：

| 类型/问题 | 例子 | 推荐/说明 |
| --------- | ---- | --------- |
| 物主限定词 | mon livre | 后面接名词 |
| 物主代词 | le mien | 替代整个名词短语 |
| 误接名词 | le mien livre | 改为 mon livre 或 le mien |
| 误用代词词干 | mien livre | 限定名词要用 mon/ma/mes |

### 12.5 不定代词 quelqu'un, quelque chose, personne, rien

不定代词表示不确定的人、物、数量或范围。否定代词常与 `ne` 配合，但作简短回答时可单独出现。

| 代词 | 含义 | 例句 | 注意 |
| ---- | ---- | ---- | ---- |
| quelqu'un | 某人 | Quelqu'un a appelé. | 指人 |
| quelque chose | 某事/某物 | Je cherche quelque chose. | 指物或事 |
| personne | 没有人 | Je ne vois personne. | 否定中配 ne |
| rien | 什么也没有 | Je ne comprends rien. | 否定中配 ne |
| tout | 一切 | Tout va bien. | 中性整体 |
| chacun/chacune | 每个人/每个 | Chacun a son avis. | 按个体 |
| certains/certaines | 某些人/物 | Certains sont partis. | 代词化 |
| plusieurs | 好几个 | Plusieurs sont d'accord. | 代词化 |
| aucun/aucune | 没有一个 | Aucun n'est venu. | 否定代词 |

不定代词 + de + 形容词：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| quelqu'un de + adjectif | quelqu'un de fiable | 某个可靠的人 |
| quelque chose de + adjectif | quelque chose d'important | 某件重要的事 |
| rien de + adjectif | rien de spécial | 没什么特别的 |
| personne de + adjectif | personne de disponible | 没有可用的人 |

否定代词位置：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| ne + V + personne | Je ne connais personne. | personne 作宾语 |
| personne + ne + V | Personne ne vient. | personne 作主语 |
| ne + V + rien | Je ne dis rien. | rien 作宾语 |
| rien + ne + V | Rien ne marche. | rien 作主语 |
| sans personne / sans rien | Il est parti sans rien dire. | sans 后不用 ne |

### 12.6 chacun, tout, tous, autre, même

这些词既可作限定词，也可作代词。作代词时不直接接名词，而是替代一个人、一个物或一个集合。

| 代词 | 含义 | 例句 | 说明 |
| ---- | ---- | ---- | ---- |
| chacun | 每个人/每个，阳性或泛指 | Chacun doit répondre. | 作主语时动词单数 |
| chacune | 每个，阴性 | Chacune a une clé. | 阴性 |
| tout | 一切 | Tout est clair. | 中性整体 |
| tous | 所有人/全部，阳性复数 | Tous sont venus. | s 常发音 |
| toutes | 所有人/全部，阴性复数 | Toutes sont prêtes. | 阴性复数 |
| un autre | 另一个 | J'en prends un autre. | 可变 |
| les autres | 其他人/物 | Les autres arrivent. | 复数 |
| le même | 同一个 | C'est le même. | 可变 |

`tout` 的读音和用法提示：

| 形式 | 例句 | 说明 |
| ---- | ---- | ---- |
| tout | Tout va bien. | 中性单数 |
| tous + 名词 | tous les jours | 限定词，s 通常不发音 |
| tous 作代词 | Ils sont tous là. | s 通常发音 /tus/ |
| toutes | Elles sont toutes là. | 阴性复数 |

`autre` / `même`：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| un autre | Je voudrais un autre. | 另一个 |
| d'autres | Il y en a d'autres. | 还有别的 |
| les autres | Les autres sont partis. | 其他人/物 |
| le même | J'ai le même. | 同一个/一样的 |
| moi-même / toi-même | Je l'ai fait moi-même. | 亲自 |

### 12.7 疑问代词 qui, que, quoi, lequel

疑问代词用于提问“谁、什么、哪一个”。形式取决于问人还是问物、是否有介词、是否要配合名词性数。

| 代词 | 问什么 | 位置/用法 | 例句 |
| ---- | ------ | --------- | ---- |
| qui | 人 | 主语或宾语 | Qui vient ? / Tu vois qui ? |
| que / qu' | 物/事 | 多在句首作 COD | Que veux-tu ? |
| quoi | 物/事 | 介词后或口语句末 | De quoi parles-tu ? / Tu fais quoi ? |
| lequel | 哪一个 | 代替已知集合中的一个 | Lequel préfères-tu ? |
| laquelle | 哪一个，阴性 | 配合阴性名词 | Laquelle est correcte ? |
| lesquels | 哪些，阳性复数 | 配合阳性复数 | Lesquels veux-tu ? |
| lesquelles | 哪些，阴性复数 | 配合阴性复数 | Lesquelles as-tu choisies ? |

介词 + 疑问代词：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| à qui | À qui tu parles ? | 问人 |
| de qui | De qui parles-tu ? | 问人 |
| avec qui | Avec qui viens-tu ? | 问人 |
| à quoi | À quoi tu penses ? | 问事物 |
| de quoi | De quoi as-tu besoin ? | 问事物 |
| pour quoi | Pour quoi faire ? | 为了什么，和 pourquoi 不同 |

`lequel` 与介词缩合：

| 结构 | 形式 | 例句 |
| ---- | ---- | ---- |
| à + lequel | auquel | Auquel penses-tu ? |
| à + lesquels | auxquels | Lesquels -> auxquels |
| à + lesquelles | auxquelles | Auxquelles réponds-tu ? |
| de + lequel | duquel | Duquel parles-tu ? |
| de + lesquels | desquels | Desquels as-tu besoin ? |
| de + lesquelles | desquelles | Desquelles parles-tu ? |

### 12.8 关系代词预览

关系代词引导关系从句，用来修饰名词或替代中性先行内容。完整规则见第 25 章，这里先建立速查直觉。

| 关系代词 | 替代功能 | 例句 | 说明 |
| -------- | -------- | ---- | ---- |
| qui | 从句主语 | C'est le livre qui est sur la table. | qui 后接变位动词 |
| que / qu' | 从句直接宾语 | C'est le livre que j'ai lu. | que 后通常有主语 |
| dont | de + 成分 | C'est le sujet dont je parle. | = parler de ce sujet |
| où | 地点/时间 | C'est la ville où j'habite. | 地点或时间点 |
| lequel 系列 | 介词后关系代词 | la raison pour laquelle je pars | 正式、清晰 |
| ce qui | 中性主语 | Ce qui m'intéresse, c'est la langue. | “让我感兴趣的事” |
| ce que | 中性 COD | Ce que je veux, c'est partir. | “我想要的事” |
| ce dont | 中性 de | Ce dont j'ai besoin, c'est du temps. | “我需要的事” |

`qui` vs `que` 最小判断：

| 句子 | 关系代词 | 原因 |
| ---- | -------- | ---- |
| Le livre qui est sur la table est à moi. | qui | qui 作从句主语 |
| Le livre que tu lis est à moi. | que | tu 是主语，que 作 COD |
| La personne qui parle est mon professeur. | qui | qui parle |
| La personne que tu vois est mon professeur. | que | tu vois cette personne |

`dont` 的常见来源：

| 原结构 | 关系从句 | 说明 |
| ------ | -------- | ---- |
| parler de ce sujet | le sujet dont je parle | de + 名词 |
| avoir besoin de ce document | le document dont j'ai besoin | besoin de |
| être fier de ce résultat | le résultat dont je suis fier | fier de |
| le père de cette fille | la fille dont le père est médecin | 所属 de |

### 12.9 常见错误速查

| 错误句 | 推荐改法 | 错因 | 记忆点 |
| ------ | -------- | ---- | ------ |
| Celui livre est intéressant. | Ce livre est intéressant. / Celui-ci est intéressant. | celui 后不能直接接名词 | ce + nom；celui-ci 独立 |
| Ce de Paul est meilleur. | Celui de Paul est meilleur. | 指示代词形式错误 | celui/celle + de |
| Cette est ma voiture. | Celle-ci est ma voiture. / C'est ma voiture. | cette 是限定词，不能裸用 | cette + nom |
| Je préfère ce-là. | Je préfère celui-là. / celle-là. | 代词形式错误 | celui-là 按性数 |
| Le mien livre est ici. | Mon livre est ici. / Le mien est ici. | 物主代词后不能接名词 | mon livre vs le mien |
| Mien livre est ici. | Mon livre est ici. | 限定名词应用物主限定词 | mon/ma/mes |
| C'est le mon. | C'est le mien. | 物主代词形式错误 | le mien |
| Je cherche quelqu'un fiable. | Je cherche quelqu'un de fiable. | 不定代词后形容词缺 de | quelqu'un de + adjectif |
| Rien spécial. | Rien de spécial. | rien 后形容词缺 de | rien de + adjectif |
| Personne vient. | Personne ne vient. | personne 作否定主语缺 ne | personne ne... |
| Je ne vois pas personne. | Je ne vois personne. | 否定词误叠 | ne...personne，不加 pas |
| Je ne comprends pas rien. | Je ne comprends rien. | 否定词误叠 | ne...rien，不加 pas |
| Tous les sont venus. | Tous sont venus. / Tous les étudiants sont venus. | 代词和限定词结构混用 | tous 单独作代词，tous les + nom |
| Chaque a son avis. | Chacun a son avis. | chaque 是限定词，不作代词 | chacun 作代词 |
| Que vient ? | Qui vient ? | 问人作主语用 qui | qui 作人主语 |
| Quoi veux-tu ? | Que veux-tu ? | 正式句首 COD 用 que | que en tête |
| Tu parles de que ? | Tu parles de quoi ? | 介词后用 quoi | de quoi |
| À que penses-tu ? | À quoi penses-tu ? | 介词后问事物用 quoi | à quoi |
| Lequel livre veux-tu ? | Quel livre veux-tu ? / Lequel veux-tu ? | lequel 是代词，不直接接名词 | quel + nom；lequel 独立 |
| Le livre que est sur la table. | Le livre qui est sur la table. | 从句主语应用 qui | qui + verbe |
| Le livre qui je lis. | Le livre que je lis. | 从句 COD 应用 que | que + sujet + verbe |
| Le sujet que je parle. | Le sujet dont je parle. | parler de -> dont | dont = de + antécédent |
| Ce que m'intéresse. | Ce qui m'intéresse. | 中性主语应用 ce qui | ce qui + verbe |
| Ce qui je veux. | Ce que je veux. | 中性 COD 应用 ce que | ce que + sujet |
