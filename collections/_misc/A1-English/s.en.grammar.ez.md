## 0. 英语语法总览（Grammar Overview）

英语语法的核心不是背零散规则，而是理解几个层级如何组合：**词形变化 → 短语结构 → 句子成分 → 从句连接 → 语篇表达**。本章是全书地图，用来建立整体框架；具体规则、例外和速查表在后续章节展开。

### 0.1 英语语法地图

| 层级 | 研究对象 | 关键问题 | 对应章节 |
| ---- | -------- | -------- | -------- |
| 词形 | nouns, verbs, adjectives, adverbs | 单复数、时态、比较级、派生变化 | 2, 5, 6, 7 |
| 词类 | noun, verb, pronoun, adjective 等 | 一个词在句中承担什么功能 | 1 |
| 短语 | noun phrase, verb phrase, prepositional phrase | 多个词如何组成一个语法单位 | 1, 2, 8 |
| 句子成分 | subject, verb, object, complement, adverbial | 谁做什么，对谁做，补充说明什么 | 1 |
| 句法结构 | simple, compound, complex sentence | 句子如何扩展、并列、嵌套 | 9, 10 |
| 时态语态语气 | tense, aspect, voice, mood, modality | 动作何时发生、是否完成、是否被动、态度如何 | 5 |
| 信息结构 | topic, focus, emphasis | 重点放在哪里，如何强调或对比 | 7, 9, 10, 12 |
| 语篇语用 | style, register, coherence | 句子在段落、会话、邮件中是否自然 | 9, 12, 14 |

**最小完整句的直觉**：

| 结构 | 例子 | 说明 |
| ---- | ---- | ---- |
| S + V | Birds fly. | 主语 + 不及物动词 |
| S + V + O | She reads books. | 主语 + 及物动词 + 宾语 |
| S + V + C | He is tired. | 主语 + 系动词 + 主语补语 |
| S + V + O + O | She gave me a book. | 双宾结构 |
| S + V + O + C | They made him captain. | 宾语补语结构 |

### 0.2 现代英语的基本特征

现代英语既有分析语特征，也保留少量屈折变化。实际学习时，应优先抓住三件事：**语序很重要、功能词很重要、少量词形变化很重要**。

| 特征 | 说明 | 例子 | 学习重点 |
| ---- | ---- | ---- | -------- |
| 固定语序 | 主语、谓语、宾语位置改变会改变意思 | The dog bit the man. / The man bit the dog. | SVO 结构 |
| 功能词发达 | 助动词、介词、冠词、连词承担大量语法信息 | will go, in the room, a book, because | 不要只背实词 |
| 屈折较少 | 词尾变化有限，但仍关键 | books, walked, runs, bigger | 少量变化必须准确 |
| 助动词系统强 | 时态、否定、疑问、被动常靠助动词 | do not go, is written, has gone | be/do/have/modal |
| 名词短语复杂 | 限定词、形容词、名词、介词短语、从句可层层修饰 | the old book on the table that I bought | 名词短语边界 |
| 从句嵌套能力强 | 一个句子可以放进另一个句子 | I know that he came. | 从句类型 |
| 语体差异明显 | 口语、学术、商务、文学表达不同 | gonna / going to; however / but | 场合选择 |

### 0.3 英语的分析语特征（Analytic Features）

**分析语**指语法关系主要依靠词序、功能词和句法结构表达，而不是依靠复杂词尾变化。现代英语高度依赖这些手段。

| 分析语特征 | 例子 | 说明 |
| ---------- | ---- | ---- |
| 词序表达语法关系 | John loves Mary. / Mary loves John. | 主宾位置决定谁爱谁 |
| 助动词表达时态/语气 | He will go. / He has gone. | `will`, `has` 承担语法信息 |
| 介词表达关系 | the book on the table; talk to him | 空间、方向、对象、原因等 |
| 冠词表达指称 | a book / the book | 是否特指、是否首次出现 |
| 连词表达逻辑 | because, although, if, while | 因果、让步、条件、时间 |

**学习启示**：
  - 英语不能像中文一样只靠语义顺着说，必须检查句子成分是否完整。
  - 介词、冠词、助动词、连词不是“小词”，而是英语语法骨架。
  - 改写句子时，先保住语序和功能词，再调整词汇。

### 0.4 英语的屈折语特征（Inflectional Features）

英语不像拉丁语、德语那样有复杂变格，但仍保留少量高频屈折。错误往往集中在这些小变化上。

| 屈折类型 | 形式 | 例子 | 常见错误 |
| -------- | ---- | ---- | -------- |
| 名词复数 | `-s/-es` 与不规则复数 | books, boxes, children | two book |
| 名词所有格 | `'s / s'` | John's book, students' books | John book |
| 动词第三人称单数 | `-s/-es` | she works, he goes | she work |
| 动词过去式 | `-ed` 与不规则过去式 | worked, went | yesterday go |
| 过去分词 | 规则/不规则 | written, gone, finished | have went |
| 现在分词 | `-ing` | running, making | runing |
| 形容词比较级 | `-er/-est` 或 more/most | bigger, most useful | more better |

**现代英语的结论**：英语是一种以分析结构为主、保留弱屈折的语言。它的难点不在大量词尾变化，而在**词序、功能词、搭配、时态体貌和从句结构**的组合。

### 0.5 英语句子的构造层级

| 层级 | 例子 | 说明 |
| ---- | ---- | ---- |
| Word | books | 单词 |
| Phrase | the old books | 短语，无完整主谓 |
| Clause | I bought the old books | 从句/分句，有主谓 |
| Sentence | I bought the old books, but I haven't read them. | 完整句 |
| Paragraph | Several sentences about one topic | 段落 |
| Text | essay, email, report, conversation | 语篇 |

**从词到句的扩展示例**：

| 扩展 | 例子 | 增加的信息 |
| ---- | ---- | ---------- |
| noun | book | 名词核心 |
| noun phrase | the book | 限定 |
| expanded noun phrase | the old grammar book | 形容词/名词修饰 |
| prepositional phrase | the old grammar book on the desk | 介词短语修饰 |
| relative clause | the old grammar book that I bought yesterday | 定语从句 |
| full sentence | The old grammar book that I bought yesterday is useful. | 主谓完整 |

### 0.6 英语语法速查方法

遇到一个句子不会分析时，按下面顺序查，比直接查中文翻译更稳定。

| 步骤 | 问题 | 示例 |
| ---- | ---- | ---- |
| 1 | 主句谓语在哪里？ | has been working, was written |
| 2 | 主语是谁？ | The book / What he said / There |
| 3 | 动词需要什么补足成分？ | give sb sth, make sb adj, depend on sth |
| 4 | 名词是否可数、是否需要冠词？ | advice, information, a book, the book |
| 5 | 时态体貌是否符合时间关系？ | has done vs did; was doing vs did |
| 6 | 从句是什么类型？ | that-clause, relative clause, if-clause |
| 7 | 介词和搭配是否固定？ | interested in, depend on, responsible for |
| 8 | 语体是否合适？ | but/however, gonna/going to, ask/request |

  - 每章优先给总览表，再给典型句型、易混辨析和高频错误。
  - 速查表优先服务写作、阅读和改错，不追求术语堆叠。


## 1. 词性和句子成分（Parts of Speech and Sentence Components）

英语句子的核心问题不是“这个词是什么意思”，而是“这个词在句子里做什么”。同一个词可以在不同位置承担不同功能：

| 例句 | book 的语法身份 | 判断依据 |
| ---- | --------------- | -------- |
| I bought a **book**. | 名词；宾语 | 在限定词 a 后，接受 bought 的动作 |
| I need to **book** a room. | 动词；谓语的一部分 | 在 to 后用动词原形，表示“预订” |
| a **book** review | 名词作定语 | 放在另一个名词前，说明 review 的类型 |

因此本章先建立四层框架：词性（word class）说明“词本身能做什么”，短语（phrase）说明“一组词合起来做什么”，句子成分（sentence component）说明“在句子里承担什么功能”，基本句型说明“核心成分如何组合”。

### 1.1 词、短语、从句、句子的层级

| 层级 | 英文 | 说明 | 例子 | 在句中可能承担的功能 |
| ---- | ---- | ---- | ---- | -------------------- |
| 词 | word | 最小的自由语法单位 | book, quickly, under | 名词、动词、形容词、副词等 |
| 短语 | phrase | 以一个核心词为中心，不一定有完整主谓 | a useful book, very quickly, in the room | 主语、宾语、定语、状语、补语等 |
| 从句 | clause | 含有主语和谓语；可独立也可依附主句 | when I arrived, that he was right | 主语、宾语、表语、定语、状语等 |
| 句子 | sentence | 表达完整信息，书面上通常以大写开头、句号/问号/感叹号结尾 | I arrived late. | 完整陈述、疑问、命令或感叹 |

**实用判断**：

| 问题 | 如果答案是 yes | 例子 |
| ---- | ------------- | ---- |
| 是否只有一个核心词？ | 多半是词或单词性成分 | quickly |
| 是否围绕一个核心词展开，但没有完整主谓？ | 多半是短语 | very quickly / a book on grammar |
| 是否有主语和谓语？ | 多半是从句或独立句 | because he was late |
| 是否能独立表达完整意思？ | 是独立句；否则是从属从句 | He was late. / because he was late |

### 1.2 句子成分总览

句子成分是功能概念，不等同于词性。一个名词短语可以做主语，也可以做宾语、表语、同位语；一个从句也可以做主语、宾语或状语。

| 成分 | 英文 | 核心作用 | 常见形式 | 例句 |
| ---- | ---- | -------- | -------- | ---- |
| 主语 | Subject | 句子谈论的对象；通常决定谓语动词的人称和数 | 名词短语、代词、动名词、不定式、从句、形式主语 it/there | **The plan** works. / **What he said** matters. |
| 谓语 | Predicate | 对主语作陈述；通常以动词短语为核心 | 实义动词、助动词、情态动词、系动词加补语 | She **has finished the report**. |
| 动词 | Verb | 谓语的核心，决定句型和后续成分 | 及物动词、不及物动词、系动词、双宾动词、宾补动词 | They **made** him angry. |
| 宾语 | Object | 动作影响、涉及或指向的对象 | 名词短语、代词、动名词、不定式、从句 | I know **the answer**. / I know **that he lied**. |
| 补语 | Complement | 补足主语、宾语或动词意义，缺少时句义不完整 | 名词、形容词、介词短语、不定式、分词、从句 | She is **ready**. / We found it **useful**. |
| 定语 | Modifier / Attributive | 修饰名词，说明“哪一个、什么样、多少、谁的” | 形容词、名词、介词短语、分词短语、定语从句 | a **red** car / the book **on the desk** |
| 状语 | Adverbial | 修饰动词、形容词、副词、整个句子，说明时间、地点、方式、原因、条件等 | 副词、介词短语、不定式、分词短语、状语从句 | She spoke **clearly**. / **If possible**, call me. |
| 同位语 | Appositive | 对前面的名词作解释、改名或补充 | 名词短语、that 从句 | My friend **Tom** called. / the fact **that he left** |
| 插入语 | Parenthetical / Disjunct | 表示说话人态度、信息来源或补充说明，不参与核心句型 | 副词、介词短语、分词结构、完整插入句 | **Fortunately**, nobody was hurt. |

**注意**：感叹词（wow, ouch, hey）是词性或语用单位，通常独立于句子结构，不应当和主语、宾语、补语并列为核心句子成分。

### 1.3 主语 Subject

主语通常位于谓语之前，表示句子陈述的对象。但英语也常用形式主语和倒装结构，所以不要只靠位置判断。

| 主语形式 | 例句 | 说明 |
| -------- | ---- | ---- |
| 名词短语 | **The new policy** caused confusion. | 最常见 |
| 代词 | **She** agreed. | 注意主格：I, he, she, we, they |
| 动名词短语 | **Learning grammar** takes time. | 动作整体作“事情” |
| 不定式短语 | **To finish this today** would be difficult. | 偏正式或书面 |
| that 从句 | **That he refused** surprised everyone. | 书面；口语常改用 it 作形式主语 |
| wh 从句 | **What you need** is practice. | 整个从句作主语 |
| 形式主语 it | **It** is important to check the data. | 真正主语是后面的 to check... |
| 存在句 there | **There** is a problem. | there 引出存在信息，真正中心是 a problem |

**主语速查**：

| 现象 | 正确表达 | 常见错误 |
| ---- | -------- | -------- |
| 英语完整句通常需要主语 | **It** is raining. | Raining. |
| 中文话题不能直接当英语主语 | **This book** is easy to read. / **I** find this book easy. | This book reads easy. |
| 动名词作主语时谓语通常用单数 | **Reading** helps. | Reading help. |
| there be 的动词跟后面的名词一致 | There **is** a reason. / There **are** reasons. | There is many reasons. |

### 1.4 谓语、动词和动词短语

谓语是句子对主语作出的陈述；动词短语是谓语的核心。英语的时态、体、语态、否定和疑问大多体现在动词短语中。

| 动词短语层次 | 例句 | 说明 |
| ------------ | ---- | ---- |
| 实义动词 | She **works**. | 表示主要动作或状态 |
| 助动词 + 实义动词 | She **does not work**. | do 用于否定、疑问、强调 |
| 情态动词 + 动词原形 | She **can work** remotely. | can, must, should, may 后接原形 |
| 完成体 | She **has finished**. | have + 过去分词 |
| 进行体 | She **is working**. | be + 现在分词 |
| 被动语态 | The report **was written** yesterday. | be + 过去分词 |
| 复杂动词短语 | She **must have been working**. | 情态 + 完成 + 进行 |

| 动词类型 | 后面常接什么 | 例句 | 语法重点 |
| -------- | ------------ | ---- | -------- |
| 不及物动词 Intransitive Verb | 不直接接宾语 | He **arrived**. | 不可直接加宾语；需用介词时另加 |
| 及物动词 Transitive Verb | 直接宾语 | He **opened the door**. | 被动语态通常可行：The door was opened. |
| 系动词 Linking Verb | 主语补语 | She **is a lawyer**. / It **seems strange**. | 后面不是宾语，而是补语 |
| 双宾动词 Ditransitive Verb | 间接宾语 + 直接宾语 | She **sent me an email**. | 可改为 sent an email to me |
| 宾补动词 Complex-transitive Verb | 宾语 + 宾语补语 | They **made him captain**. | him 和 captain 指同一对象 |

### 1.5 宾语 Object

宾语是动作直接影响、涉及或指向的对象。是否需要宾语取决于动词，而不是中文意思。

| 宾语类型 | 结构 | 例句 | 说明 |
| -------- | ---- | ---- | ---- |
| 直接宾语 Direct Object | V + O | She read **the report**. | 动作直接作用对象 |
| 间接宾语 Indirect Object | V + IO + DO | She gave **me** **a chance**. | me 是接受者，a chance 是被给予的东西 |
| 介词宾语 Object of Preposition | Prep + O | We talked about **the issue**. | 介词后必须接宾语 |
| 从句宾语 Clausal Object | V + clause | I believe **that he is right**. | 整个从句作宾语 |
| 形式宾语 it | V + it + C + real object | I found **it** hard **to focus**. | it 占位，真正宾语在后面 |

**宾语与介词**：

| 中文想法 | 英语表达 | 说明 |
| -------- | -------- | ---- |
| 讨论这个问题 | discuss **the issue** | discuss 是及物动词，不说 discuss about |
| 等他 | wait **for him** | wait 是不及物动词，需 for |
| 听音乐 | listen **to music** | listen 后通常接 to |
| 进入房间 | enter **the room** / go **into the room** | enter 是及物动词；go 需介词 |

### 1.6 补语 Complement

补语用来补足句子核心意义。它不是可随意删除的修饰语；删掉后句子往往不完整或意义改变。

| 补语类型 | 结构 | 例句 | 判断方法 |
| -------- | ---- | ---- | -------- |
| 主语补语 Subject Complement | S + linking verb + C | She is **confident**. / He became **a doctor**. | 补语说明主语是什么、怎么样 |
| 宾语补语 Object Complement | S + V + O + C | We made him **leader**. / I found the task **easy**. | 补语说明宾语是什么、怎么样 |
| 动词补足成分 Verb Complement | V + required phrase/clause | It depends **on the context**. | 动词搭配要求，缺少则不完整 |

| 补语形式 | 例句 | 说明 |
| -------- | ---- | ---- |
| 形容词 | The result seems **reasonable**. | 说明状态或性质 |
| 名词短语 | She became **a manager**. | 说明身份 |
| 介词短语 | The key is **in the drawer**. | 说明位置、状态、关系 |
| 不定式 | I want you **to stay**. | 常见于 want/ask/tell/expect 等 |
| 现在分词 | I saw him **running**. | 强调动作正在进行 |
| 过去分词 | I had my phone **repaired**. | 强调被动或完成 |
| 从句 | The question is **whether we can finish**. | 整个从句作补语 |

**宾语和补语的区别**：

| 句子 | 分析 |
| ---- | ---- |
| We elected **him**. | him 是宾语；句子已经完整 |
| We elected **him president**. | him 是宾语，president 是宾语补语，说明 him 的身份 |
| She made **a cake**. | a cake 是宾语，被制作出来 |
| She made **me angry**. | me 是宾语，angry 是宾语补语，说明 me 的状态 |

### 1.7 定语、状语、同位语与插入语

这些成分通常不是五大基本句型的核心，但它们决定句子的精确度和信息密度。

#### 定语 Modifier / Attributive

定语修饰名词，回答“哪一个、什么样、多少、谁的、关于什么”。

| 定语形式 | 位置 | 例句 |
| -------- | ---- | ---- |
| 限定词 | 名词前 | **the** book, **my** laptop, **three** options |
| 形容词 | 名词前；少数可后置 | a **clear** answer / something **important** |
| 名词 | 名词前 | a **grammar** book, a **sales** team |
| 介词短语 | 名词后 | the book **on the table** |
| 分词短语 | 名词前或后 | a **broken** window / people **living nearby** |
| 不定式 | 名词后 | a plan **to reduce costs** |
| 定语从句 | 名词后 | the person **who called you** |

#### 状语 Adverbial

状语修饰动作、性质、程度或整句，回答“何时、何地、如何、为什么、在什么条件下、到什么程度”。

| 意义 | 常见形式 | 例句 |
| ---- | -------- | ---- |
| 时间 | 副词、介词短语、从句 | We met **yesterday**. / **After the meeting**, we left. |
| 地点 | 副词、介词短语 | Put it **there**. / She lives **in Tokyo**. |
| 方式 | 副词、介词短语 | He answered **politely**. |
| 原因 | 介词短语、从句 | She stayed home **because she was sick**. |
| 目的 | 不定式、介词短语 | I called **to confirm the time**. |
| 条件 | 从句、介词短语 | **If it rains**, we will cancel. |
| 让步 | 从句、介词短语 | **Although it was late**, they continued. |
| 程度 | 副词 | It is **very** useful. |
| 句子态度 | 副词、插入语 | **Honestly**, I disagree. |

#### 同位语 Appositive

| 类型 | 例句 | 标点特点 |
| ---- | ---- | -------- |
| 限定性同位语 | my friend **Tom** | 不用逗号；Tom 用来限定是哪位朋友 |
| 非限定性同位语 | Tom, **my friend**, called. | 用逗号；补充说明 |
| that 同位语从句 | the idea **that grammar matters** | that 说明 idea 的内容，不作从句成分 |

#### 插入语 Parenthetical / Disjunct

| 功能 | 例句 | 说明 |
| ---- | ---- | ---- |
| 表态度 | **Fortunately**, no one was injured. | 说话人评价整句 |
| 表信息来源 | **According to the report**, sales increased. | 说明依据 |
| 表转折/补充 | The plan, **however**, failed. | 插入句中，两边常用逗号 |
| 表确认 | This is, **I think**, the best option. | 不改变核心句型 |

### 1.8 八大词性总览

词性是单词的类别，但英语中很多词可以跨词性使用，所以判断时要看位置、搭配和功能。

| 词性 | 英文 | 核心功能 | 典型位置/搭配 | 例子 |
| ---- | ---- | -------- | ------------- | ---- |
| 名词 | Noun | 表示人、物、地点、概念、活动 | 可作主语、宾语、补语；可被限定词修饰 | book, city, happiness |
| 代词 | Pronoun | 代替名词或名词短语 | 需注意格、数、人称、指代清楚 | I, me, they, this, who |
| 动词 | Verb | 表示动作、状态、发生 | 构成谓语核心；有时态、体、语态变化 | run, be, have, seem |
| 形容词 | Adjective | 修饰名词或作补语 | 名词前；系动词后 | useful, large, ready |
| 副词 | Adverb | 修饰动词、形容词、副词或整句 | 位置灵活；常表达方式、程度、时间 | quickly, very, here, however |
| 介词 | Preposition | 表示名词与其他成分的关系 | 后接名词、代词、动名词或名词从句 | in, on, at, for, with |
| 连词 | Conjunction | 连接词、短语、从句或句子 | 并列、从属、关联结构 | and, but, because, although |
| 感叹词 | Interjection | 表达情绪、反应、呼唤 | 多独立使用，不参与核心句型 | wow, ouch, hey |

**限定词 Determiner** 是现代语法中非常重要的一类，传统八大词性常把它归入形容词或单独处理。本文件单列“冠词与限定词”一章。

| 限定词类型 | 例子 | 功能 |
| ---------- | ---- | ---- |
| 冠词 | a, an, the | 标记泛指、特指、新旧信息 |
| 指示限定词 | this, that, these, those | 指示远近或上下文对象 |
| 物主限定词 | my, your, his, her, its, our, their | 表示所属或关联 |
| 数量限定词 | some, any, many, much, few, little, all | 表示数量或范围 |
| 数词 | one, two, first, second | 表示数量或顺序 |

### 1.9 短语类型

短语的类别由核心词决定。分析长句时，先找短语边界，再判断短语在句中做什么成分。

| 短语类型 | 英文 | 核心词 | 例子 | 常见功能 |
| -------- | ---- | ------ | ---- | -------- |
| 名词短语 | Noun Phrase, NP | 名词/代词 | the old house near the river | 主语、宾语、补语、介词宾语 |
| 动词短语 | Verb Phrase, VP | 动词 | has been working on it | 谓语核心 |
| 形容词短语 | Adjective Phrase, AdjP | 形容词 | very difficult to solve | 定语、主语补语、宾语补语 |
| 副词短语 | Adverb Phrase, AdvP | 副词 | quite slowly, very carefully | 状语、程度修饰 |
| 介词短语 | Prepositional Phrase, PP | 介词 | in the morning, with a smile | 定语、状语、补语 |
| 不定式短语 | Infinitive Phrase | to + 动词原形 | to finish the project | 主语、宾语、定语、状语、补语 |
| 动名词短语 | Gerund Phrase | -ing 动名词 | working from home | 主语、宾语、介词宾语 |
| 分词短语 | Participle Phrase | 现在分词/过去分词 | standing by the door / written in 2020 | 定语、状语、补语 |

**同一个短语，不同功能**：

| 短语 | 例句 | 功能 |
| ---- | ---- | ---- |
| in the room | The key is **in the room**. | 主语补语 |
| in the room | I found the key **in the room**. | 状语 |
| in the room | the key **in the room** | 定语 |

### 1.10 五大基本句型

英语核心句型可压缩为五类。长句通常是在这些核心结构上增加定语、状语、从句和插入语。

| 句型 | 结构 | 例句 | 核心判断 |
| ---- | ---- | ---- | -------- |
| SV | 主语 + 不及物动词 | The baby **slept**. | 动词后不需要宾语或补语 |
| SVO | 主语 + 及物动词 + 宾语 | She **opened the window**. | 动作直接作用于宾语 |
| SVC | 主语 + 系动词 + 主语补语 | The sky **looks clear**. | clear 说明 sky |
| SVOO | 主语 + 动词 + 间接宾语 + 直接宾语 | He **sent me a message**. | me 是接受者，message 是内容 |
| SVOC | 主语 + 动词 + 宾语 + 宾语补语 | They **painted the wall white**. | white 说明 wall 的结果状态 |

| 易混结构 | 例句 | 分析 |
| -------- | ---- | ---- |
| SVO vs SVC | She became **a teacher**. | a teacher 不是宾语，而是主语补语 |
| SVOO vs SVO + PP | She gave **me** **a book**. / She gave **a book** **to me**. | 双宾结构可改为介词结构 |
| SVOC vs SVO + 状语 | I found him **honest**. / I found him **in the library**. | honest 是宾补；in the library 通常是地点状语 |
| SV vs SVA | He lives **in London**. | 有些语法把必要地点状语单列为 SVA |

### 1.11 句子成分分析步骤

分析英文句子时，优先找核心，不要先被长定语或插入语带偏。

| 步骤 | 要问的问题 | 操作示例 |
| ---- | ---------- | -------- |
| 1 | 谓语动词在哪里？ | 找有时态的人称动词：has decided, was built, should leave |
| 2 | 谁/什么执行或承受这个谓语？ | 谓语前后找主语；被动句主语是承受者 |
| 3 | 动词类型是什么？ | 及物、不及物、系动词、双宾动词、宾补动词 |
| 4 | 动词后是否有必需成分？ | 宾语、补语、介词补足成分 |
| 5 | 哪些成分只是修饰？ | 定语修饰名词；状语修饰动作、性质或整句 |
| 6 | 从句在做什么功能？ | that he left 可能作主语、宾语、表语或同位语 |
| 7 | 代词指代是否清楚？ | it/they/this/which 指向哪个名词或事件 |

**示例分析**：

| 句子 | 核心结构 | 分析 |
| ---- | -------- | ---- |
| The report on climate risk was released yesterday. | S + V | The report 是主语；on climate risk 是定语；was released 是谓语；yesterday 是状语 |
| I found the explanation surprisingly clear. | S + V + O + C | I 主语；found 谓语；the explanation 宾语；clear 宾补；surprisingly 修饰 clear |
| What she needs is a clear deadline. | S + V + C | What she needs 是主语从句；is 系动词；a clear deadline 是主语补语 |

### 1.12 常见错误速查

| 错误类型 | 不自然/错误 | 推荐表达 | 原因 |
| -------- | ----------- | -------- | ---- |
| 缺主语 | Is important to review it. | **It** is important to review it. | 英语完整句通常需要主语；it 作形式主语 |
| 缺谓语 | The solution very useful. | The solution **is** very useful. | 形容词不能单独作谓语 |
| 句子碎片 | Because he was late. | He missed the meeting **because he was late**. | because 从句不能单独成完整书面句 |
| 逗号拼接 | It was late, we left. | It was late, **so** we left. / It was late; we left. | 两个独立句不能只用逗号连接 |
| 主语和谓语不一致 | The results **shows** a trend. | The results **show** a trend. | results 是复数 |
| 形容词/副词混用 | She speaks English **good**. | She speaks English **well**. | 修饰 speaks 用副词 |
| 宾语遗漏 | I discussed about the issue. | I discussed **the issue**. | discuss 直接接宾语 |
| 补语误判为宾语 | She is **happy**. | happy 是主语补语 | 系动词后不是宾语 |
| 中文话题直译 | This problem we should solve. | We should solve this problem. | 英语普通陈述句通常主语在谓语前 |
| 修饰语位置不清 | I only told him yesterday. | Only I told him yesterday. / I told only him yesterday. | only 的位置改变焦点 |

## 2. 名词与名词短语（Nouns and Noun Phrases）

名词是英语名词短语的中心词，可以表示人、物、地点、机构、材料、事件、行为、性质、状态和抽象概念。真正写句子时，单个名词很少孤立出现，更多是和限定词、形容词、数量词、介词短语、分词短语、定语从句等组成名词短语。

| 形式 | 例子 | 在句中功能 |
| ---- | ---- | ---------- |
| 单个名词 | **Grammar** matters. | 主语 |
| 限定词 + 名词 | I read **the report**. | 宾语 |
| 复杂名词短语 | **The latest report on energy prices** was released. | 主语 |
| 名词性从句 | **What he said** was true. | 主语；本质上起名词短语功能 |

本章重点不是背名词列表，而是解决四个实用问题：名词是否可数、单复数如何变化、名词短语如何扩展、名词在句中如何和动词/限定词配合。

### 2.1 名词分类总览

| 分类 | 英文 | 含义 | 语法重点 | 例子 |
| ---- | ---- | ---- | -------- | ---- |
| 普通名词 | Common Noun | 表示一类人、物、地点或概念 | 通常可加限定词；可有单复数或不可数用法 | book, city, problem |
| 专有名词 | Proper Noun | 表示特定人名、地名、机构、作品、品牌等 | 首字母大写；通常不用冠词，但有例外 | London, Microsoft, the United Nations |
| 可数名词 | Countable Noun | 可以按个体计数 | 单数通常需要限定词；有复数 | a plan, two plans |
| 不可数名词 | Uncountable Noun | 不能直接按个体计数 | 通常无复数；不用 a/an；用量词表达单位 | information, water, advice |
| 集合名词 | Collective Noun | 表示一组成员构成的整体 | 英美用法和语义焦点会影响单复数动词 | team, staff, family |
| 具体名词 | Concrete Noun | 可感知的实体 | 多数可数，也有物质名词不可数 | table, paper, metal |
| 抽象名词 | Abstract Noun | 概念、性质、状态、活动 | 常不可数，但可表示一次经历或一种形式 | freedom, success, experience |
| 物质名词 | Material Noun | 材料、液体、气体、粉末等 | 通常不可数；可用量词或表示种类 | steel, coffee, sugar |
| 复合名词 | Compound Noun | 由两个或多个词构成一个名词单位 | 复数位置、连字符、重音需注意 | bus stop, editor-in-chief, software engineer |

**速查原则**：

| 判断问题 | 结论 |
| -------- | ---- |
| 能不能直接说 one/two/three + 名词？ | 能，多半可数：one idea, two chairs |
| 能不能直接加 a/an？ | 能，通常是单数可数：a problem |
| 是否需要 a piece of / a cup of / an item of？ | 多半不可数：a piece of advice |
| 是否表示材料、信息、抽象概念整体？ | 多半不可数：furniture, evidence, progress |
| 是否表示具体一次事件、作品、种类、份量？ | 可能转为可数：a success, two coffees, several wines |

### 2.2 可数名词 Countable Nouns

可数名词有单数和复数。单数可数名词不能裸用，通常需要冠词、物主限定词、指示限定词、数词或其他限定词。

| 表达 | 是否自然 | 原因 |
| ---- | -------- | ---- |
| I need **a suggestion**. | 正确 | suggestion 是单数可数名词，需要 a |
| I need **suggestions**. | 正确 | 复数可数名词可裸用，表示泛指 |
| I need **suggestion**. | 错误 | 单数可数名词缺少限定词 |
| I need **some suggestions**. | 正确 | some 表示不定数量 |

| 单数可数名词前常见限定方式 | 例子 |
| -------------------------- | ---- |
| 不定冠词 | a question, an answer |
| 定冠词 | the question |
| 指示限定词 | this question, that answer |
| 物主限定词 | my question, their answer |
| 数词 | one question |
| each/every | each student, every reason |
| another | another option |

### 2.3 复数形式 Plural Forms

| 规则 | 变化 | 例子 | 注意 |
| ---- | ---- | ---- | ---- |
| 一般情况 | 加 -s | book -> books, plan -> plans | 最常见 |
| 以 s, x, z, ch, sh 结尾 | 加 -es | class -> classes, box -> boxes, wish -> wishes | 便于发音 |
| 辅音字母 + y | y 变 i 加 -es | city -> cities, policy -> policies | 元音 + y 直接加 -s：day -> days |
| 以 f / fe 结尾的部分词 | f/fe 变 v 加 -es | leaf -> leaves, life -> lives | 不是全部：roof -> roofs |
| 以 o 结尾的部分词 | 加 -es 或 -s | tomato -> tomatoes, photo -> photos | 常见外来词多加 -s |
| 复合名词 | 主要名词变复数 | editors-in-chief, passers-by | 若无明显中心词，末尾加 -s：grown-ups |
| 字母、数字、缩写 | 常加 -s | CDs, the 1990s, two As | 不要滥用撇号 |

**常见不规则复数**：

| 单数 | 复数 | 说明 |
| ---- | ---- | ---- |
| man | men | 元音变化 |
| woman | women | 注意发音也变化 |
| child | children | -en 复数 |
| person | people | people 表示“人们”；persons 用于法律/正式语境 |
| foot | feet | 元音变化 |
| tooth | teeth | 元音变化 |
| basis | bases | -is -> -es |
| analysis | analyses | -sis -> -ses |
| crisis | crises | -sis -> -ses |
| phenomenon | phenomena | 学术词；phenomenons 也可见但不如 phenomena 标准 |
| criterion | criteria | criterion 是单数，criteria 是复数 |
| datum | data | 现代英语 data 常作集合/不可数处理，学术严谨写作中也可作复数 |

**单复数同形或特殊复数**：

| 形式 | 例子 | 用法 |
| ---- | ---- | ---- |
| 单复数同形 | series, species, aircraft | one series / two series |
| 只有复数形式 | clothes, belongings, surroundings | 谓语通常用复数 |
| 形式复数但常作单数 | news, physics, economics, politics | The news is important. |
| 成双物件 | glasses, scissors, trousers | 常用 a pair of 表示一件/一副 |

### 2.4 不可数名词 Uncountable Nouns

不可数名词表示物质、整体、抽象概念、活动或信息，通常不能直接用 a/an，也不能直接加复数 -s。

| 类别 | 常见不可数名词 | 正确表达 |
| ---- | -------------- | -------- |
| 信息/知识 | information, advice, evidence, knowledge, research, news | a piece of information, some advice |
| 工作/学习 | work, homework, progress, practice, training | a piece of work, much progress |
| 物质/食物 | water, coffee, bread, rice, cheese, sugar, salt | a glass of water, a slice of bread |
| 抽象概念 | time, money, luck, help, damage, traffic, behavior | a bit of luck, a lot of traffic |
| 集合/总称 | furniture, equipment, luggage, baggage, clothing, software | a piece of furniture, an item of clothing |
| 自然现象 | weather, rain, snow, heat, light | heavy rain, a flash of light |

| 错误 | 正确 | 说明 |
| ---- | ---- | ---- |
| an information | a piece of information | information 不直接加 a |
| many advices | much advice / many pieces of advice | advice 不加复数 -s |
| several equipments | several pieces of equipment | equipment 不可数 |
| a furniture | a piece of furniture | furniture 是集合性不可数 |
| many researches | much research / many studies | research 常不可数；study 可数 |
| homeworks | homework assignments / pieces of homework | homework 不可数 |

### 2.5 可数与不可数的转换

很多名词不是永久固定为可数或不可数，而是随意义变化。

| 名词 | 不可数用法 | 可数用法 |
| ---- | ---------- | -------- |
| coffee | Coffee is expensive. 咖啡这种饮品 | Two coffees, please. 两杯咖啡 |
| paper | Paper is recyclable. 纸这种材料 | I wrote three papers. 论文/文件 |
| glass | Glass breaks easily. 玻璃材料 | a glass / two glasses 杯子 |
| stone | Stone is durable. 石材 | stones on the path 石块 |
| experience | Experience matters. 经验 | memorable experiences 经历 |
| success | Success takes effort. 成功这个概念 | The project was a success. 一次成功 |
| work | Work can be stressful. 工作 | a work of art 一件作品 |
| business | Business is slow. 生意总体 | several businesses 几家公司 |
| room | There is no room. 空间 | three rooms 三个房间 |
| light | Light travels fast. 光 | three lights 三盏灯 |

**标准英语中通常不要复数化的词**：

| 不推荐 | 推荐 |
| ------ | ---- |
| informations | pieces of information / information |
| knowledges | knowledge / areas of knowledge |
| advices | pieces of advice / advice |
| evidences | evidence / pieces of evidence |
| furnitures | furniture / pieces of furniture |

### 2.6 数量表达与量词

不可数名词要表达“一个/几个单位”，通常借助量词结构：

```text
a / an / number + measure word + of + noun
```

| 量词类型 | 量词 | 搭配例子 |
| -------- | ---- | -------- |
| 通用单位 | a piece of, a bit of, an item of | a piece of advice, an item of clothing |
| 容器 | a cup of, a glass of, a bottle of, a bowl of | a cup of tea, a bottle of water |
| 形状/切分 | a slice of, a loaf of, a bar of, a sheet of | a slice of bread, a sheet of paper |
| 微小单位 | a drop of, a grain of, a pinch of | a drop of water, a grain of rice |
| 集合单位 | a pair of, a set of, a series of, a group of | a pair of glasses, a series of events |
| 度量单位 | a liter of, a pound of, a kilogram of, a meter of | a liter of milk, a meter of fabric |
| 抽象单位 | a sense of, a lack of, a sign of, a degree of | a sense of responsibility, a lack of evidence |

| 表数量的词 | 接可数名词 | 接不可数名词 | 两者都可 |
| ---------- | ---------- | ------------ | -------- |
| many / few / a few | many reasons, a few questions | 不用 | - |
| much / little / a little | 不用 | much time, a little money | - |
| several | several options | 不用 | - |
| a number of | a number of reports | 不用 | - |
| a great deal of | 不用 | a great deal of work | - |
| some / any | some ideas | some information | 都可 |
| a lot of / lots of | a lot of people | a lot of traffic | 都可 |
| plenty of | plenty of examples | plenty of evidence | 都可 |
| enough | enough chairs | enough time | 都可 |
| no | no mistakes | no progress | 都可 |

### 2.7 集合名词 Collective Nouns

集合名词可以看作整体，也可以强调成员。美国英语更常把 team, staff, company 等看作单数整体；英国英语中复数动词更常见。

| 表达焦点 | 例句 | 说明 |
| -------- | ---- | ---- |
| 整体 | The team **is** ready. | 团队作为一个单位 |
| 成员 | The team **are** discussing their roles. | 英国英语更常见；强调成员各自行动 |
| 机构整体 | The company **has** changed its policy. | 公司作为法人/整体 |
| 员工群体 | The staff **are** working late. | staff 强调成员时可用复数意义 |

| 常见集合名词 | 常见搭配 |
| ------------ | -------- |
| team | a team of engineers |
| staff | the staff, staff members |
| family | a family of four |
| committee | a committee meeting |
| audience | a large audience |
| public | the public is / are |
| police | the police are |
| people | people are |

### 2.8 专有名词 Proper Nouns

专有名词表示独一对象，首字母大写。是否加 the 取决于名称类型和习惯。

| 类型 | 通常不用 the | 通常用 the |
| ---- | ------------ | ---------- |
| 人名 | David, Jane Austen | the Smiths 表示一家人 |
| 城市/国家 | Tokyo, France, China | the United States, the Netherlands |
| 公司/品牌 | Apple, Google, Toyota | the BBC, the New York Times |
| 大学 | Harvard University | the University of Oxford |
| 山峰/湖泊 | Mount Fuji, Lake Geneva | the Alps, the Himalayas |
| 河流/海洋/沙漠 | - | the Nile, the Pacific, the Sahara |
| 组织/机构 | NATO | the United Nations, the World Bank |

**专有名词普通化**：

| 用法 | 例句 | 含义 |
| ---- | ---- | ---- |
| 表示某一家族成员 | The Smiths are moving. | Smith 一家 |
| 表示某作品/版本 | I bought a Picasso. | 一幅毕加索作品 |
| 表示某类典型人物 | He is no Einstein. | 他不是天才型人物 |

### 2.9 性别、职业名词与指代 Gender and Reference

英语名词没有像法语、德语那样系统的语法性别。多数事物、概念、机构和地点本身没有阳性/阴性变化；性别主要体现在自然性别、称谓、职业名词和代词指代中。

| 类型 | 传统/带性别形式 | 更中性或现代常用形式 | 说明 |
| ---- | --------------- | -------------------- | ---- |
| 职业 | chairman | chair / chairperson | 正式写作常避免不必要的男性默认 |
| 职业 | salesman | salesperson / sales representative | 强调岗位，不强调性别 |
| 职业 | policeman | police officer | 中性表达更通用 |
| 婚姻状态 | Miss / Mrs. | Ms. | 不必暴露婚姻状态 |
| 演艺身份 | actor / actress | actor | actor 可中性使用；actress 仍常见 |

| 指代对象 | 常见代词 | 例句 |
| -------- | -------- | ---- |
| 明确男性 | he / him / his | David said **he** would call. |
| 明确女性 | she / her / hers | Maria said **she** would call. |
| 性别未知或不重要的单数人 | they / them / their | If a student has a question, **they** should ask. |
| 事物、抽象概念、机构产品 | it / its | The system lost **its** connection. |
| 公司/团队作为成员群体 | they / their | The company said **they** were hiring. |

**写作建议**：不知道性别时，单数 they 在现代英语中已经很常见，尤其适合说明书、政策文本和泛指场景。极正式文本可改写为复数：Students should submit their forms.

### 2.10 名词的格与所有格 Case and Possessive

现代英语中，普通名词的主格和宾格形式通常相同；格变化主要体现在代词和名词所有格上。

| 格 | 功能 | 名词例句 | 代词变化 |
| -- | ---- | -------- | -------- |
| 主格 | 作主语 | **The manager** approved it. | I, he, she, we, they |
| 宾格 | 作宾语或介词宾语 | I called **the manager**. | me, him, her, us, them |
| 所有格 | 表示所属、来源、关联、时间等 | **the manager's** decision | my/mine, his, her/hers |

**所有格形式**：

| 名词类型 | 形式 | 例子 |
| -------- | ---- | ---- |
| 单数名词 | 加 's | the user's password |
| 以 s 结尾的单数名词 | 加 's 或只加 '；风格保持一致 | James's book / James' book |
| 规则复数名词 | 只加 ' | the students' essays |
| 不规则复数名词 | 加 's | children's books, people's rights |
| 复合名词 | 最后一个词加 's | my brother-in-law's car |
| 共同拥有 | 最后一个名词加 's | Alice and Ben's apartment |
| 分别拥有 | 每个名词都加 's | Alice's and Ben's apartments |

**'s 所有格与 of 结构**：

| 倾向用 's | 倾向用 of | 例子 |
| --------- | -------- | ---- |
| 人、机构、群体 | 无生命物体的部分或抽象关系 | Sarah's idea / the roof of the building |
| 时间、距离、价值 | 正式抽象名词关系 | today's meeting / the importance of accuracy |
| 固定表达 | 长名词短语 | a week's work / the decision of the committee |

### 2.11 复合名词与名词作定语

名词可以放在另一个名词前作定语，说明类型、用途、材料、领域、地点或对象。名词作定语时通常用单数形式，即使含义是复数。

| 结构 | 例子 | 说明 |
| ---- | ---- | ---- |
| 名词 + 名词 | data analysis, project manager | 前一个名词限定后一个名词 |
| 名词 + 名词 + 名词 | customer support team | 从右往左找中心词：team 是中心 |
| 数字 + 名词 + 名词 | a five-year plan | year 用单数，因为整体作前置定语 |
| 名词 + 动名词 | decision-making process | 常用连字符 |
| 形容词 + 名词复合 | high school student | high school 作为整体修饰 student |
| 介词短语等价 | company policy = policy of the company | 名词前置更简洁 |

| 错误 | 正确 | 原因 |
| ---- | ---- | ---- |
| a five-years plan | a five-year plan | 复合前置定语中的 year 用单数 |
| a shoes store | a shoe store | 名词作定语通常用单数 |
| informations system | information system | information 不可数，也常作名词定语 |
| a two hours meeting | a two-hour meeting / a meeting of two hours | 前置复合形容词用单数 |

**复合名词的书写形式没有完全统一**：

| 形式 | 例子 | 建议 |
| ---- | ---- | ---- |
| 分写 | bus stop, credit card | 查词典或遵循领域习惯 |
| 连字符 | editor-in-chief, decision-making | 用于避免歧义或固定复合 |
| 合写 | notebook, database, website | 高频固定词常合写 |

### 2.12 名词短语结构 Noun Phrase Structure

名词短语的核心是中心名词或代词，基本结构如下：

```text
[前置限定/修饰] + 中心名词 + [后置修饰/补足]
```

| 部分 | 常见内容 | 例子 |
| ---- | -------- | ---- |
| 前位限定词 | all, both, half, twice | all the data |
| 中位限定词 | a, an, the, this, my, each, no | the plan, my idea |
| 后位限定词 | one, two, many, few, several | the two reports |
| 前置修饰语 | 形容词、名词、分词、复合修饰语 | a detailed financial report |
| 中心词 | 名词或代词 | report, idea, they |
| 后置修饰语 | 介词短语、分词短语、不定式、定语从句、同位语 | the report on inflation that we discussed |

| 名词短语 | 结构分析 |
| -------- | -------- |
| the report | the 限定词 + report 中心词 |
| the latest report | the 限定词 + latest 前置修饰 + report |
| the latest report on inflation | the + latest + report + on inflation 后置修饰 |
| the latest report on inflation that we discussed yesterday | the + latest + report + on inflation + that 从句 |
| all the three major policy changes | all 前位限定 + the 中位限定 + three 后位限定 + major policy 前置修饰 + changes 中心词 |

**限定词顺序速查**：

| 顺序 | 类别 | 例子 |
| ---- | ---- | ---- |
| 1 | 前位限定词 | all, both, half |
| 2 | 中位限定词 | the, a, this, my, no, each, every |
| 3 | 后位限定词 | one, two, many, several, few |
| 4 | 形容词/名词修饰语 | important, financial, research |
| 5 | 中心名词 | report, question, system |

自然表达：**all my many old research notes**  
不自然：**my all many old research notes**

### 2.13 名词短语的后置修饰

英语名词短语很容易向右扩展。阅读长句时，先找中心名词，再判断后面的短语或从句修饰谁。

| 后置修饰类型 | 例子 | 说明 |
| ------------ | ---- | ---- |
| 介词短语 | the book **on the shelf** | 表位置、关系、内容、来源等 |
| 定语从句 | the person **who approved the plan** | 限定或补充说明名词 |
| 现在分词短语 | the people **working on the project** | 主动或进行意义 |
| 过去分词短语 | the report **published yesterday** | 被动或完成意义 |
| 不定式短语 | the next step **to take** | 未来、目的、需要完成的动作 |
| 形容词短语后置 | something **important** | -thing/-one/-body 类词后常后置 |
| 同位语 | Paris, **the capital of France** | 解释或改名 |

| 句子 | 中心名词 | 后置修饰 |
| ---- | -------- | -------- |
| The proposal from the finance team was rejected. | proposal | from the finance team |
| The proposal that the finance team submitted was rejected. | proposal | that the finance team submitted |
| The proposal submitted by the finance team was rejected. | proposal | submitted by the finance team |

### 2.14 名词短语在句中的功能

| 功能 | 例句 | 分析 |
| ---- | ---- | ---- |
| 主语 | **The new policy** caused debate. | 名词短语作主语 |
| 宾语 | We reviewed **the new policy**. | 名词短语作直接宾语 |
| 介词宾语 | We talked about **the new policy**. | 名词短语作介词 about 的宾语 |
| 主语补语 | The issue is **a lack of evidence**. | 说明主语是什么 |
| 宾语补语 | They elected him **chairperson**. | chairperson 补充说明 him 的身份 |
| 同位语 | The issue, **a lack of evidence**, remains unresolved. | 解释 issue |
| 前置定语 | a **company** policy | 名词 company 修饰 policy |

### 2.15 名词常见错误速查

| 错误类型 | 不自然/错误 | 推荐表达 | 原因 |
| -------- | ----------- | -------- | ---- |
| 单数可数名词裸用 | I need **suggestion**. | I need **a suggestion**. | 单数可数名词通常需要限定词 |
| 不可数名词加 a/an | an advice | a piece of advice | advice 不可数 |
| 不可数名词复数化 | informations, equipments | information, equipment | 标准英语中通常不加 -s |
| many/much 混用 | much problems | many problems | problem 可数 |
| few/little 混用 | few progress | little progress | progress 不可数 |
| 复合定语复数化 | a five-years plan | a five-year plan | 前置复合修饰语用单数形式 |
| 所有格位置错 | my brother's-in-law car | my brother-in-law's car | 复合名词最后加 's |
| criteria 当单数 | this criteria | this criterion / these criteria | criterion 单数，criteria 复数 |
| data 搭配不一致 | the data is / are 混用 | 按文体统一：the data are 更正式；the data is 常见于现代一般用法 | 同一文本中保持一致 |
| 名词短语边界误读 | the report on prices from 2020 | 明确：the 2020 report on prices / the report from 2020 on prices | 多个后置修饰可能造成歧义 |

## 3. 冠词与限定词（Articles and Determiners）

限定词放在名词短语的开头，用来说明名词的范围、数量、特指程度、所属关系或说话者与名词的距离。冠词（a/an/the）只是限定词的一部分；真正写作时，冠词要和指示限定词、物主限定词、数量限定词、数词等一起考虑。

| 名词短语 | 限定词 | 中心名词 | 含义 |
| -------- | ------ | -------- | ---- |
| **a** book | a | book | 任意一本书；第一次引入 |
| **the** book | the | book | 双方都能识别的那本书 |
| **this** book | this | book | 说话者附近或当前谈论的这本书 |
| **my** book | my | book | 属于我或与我有关的书 |
| **some** books | some | books | 一些书，数量不精确 |
| **all three books** | all + three | books | 三本书全部 |

本章的核心判断是：这个名词是可数还是不可数？单数还是复数？泛指还是特指？是否需要表达数量、所属、远近或整体范围？

### 3.1 限定词总览

| 类型 | 英文 | 常见词 | 功能 | 例子 |
| ---- | ---- | ------ | ---- | ---- |
| 冠词 | Articles | a, an, the, zero article | 表示泛指、特指、新旧信息 | a problem, the problem, problems |
| 指示限定词 | Demonstratives | this, that, these, those | 表示远近、上下文指向 | this report, those results |
| 物主限定词 | Possessives | my, your, his, her, its, our, their | 表示所属、关联、责任 | our team, their decision |
| 数量限定词 | Quantifiers | some, any, no, many, much, few, little, several, enough | 表示数量或范围 | many questions, much time |
| 分配限定词 | Distributives | each, every, either, neither | 表示每个、任一、两者都不 | each student, every day |
| 数词 | Numerals | one, two, first, second | 表示数量或顺序 | two options, the first step |
| 疑问/关系限定词 | Interrogative / Relative Determiners | which, what, whose | 提问或引导从句 | which file, whose idea |
| 前位限定词 | Predeterminers | all, both, half, twice, double, such, what | 放在主要限定词前 | all the data, such a mistake |

**限定词和代词的区别**：

| 用法 | 例句 | 说明 |
| ---- | ---- | ---- |
| 限定词 | **This report** is useful. | this 后面有名词 report |
| 代词 | **This** is useful. | this 单独代替一个名词短语 |
| 限定词 | I like **some ideas**. | some 修饰 ideas |
| 代词 | I like **some**. | some 单独指代一部分 |

### 3.2 限定词顺序

一个名词前可以有多个限定成分，但顺序比较固定：

```text
前位限定词 + 中位限定词 + 后位限定词 + 形容词/名词修饰语 + 中心名词
```

| 位置 | 常见词 | 例子 |
| ---- | ------ | ---- |
| 前位限定词 | all, both, half, double, twice, such, what | all the students, such a problem |
| 中位限定词 | a/an, the, this/that, my/your, no, each, every, either, neither | my two books, each student |
| 后位限定词 | one/two, first/second, many, few, several, next, last, other | the next three weeks |
| 修饰语 | 形容词、名词、分词、复合修饰语 | the next three important policy changes |
| 中心名词 | 名词 | changes |

| 自然 | 不自然 | 原因 |
| ---- | ------ | ---- |
| all **the** students | the all students | all 是前位限定词 |
| both **my** parents | my both parents | both 通常在物主限定词前 |
| such **a** mistake | a such mistake | such 在 a/an 前 |
| the **first two** chapters | the two first chapters | 序数词通常在基数词前 |
| my **many** old notes | many my old notes | 物主限定词在数量限定词前 |

### 3.3 a / an：不定冠词

a/an 用于单数可数名词，通常表示“一个、某一个、任意一个、某类成员”。选择 a 还是 an 看发音的首音素，不看拼写。

| 用 a | 用 an | 原因 |
| ---- | ---- | ---- |
| a book | an apple | book 辅音音素开头；apple 元音音素开头 |
| a university | an hour | university 读 /ju-/；hour 的 h 不发音 |
| a European country | an honest answer | European 读 /j-/；honest 的 h 不发音 |
| a user | an umbrella | user 读 /ju-/；umbrella 元音开头 |
| a one-time fee | an MBA | one 读 /w/；MBA 读 /em/ |

| 用法 | 例句 | 说明 |
| ---- | ---- | ---- |
| 第一次引入 | I saw **a dog** outside. | 听者还不知道是哪只狗 |
| 表示任意一个 | Can I borrow **a pen**? | 哪支笔不重要 |
| 表示职业/身份 | She is **an engineer**. | 单数可数身份名词前常用 a/an |
| 表示一类中的一个成员 | A whale is **a mammal**. | 泛指一类成员 |
| 表示每一单位 | twice **a** week, 60 miles **an** hour | 相当于 per |
| 表示某种程度或结果 | It was **a success**. | 抽象名词转为一次事件 |

| 错误 | 正确 | 原因 |
| ---- | ---- | ---- |
| a information | a piece of information / some information | information 不可数 |
| an useful tool | a useful tool | useful 首音素是 /ju-/ |
| a hour | an hour | hour 的 h 不发音 |
| She is engineer. | She is an engineer. | 职业身份为单数可数名词 |

### 3.4 the：定冠词

the 表示“可识别”。不一定是前文出现过，也可以因为上下文、唯一性、限定修饰或共同知识而可识别。

| 特指来源 | 例句 | 为什么用 the |
| -------- | ---- | ------------ |
| 前文提到 | I bought **a book**. **The book** is expensive. | 第二次提到，听者知道是哪本 |
| 上下文唯一 | Please close **the door**. | 当前场景中双方知道是哪扇门 |
| 后置限定 | **The book on the desk** is mine. | on the desk 限定出具体对象 |
| 最高级/序数词 | **the best** answer, **the first** day | 在比较范围内可识别 |
| 唯一事物 | **the sun**, **the moon**, **the internet** | 常识中唯一或近似唯一 |
| 机构/服务场所 | I went to **the bank**. | 说话语境中可识别的机构功能 |
| 整类事物 | **The smartphone** changed communication. | 单数名词表示一类发明/物种/工具 |
| 形容词名词化 | **the rich**, **the poor**, **the unknown** | 表示一类人或抽象领域 |

**the + 比较级 / 最高级 / 序数词**：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| the + 最高级 | the most important point | 在范围内最高 |
| the + 序数词 | the second chapter | 排序中具体一个 |
| the + 比较级..., the + 比较级... | The sooner, the better. | “越……越……” |
| the + same / only / main / right / wrong | the same issue, the only option | 这些词本身强烈指向特定对象 |

### 3.5 零冠词 Zero Article

零冠词不是“忘了加冠词”，而是名词前有意不用 a/an/the。它常用于复数可数名词和不可数名词的泛指，也用于许多专有名词和固定表达。

| 用法 | 例句 | 说明 |
| ---- | ---- | ---- |
| 复数可数名词泛指 | **Dogs** are loyal. | 泛指狗这一类 |
| 不可数名词泛指 | **Water** is essential. | 泛指水这种物质 |
| 抽象概念 | **Freedom** matters. | 泛指概念 |
| 学科 | She studies **biology**. | 学科名通常零冠词 |
| 语言 | He speaks **Japanese**. | 语言名通常零冠词 |
| 三餐常规活动 | We had **lunch** at noon. | 泛指常规餐 |
| 球类/运动 | She plays **tennis**. | 运动名通常零冠词 |
| by + 交通方式 | by bus, by train, by car | 表交通方式，不指具体车辆 |
| 月份/星期/节日 | in July, on Monday, at Christmas | 通常零冠词 |
| 专有名词 | Tokyo, China, Harvard University | 多数人名、城市、国家、大学名零冠词 |

| 零冠词 | 加 the 后含义变化 |
| ------ | ---------------- |
| go to school | 上学，作为学生参与学校功能 |
| go to the school | 去那所学校建筑/地点 |
| be in hospital（英）/ be in the hospital（美） | 住院 |
| go to prison | 入狱 |
| go to the prison | 去监狱这个地点 |
| be at sea | 在海上航行/迷茫 |
| be at the sea | 在海边/海这个具体地点 |

### 3.6 泛指：a/an、the、零冠词的区别

英语表达“某一类事物”有三种常见方式，语气和适用范围不同。

| 形式 | 例句 | 语气/用法 |
| ---- | ---- | -------- |
| a/an + 单数可数名词 | **A dog** needs exercise. | 一个典型成员代表全类；解释定义常用 |
| the + 单数可数名词 | **The dog** is a loyal animal. | 较正式；把物种/发明/工具看作一类 |
| 零冠词 + 复数可数名词 | **Dogs** need exercise. | 最自然、最常用的泛指复数 |
| 零冠词 + 不可数名词 | **Coffee** is popular. | 泛指物质、概念、活动 |

| 不同表达 | 含义差别 |
| -------- | -------- |
| I like **coffee**. | 我喜欢咖啡这种饮品 |
| I like **the coffee**. | 我喜欢这杯/这里的/刚提到的咖啡 |
| I need **a coffee**. | 我要一杯咖啡 |
| **Life** is short. | 泛指人生 |
| **The life of a doctor** is stressful. | 被 of 短语限定，特指某类生活 |
| He had **a difficult life**. | 一种/一段具体人生经历 |

### 3.7 this / that / these / those：指示限定词

指示限定词表示空间距离、时间距离、文本距离或心理距离。

| 词 | 数 | 距离 | 例子 |
| ---- | ---- | ---- | ---- |
| this | 单数 | 近 | this question |
| that | 单数 | 远 | that question |
| these | 复数 | 近 | these questions |
| those | 复数 | 远 | those questions |

| 用法 | 例句 | 说明 |
| ---- | ---- | ---- |
| 空间距离 | I like **this chair**, not **that chair**. | 近/远 |
| 时间距离 | **This week** is busy. / **That day** changed everything. | 当前/过去或远离当前 |
| 上下文指代 | **This argument** is weak. | 指当前正在说的论点 |
| 情绪距离 | I hate **that tone**. | that 可带疏远或负面态度 |

### 3.8 my / your / his / her / its / our / their：物主限定词

物主限定词放在名词前，表示所属、来源、责任、关联或身体/家庭/组织关系。它们不能和 a/an/the 直接并列。

| 物主限定词 | 例子 | 说明 |
| ---------- | ---- | ---- |
| my | my phone | 我的/与我有关 |
| your | your idea | 你的/你们的 |
| his | his office | 他的 |
| her | her decision | 她的 |
| its | its purpose | 它的；注意没有撇号 |
| our | our team | 我们的 |
| their | their results | 他们/她们/它们的 |

| 错误 | 正确 | 原因 |
| ---- | ---- | ---- |
| the my book | my book / the book of mine | 物主限定词和 the 不能同位并列 |
| a my friend | a friend of mine | a 和 my 不能直接并列 |
| it's price | its price | its 是物主限定词；it's = it is / it has |
| mine book | my book | mine 是名词性物主代词，不放名词前 |

### 3.9 some / any / no

some, any, no 可修饰复数可数名词和不可数名词。

| 词 | 常见语境 | 例句 | 说明 |
| ---- | -------- | ---- | ---- |
| some | 肯定句；期待肯定回答的请求/邀请 | I need **some help**. / Would you like **some coffee**? | 表不定数量 |
| any | 疑问句、否定句、条件句；“任何” | Do you have **any questions**? / If you need **any help**, call me. | 范围开放 |
| no | 否定限定词 | There is **no evidence**. | no + 名词，本身是否定 |

| 对比 | 例句 | 含义 |
| ---- | ---- | ---- |
| not any | We don't have any time. | 没有时间 |
| no | We have no time. | 更直接、更强 |
| some + 单数可数名词 | Some guy called you. | 某个、不认识或不重要的人 |
| any + 单数可数名词 | Any student can answer this. | 任意一个 |

### 3.10 many / much / few / little / several / enough

| 限定词 | 接可数复数 | 接不可数 | 含义 |
| ------ | ---------- | -------- | ---- |
| many | many reasons | 不接 | 多 |
| much | 不接 | much time | 多；肯定句中常偏正式 |
| a few | a few options | 不接 | 有几个，偏肯定 |
| few | few options | 不接 | 几乎没有，偏否定 |
| a little | 不接 | a little time | 有一点，偏肯定 |
| little | 不接 | little time | 几乎没有，偏否定 |
| several | several people | 不接 | 几个，超过 two，但不多 |
| enough | enough chairs | enough time | 足够 |
| plenty of | plenty of chairs | plenty of time | 很多、充足 |
| a lot of / lots of | a lot of books | a lot of work | 口语和中性写作都常用 |

| 易混 | 例句 | 说明 |
| ---- | ---- | ---- |
| a few vs few | We have **a few** options. / We have **few** options. | 前者“有几个”，后者“几乎没有” |
| a little vs little | There is **a little** hope. / There is **little** hope. | 前者“还有一点”，后者“几乎没有” |
| much vs many | much information / many reports | 看名词是否可数 |
| less vs fewer | less water / fewer mistakes | 传统规范：不可数用 less，可数复数用 fewer |

### 3.11 all / both / each / every / either / neither

这些限定词处理“整体、两者、每一个、任一个、两者都不”等逻辑关系。

| 限定词 | 范围 | 后接 | 例句 | 谓语倾向 |
| ------ | ---- | ---- | ---- | -------- |
| all | 三者以上或整体 | 复数可数/不可数 | **All students** passed. / **All information** is useful. | 复数或单数按名词 |
| both | 两者全部 | 复数可数 | **Both answers** are correct. | 复数 |
| each | 两者或以上逐个 | 单数可数 | **Each student** has a card. | 单数 |
| every | 三者以上整体中的每个 | 单数可数 | **Every student** has a card. | 单数 |
| either | 两者任一 | 单数可数 | **Either option** is fine. | 单数 |
| neither | 两者都不 | 单数可数 | **Neither option** is ideal. | 单数；正式语法多用单数 |

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| all of / both of + 限定名词短语 | all of the data, both of my parents | of 后通常需要限定词或代词 |
| each of / either of / neither of + 复数代词/限定名词 | each of them, neither of the options | 谓语常用单数，口语中也可见复数 |
| every one of | every one of the files | 强调每一个个体 |
| not every | Not every answer is correct. | 部分否定：不是每个都 |

### 3.12 数词与顺序限定

| 类型 | 例子 | 用法 |
| ---- | ---- | ---- |
| 基数词 | one file, two files | 表数量 |
| 序数词 | the first file, the second chapter | 表顺序；通常和 the 或物主限定词连用 |
| 分数/倍数 | half the price, twice the size | 可作前位限定 |
| next / last | the next chapter, last week | 表顺序或时间位置 |
| another / other | another question, other questions | 表另一个/其他 |

| 表达 | 含义 |
| ---- | ---- |
| another two weeks | 另外两周 |
| the other two weeks | 剩下那两周 |
| other people | 其他人，泛指 |
| the other people | 其余那些人，特指 |
| one more question | 再一个问题 |
| the next question | 下一个问题 |

### 3.13 专有名词与 the

多数专有名词不用冠词，但一些名称因结构或习惯要用 the。

| 类别 | 通常零冠词 | 通常用 the |
| ---- | ---------- | ---------- |
| 人名 | Jane Austen, Barack Obama | the Obamas 表示一家人 |
| 国家/城市 | Japan, China, Paris, Tokyo | the United States, the Netherlands, the Philippines |
| 大洲/州/街道 | Asia, California, Oxford Street | the Middle East, the Bronx |
| 山峰/湖泊 | Mount Fuji, Lake Michigan | the Alps, the Himalayas, the Great Lakes |
| 河流/海洋/海峡/沙漠 | - | the Nile, the Pacific, the English Channel, the Sahara |
| 大学 | Harvard University, Oxford University | the University of Tokyo, the University of Oxford |
| 报刊/机构 | Google, NATO | the BBC, the New York Times, the World Bank |
| 建筑/地标 | Buckingham Palace | the Eiffel Tower, the White House |

**同一词加不加 the 可能表示不同意义**：

| 表达 | 含义 |
| ---- | ---- |
| Congress | 美国国会这个机构名，常零冠词 |
| the congress | 某一次会议/代表大会 |
| school | 学校功能：go to school |
| the school | 具体学校建筑或机构 |
| church | 宗教活动：go to church |
| the church | 教堂建筑或教会组织 |

### 3.14 固定场景：餐食、交通、机构、疾病

| 场景 | 零冠词 | 加冠词时 |
| ---- | ------ | -------- |
| 三餐 | have breakfast/lunch/dinner | a big dinner, the dinner we had yesterday |
| 运动 | play football/tennis/chess | the football from yesterday's game（具体球） |
| 交通方式 | by bus/train/car/air/sea | take a bus, get on the train |
| 机构功能 | go to school/prison/church/bed | go to the school/prison/church（地点） |
| 媒体/通信 | on TV, by email | on the radio, on the phone |
| 疾病 | have flu（英）/ have the flu（美）, have cancer | a cold, a headache, the measles |

### 3.15 冠词选择流程

| 步骤 | 问题 | 选择 |
| ---- | ---- | ---- |
| 1 | 名词是专有名词吗？ | 多数零冠词；查是否属于 the United States / the Nile 这类固定 the |
| 2 | 是单数可数名词吗？ | 需要 a/an、the、this、my、one 等限定词 |
| 3 | 是复数可数或不可数泛指吗？ | 通常零冠词：Books are useful. / Water is essential. |
| 4 | 听者能识别具体对象吗？ | 用 the：the book on the desk |
| 5 | 第一次引入且不特指吗？ | 单数可数用 a/an；复数/不可数用 some 或零冠词 |
| 6 | 是否强调数量？ | 用 many/much/few/little/several/enough/a lot of 等 |
| 7 | 是否强调所属或远近？ | 用 my/your/our 或 this/that/these/those |

**短例**：

| 语境 | 推荐表达 | 原因 |
| ---- | -------- | ---- |
| 第一次提到一本书 | I bought **a book**. | 单数可数，未特指 |
| 第二句继续说这本书 | **The book** is useful. | 已知对象 |
| 泛指书 | **Books** are useful. | 复数泛指零冠词 |
| 泛指信息 | **Information** is useful. | 不可数泛指零冠词 |
| 特指这份信息 | **The information** you sent is useful. | 被从句限定 |

### 3.16 常见错误速查

| 错误类型 | 不自然/错误 | 推荐表达 | 原因 |
| -------- | ----------- | -------- | ---- |
| 单数可数名词缺限定词 | I need **answer**. | I need **an answer**. | answer 是单数可数名词 |
| 不可数名词误用 a/an | a research | a study / some research | research 常不可数 |
| a/an 看字母不看发音 | an university | a university | university 首音素是 /j/ |
| the 泛滥 | The life is hard. | Life is hard. | 泛指抽象概念通常零冠词 |
| 泛指复数误加 the | The dogs are loyal animals. | Dogs are loyal animals. | 泛指类别用零冠词更自然 |
| 特指漏 the | book on the desk is mine | The book on the desk is mine. | 后置修饰限定出具体对象 |
| 物主限定词与冠词叠用 | the my plan | my plan / the plan of mine | 中位限定词不能这样并列 |
| much/many 混用 | many information | much information / a lot of information | information 不可数 |
| few/little 混用 | few evidence | little evidence | evidence 不可数 |
| every 后接复数 | every students | every student / all students | every 后接单数可数名词 |
| both 后接单数 | both answer | both answers | both 后接复数 |
| such/a 顺序错 | a such problem | such a problem | such 是前位限定词 |

## 4. 代词与指代（Pronouns and Reference）

代词用来代替名词、名词短语、从句或整个句子，避免重复，并建立上下文中的指代关系。代词的难点不在“背表格”，而在三件事：格是否正确、先行词是否清楚、数/人称/性别是否一致。

| 原句 | 使用代词后 | 说明 |
| ---- | ---------- | ---- |
| Sarah called Sarah's manager because Sarah needed help. | Sarah called **her** manager because **she** needed help. | her/she 指 Sarah |
| The report was late, and the delay caused problems. | The report was late, and **this** caused problems. | this 指整个前句事件 |
| I need a pen. Do you have a pen? | I need a pen. Do you have **one**? | one 代替 a pen |

### 4.1 代词总览

| 类型 | 英文 | 常见形式 | 核心用途 | 例句 |
| ---- | ---- | -------- | -------- | ---- |
| 人称代词 | Personal Pronouns | I, me, you, he, him, she, her, it, we, us, they, them | 指人、事物或群体 | **They** called **us**. |
| 物主代词 | Possessive Pronouns | mine, yours, his, hers, ours, theirs | 代替“物主限定词 + 名词” | This is **mine**. |
| 反身代词 | Reflexive Pronouns | myself, yourself, himself, herself, itself, ourselves, yourselves, themselves | 主语和宾语同指，或加强语气 | She blamed **herself**. |
| 指示代词 | Demonstrative Pronouns | this, that, these, those | 指近远对象或上下文内容 | **This** is useful. |
| 不定代词 | Indefinite Pronouns | someone, anything, all, none, each, either | 指不确定的人、物、数量或范围 | **Everyone** agrees. |
| 相互代词 | Reciprocal Pronouns | each other, one another | 表示彼此关系 | They helped **each other**. |
| 疑问代词 | Interrogative Pronouns | who, whom, whose, what, which | 提问 | **Who** called? |
| 关系代词 | Relative Pronouns | who, whom, whose, which, that | 引导定语从句 | the book **that** I bought |
| 连接代词 | Conjunctive Pronouns | who, what, which, whoever, whatever | 引导名词性从句 | I know **what** happened. |
| 替代代词 | Substitute Pronouns | one, ones, so, not | 避免重复 | I think **so**. |

### 4.2 人称代词、物主形式、反身代词

| 人称 | 主格 | 宾格 | 物主限定词 | 名词性物主代词 | 反身代词 |
| ---- | ---- | ---- | ---------- | -------------- | -------- |
| 第一人称单数 | I | me | my | mine | myself |
| 第一人称复数 | we | us | our | ours | ourselves |
| 第二人称单数 | you | you | your | yours | yourself |
| 第二人称复数 | you | you | your | yours | yourselves |
| 第三人称单数男性 | he | him | his | his | himself |
| 第三人称单数女性 | she | her | her | hers | herself |
| 第三人称单数事物 | it | it | its | its | itself |
| 第三人称复数/单数 they | they | them | their | theirs | themselves / themself |

| 类别 | 位置 | 例句 | 注意 |
| ---- | ---- | ---- | ---- |
| 主格 | 作主语 | **She** knows the answer. | I, he, she, we, they |
| 宾格 | 作动词宾语或介词宾语 | I called **her**. / for **them** | me, him, her, us, them |
| 物主限定词 | 名词前 | **Her** answer was clear. | 后面必须有名词 |
| 名词性物主代词 | 单独代替名词短语 | The answer is **hers**. | mine/yours/his/hers/ours/theirs |
| 反身代词 | 主语与宾语同指 | He hurt **himself**. | 不能随便代替普通宾格 |

### 4.3 格：I / me, who / whom

英语代词仍保留明显的格变化。判断格时，看代词在自己的小句中做什么成分。

| 功能 | 正确 | 不自然/错误 | 原因 |
| ---- | ---- | ----------- | ---- |
| 作主语 | **She and I** joined the meeting. | Her and me joined the meeting. | 主语位置用主格 |
| 作宾语 | The manager called **her and me**. | The manager called she and I. | 宾语位置用宾格 |
| 介词后 | between **you and me** | between you and I | 介词 between 后用宾格 |
| 比较省略 | He is taller than **I am**. / taller than **me** | - | 正式可补全 I am；口语常用 me |
| who 作主语 | **Who** called you? | Whom called you? | who 在从句中作主语 |
| whom 作宾语 | **Whom** did you call? | - | 正式；口语常用 who |
| 介词 + whom | To **whom** did you speak? | - | 正式书面 |
| 介词后置 | Who did you speak **to**? | - | 现代口语和普通写作更常见 |

**实用判断**：把并列部分拆开。  
`The manager called Sarah and me.` -> `The manager called me.`，所以用 me，不用 I。

### 4.4 it 的主要用法

it 可以指代事物、动物、婴儿、抽象情况，也可以作形式主语或形式宾语。

| 用法 | 例句 | 说明 |
| ---- | ---- | ---- |
| 指代前文名词 | I found the file and opened **it**. | it = the file |
| 指天气/时间/距离 | **It** is raining. / **It** is late. / **It** is five miles away. | 非实义主语 |
| 形式主语 | **It** is important to check the data. | 真正主语是 to check the data |
| 形式宾语 | I found **it** hard to focus. | 真正宾语是 to focus |
| 强调句 | **It was John who** broke the rule. | it-cleft，用来突出 John |
| 指整个情境 | I missed the train. **It** was frustrating. | it 指前一事件或情况 |

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| It is + adj + to do | It is easy to forget this rule. | to do 是真正主语 |
| It is + adj + that-clause | It is clear that he was wrong. | that 从句是真正主语 |
| find/make/think + it + adj/n + to do | We made it possible to continue. | it 作形式宾语 |
| It takes + time + to do | It takes two hours to finish. | 表耗时 |

### 4.5 there 与 it 的区别

there 引出“存在”，it 指代“已知对象/情况”或作形式主语。

| 结构 | 例句 | 功能 |
| ---- | ---- | ---- |
| There is/are + 名词 | **There is** a problem. | 引入新信息 |
| It is + 名词/形容词 | **It is** a serious problem. | 评价或识别已知对象 |
| There seems/appears to be | **There seems to be** a mistake. | 表存在的可能 |
| It seems/appears that | **It seems that** he forgot. | 表整个判断 |

| 易错 | 推荐 | 原因 |
| ---- | ---- | ---- |
| It has many people in the room. | There are many people in the room. | 表存在用 there be |
| There is important to check it. | It is important to check it. | 形式主语用 it |

### 4.6 this / that / these / those：指示代词

指示代词可单独代替名词短语或前文内容；如果后面接名词，就是指示限定词。

| 用法 | 代词例句 | 限定词例句 |
| ---- | -------- | ---------- |
| 近指单数 | **This** is useful. | **This method** is useful. |
| 远指单数 | **That** was unexpected. | **That result** was unexpected. |
| 近指复数 | **These** are new. | **These files** are new. |
| 远指复数 | **Those** were expensive. | **Those tickets** were expensive. |

| 指代范围 | 例句 | 说明 |
| -------- | ---- | ---- |
| 指一个对象 | This is my laptop. | this = 这个对象 |
| 指前一句话 | He missed the deadline. **This** caused problems. | this = 前句事件 |
| 指后文内容 | Remember **this**: keep the message short. | this 指冒号后的内容 |
| 情感距离 | That's ridiculous. | that 可表达疏离、评价 |

### 4.7 反身代词与强调用法

反身代词有两种功能：反身（主语和宾语同一对象）和强调（强调某人亲自）。

| 用法 | 例句 | 说明 |
| ---- | ---- | ---- |
| 反身宾语 | She introduced **herself**. | she = herself |
| 介词宾语 | He was talking to **himself**. | 对自己说话 |
| 固定搭配 | by myself, enjoy yourself, help yourself | 习惯表达 |
| 强调主语 | The CEO **herself** approved it. | CEO 亲自批准 |
| 强调宾语 | I spoke to the manager **himself**. | 正是经理本人 |

| 错误 | 正确 | 原因 |
| ---- | ---- | ---- |
| Please contact myself. | Please contact me. | 普通宾语用 me |
| John and myself will attend. | John and I will attend. | 主语位置用 I |
| I did it by me. | I did it by myself. | by oneself 表“独自” |

### 4.8 相互代词 each other / one another

each other 和 one another 表示“彼此、互相”。传统上 each other 用于两者，one another 用于三者以上；现代英语中二者常可互换。

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| 动词宾语 | They helped **each other**. | 互相帮助 |
| 介词宾语 | They looked at **each other**. | 互相看 |
| 所有格 | They respect **each other's** opinions. | 彼此的意见 |
| one another | The members supported **one another**. | 多人之间互相支持 |

**注意**：相互代词需要至少两个参与者。`He helped each other` 不成立。

### 4.9 不定代词 Indefinite Pronouns

不定代词表示不明确的人、事物、数量或范围。

| 类别 | 代词 | 例句 | 谓语 |
| ---- | ---- | ---- | ---- |
| some 系列 | someone, somebody, something | **Someone** is here. | 单数 |
| any 系列 | anyone, anybody, anything | **Anything** is possible. | 单数 |
| no 系列 | no one, nobody, nothing | **Nobody** knows. | 单数 |
| every 系列 | everyone, everybody, everything | **Everyone** has arrived. | 单数 |
| 两者 | both, either, neither | **Both** are correct. / **Neither** is ideal. | both 复数；either/neither 常单数 |
| 个体 | each | **Each** has a role. | 单数 |
| 全体/部分 | all, some, most, none, any | **Some** are ready. / **Some** is missing. | 依指代对象 |
| 其他 | another, others, the other, the others | **Others** disagreed. | 依形式 |

| 代词 | 指人 | 指物 | 说明 |
| ---- | ---- | ---- | ---- |
| someone/somebody | 是 | 否 | 肯定句常用 |
| anyone/anybody | 是 | 否 | 疑问、否定、条件或“任何人” |
| no one/nobody | 是 | 否 | no one 更常分写 |
| everyone/everybody | 是 | 否 | 单数谓语，可用 they 指代 |
| something | 否 | 是 | 某事/某物 |
| anything | 否 | 是 | 任何事/某事 |
| nothing | 否 | 是 | 没什么 |
| everything | 否 | 是 | 一切 |

### 4.10 some / any / no / none

这些词既可作限定词，也可作代词。作代词时，后面不直接接名词。

| 形式 | 例句 | 说明 |
| ---- | ---- | ---- |
| some | I need some. | 指“一些” |
| any | Do you have any? | 疑问句或否定句 |
| no | No students came. | no 是限定词，后接名词 |
| none | None came. | none 是代词，单独使用 |
| none of + 名词短语 | None of the answers is/are correct. | 谓语单复数都可见；正式常用单数 |

| 易混 | 例句 | 说明 |
| ---- | ---- | ---- |
| no one vs none | **No one** called. / **None** of them called. | no one 指人；none 指“没有一个/一点” |
| nothing vs none | Nothing happened. / None of the files opened. | nothing 指没有事情；none 指某范围中没有 |
| any 否定范围 | I don't have any. | not + any = none |

### 4.11 other / another / the other / others / the others

| 形式 | 后接名词？ | 含义 | 例句 |
| ---- | -------- | ---- | ---- |
| another | 可接单数名词；也可单独作代词 | 另一个；再一个 | I need **another**. / another question |
| other | 接复数或不可数名词 | 其他的，泛指 | other people, other information |
| the other | 可接单数/复数；也可作代词 | 两者中的另一个；其余特定对象 | One is red; **the other** is blue. |
| others | 单独作代词 | 其他人/物，泛指 | Some agreed; **others** disagreed. |
| the others | 单独作代词 | 其余那些，特指 | Two left; **the others** stayed. |

| 错误 | 正确 | 原因 |
| ---- | ---- | ---- |
| another informations | other information / another piece of information | another 后接单数可数名词 |
| others people | other people | others 是代词，不能再接名词 |
| the another one | the other one / another one | the 和 another 不直接并列 |

### 4.12 one / ones / that / those 的替代

one/ones 可代替前文提到的可数名词，that/those 常用于比较结构中避免重复。

| 替代词 | 替代对象 | 例句 | 说明 |
| ------ | -------- | ---- | ---- |
| one | 单数可数名词 | I lost my pen. I need **one**. | one = a pen |
| ones | 复数可数名词 | I prefer the black **ones**. | ones = shoes/files/items 等复数可数名词 |
| the one | 特指单数 | The blue one is cheaper. | the one = the blue item |
| that | 单数/不可数名词短语 | The cost is higher than **that** of last year. | 正式比较 |
| those | 复数名词短语 | These results differ from **those** of 2020. | those = the results |

| 不自然 | 推荐 | 原因 |
| ------ | ---- | ---- |
| I need an information. Do you have one? | I need some information. Do you have any? | one 不能代替不可数名词 |
| The population of Japan is larger than China. | The population of Japan is larger than that of China. | 比较对象要平行 |

### 4.13 so / not 替代从句

so 和 not 可以代替前文或后文的整句内容，常见于 think, hope, believe, suppose, expect, say, do so 等结构。

| 结构 | 例句 | so/not 指什么 |
| ---- | ---- | ------------- |
| think so | I think **so**. | 前文命题为真 |
| hope so | I hope **so**. | 希望前文会发生 |
| hope not | I hope **not**. | 希望前文不会发生 |
| say so | She said **so**. | 她这样说 |
| do so | If you need to cancel, do **so** early. | do so = cancel |
| not | Maybe he will resign, but I hope **not**. | not = he will not resign |

**注意**：`do so` 多用于有意动作，不自然用于状态。  
自然：If you want to apply, do so now.  
不自然：He knows French, and she does so too. -> 推荐：She does too.

### 4.14 疑问代词 Interrogative Pronouns

| 疑问代词 | 问什么 | 例句 | 注意 |
| -------- | ------ | ---- | ---- |
| who | 人；主语或身份 | **Who** called? | 作主语 |
| whom | 人；宾语 | **Whom** did you invite? | 正式；口语常用 who |
| whose | 所属 | **Whose** is this? / **Whose book** is this? | 可作代词或限定词 |
| what | 事物、身份、职业、开放范围 | **What** happened? | 开放选择 |
| which | 特定范围中的哪一个 | **Which** do you prefer? | 有明确选项范围 |

| 对比 | 例句 | 区别 |
| ---- | ---- | ---- |
| who vs what | Who is he? / What is he? | who 问身份姓名；what 可问职业/性质 |
| what vs which | What do you want? / Which do you want? | what 开放；which 在给定范围内选择 |
| whose 代词/限定词 | Whose is this? / Whose phone is this? | 后接名词时是限定词 |

### 4.15 关系代词 Relative Pronouns

关系代词引导定语从句，并在从句中作主语、宾语、定语或介词宾语。

| 关系代词 | 先行词 | 从句中功能 | 例句 |
| -------- | ------ | ---------- | ---- |
| who | 人 | 主语/宾语 | the person **who** called |
| whom | 人 | 宾语/介词宾语 | the person **whom** we invited |
| whose | 人/物 | 所属定语 | the writer **whose** book won |
| which | 物/事 | 主语/宾语 | the file **which** was deleted |
| that | 人/物 | 主语/宾语 | the file **that** I sent |
| as | 人/物/整句 | 固定结构或非限制性补充 | such problems **as** we discussed |

| 规则 | 例句 | 说明 |
| ---- | ---- | ---- |
| 宾语关系代词可省略 | the book **(that)** I bought | that 在从句中作 bought 的宾语 |
| 主语关系代词不可省略 | the person **who** called | who 是 called 的主语 |
| 非限制性定语从句不用 that | My car, **which** is old, still works. | 逗号后不用 that |
| 介词前置用 whom/which | the person **to whom** I spoke | 正式 |
| 介词后置更口语 | the person **who/that** I spoke to | 普通表达 |

### 4.16 连接代词与自由关系从句

连接代词引导名词性从句，可作主语、宾语、表语、同位语等。形式和疑问代词相同，但它们嵌在另一个句子里，不是直接提问。

| 连接代词 | 例句 | 从句功能 |
| -------- | ---- | -------- |
| who | I know **who called**. | 宾语从句 |
| whom | I know **whom they chose**. | 宾语从句；正式 |
| whose | Tell me **whose idea this was**. | 宾语从句 |
| what | **What he said** matters. | 主语从句 |
| which | I can't decide **which is better**. | 宾语从句 |
| whoever | **Whoever arrives first** should call me. | 自由关系从句 |
| whatever | Take **whatever you need**. | 自由关系从句 |
| whichever | Choose **whichever works best**. | 自由关系从句 |

| 类型 | 例句 | 区别 |
| ---- | ---- | ---- |
| 直接疑问 | What did he say? | 独立问题，疑问语序 |
| 间接疑问/名词性从句 | I know what he said. | 陈述语序：what + 主语 + 谓语 |
| 自由关系从句 | What he said was true. | what = the thing that |

### 4.17 先行词、一致与指代清晰

代词通常要有清楚的先行词，并在人称、数、性别或语义上保持一致。

| 规则 | 清楚表达 | 问题表达 | 说明 |
| ---- | -------- | -------- | ---- |
| 数一致 | The student submitted **his or her/their** form. | The student submitted their forms. | 单数人可用 singular they；form 数量也要清楚 |
| 复数一致 | The students submitted **their** forms. | The students submitted his form. | students 是复数 |
| 性别未知 | If anyone calls, ask **them** to wait. | ask him to wait | 现代英语常用 singular they |
| 指代最近合理名词 | Sarah told Anna that **she** was late. | 有歧义 | she 可能是 Sarah 或 Anna |
| this/which 指整句 | Sales fell sharply. **This** surprised investors. | this 指前句事件 | 可以用 this trend/this result 更清楚 |

**消除歧义的方法**：

| 问题 | 改写 |
| ---- | ---- |
| Sarah told Anna that she was late. | Sarah told Anna, "I am late." / Sarah told Anna that Anna was late. |
| The report mentioned the policy, but it was unclear. | The report was unclear about the policy. / The policy was unclear. |
| When the team met the client, they were angry. | The client was angry when the team met them. |

### 4.18 常见错误速查

| 错误类型 | 不自然/错误 | 推荐表达 | 原因 |
| -------- | ----------- | -------- | ---- |
| 主格/宾格混用 | Me and John went. | John and I went. | 主语位置用主格 |
| 介词后用主格 | between you and I | between you and me | 介词后用宾格 |
| 反身代词滥用 | Please email myself. | Please email me. | myself 不是礼貌版 me |
| 物主 its/it's 混用 | it's purpose | its purpose | it's = it is / it has |
| 单数可数名词用 one 错位 | I need advice. Do you have one? | Do you have any? / a piece of advice? | one 代替单数可数名词 |
| this 指代不明 | He changed the plan after the meeting. This was bad. | This decision was bad. / This delay was bad. | this 后加名词更清楚 |
| each other 单数主体 | He helped each other. | They helped each other. | 相互代词需要复数参与者 |
| every 后代词不一致 | Every student brought their books. | Every student brought their book. | 若每人一本，book 用单数 |
| who/which 先行词错 | the person which called | the person who/that called | 人用 who/that |
| 关系代词省略错误 | the man called me is Tom | the man who called me is Tom | 作主语的关系代词不可省略 |
| 间接疑问语序错 | I know what did he say. | I know what he said. | 名词性从句用陈述语序 |
| none/no one 混用 | None called me. | No one called me. | 指人且无 of 范围时 no one 更自然 |

## 5. 动词、时态、语态与语气（Verbs, Tense, Voice and Mood）

动词是英语句子的发动机：它决定句子的核心结构、时间关系、否定疑问形式、语态和语气。学动词不能只背“16 种时态”，还要同时看四层：

| 层级 | 要问的问题 | 例子 |
| ---- | ---------- | ---- |
| 动词类型 | 这个动词后面需要什么成分？ | arrive 不接宾语；discuss 直接接宾语；make 可接宾语补语 |
| 动词形式 | 这个动词用原形、三单、过去式、过去分词还是 -ing？ | work, works, worked, working |
| 时态体貌 | 动作发生在什么时候，是否完成、持续或正在进行？ | works, worked, has worked, is working |
| 语态和语气 | 主语是执行者还是承受者？表达事实、命令、假设还是态度？ | The file was deleted. / If I were you... |

### 5.1 动词类型总览

| 类型 | 英文 | 后接结构 | 例句 | 判断重点 |
| ---- | ---- | -------- | ---- | -------- |
| 不及物动词 | Intransitive Verb | 不直接接宾语 | The baby **slept**. | 后面不需要宾语；若接信息常用介词 |
| 及物动词 | Transitive Verb | V + O | She **opened the file**. | 有直接宾语；通常可变被动 |
| 双宾动词 | Ditransitive Verb | V + IO + DO | He **sent me an email**. | 可改为 sent an email to me |
| 宾补动词 | Complex-transitive Verb | V + O + C | They **made him angry**. | 补语说明宾语 |
| 系动词 | Linking Verb | V + Subject Complement | She **is tired**. / It **seems true**. | 后面不是宾语，而是主语补语 |
| 助动词 | Auxiliary Verb | be/do/have + 主动词 | She **has finished**. | 构成时态、否定、疑问、被动 |
| 情态动词 | Modal Verb | modal + 动词原形 | You **should leave**. | 表能力、可能、义务、建议等 |
| 短语动词 | Phrasal Verb | V + particle/preposition | give up, look after | 意义常不是字面组合 |

**常见动词句型**：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| S + V | He **arrived**. | 不及物 |
| S + V + O | He **answered the question**. | 及物 |
| S + V + C | He **became a lawyer**. | 系动词 + 主语补语 |
| S + V + IO + DO | He **gave me a chance**. | 双宾 |
| S + V + O + C | He **made me nervous**. | 宾语补语 |
| S + V + Prep + O | He **listened to music**. | 动词搭配要求介词 |

### 5.2 实义动词、助动词、情态动词

| 类别 | 作用 | 常见词 | 例句 |
| ---- | ---- | ------ | ---- |
| 实义动词 | 表示主要动作或状态 | work, read, know, become | She **works** here. |
| be 助动词 | 构成进行、被动 | am, is, are, was, were, been, being | She **is working**. / It **was built**. |
| have 助动词 | 构成完成体 | have, has, had | They **have finished**. |
| do 助动词 | 构成否定、疑问、强调 | do, does, did | **Do** you agree? / I **do** agree. |
| 情态动词 | 表示态度、可能性、义务、能力等 | can, could, may, might, must, shall, should, will, would | You **must wait**. |

**助动词 do 的核心规则**：

| 场景 | 结构 | 例句 |
| ---- | ---- | ---- |
| 一般现在否定 | do/does not + 原形 | He **does not know**. |
| 一般过去否定 | did not + 原形 | He **did not know**. |
| 一般现在疑问 | Do/Does + 主语 + 原形 | **Does** he **know**? |
| 一般过去疑问 | Did + 主语 + 原形 | **Did** he **know**? |
| 强调 | do/does/did + 原形 | I **do understand**. |

### 5.3 动词五种基本形式

| 形式 | 英文 | 例子 | 主要用途 |
| ---- | ---- | ---- | -------- |
| 原形 | base form | work, go, be | 助动词/情态后、祈使句、不定式 to 后 |
| 第三人称单数 | third-person singular | works, goes, has | 一般现在时，主语为 he/she/it 或单数名词 |
| 过去式 | past form | worked, went | 一般过去时；部分虚拟结构 |
| 过去分词 | past participle | worked, gone | 完成体、被动语态、分词形容词 |
| 现在分词/动名词 | -ing form | working, going | 进行体、动名词、分词结构 |

| 原形 | 三单 | 过去式 | 过去分词 | -ing |
| ---- | ---- | ------ | -------- | ---- |
| work | works | worked | worked | working |
| study | studies | studied | studied | studying |
| stop | stops | stopped | stopped | stopping |
| make | makes | made | made | making |
| go | goes | went | gone | going |
| be | is / am / are | was / were | been | being |
| have | has | had | had | having |
| do | does | did | done | doing |

### 5.4 拼写变化规则

#### 第三人称单数

| 规则 | 变化 | 例子 |
| ---- | ---- | ---- |
| 一般情况 | 加 -s | work -> works, read -> reads |
| s, x, ch, sh, o 结尾 | 加 -es | pass -> passes, fix -> fixes, go -> goes |
| 辅音字母 + y | y 变 i 加 -es | study -> studies, try -> tries |
| 元音字母 + y | 直接加 -s | play -> plays, enjoy -> enjoys |
| 特殊 | have -> has | have 是高频特殊词 |

#### 过去式和过去分词

| 规则 | 变化 | 例子 |
| ---- | ---- | ---- |
| 一般情况 | 加 -ed | work -> worked |
| 不发音 e 结尾 | 加 -d | live -> lived |
| 辅音字母 + y | y 变 i 加 -ed | study -> studied |
| 重读闭音节 | 双写尾辅音加 -ed | stop -> stopped, plan -> planned |
| 非重读结尾 | 通常不双写 | open -> opened, visit -> visited |

| 规则 | 变化 | 例子 |
| ---- | ---- | ---- |
| 一般情况 | 加 -ing | work -> working |

| 重读闭音节 | 双写尾辅音加 -ing | run -> running, sit -> sitting |
| ie 结尾 | ie 变 y 加 -ing | lie -> lying, die -> dying |
| c 结尾 | 加 k 再加 -ing | picnic -> picnicking, panic -> panicking |
| ee / oe / ye 结尾 | 不去 e | see -> seeing, agree -> agreeing |

### 5.6 时态、体貌和时间

英语传统“时态”其实由时间 tense 和体貌 aspect 组合而成。核心不是背名字，而是判断动作与时间点的关系。

| 维度 | 形式 | 核心意义 | 例子 |
| ---- | ---- | -------- | ---- |
| 现在 | present | 现在事实、习惯、一般状态 | She works. |
| 过去 | past | 过去时间或心理距离 | She worked. |
| 将来 | future expression | will, be going to, present continuous 等表示未来 | She will work. |
| 简单体 | simple | 整体看动作或状态 | She works. |
| 进行体 | progressive | 某时刻正在进行或临时持续 | She is working. |
| 完成体 | perfect | 之前发生，对某时间点有结果、经验或持续关系 | She has worked. |
| 完成进行体 | perfect progressive | 从之前开始持续到某时间点，强调过程和持续时间 | She has been working. |

**动词短语顺序**：

```text
情态动词 + have + been + being + 主动词
```

| 组合 | 例句 | 说明 |
| ---- | ---- | ---- |
| modal + base | She **can work**. | 情态后接原形 |
| have + past participle | She **has worked**. | 完成体 |
| be + -ing | She **is working**. | 进行体 |
| be + past participle | It **was built**. | 被动语态 |
| modal + perfect + progressive | She **must have been working**. | 情态 + 完成 + 进行 |
| perfect + passive | It **has been built**. | 完成 + 被动 |

### 5.7 12 个核心时态速查

实际英语中最常用的是 12 个核心组合；“过去将来”系列多用于间接引语或从过去看未来，可单独理解为 would 结构。

| 时态 | 结构 | 例句 | 核心用法 |
| ---- | ---- | ---- | -------- |
| 一般现在 | V / V-s | She **works** here. | 习惯、事实、状态、规律 |
| 一般过去 | V-ed / irregular past | She **worked** yesterday. | 过去具体时间发生 |
| 一般将来 | will + V | She **will work** tomorrow. | 预测、临时决定、承诺 |
| 现在进行 | am/is/are + V-ing | She **is working** now. | 现在正在进行；临时状态；已安排未来 |
| 过去进行 | was/were + V-ing | She **was working** at 8. | 过去某时正在进行；背景动作 |
| 将来进行 | will be + V-ing | She **will be working** at 8. | 未来某时正在进行；礼貌询问安排 |
| 现在完成 | have/has + V-ed/V-en | She **has worked** here for years. | 经验、结果、持续到现在 |
| 过去完成 | had + V-ed/V-en | She **had left** before I arrived. | 过去的过去 |
| 将来完成 | will have + V-ed/V-en | She **will have finished** by Friday. | 未来某时之前完成 |
| 现在完成进行 | have/has been + V-ing | She **has been working** for hours. | 持续到现在，强调过程 |
| 过去完成进行 | had been + V-ing | She **had been working** for hours. | 过去某时之前一直持续 |
| 将来完成进行 | will have been + V-ing | She **will have been working** for ten years. | 未来某时之前持续多久 |

### 5.8 一般现在与一般过去

| 时态 | 结构 | 典型时间词 | 例句 |
| ---- | ---- | ---------- | ---- |
| 一般现在 | V / V-s | usually, often, every day, always | He **takes** the train every day. |
| 一般过去 | V-ed / irregular past | yesterday, last year, in 2020, ago | He **took** the train yesterday. |

**一般现在常见用法**：

| 用法 | 例句 | 说明 |
| ---- | ---- | ---- |
| 习惯 | She **runs** every morning. | 反复发生 |
| 事实/规律 | Water **boils** at 100°C. | 普遍真理 |
| 状态 | He **knows** the answer. | 状态动词常用简单体 |
| 时间表 | The train **leaves** at 7. | 固定安排 |
| 评论/叙事 | The author **argues** that... | 学术、评论中常用 |

**一般过去常见用法**：

| 用法 | 例句 | 说明 |
| ---- | ---- | ---- |
| 过去事件 | I **met** her yesterday. | 时间已结束 |
| 过去习惯 | We **lived** in Osaka. | 过去曾经如此 |
| 礼貌/距离 | I **wanted** to ask a question. | 过去式可降低直接性 |
| 虚拟距离 | If I **were** you... | 不是真正过去，而是非现实 |

### 5.9 进行体 Progressive Aspect

进行体的核心是“某时间点正在展开”，常带临时性、未完成或背景感。

| 时态 | 结构 | 例句 | 用法 |
| ---- | ---- | ---- | ---- |
| 现在进行 | am/is/are + V-ing | I **am writing** now. | 现在正在进行 |
| 过去进行 | was/were + V-ing | I **was writing** when he called. | 过去背景动作 |
| 将来进行 | will be + V-ing | I **will be writing** at 9. | 未来某时正在进行 |

| 对比 | 例句 | 差别 |
| ---- | ---- | ---- |
| 一般现在 vs 现在进行 | I work from home. / I am working from home this week. | 前者习惯，后者临时 |
| 一般过去 vs 过去进行 | I read at 8. / I was reading at 8. | 前者可指完成事件，后者强调当时正在读 |
| always + 进行体 | He is always complaining. | 表不满或强调反复 |

**状态动词通常不用进行体**：

| 类型 | 常见动词 | 自然表达 |
| ---- | -------- | -------- |
| 认知 | know, believe, understand, remember | I know the answer. |
| 情感 | like, love, hate, prefer | She likes tea. |
| 拥有 | have, own, belong | This belongs to me. |
| 感官状态 | seem, appear, sound | It seems wrong. |

有些状态动词转为动态意义时可用进行体：`I am thinking about it` 表“正在考虑”，不同于 `I think he is right`。

### 5.10 完成体 Perfect Aspect

完成体连接两个时间点：动作发生在参照时间之前，并与参照时间有结果、经验、持续或先后关系。

| 时态 | 结构 | 例句 | 核心 |
| ---- | ---- | ---- | ---- |
| 现在完成 | have/has + 过去分词 | I **have finished**. | 过去到现在 |
| 过去完成 | had + 过去分词 | I **had finished** before he arrived. | 过去的过去 |
| 将来完成 | will have + 过去分词 | I **will have finished** by Friday. | 未来某时之前 |

**现在完成的常见用法**：

| 用法 | 例句 | 常见时间词 |
| ---- | ---- | ---------- |
| 经验 | I **have visited** London. | ever, never, before |
| 结果 | She **has lost** her keys. | already, just, yet |
| 持续 | We **have lived** here for years. | for, since |
| 最近变化 | Prices **have risen**. | recently, lately |

**现在完成 vs 一般过去**：

| 表达 | 含义 |
| ---- | ---- |
| I **lost** my keys yesterday. | 过去具体时间发生 |
| I **have lost** my keys. | 现在结果是找不到钥匙 |
| She **went** to Paris in 2020. | 过去具体经历 |
| She **has been** to Paris. | 有过这个经验 |

### 5.11 完成进行体 Perfect Progressive

完成进行体强调“持续过程”和“时间长度”，常与 for/since/all day/recently 连用。

| 时态 | 结构 | 例句 | 重点 |
| ---- | ---- | ---- | ---- |
| 现在完成进行 | have/has been + V-ing | I **have been waiting** for an hour. | 到现在为止一直在等 |
| 过去完成进行 | had been + V-ing | I **had been waiting** for an hour when he arrived. | 到过去某时为止一直在等 |
| 将来完成进行 | will have been + V-ing | I **will have been working** here for ten years. | 到未来某时为止持续多久 |

| 对比 | 例句 | 差别 |
| ---- | ---- | ---- |
| 现在完成 | I have written the report. | 强调结果：报告写完 |
| 现在完成进行 | I have been writing the report. | 强调过程：一直在写，未必完成 |
| 完成进行 + 状态动词 | I have known her for years. | know 通常不用 have been knowing |

### 5.12 表达将来

英语没有单一“将来时”词尾，未来意义由多种结构表达。

| 结构 | 例句 | 常见含义 |
| ---- | ---- | -------- |
| will + 原形 | I **will call** you later. | 预测、承诺、临时决定 |
| be going to + 原形 | It **is going to rain**. | 计划、已有迹象 |
| 现在进行 | I **am meeting** her tonight. | 已安排的未来 |
| 一般现在 | The train **leaves** at 7. | 时间表、日程 |
| be about to + 原形 | The meeting **is about to start**. | 马上发生 |
| be to + 原形 | The president **is to visit** Japan. | 正式安排、命令 |

| 对比 | 例句 | 差别 |
| ---- | ---- | ---- |
| will vs going to | I think it **will rain**. / Look at the clouds. It **is going to rain**. | will 偏预测；going to 常有迹象或计划 |
| will vs present continuous | I **will meet** her someday. / I **am meeting** her tonight. | 后者是已安排 |
| be going to vs about to | We are going to leave soon. / We are about to leave. | about to 更接近“马上” |

### 5.13 从过去看未来：would / was going to

传统语法常称“过去将来时”。实际使用中，它表示站在过去某个时间点看后来的事情。

| 结构 | 例句 | 用法 |
| ---- | ---- | ---- |
| would + 原形 | He said he **would call**. | 间接引语、过去意图 |
| was/were going to + 原形 | I **was going to call**, but I forgot. | 过去计划，可能未实现 |
| was/were about to + 原形 | She **was about to leave** when the phone rang. | 过去某时正要发生 |
| would be + V-ing | He said he **would be working** at 8. | 从过去看未来某时正在进行 |
| would have + 过去分词 | He thought he **would have finished** by Friday. | 从过去看未来某时之前完成 |

### 5.14 被动语态 Passive Voice

被动语态把动作承受者放到主语位置，结构是 `be + 过去分词`。只有能带宾语的及物动词通常才能变被动。

| 主动 | 被动 | 说明 |
| ---- | ---- | ---- |
| Someone deleted the file. | The file **was deleted**. | 执行者未知或不重要 |
| The team built the bridge. | The bridge **was built by the team**. | 需要说明执行者时用 by |
| They will review the plan. | The plan **will be reviewed**. | 情态/将来 + be + 过去分词 |

| 时态/结构 | 被动结构 | 例句 |
| -------- | -------- | ---- |
| 一般现在 | am/is/are + 过去分词 | The room **is cleaned** daily. |
| 一般过去 | was/were + 过去分词 | The room **was cleaned** yesterday. |
| 一般将来 | will be + 过去分词 | The room **will be cleaned**. |
| 现在进行 | am/is/are being + 过去分词 | The room **is being cleaned**. |
| 过去进行 | was/were being + 过去分词 | The room **was being cleaned**. |
| 现在完成 | have/has been + 过去分词 | The room **has been cleaned**. |
| 过去完成 | had been + 过去分词 | The room **had been cleaned**. |
| 情态动词 | modal + be + 过去分词 | The room **must be cleaned**. |
| 完成情态 | modal + have been + 过去分词 | The room **should have been cleaned**. |

**被动语态适用场景**：

| 场景 | 例句 |
| ---- | ---- |
| 执行者未知 | My bike **was stolen**. |
| 执行者不重要 | The road **was repaired** last year. |
| 强调承受者 | The proposal **was rejected**. |
| 学术/流程写作 | The samples **were tested** at room temperature. |

**不能或不宜被动的情况**：

| 动词/结构 | 例句 | 说明 |
| -------- | ---- | ---- |
| 不及物动词 | He **arrived** late. | arrive 无宾语，不能说 was arrived |
| 系动词 | She **became** tired. | tired 是补语，不是宾语 |
| 状态拥有 | The bag **contains** books. | contains 可被动但通常主动更自然 |
| 动词短语 | The child **was looked after**. | 有些短语动词可整体被动 |

### 5.15 情态动词 Modal Verbs

情态动词后接动词原形，没有第三人称 -s，本身通常不接 to。

| 情态 | 核心意义 | 例句 |
| ---- | -------- | ---- |
| can | 能力、许可、可能 | She **can swim**. |
| could | 过去能力、礼貌请求、较弱可能 | **Could** you help? |
| may | 许可、可能 | You **may leave**. |
| might | 较弱可能 | It **might rain**. |
| must | 必须、强推测 | You **must stop**. / He **must be** tired. |
| should | 建议、应当、预期 | You **should rest**. |
| shall | 正式提议、法律文本、英式第一人称将来 | **Shall** we begin? |
| will | 将来、意愿、习惯性倾向 | I **will call**. |
| would | 礼貌、过去习惯、假设结果 | I **would agree**. |

| 结构 | 例句 | 含义 |
| ---- | ---- | ---- |
| modal + 原形 | He **must leave**. | 现在/将来义务或判断 |
| modal + be + -ing | He **must be working**. | 对正在进行的推测 |
| modal + have + 过去分词 | He **must have left**. | 对过去的推测 |
| modal + have been + -ing | He **must have been working**. | 对过去持续动作的推测 |
| modal + be + 过去分词 | It **must be repaired**. | 情态被动 |

**易混情态**：

| 对比 | 例句 | 差别 |
| ---- | ---- | ---- |
| must vs have to | I must go. / I have to go. | must 偏说话人判断；have to 偏外部要求 |
| must not vs do not have to | You must not leave. / You don't have to leave. | 前者禁止，后者不必 |
| should vs had better | You should see a doctor. / You had better see a doctor. | had better 更强，常暗含后果 |
| can vs be able to | I can swim. / I was able to escape. | be able to 可用于更多时态，强调成功做到 |

### 5.16 语气 Mood

语气表示说话人如何看待句子内容：事实、命令、假设、愿望、建议等。

| 语气 | 英文 | 结构 | 例句 |
| ---- | ---- | ---- | ---- |
| 陈述语气 | Indicative | 普通时态结构 | She **is** ready. |
| 祈使语气 | Imperative | 动词原形；主语 you 省略 | **Close** the door. |
| 虚拟语气 | Subjunctive | 原形、were、had done、would do 等 | If I **were** you, I **would leave**. |

#### 祈使语气

| 功能 | 例句 | 说明 |
| ---- | ---- | ---- |
| 命令 | Stop. | 直接 |
| 请求 | Please wait. | 加 please 更礼貌 |
| 禁止 | Don't move. | Don't + 原形 |
| 建议 | Let's leave. / Let's not argue. | 包含说话人 |
| 强调 | Do be careful. | do + 原形加强语气 |

#### 虚拟语气与非现实条件

| 类型 | if 从句 | 主句 | 例句 |
| ---- | ------ | ---- | ---- |
| 真实条件 | present | will/can/may + 原形 | If it rains, we will cancel. |
| 现在非现实 | past / were | would/could/might + 原形 | If I were you, I would wait. |
| 过去非现实 | had + 过去分词 | would/could/might have + 过去分词 | If I had known, I would have helped. |
| 未来低可能性 | should / were to + 原形 | would/could/might + 原形 | If he should call, tell me. |
| 混合条件 | past perfect + now result | would + 原形 | If I had studied medicine, I would be a doctor now. |

**wish / if only**：

| 时间指向 | 结构 | 例句 |
| -------- | ---- | ---- |
| 现在遗憾 | wish + past / were | I wish I **were** taller. |
| 过去遗憾 | wish + had + 过去分词 | I wish I **had studied** harder. |
| 对未来不满或愿望 | wish + would + 原形 | I wish it **would stop** raining. |

**建议、要求、命令后的原形虚拟**：

| 触发词 | 结构 | 例句 |
| ------ | ---- | ---- |
| suggest, recommend | that + 主语 + 原形 | I suggest that he **go** now. |
| demand, insist, require | that + 主语 + 原形 | They demanded that she **be** present. |
| important, necessary, essential | that + 主语 + 原形 | It is essential that he **be** informed. |

### 5.17 非谓语动词 Non-finite Verbs

非谓语动词不独立体现人称和时态，常作主语、宾语、补语、定语、状语。

| 形式 | 结构 | 例句 | 常见功能 |
| ---- | ---- | ---- | -------- |
| 不定式 | to + 原形 | **To learn** takes time. | 目的、计划、未来、结果 |
| 裸不定式 | 原形 | Let him **go**. | 情态后、使役/感官动词后 |
| 动名词 | V-ing | **Swimming** is relaxing. | 名词功能 |
| 现在分词 | V-ing | the girl **reading** there | 主动、进行 |
| 过去分词 | V-ed/V-en | the file **deleted** yesterday | 被动、完成 |

**动名词 vs 不定式**：

| 对比 | 动名词 | 不定式 |
| ---- | ------ | ------ |
| 侧重点 | 活动本身、习惯、已发生或一般行为 | 目的、计划、未来、具体一次 |
| 作主语 | **Learning** grammar helps. | **To learn** grammar quickly is hard. |
| 作宾语 | enjoy **reading**, avoid **waiting** | want **to leave**, decide **to wait** |
| like/love/prefer | I like **swimming**. | I like **to swim** in the morning. |

**只能或常接动名词的动词**：

| 动词 | 例句 |
| ---- | ---- |
| enjoy | She enjoys **reading**. |
| avoid | Avoid **making** the same mistake. |
| finish | He finished **writing**. |
| mind | Do you mind **waiting**? |
| consider | We considered **moving**. |
| suggest | She suggested **leaving** early. |

**只能或常接不定式的动词**：

| 动词 | 例句 |
| ---- | ---- |
| want | I want **to leave**. |
| decide | She decided **to stay**. |
| hope | We hope **to win**. |
| plan | They plan **to expand**. |
| promise | He promised **to call**. |
| refuse | She refused **to answer**. |

### 5.18 分词作形容词和分词结构

| 对比 | -ing 现在分词 | -ed 过去分词 |
| ---- | ------------- | ------------ |
| 核心意义 | 令人产生某种感受；主动；进行 | 感到某种状态；被动；完成 |
| 情绪类 | an **interesting** book | an **interested** student |
| 动作类 | the man **standing** there | the window **broken** yesterday |
| 状态类 | boiling water | boiled water |

| 分词结构 | 例句 | 说明 |
| -------- | ---- | ---- |
| 现在分词定语 | people **living nearby** | 主动或正在进行 |
| 过去分词定语 | a report **written in 2020** | 被动或完成 |
| 现在分词状语 | **Walking home**, I saw her. | 主语与分词动作执行者一致 |
| 过去分词状语 | **Surprised by the news**, he left. | 主语承受动作或处于状态 |

**悬垂分词错误**：

| 错误 | 推荐 | 原因 |
| ---- | ---- | ---- |
| Walking down the street, the house looked old. | Walking down the street, I saw an old house. | walking 的执行者应是句子主语 |
| Written in haste, I found the report unclear. | I found the report, written in haste, unclear. | written 修饰 report，不修饰 I |

### 5.19 常见错误速查

| 错误类型 | 不自然/错误 | 推荐表达 | 原因 |
| -------- | ----------- | -------- | ---- |
| 三单漏 -s | He work here. | He works here. | 一般现在第三人称单数加 -s |
| 助动词后动词未还原 | Did he went? | Did he go? | did 后用原形 |
| 情态后加 to | must to go | must go | 情态动词后接原形 |
| be 后误接原形 | She is work now. | She is working now. | 进行体是 be + -ing |
| 完成体误用过去式 | I have went. | I have gone. | have 后接过去分词 |
| 过去时间误用现在完成 | I have seen him yesterday. | I saw him yesterday. | 具体过去时间通常用一般过去 |
| for/since 混用 | since three years | for three years / since 2021 | for + 时间段；since + 起点 |
| 状态动词误用进行体 | I am knowing him. | I know him. | know 通常不用进行体 |
| 被动缺 be | The file deleted yesterday. | The file was deleted yesterday. | 被动需要 be + 过去分词 |
| 不及物动词被动 | The car was arrived. | The car arrived. | arrive 无直接宾语 |
| 虚拟条件主句错误 | If I knew, I will tell you. | If I knew, I would tell you. | 非现实条件主句用 would/could/might |
| wish 后时态过直 | I wish I am taller. | I wish I were taller. | wish 表现在遗憾用过去式/were |
| 动名词/不定式搭配错 | enjoy to read | enjoy reading | enjoy 后常接动名词 |
| 悬垂分词 | Driving to work, the accident happened. | While I was driving to work, the accident happened. | 分词逻辑主语不清 |

## 6. 形容词（Adjectives）

形容词用来描述名词或代词的性质、状态、类别、数量评价或身份特征。它最常见的两个位置是：名词前作定语，系动词后作补语。

| 位置 | 结构 | 例句 | 功能 |
| ---- | ---- | ---- | ---- |
| 名词前 | adjective + noun | a **clear** answer | 定语，修饰名词 |
| 系动词后 | linking verb + adjective | The answer is **clear**. | 主语补语，说明主语 |
| 宾语后 | verb + object + adjective | We found the answer **clear**. | 宾语补语，说明宾语 |
| 不定代词后 | something/anything + adjective | something **important** | 后置定语 |
| 名词后 | noun + adjective phrase | the people **responsible for the error** | 后置修饰 |

### 6.1 形容词总览

| 类型 | 说明 | 例子 |
| ---- | ---- | ---- |
| 性质形容词 | 描述性质、状态、评价 | good, clear, useful, difficult |
| 类别形容词 | 表示种类、领域、来源，通常不比较 | medical, financial, legal, wooden |
| 数量/程度形容词 | 表示数量、范围或程度 | many, few, several, enough |
| 关系形容词 | 与某领域或对象有关 | political, cultural, economic |
| 分词形容词 | 由 -ing / -ed 分词发展而来 | interesting, interested, broken |
| 复合形容词 | 多词组合成一个前置修饰语 | well-known, five-year, high-quality |

**形容词和限定词不同**：限定词决定“哪一个、多少、谁的”，形容词描述“什么样”。  
`my three old books` 中，`my/three` 是限定成分，`old` 是形容词。

### 6.2 形容词在句中的功能

| 功能 | 例句 | 说明 |
| ---- | ---- | ---- |
| 前置定语 | a **serious** problem | 直接修饰名词 |
| 后置定语 | the people **present** | 某些形容词常后置 |
| 主语补语 | The problem is **serious**. | 系动词后说明主语 |
| 宾语补语 | This made the problem **worse**. | 说明宾语状态或结果 |
| 形容词短语核心 | very **difficult to solve** | 形容词可带程度副词、介词短语、不定式 |
| the + 形容词 | **The rich** are not always happy. | 表示一类人 |
| 状态伴随 | He came home **tired**. | 描述主语当时状态，不能随意替代副词 |

| 系动词类型 | 常见词 | 例句 |
| ---------- | ------ | ---- |
| 存在/状态 | be, remain, stay, keep | Please **stay calm**. |
| 感官 | look, sound, smell, taste, feel | That **sounds strange**. |
| 变化 | become, get, grow, turn, go | It **became clear**. |
| 判断/结果 | seem, appear, prove | The method **proved effective**. |

### 6.3 形容词的位置：前置与后置

大多数形容词放在名词前，但有些结构要求或倾向后置。

| 位置 | 例句 | 说明 |
| ---- | ---- | ---- |
| 名词前 | a **useful** tool | 最常见 |
| 不定代词后 | something **useful** / anyone **available** | -thing/-one/-body 后置 |
| 固定后置 | the president **elect**, the attorney **general** | 部分职位/称谓固定后置 |
| 形容词短语后置 | a problem **difficult to solve** | 形容词带长补足语时常后置 |
| 现在/过去分词短语后置 | people **living nearby**, files **deleted yesterday** | 分词短语通常后置 |
| alive/alone/asleep 等 | the only person **alive** | 某些 a- 开头形容词多作表语或后置 |

| 前置/后置差异 | 例句 | 含义 |
| ------------- | ---- | ---- |
| present | the **present** members / the members **present** | 现任成员 / 在场成员 |
| responsible | a **responsible** person / the person **responsible** | 负责任的人 / 负有责任的人 |
| concerned | a **concerned** parent / the people **concerned** | 担心的父母 / 相关人员 |
| involved | an **involved** explanation / the people **involved** | 复杂的解释 / 涉及的人 |

### 6.4 形容词补足结构

形容词常带介词短语、不定式或 that 从句作为补足语。

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| adjective + preposition | afraid **of** spiders | 介词由形容词搭配决定 |
| adjective + to do | easy **to understand** | 不定式补足形容词 |
| adjective + for sb. + to do | difficult **for me to explain** | 指出动作执行者 |
| adjective + of sb. + to do | kind **of you to help** | 评价人的品质 |
| adjective + that-clause | sure **that he is right** | 从句补足内容 |
| adjective + enough + to do | old **enough to vote** | 足够……可以…… |
| too + adjective + to do | too tired **to continue** | 太……以至于不能…… |

| for sb. / of sb. | 例句 | 差别 |
| ---------------- | ---- | ---- |
| for sb. to do | It is hard **for him** to admit it. | 强调事情对某人难 |
| of sb. to do | It was honest **of him** to admit it. | 评价某人的品质 |

### 6.5 形容词的比较等级

形容词有原级、比较级、最高级。比较级通常用于两者比较，最高级用于三者以上或某一范围内“最……”。

| 等级 | 结构 | 例句 |
| ---- | ---- | ---- |
| 原级 | as + adjective + as | She is **as tall as** her brother. |
| 比较级 | adjective-er / more adjective + than | This plan is **cheaper than** that one. |
| 最高级 | the adjective-est / the most adjective | This is **the cheapest** option. |

**规则变化**：

| 形容词类型 | 比较级 | 最高级 | 例子 |
| ---------- | ------ | ------ | ---- |
| 单音节 | -er | -est | tall -> taller -> tallest |
| 以 e 结尾 | -r | -st | large -> larger -> largest |
| 辅音 + y | y 变 i + -er/-est | y 变 i + -er/-est | easy -> easier -> easiest |
| 重读闭音节 | 双写尾辅音 + -er/-est | 双写尾辅音 + -er/-est | big -> bigger -> biggest |
| 多音节 | more | most | useful -> more useful -> most useful |
| 部分双音节 | -er/-est 或 more/most | -er/-est 或 more/most | cleverer / more clever |

**不规则变化**：

| 原级 | 比较级 | 最高级 | 说明 |
| ---- | ------ | ------ | ---- |
| good / well | better | best | well 作“健康的”时是形容词 |
| bad / ill | worse | worst | ill 在英式英语中常见 |
| far | farther / further | farthest / furthest | farther 偏实际距离，further 也表进一步 |
| little | less | least | 数量少 |
| many / much | more | most | 可数/不可数都可 |
| old | older / elder | oldest / eldest | elder/eldest 多用于家庭长幼 |
| late | later / latter | latest / last | later 时间更晚；latter 后者；latest 最新；last 最后 |

### 6.6 比较结构速查

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| 比较级 + than | This is **better than** that. | 标准比较 |
| much/far/a lot + 比较级 | much **better** | 加强比较 |
| a little/slightly + 比较级 | slightly **cheaper** | 弱化比较 |
| less + adjective + than | less expensive than expected | 较不…… |
| as + adjective + as | as clear as possible | 同等比较 |
| not as/so + adjective + as | not as easy as it looks | 不如…… |
| the + 比较级, the + 比较级 | The sooner, the better. | 越……越…… |
| 比较级 and 比较级 | colder and colder | 越来越…… |
| one of the + 最高级 + 复数名词 | one of the best options | “最……之一”后接复数名词 |

| 易错 | 推荐 | 原因 |
| ---- | ---- | ---- |
| more better | much better / better | better 已经是比较级 |
| the most easiest | the easiest | 不双重最高级 |
| than me / than I | She is taller than me. / than I am. | 口语常用 me；正式可补完整从句 |
| one of the best option | one of the best options | one of 后接复数范围 |

### 6.7 绝对形容词与不可比较形容词

有些形容词表示绝对状态或类别，通常不适合普通比较级；若要表达程度，应换表达方式。

| 类型 | 例子 | 更自然的表达 |
| ---- | ---- | ------------ |
| 绝对状态 | dead, impossible, perfect, unique | almost impossible, nearly perfect, truly unique |
| 几何/分类 | square, circular, wooden, medical | more nearly square, more medical in nature |
| 极限意义 | empty, full, complete | completely full, almost empty |

实际英语中也可见 `more perfect`, `very unique` 这类强调用法，但正式写作中要谨慎。

### 6.8 多个形容词的顺序

多个形容词同时修饰名词时，顺序通常按“主观评价 -> 客观属性 -> 类别用途”排列。

| 顺序 | 类别 | 例子 |
| ---- | ---- | ---- |
| 1 | 限定词 | a, the, my, these |
| 2 | 数量 | two, several, many |
| 3 | 评价/观点 | beautiful, useful, strange |
| 4 | 大小 | big, small, tiny |
| 5 | 年龄 | old, new, young |
| 6 | 形状 | round, square, flat |
| 7 | 颜色 | red, blue, black |
| 8 | 来源/国籍 | Japanese, French, local |
| 9 | 材质 | wooden, cotton, plastic |
| 10 | 用途/类别 | sleeping, running, kitchen |
| 11 | 中心名词 | bag, table, shoes |

| 自然 | 不自然 |
| ---- | ------ |
| a beautiful old wooden table | a wooden old beautiful table |
| two small round black stones | two black round small stones |
| a useful Japanese grammar book | a Japanese useful grammar book |
| an expensive leather laptop bag | a leather expensive laptop bag |

**逗号规则**：

| 类型 | 例句 | 说明 |
| ---- | ---- | ---- |
| 同类并列形容词 | a long, difficult, exhausting process | 可用 and 连接：long and difficult |
| 不同类别形容词 | a beautiful old wooden table | 通常不用逗号 |

### 6.9 -ing 与 -ed 形容词

许多情绪和感受类形容词有 -ing / -ed 对立。

| -ing 形容词 | -ed 形容词 | 例句 |
| ----------- | ---------- | ---- |
| interesting | interested | The book is **interesting**. / I am **interested** in it. |
| boring | bored | The lecture was **boring**. / The students were **bored**. |
| exciting | excited | The news is **exciting**. / We are **excited**. |
| confusing | confused | The rule is **confusing**. / I am **confused**. |
| surprising | surprised | The result was **surprising**. / She was **surprised**. |
| tiring | tired | The trip was **tiring**. / We were **tired**. |

**判断方法**：

| 问题 | 选择 |
| ---- | ---- |
| 这个人/物让别人产生感觉吗？ | 用 -ing：an interesting story |
| 这个人自己感到某种情绪吗？ | 用 -ed：an interested reader |
| 表被动或完成结果吗？ | 多用过去分词：a broken window, a written agreement |

### 6.10 复合形容词 Compound Adjectives

复合形容词由多个词组成，放在名词前时常用连字符，避免误读。

| 结构 | 例子 | 说明 |
| ---- | ---- | ---- |
| 数字 + 单数名词 | a **five-year** plan | year 用单数 |
| 副词 + 分词 | a **well-known** author | well-known 常用连字符 |
| 形容词 + 名词-ed | a **blue-eyed** child | 表“有……的” |
| 名词 + 分词 | a **time-saving** tool | 节省时间的 |
| 形容词 + 名词 | a **high-quality** product | 高质量的 |
| open/closed class | an **open-minded** person | 固定复合 |

| 前置 | 后置 |
| ---- | ---- |
| a **five-year-old** child | The child is **five years old**. |
| a **well-known** writer | The writer is **well known**. |
| a **high-quality** product | The product is **high quality**. |

### 6.11 形容词作名词

| 结构 | 含义 | 例句 | 语法 |
| ---- | ---- | ---- | ---- |
| the + 形容词 | 某一类人 | **The rich** should help **the poor**. | 通常复数意义 |
| the + 形容词 | 抽象领域 | the unknown, the impossible | 多为抽象概念 |
| 颜色/语言/国籍等 | blue, English, French | I like **blue**. / She speaks **English**. | 依具体词类判断 |
| 形容词 + one/ones | 代替名词 | the red **one**, the old **ones** | 更常用、更清楚 |

**注意**：`the rich` 表示“富人这一类”，谓语通常用复数：`The rich are...`。若指单个富人，用 `a rich person`。

### 6.12 of + 名词作形容词性表达

`of + 名词` 可以像形容词一样描述性质、价值、重要性、年龄、尺寸、来源或组成，常见于较正式表达。

| 结构 | 例句 | 近似形容词表达 |
| ---- | ---- | -------------- |
| of importance | This issue is **of great importance**. | very important |
| of value | The data is **of value**. | valuable |
| of interest | a topic **of interest** | interesting / relevant |
| of use | This tool is **of no use**. | useless |
| of benefit | The policy is **of benefit** to workers. | beneficial |
| of age/size/color | children **of the same age** | same-aged children 不自然 |
| of courage/intelligence | a person **of courage** | a courageous person |

| 用法 | 例子 | 说明 |
| ---- | ---- | ---- |
| 性质 | a matter of importance | 抽象性质 |
| 部分整体 | the roof of the house | 所属/部分 |
| 内容/度量 | a cup of coffee | 量词结构 |
| 类别 | a type of music | 种类范围 |

### 6.13 形容词 + 介词搭配

| 形容词 | 常用介词 | 例句 |
| ------ | -------- | ---- |
| afraid | of | afraid **of** spiders |
| angry | with / about | angry **with** him / angry **about** the delay |
| anxious | about | anxious **about** the exam |
| aware | of | aware **of** the risk |
| capable | of | capable **of** handling it |
| different | from / to / than | different **from** mine |
| familiar | with / to | familiar **with** the topic / familiar **to** me |
| famous | for | famous **for** its food |
| good / bad | at | good **at** math |
| interested | in | interested **in** politics |
| married | to | married **to** a doctor |
| proud | of | proud **of** her work |
| responsible | for | responsible **for** the error |
| similar | to | similar **to** this one |
| suitable | for | suitable **for** children |
| tired | of / from | tired **of** waiting / tired **from** work |
| worried | about | worried **about** money |

### 6.14 形容词 + that / to do / preposition 常见句型

| 结构 | 常见形容词 | 例句 |
| ---- | ---------- | ---- |
| be sure/certain + that | sure, certain, confident | I am **sure that** he is right. |
| be glad/sorry + that | glad, sorry, happy | She was **glad that** he came. |
| be ready/willing/able + to do | ready, willing, able | We are **ready to start**. |
| be likely/unlikely + to do | likely, unlikely | It is **likely to rain**. |
| be easy/difficult + to do | easy, difficult, hard | This rule is **hard to explain**. |
| be good/bad + for | good, bad, useful | Exercise is **good for** you. |
| be good/bad + at | good, bad, terrible | She is **good at** writing. |

### 6.15 常见错误速查

| 错误类型 | 不自然/错误 | 推荐表达 | 原因 |
| -------- | ----------- | -------- | ---- |
| 形容词/副词混用 | She speaks English **good**. | She speaks English **well**. | 修饰动词 speak 用副词 |
| 系动词后误用副词 | The soup tastes **well**. | The soup tastes **good**. | taste 作系动词后接形容词 |
| 双重比较级 | more better | much better / better | better 已是比较级 |
| 双重最高级 | the most easiest | the easiest | easiest 已是最高级 |
| 比较对象不平行 | My car is faster than John. | My car is faster than John's. | 车和车比较 |
| one of 后名词单数 | one of the best student | one of the best students | one of 后接复数范围 |
| -ing/-ed 混用 | I am boring. | I am bored. | 人感到无聊用 bored |
| 复合形容词复数化 | a five-years plan | a five-year plan | 前置复合形容词中名词用单数 |
| 形容词顺序不自然 | a wooden old table | an old wooden table | 年龄通常在材质前 |
| responsible 位置误解 | a responsible person 和 the person responsible 混用 | a responsible person / the person responsible | 区分“负责任的”与“负有责任的” |
| afraid 后搭配错 | afraid from spiders | afraid of spiders | afraid 常接 of |
| worth 用法错 | It is worth to read. | It is worth reading. | worth 后常接动名词 |

## 7. 副词与状语（Adverbs and Adverbials）

副词是词类，状语是句子功能。一个副词可以作状语，但状语不一定是副词，也可以是介词短语、不定式、分词短语或从句。

| 表达 | 词类/结构 | 句中功能 | 例句 |
| ---- | --------- | -------- | ---- |
| quickly | 副词 | 方式状语 | She answered **quickly**. |
| in the morning | 介词短语 | 时间状语 | She left **in the morning**. |
| to save time | 不定式短语 | 目的状语 | She called **to save time**. |
| because she was tired | 从句 | 原因状语 | She left **because she was tired**. |
| fortunately | 副词 | 句子状语 | **Fortunately**, nobody was hurt. |

本章重点是：副词修饰什么、放在哪里、表达什么语义，以及如何避免形容词/副词混用和状语位置歧义。

### 7.1 副词与状语总览

| 概念 | 英文 | 含义 | 例子 |
| ---- | ---- | ---- | ---- |
| 副词 | Adverb | 词类，常修饰动词、形容词、副词、整句 | quickly, very, often, here |
| 副词短语 | Adverb Phrase | 以副词为核心的短语 | very quickly, almost never |
| 状语 | Adverbial | 句子功能，说明时间、地点、方式、原因、条件等 | yesterday, in Tokyo, if possible |
| 句子副词 | Sentence Adverb / Disjunct | 表示说话者态度、评价或信息组织 | honestly, fortunately, however |
| 连接副词 | Conjunctive Adverb | 连接两个句子或语篇关系 | however, therefore, meanwhile |

| 副词修饰对象 | 例句 | 说明 |
| ------------ | ---- | ---- |
| 动词 | She speaks **clearly**. | clearly 修饰 speaks |
| 形容词 | The answer is **very** clear. | very 修饰 clear |
| 副词 | She speaks **extremely** clearly. | extremely 修饰 clearly |
| 介词短语 | It is **right** under the desk. | right 修饰 under the desk |
| 限定词/数量 | **Almost** all students passed. | almost 修饰 all |
| 整个句子 | **Probably**, he forgot. | probably 修饰整个判断 |

### 7.2 副词的主要类型

| 类型 | 回答问题 | 常见副词 | 例句 |
| ---- | -------- | -------- | ---- |
| 方式副词 | how? 怎样 | carefully, quickly, well, badly | She drove **carefully**. |
| 时间副词 | when? 何时 | now, then, today, yesterday, soon | I will call **soon**. |
| 地点/方向副词 | where? 到哪 | here, there, outside, upstairs, away | Come **here**. |
| 频率副词 | how often? 多频繁 | always, often, usually, sometimes, rarely, never | He **often** travels. |
| 程度副词 | how much? 到什么程度 | very, too, quite, rather, almost, completely | It is **almost** ready. |
| 焦点副词 | 强调哪一部分 | only, even, just, also, too, especially | **Only** Anna agreed. |
| 评价副词 | 说话者态度 | fortunately, clearly, surprisingly, frankly | **Surprisingly**, it worked. |
| 连接副词 | 逻辑关系 | however, therefore, moreover, meanwhile | It was late; **therefore**, we left. |
| 疑问副词 | 提问时间、地点、原因、方式 | when, where, why, how | **Why** did he leave? |
| 关系副词 | 引导定语从句 | where, when, why | the place **where** we met |

### 7.3 副词的位置总规则

副词位置取决于它修饰什么。位置变化常会改变焦点或语气。

| 位置 | 常见副词类型 | 例句 | 说明 |
| ---- | ------------ | ---- | ---- |
| 句首 | 时间、连接、评价副词 | **Yesterday**, I met her. / **However**, I stayed. | 组织信息或修饰整句 |
| 主语和实义动词之间 | 频率、焦点副词 | She **often** travels. | 中位位置 |
| 助动词/情态动词后 | 频率、程度、否定 | She has **never** been late. / You should **always** check. | 助动词后 |
| be 动词后 | 频率、程度 | He is **always** polite. | be 后 |
| 动词后 | 方式、地点、方向 | She spoke **clearly**. / He went **outside**. | 常见于方式/地点 |
| 宾语后 | 方式副词 | She explained the rule **clearly**. | 及物动词有宾语时，副词通常放宾语后 |
| 被修饰词前 | 程度副词 | **very** useful, **almost** ready | 修饰形容词/副词/限定词 |
| 句尾 | 时间、地点、方式 | We met **there yesterday**. | 补充背景信息 |

| 不自然/错误 | 推荐 | 原因 |
| ----------- | ---- | ---- |
| She speaks fluently English. | She speaks English fluently. | 宾语 English 通常紧跟动词 |
| He always is late. | He is always late. | 频率副词在 be 后 |
| I have seen never this. | I have never seen this. | never 在助动词 have 后 |
| I only told Anna yesterday. | Only I told Anna yesterday. / I told only Anna yesterday. | only 位置决定焦点 |

### 7.4 方式副词 Adverbs of Manner

方式副词说明动作如何发生，常由 `形容词 + -ly` 构成。

| 形容词 | 副词 | 例句 |
| ------ | ---- | ---- |
| careful | carefully | She checked the file **carefully**. |
| quick | quickly | He replied **quickly**. |
| fluent | fluently | She speaks English **fluently**. |
| quiet | quietly | Please speak **quietly**. |
| good | well | She writes **well**. |
| bad | badly | The system performed **badly**. |

**位置规则**：

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| 不及物动词后 | He ran **quickly**. | 动词后 |
| 宾语后 | She solved the problem **quickly**. | 不插在动词和宾语之间 |
| 句首强调方式 | **Carefully**, she opened the box. | 强调方式，较书面 |
| 被动句 | The file was **carefully** reviewed. | 常放过去分词前 |

### 7.5 时间、地点、频率副词

| 类型 | 常见词 | 例句 | 位置 |
| ---- | ------ | ---- | ---- |
| 时间点 | now, then, today, yesterday, tomorrow | I called her **yesterday**. | 句首或句尾 |
| 时间顺序 | first, then, next, finally, afterwards | **Then** we left. | 句首常见 |
| 持续/期限 | still, yet, already, recently, lately | She has **already** left. | 位置依副词 |
| 地点 | here, there, nearby, outside, upstairs | She lives **nearby**. | 动词后或句尾 |
| 方向 | away, back, out, up, down | He walked **away**. | 动词后 |
| 确定频率 | daily, weekly, monthly, yearly | We meet **weekly**. | 句尾或句中 |
| 不确定频率 | always, usually, often, sometimes, rarely, never | She **often** works late. | 中位位置 |

**already / yet / still**：

| 副词 | 常见句型 | 例句 |
| ---- | -------- | ---- |
| already | 肯定句；表示“已经” | She has **already** left. |
| yet | 否定句/疑问句；表示“还、已经” | She hasn't left **yet**. / Has she left **yet**? |
| still | 表示状态持续 | She is **still** here. |

### 7.6 程度副词 Degree Adverbs

程度副词修饰形容词、副词、动词或整个数量范围。

| 强度 | 常见副词 | 例句 |
| ---- | -------- | ---- |
| 极强 | absolutely, completely, totally, entirely | completely wrong |
| 很强 | very, extremely, highly, deeply | very useful, highly likely |
| 中等 | quite, rather, fairly, pretty | quite good, fairly easy |
| 接近 | almost, nearly, virtually, practically | almost ready |
| 不足 | barely, hardly, scarcely | hardly visible |
| 过度 | too, excessively | too expensive |
| 足够 | enough | good enough, enough time |

**very / much / too / enough**：

| 副词 | 位置 | 例句 | 说明 |
| ---- | ---- | ---- | ---- |
| very | 形容词/副词前 | very good, very quickly | 不修饰比较级 |
| much | 比较级前；动词后 | much better, thank you very much | 比较级用 much/far/a lot |
| too | 形容词/副词前 | too late to change | 常含“过分” |
| enough | 形容词/副词后；名词前 | good enough / enough money | 位置不同 |

### 7.7 焦点副词：only, even, just, also, too

焦点副词的位置决定它强调哪一部分。

| 句子 | 含义 |
| ---- | ---- |
| **Only Anna** called Ben. | 只有 Anna 打给 Ben；别人没有 |
| Anna **only called** Ben. | Anna 只是打电话，没有做别的 |
| Anna called **only Ben**. | Anna 只打给 Ben，没有打给别人 |
| Anna called Ben **only yesterday**. | 只是昨天才打 |

| 副词 | 常见位置 | 例句 |
| ---- | -------- | ---- |
| also | 肯定句中位；句尾也可 | She **also** agreed. |
| too | 通常句尾 | She agreed **too**. |
| either | 否定句句尾 | She didn't agree **either**. |
| even | 被强调成分前 | **Even** John agreed. |
| just | 被强调成分前；也表“刚刚” | I **just** saw him. |
| only | 被强调成分前 | I **only** need one. |

### 7.8 句子副词与连接副词

句子副词修饰整个命题，连接副词说明句子之间的逻辑关系。连接副词不是并列连词，不能单独用逗号连接两个完整句。

| 类型 | 常见副词 | 例句 |
| ---- | -------- | ---- |
| 评价 | fortunately, unfortunately, surprisingly | **Fortunately**, nobody was hurt. |
| 确信程度 | probably, possibly, certainly, clearly | He **probably** forgot. |
| 说话态度 | honestly, frankly, personally | **Honestly**, I disagree. |
| 结果 | therefore, thus, consequently | It was late; **therefore**, we left. |
| 转折 | however, nevertheless, still | It was risky; **however**, it worked. |
| 补充 | moreover, furthermore, also | The plan is cheap; **moreover**, it is fast. |
| 对比 | meanwhile, otherwise, instead | Call now; **otherwise**, we may lose it. |

| 错误 | 正确 | 原因 |
| ---- | ---- | ---- |
| It was late, however we stayed. | It was late; however, we stayed. / It was late, but we stayed. | however 不是并列连词 |
| He was tired, therefore he left. | He was tired; therefore, he left. | therefore 连接独立句时常用分号/句号 |

### 7.9 状语的形式

状语不是副词专属功能。写长句时，很多状语由短语或从句承担。

| 状语形式 | 例句 | 语义 |
| -------- | ---- | ---- |
| 副词 | She left **early**. | 时间/方式 |
| 副词短语 | She left **very early**. | 时间 + 程度 |
| 介词短语 | She left **after lunch**. | 时间 |
| 名词短语 | She left **last week**. | 时间 |
| 不定式短语 | She left **to catch the train**. | 目的 |
| 分词短语 | **Feeling tired**, she left. | 原因/伴随 |
| 从句 | She left **because she was tired**. | 原因 |
| 独立结构 | **The meeting over**, she left. | 时间/背景 |

### 7.10 状语顺序

多个状语同时出现时，常见顺序是：方式 -> 地点 -> 时间；但信息焦点、长度和语篇需要会改变顺序。

| 顺序 | 例句 | 说明 |
| ---- | ---- | ---- |
| 方式 + 地点 + 时间 | She worked **quietly in the library yesterday**. | 中性顺序 |
| 地点 + 时间 | We met **in Tokyo last year**. | 常见 |
| 时间前置 | **Last year**, we met in Tokyo. | 强调时间或承接上下文 |
| 长状语后置 | She explained the issue clearly **after everyone had arrived**. | 长从句放后面更自然 |
| 短副词前移 | She often works from home. | 频率副词中位 |

**方式、地点、时间同时出现**：

| 自然 | 不自然 |
| ---- | ------ |
| He spoke clearly at the meeting yesterday. | He spoke yesterday clearly at the meeting. |
| She studied quietly in her room all night. | She studied all night quietly in her room. |

### 7.11 副词的比较级和最高级

| 副词类型 | 比较级 | 最高级 | 例子 |
| -------- | ------ | ------ | ---- |
| 与形容词同形的短副词 | -er | -est | fast -> faster -> fastest |
| -ly 副词 | more + adv | most + adv | carefully -> more carefully -> most carefully |
| 不规则 | 特殊变化 | 特殊变化 | well -> better -> best |

| 原级 | 比较级 | 最高级 |
| ---- | ------ | ------ |
| well | better | best |
| badly | worse | worst |
| little | less | least |
| much | more | most |
| far | farther / further | farthest / furthest |
| early | earlier | earliest |
| fast | faster | fastest |
| hard | harder | hardest |

### 7.12 形容词与副词区别

| 判断问题 | 用形容词 | 用副词 |
| -------- | -------- | ------ |
| 修饰名词？ | a **careful** driver | 不用副词 |
| 系动词后说明主语？ | She looks **tired**. | 不用 tiredly |
| 修饰动作？ | 不用形容词 | She drives **carefully**. |
| 修饰形容词/副词？ | 不用形容词 | **very** careful / **very** carefully |
| 修饰整句？ | 不用普通形容词 | **Honestly**, I disagree. |

| 对比 | 正确 | 说明 |
| ---- | ---- | ---- |
| good / well | She is **good**. / She writes **well**. | good 形容词；well 多作副词，也可表“健康的” |
| bad / badly | I feel **bad**. / I slept **badly**. | feel 作系动词后接形容词 |
| real / really | a **real** problem / **really** useful | really 修饰形容词 useful |
| slow / slowly | Drive **slowly**. / Go **slow**. | 正式写作多用 slowly；slow 作副词口语常见 |

### 7.13 形容词副词同形 Flat Adverbs

有些词形容词和副词同形，称 flat adverbs。部分在正式写作中受限制。

| 词 | 形容词例句 | 副词例句 | 注意 |
| ---- | ---------- | -------- | ---- |
| fast | a fast train | run fast | 标准 |
| hard | a hard problem | work hard | hardly 不是 hard 的普通副词 |
| late | the late train | arrive late | lately = 最近 |
| early | an early meeting | arrive early | 标准 |
| straight | a straight line | go straight | 标准 |
| right | the right answer | do it right | 口语常见 |
| wrong | the wrong answer | do it wrong | 口语常见；正式可用 wrongly |
| high | a high wall | fly high | highly 表抽象程度 |
| deep | deep water | dive deep | deeply 表感情/抽象 |
| clean | a clean cut | wipe it clean | 结果补语意味 |

### 7.14 -ly 形式含义不同

| 基本词 | -ly 形式 | 区别 |
| ------ | -------- | ---- |
| hard | hardly | hard = 努力地；hardly = 几乎不 |
| late | lately | late = 迟；lately = 最近 |
| high | highly | high = 高地；highly = 高度地、非常 |
| deep | deeply | deep = 到深处；deeply = 深深地、强烈地 |
| near | nearly | near = 近；nearly = 几乎 |
| close | closely | close = 接近；closely = 仔细地、密切地 |
| wide | widely | wide = 张得很大；widely = 广泛地 |
| free | freely | free = 免费地；freely = 自由地、坦率地 |
| short | shortly | short = 突然/短地；shortly = 不久 |
| direct | directly | direct = 直达；directly = 直接地/马上 |

| 例句 | 含义 |
| ---- | ---- |
| She works **hard**. | 她努力工作 |
| She **hardly** works. | 她几乎不工作 |
| The bird flew **high**. | 飞得高 |
| The plan is **highly** risky. | 风险很高 |
| Stay **close**. | 靠近 |
| Watch **closely**. | 仔细看 |

### 7.15 常见错误速查

| 错误类型 | 不自然/错误 | 推荐表达 | 原因 |
| -------- | ----------- | -------- | ---- |
| 形容词修饰动词 | She sings beautiful. | She sings beautifully. | 修饰动作要用副词 |
| 系动词后误用副词 | The soup tastes well. | The soup tastes good. | taste 作系动词后接形容词 |
| good/well 混用 | He speaks English good. | He speaks English well. | speak 需要方式副词 |
| 副词插入动宾之间 | She explained clearly the rule. | She explained the rule clearly. | 宾语通常紧跟动词 |
| 频率副词位置错 | He always is late. | He is always late. | be 后放频率副词 |
| never 位置错 | I have seen never it. | I have never seen it. | never 在助动词后 |
| only 位置歧义 | I only told Anna yesterday. | I told only Anna yesterday. / Only yesterday did I tell Anna. | only 应靠近被强调对象 |
| hardly 误作 hard | She hardly worked for the exam. | She worked hard for the exam. | hardly = 几乎不 |
| too/enough 位置错 | enough good | good enough | enough 修饰形容词时后置 |
| 连接副词逗号拼接 | It was late, however we stayed. | It was late; however, we stayed. | however 不能只用逗号连接独立句 |
| 双重比较 | more faster | faster / much faster | faster 已是比较级 |
| 状语顺序不自然 | He spoke yesterday clearly. | He spoke clearly yesterday. | 方式通常在时间前 |

## 8. 介词与介词短语（Prepositions and Prepositional Phrases）

介词表示名词性成分和句中其他成分之间的关系。介词本身通常不单独完成意义，后面要接宾语，构成介词短语。

| 结构 | 例子 | 说明 |
| ---- | ---- | ---- |
| preposition + noun phrase | **in the room** | 最常见 |
| preposition + pronoun | **for him** | 代词用宾格 |
| preposition + gerund | **after leaving** | 介词后动词用 -ing |
| preposition + wh-clause | **about what happened** | 从句作介词宾语 |
| complex preposition + noun phrase | **because of the rain** | 多词介词整体使用 |

介词学习的重点不是逐个背中文意思，而是掌握：介词短语在句中做什么功能、核心介词之间如何区分、哪些动词/形容词/名词固定搭配特定介词。

### 8.1 介词与介词短语总览

| 概念 | 英文 | 说明 | 例子 |
| ---- | ---- | ---- | ---- |
| 介词 | Preposition | 表示关系的功能词 | in, on, at, for, with |
| 介词宾语 | Object of Preposition | 介词后面的名词性成分 | in **the room**, for **me** |
| 介词短语 | Prepositional Phrase, PP | 介词 + 宾语 | after the meeting |
| 复合介词 | Complex Preposition | 多词构成一个介词意义 | because of, in front of, in spite of |
| 依存介词 | Dependent Preposition | 与动词/形容词/名词固定搭配 | depend on, interested in |
| 小品词 | Particle | 与动词构成短语动词，不一定有宾语 | give up, turn off |

**介词短语常见功能**：

| 功能 | 例句 | 说明 |
| ---- | ---- | ---- |
| 状语 | She left **after lunch**. | 时间状语 |
| 定语 | the book **on the desk** | 修饰名词 book |
| 主语补语 | The key is **in the drawer**. | 说明主语位置 |
| 宾语补语 | Put the file **on my desk**. | 说明宾语结果位置 |
| 动词补足语 | It depends **on the context**. | 动词搭配要求 |
| 形容词补足语 | She is afraid **of spiders**. | 形容词搭配要求 |
| 名词补足语 | the reason **for the delay** | 名词搭配要求 |

### 8.2 介词宾语：介词后接什么

| 介词宾语类型 | 例句 | 注意 |
| ------------ | ---- | ---- |
| 名词短语 | about **the problem** | 最常见 |
| 代词 | between **you and me** | 介词后用宾格：me, him, her, us, them |
| 动名词 | after **finishing** the work | 介词后不用动词原形 |
| wh 从句 | about **what he said** | 用陈述语序 |
| whether 从句 | about **whether we should leave** | 介词后通常用 whether，不用 if |

| 错误 | 正确 | 原因 |
| ---- | ---- | ---- |
| between you and I | between you and me | 介词后用宾格 |
| after finish work | after finishing work | 介词后动词用 -ing |
| about what did he say | about what he said | 名词性从句用陈述语序 |
| about if we should leave | about whether we should leave | 介词后通常用 whether |

### 8.3 时间介词：at / on / in

| 介词 | 核心概念 | 常见搭配 | 例句 |
| ---- | -------- | -------- | ---- |
| at | 时间点 | at 5:00, at noon, at night, at the moment | The meeting starts **at 9**. |
| on | 具体日子/日期 | on Monday, on July 2, on Christmas Day | We met **on Friday**. |
| in | 较长时间段 | in 2026, in July, in summer, in the morning | It happened **in 2026**. |

| 特殊搭配 | 例句 | 说明 |
| -------- | ---- | ---- |
| at night | I work better **at night**. | 固定习惯 |
| in the morning/afternoon/evening | I exercise **in the morning**. | 一天中的时段 |
| on Monday morning | We met **on Monday morning**. | 具体某天的早晨用 on |
| at the weekend / on the weekend | British: at the weekend; American: on the weekend | 英美差异 |
| in time | We arrived **in time**. | 及时 |
| on time | The train arrived **on time**. | 准时 |

### 8.4 时间范围：for / since / during / while / until / by

| 介词/连词 | 后接 | 例句 | 含义 |
| --------- | ---- | ---- | ---- |
| for | 时间长度 | for three years | 持续多久 |
| since | 时间起点 | since 2020 | 自从某时起 |
| during | 名词短语 | during the meeting | 在某段活动期间 |
| while | 从句 | while I was waiting | 当……期间 |
| until/till | 终点 | until Friday | 一直到某时 |
| by | 截止点 | by Friday | 不晚于某时 |
| from ... to/until | 起点 + 终点 | from Monday to Friday | 从……到…… |
| within | 时间范围内 | within two weeks | 在……之内 |

| 易混 | 例句 | 差别 |
| ---- | ---- | ---- |
| for vs since | for ten years / since 2016 | for + 时长；since + 起点 |
| during vs while | during the storm / while it was raining | during 后接名词；while 后接从句 |
| until vs by | I will stay until 5. / Finish it by 5. | until 表持续到终点；by 表截止前完成 |
| in vs within | in two weeks / within two weeks | in 可表“两周后”；within 表“两周内” |

### 8.5 地点介词：at / in / on

| 介词 | 核心概念 | 例句 | 说明 |
| ---- | -------- | ---- | ---- |
| at | 点、具体位置、活动场所 | at the door, at school, at the station | 强调地点点位或功能 |
| in | 内部、范围、区域 | in the room, in Tokyo, in the file | 强调在范围内 |
| on | 表面、线、平台 | on the table, on the wall, on the road | 强调接触表面或沿线 |

| 对比 | 例句 | 差别 |
| ---- | ---- | ---- |
| at school / in the school | The children are **at school**. / The office is **in the school**. | at school 表上学/在校；in the school 表建筑内部 |
| at the corner / on the corner / in the corner | at the corner of the street / on the corner lot / in the corner of the room | 点位 / 街角地块 / 房间角落 |
| in the street / on the street | British 常用 in the street；American 常用 on the street | 英美差异 |
| in a car / on a bus | in a car, in a taxi; on a bus, on a train | 小型封闭车辆常 in；公共交通常 on |

### 8.6 空间关系介词

| 介词 | 含义 | 例句 |
| ---- | ---- | ---- |
| above | 在上方；高于，不一定垂直 | above sea level |
| over | 在正上方；越过；覆盖 | over the bridge, over the wall |
| below | 在下方；低于 | below average |
| under | 在正下方；被覆盖/压着 | under the table |
| between | 两者之间；清晰分隔的多个对象之间 | between two buildings |
| among | 三者以上群体中 | among the trees |
| in front of | 在外部前面 | in front of the building |
| before | 顺序/时间上在前；正式空间用法 | before the court |
| behind | 在后面 | behind the door |
| beside / next to | 在旁边 | beside the bed, next to me |
| opposite | 在对面 | opposite the bank |
| near / close to | 附近 | near the station |
| around | 周围；大约 | around the table, around noon |

**above / over 与 below / under**：

| 表达 | 典型含义 |
| ---- | -------- |
| The lamp is **above** the table. | 在上方，不强调覆盖或跨越 |
| The plane flew **over** the city. | 从上方经过 |
| The temperature is **below** zero. | 低于抽象标准 |
| The shoes are **under** the bed. | 在床下方 |

### 8.7 方向与移动介词

| 介词 | 核心意义 | 例句 |
| ---- | -------- | ---- |
| to | 到某目的地 | go to school |
| toward(s) | 朝……方向，不一定到达 | walk toward the river |
| into | 进入内部 | go into the room |
| out of | 从内部出来 | get out of the car |
| onto | 到表面上 | climb onto the roof |
| off | 离开表面 | fall off the bike |
| through | 从内部穿过 | walk through the tunnel |
| across | 从表面横穿 | walk across the street |
| along | 沿着 | walk along the river |
| past | 经过 | walk past the shop |
| around | 绕过/绕着 | drive around the city |
| from | 从某处来 | come from Japan |

| 易混 | 例句 | 差别 |
| ---- | ---- | ---- |
| to vs toward | He walked **to** the door. / He walked **toward** the door. | to 暗示到达；toward 只表方向 |
| in vs into | She is **in** the room. / She went **into** the room. | in 表位置；into 表移动进入 |
| on vs onto | The book is **on** the desk. / Put it **onto** the desk. | on 表位置；onto 表移动到表面 |
| through vs across | through the forest / across the road | through 是内部穿过；across 是横跨表面 |

### 8.8 方式、工具、材料与伴随

| 介词 | 用法 | 例句 |
| ---- | ---- | ---- |
| by | 方式、手段、交通方式、执行者 | by email, by train, written by her |
| with | 工具、伴随、具有 | cut with a knife, with friends, a man with glasses |
| without | 没有、缺少 | without permission |
| in | 语言、材料呈现形式、方式 | in English, in ink, in a calm voice |
| on | 设备/平台 | on the phone, on TV, on the internet |
| through | 通过某渠道/过程 | through an agency |
| via | 经由、通过 | via email, via Tokyo |
| like | 像……一样 | He talks like a teacher. |
| as | 作为……身份 | He works as a teacher. |

| 易混 | 例句 | 差别 |
| ---- | ---- | ---- |
| by car / in my car | I go by car. / I came in my car. | by + 交通方式无冠词；具体车辆用 in/on |
| with a knife / by hand | cut it with a knife / made by hand | with 表工具；by 表方式 |
| like vs as | She sings like a professional. / She works as a singer. | like 表相似；as 表身份 |

### 8.9 原因、目的、让步和例外

| 介词/短语 | 含义 | 例句 |
| --------- | ---- | ---- |
| for | 为了；因为 | for a meeting, fined for speeding |
| because of | 因为 | because of the rain |
| due to | 由于；常作表语或正式原因 | The delay was due to traffic. |
| owing to | 由于；较正式 | owing to bad weather |
| thanks to | 多亏；也可讽刺 | thanks to your help |
| in order to / so as to | 为了做某事 | in order to save time |
| despite / in spite of | 尽管 | despite the delay |
| except / except for | 除了 | everyone except Tom |
| apart from | 除了；此外 | apart from cost |
| instead of | 而不是 | instead of waiting |

| because / because of | 例句 |
| -------------------- | ---- |
| because + 从句 | We canceled because it rained. |
| because of + 名词短语 | We canceled because of the rain. |

### 8.10 of 的核心用法

of 是英语中最高频介词之一，常表示所属、部分整体、内容、性质、来源或度量关系。

| 用法 | 例句 | 说明 |
| ---- | ---- | ---- |
| 所属/关联 | the roof **of** the house | 房子的屋顶 |
| 部分整体 | a slice **of** bread | 整体中的一部分 |
| 成员/组成 | a member **of** the team | 团队成员 |
| 内容 | a cup **of** coffee | 杯中内容 |
| 性质 | a man **of** courage | 具有某种品质 |
| 数量/度量 | two kilos **of** rice | 度量对象 |
| 主题 | a story **of** survival | 关于某主题，较文学 |
| 同位/说明 | the city **of** London | London 说明 city |

### 8.11 to / for / with / about / on

这些介词常出现在动词、名词、形容词后，中文都可能译得很宽，必须按搭配掌握。

| 介词 | 核心方向 | 常见搭配 |
| ---- | -------- | -------- |
| to | 方向、对象、对应、归属 | listen to, belong to, similar to, solution to |
| for | 目的、受益者、原因、交换 | wait for, pay for, suitable for, reason for |
| with | 伴随、工具、关系、一致 | agree with, deal with, satisfied with |
| about | 主题、担忧、信息 | talk about, worry about, information about |
| on | 接触、依赖、主题、平台 | depend on, focus on, effect on, on TV |

| 易混 | 正确表达 | 说明 |
| ---- | -------- | ---- |
| explain me the rule | explain the rule to me | explain 直接接内容，接人用 to |
| discuss about the issue | discuss the issue | discuss 是及物动词 |
| enter into the room | enter the room / go into the room | enter 通常直接接地点 |
| request for help | request help / make a request for help | request 作动词直接接宾语 |

### 8.12 动词 + 介词搭配

| 动词 + 介词 | 例句 | 含义 |
| ----------- | ---- | ---- |
| agree with | I agree **with** you. | 同意某人/观点 |
| apologize for | She apologized **for** the delay. | 因……道歉 |
| apply for | He applied **for** the job. | 申请 |
| belong to | This belongs **to** me. | 属于 |
| care about | He cares **about** the result. | 关心 |
| concentrate on | Focus **on** the task. | 专注于 |
| consist of | The team consists **of** five people. | 由……组成 |
| depend on | It depends **on** the context. | 取决于 |
| listen to | Listen **to** me. | 听 |
| look for | I'm looking **for** my keys. | 寻找 |
| object to | They objected **to** the plan. | 反对 |
| rely on | You can rely **on** us. | 依靠 |
| result in | The delay resulted **in** losses. | 导致 |
| suffer from | She suffers **from** allergies. | 患有/遭受 |
| wait for | We waited **for** an hour. | 等待 |

### 8.13 形容词/名词 + 介词搭配

| 形容词 + 介词 | 例句 |
| ------------- | ---- |
| afraid of | afraid **of** spiders |
| angry with/about | angry **with** him / angry **about** the delay |

### 8.14 短语动词、介词动词与小品词

动词后的小词可能是介词，也可能是副词小品词。区别会影响宾语位置和被动语态。

| 类型 | 结构 | 例句 | 特点 |
| ---- | ---- | ---- | ---- |
| 介词动词 | verb + preposition + object | look **at** the picture | 介词后必须有宾语 |
| 短语动词 | verb + particle | give **up** | 小品词可无宾语 |
| 及物短语动词 | verb + particle + object | turn **off** the light | 代词宾语常放中间：turn it off |
| 三词动词 | verb + particle + preposition | put **up with** noise | 整体固定 |

| 对比 | 例句 | 说明 |
| ---- | ---- | ---- |
| look at | Look at it. | at 是介词，宾语跟在后面 |
| look up | Look it up. | up 是小品词，代词宾语放中间 |
| run into | I ran into an old friend. | 遇见；into 是介词 |
| run out of | We ran out of time. | 三词固定表达 |

### 8.15 介词后置 Stranded Prepositions

英语中介词可以出现在从句或疑问句末尾，尤其在口语和普通写作中很自然。

| 普通表达 | 正式表达 | 说明 |
| -------- | -------- | ---- |
| Who are you talking **to**? | To whom are you talking? | 正式文体可前置 |
| This is the issue we talked **about**. | This is the issue about which we talked. | 介词后置更自然 |
| The bed was slept **in**. | - | 被动中介词保留 |
| She has no one to talk **to**. | - | 不定式结构中常后置 |

**注意**：不要因为“不能以介词结尾”的旧说法而写出僵硬句子；正式程度和自然度要平衡。

### 8.16 介词短语的位置和歧义

介词短语可以修饰名词，也可以修饰动词或整个句子；位置不清会造成歧义。

| 句子 | 可能含义 | 更清楚的改写 |
| ---- | -------- | ------------ |
| I saw the man with a telescope. | 我用望远镜看见他 / 我看见带望远镜的人 | With a telescope, I saw the man. / I saw the man who had a telescope. |
| The report on prices from 2020 was unclear. | 2020 年的报告 / 关于 2020 年价格的报告 | The 2020 report on prices... / The report on 2020 prices... |
| She put the book on the table in the kitchen. | table 在厨房 / 放书动作发生在厨房 | She put the book on the kitchen table. |

| 位置 | 例句 | 功能 |
| ---- | ---- | ---- |
| 名词后 | the book **on the desk** | 定语 |
| 动词后 | She slept **on the sofa**. | 地点状语 |
| 句首 | **After the meeting**, we left. | 时间状语 |
| 形容词后 | ready **for the exam** | 形容词补足语 |

### 8.17 常见错误速查

| 错误类型 | 不自然/错误 | 推荐表达 | 原因 |
| -------- | ----------- | -------- | ---- |
| 介词后用主格 | between you and I | between you and me | 介词后用宾格 |
| 介词后接原形 | after finish work | after finishing work | 介词后动词用 -ing |
| at/on/in 混用 | at Monday | on Monday | 具体日子用 on |
| for/since 混用 | since three years | for three years / since 2023 | for + 时长；since + 起点 |
| during/while 混用 | during I was there | while I was there / during my stay | during 后接名词 |
| by/until 混用 | Stay here by 5. | Stay here until 5. | 持续到某时用 until |
| discuss 后多余介词 | discuss about the plan | discuss the plan | discuss 是及物动词 |
| enter 后多余介词 | enter into the room | enter the room / go into the room | enter 地点时直接接宾语 |
| listen 漏介词 | listen music | listen to music | listen 后通常接 to |
| depend 漏介词 | depends the weather | depends on the weather | depend on 固定搭配 |
| married 搭配错 | married with her | married to her | married to |
| responsible 搭配错 | responsible of the error | responsible for the error | responsible for |
| despite 后接从句 | despite he was tired | although he was tired / despite being tired | despite 是介词 |
| because of 后接从句 | because of it rained | because it rained / because of the rain | because of 后接名词短语 |
| 介词短语歧义 | I saw the man with a telescope. | I used a telescope to see the man. | 明确 PP 修饰对象 |

## 9. 连词与逻辑连接（Conjunctions and Connectors）

连词和连接词负责把词、短语、从句和句子组织成逻辑关系。学习这一章要区分三件事：语法上是否真的是连词、连接的是同级结构还是主从结构、标点是否正确。

| 类型 | 英文 | 连接对象 | 例子 |
| ---- | ---- | -------- | ---- |
| 并列连词 | coordinating conjunction | 同级词、短语、从句、独立句 | and, but, or, so |
| 从属连词 | subordinating conjunction | 从属从句 + 主句 | because, although, if, when |
| 关联连词 | correlative conjunction | 成对连接平行成分 | either...or, both...and |
| 连接副词 | conjunctive adverb | 连接句子逻辑，但不是语法连词 | however, therefore, moreover |
| 话语连接词 | discourse connector | 组织段落和论证 | first, in contrast, for example |

### 9.1 连接方式总览

| 连接方式 | 结构 | 例句 | 标点 |
| -------- | ---- | ---- | ---- |
| 单词 + 单词 | A and B | tea **and** coffee | 不用逗号，除非列表 |
| 短语 + 短语 | phrase and phrase | in Japan **and** in Korea | 保持结构平行 |
| 独立句 + 独立句 | clause, and clause | It was late, **so** we left. | 并列连词前常加逗号 |
| 从属从句 + 主句 | because clause, main clause | **Because** it rained, we stayed home. | 从句在前常加逗号 |
| 主句 + 从属从句 | main clause because clause | We stayed home **because** it rained. | 通常不用逗号 |
| 独立句 + 连接副词 + 独立句 | clause; however, clause | It was late; **however**, we stayed. | 不能只用逗号 |

**核心区别**：

| 表达 | 词类 | 正确标点 |
| ---- | ---- | -------- |
| It was late, **but** we stayed. | but 是并列连词 | 逗号 + but |
| It was late; **however**, we stayed. | however 是连接副词 | 分号/句号 + however |
| We stayed **because** it was late. | because 是从属连词 | 主句后通常不用逗号 |

### 9.2 并列连词 FANBOYS

传统上常用 FANBOYS 记忆七个并列连词：for, and, nor, but, or, yet, so。

| 连词 | 关系 | 例句 | 注意 |
| ---- | ---- | ---- | ---- |
| for | 原因；书面 | He left, **for** he was tired. | 不能放句首引导原因从句 |
| and | 添加、顺承 | She opened the file **and** read it. | 连接同级结构 |
| nor | 否定并列 | He didn't call, **nor** did he write. | nor 后常倒装 |
| but | 转折 | It is small, **but** useful. | 语气中性常用 |
| or | 选择、否则 | Call me, **or** send an email. | 可表选择或后果 |
| yet | 转折；较正式 | It is simple, **yet** effective. | 类似 but |
| so | 结果 | It was raining, **so** we stayed. | 表结果，不表原因 |

**并列连接必须平行**：

| 不平行 | 平行 |
| ------ | ---- |
| She likes reading, music, and to travel. | She likes reading, listening to music, and traveling. |
| The plan is cheap, fast, and it can be changed. | The plan is cheap, fast, and flexible. |
| We need to reduce costs and quality should improve. | We need to reduce costs and improve quality. |

### 9.3 and / but / or / so 的实用区别

| 关系 | 连接词 | 例句 | 说明 |
| ---- | ------ | ---- | ---- |
| 添加 | and | We checked the data **and** fixed the chart. | 两个动作顺接 |
| 对比/转折 | but | The method is simple **but** effective. | 后项与预期相反 |
| 选择 | or | You can call **or** email me. | 二选一或多选一 |
| 否则 | or | Hurry up, **or** we'll be late. | 相当于 if not |
| 结果 | so | It was late, **so** we left. | 前因后果 |

| 易错 | 推荐 | 原因 |
| ---- | ---- | ---- |
| Because it rained, so we stayed home. | Because it rained, we stayed home. / It rained, so we stayed home. | because 和 so 不同时连接同一因果 |
| Although it was late, but we stayed. | Although it was late, we stayed. / It was late, but we stayed. | although 和 but 不同时使用 |
| He didn't call, nor he wrote. | He didn't call, nor did he write. | nor 连接独立句时常倒装 |

### 9.4 从属连词总览

从属连词引导从句，使从句依附于主句。它们主要形成状语从句，也可参与名词性从句。

| 关系 | 常见从属连词 | 例句 |
| ---- | ------------ | ---- |
| 时间 | when, while, before, after, until, since, as soon as | Call me **when** you arrive. |
| 原因 | because, since, as | We left **because** it was late. |
| 条件 | if, unless, provided that, as long as | **If** it rains, we will cancel. |
| 让步 | although, though, even though, even if, while, whereas | **Although** it was late, we stayed. |
| 目的 | so that, in order that, lest | Speak clearly **so that** everyone can hear. |
| 结果 | so...that, such...that | It was **so** cold **that** the lake froze. |
| 方式 | as, as if, as though | Do it **as** I showed you. |
| 比较 | than, as...as | She is taller **than** I am. |
| 名词性从句 | that, whether, if | I know **that** he left. |

### 9.5 时间从属连词

| 连词 | 含义 | 例句 | 注意 |
| ---- | ---- | ---- | ---- |
| when | 当……时 | Call me **when** you arrive. | 可指点或段 |
| while | 当……期间；而 | I waited **while** she talked. | 强调持续或对比 |
| as | 当……时；随着 | **As** time passed, things improved. | 强调同步变化 |
| before | 在……之前 | Finish this **before** you leave. | 从句用现在表将来 |
| after | 在……之后 | We left **after** the meeting ended. | 时间先后 |
| until/till | 直到 | Wait **until** I return. | 主句动作持续到终点 |
| since | 自从 | I haven't seen her **since** she moved. | 主句常用完成时 |
| as soon as | 一……就 | I'll call **as soon as** I know. | 从句用现在表将来 |
| once | 一旦 | **Once** you start, continue. | 条件 + 时间 |

**时间从句中现在表将来**：

| 不自然 | 推荐 |
| ------ | ---- |
| I will call you when I will arrive. | I will call you when I arrive. |
| We will leave after he will come. | We will leave after he comes. |

### 9.6 原因、目的、结果

| 关系 | 连接词 | 例句 | 说明 |
| ---- | ------ | ---- | ---- |
| 直接原因 | because | We stayed home **because** it rained. | 最明确 |
| 已知原因/既然 | since | **Since** you're here, let's start. | 原因常是双方已知 |
| 背景原因 | as | **As** it was late, we left. | 较书面、较弱 |
| 书面原因 | for | We left, **for** it was late. | 并列连词，不放句首 |
| 目的 | so that | I wrote it down **so that** I wouldn't forget. | 常含 can/could/will/would |
| 正式目的 | in order that | He left early **in order that** he might arrive on time. | 正式 |
| 结果 | so...that | It was **so** noisy **that** I left. | so + 形容词/副词 |
| 结果 | such...that | It was **such** a noisy room **that** I left. | such + 名词短语 |

| because / because of | 例句 | 词类 |
| -------------------- | ---- | ---- |
| because + 从句 | We canceled **because it rained**. | 连词 |
| because of + 名词短语 | We canceled **because of the rain**. | 复合介词 |

### 9.7 条件连词

| 连词 | 含义 | 例句 | 注意 |
| ---- | ---- | ---- | ---- |
| if | 如果 | **If** it rains, we will cancel. | 最常见 |
| unless | 除非 | **Unless** you hurry, you'll be late. | = if not |
| as long as | 只要 | You can stay **as long as** you keep quiet. | 条件或时间 |
| provided/providing that | 只要；如果 | You can go **provided that** you finish. | 较正式 |
| on condition that | 条件是 | He agreed **on condition that** he be paid. | 正式 |
| in case | 以防 | Take an umbrella **in case** it rains. | 不是 if 的普通替换 |
| even if | 即使 | I'll go **even if** it rains. | 让步条件 |

| 易混 | 例句 | 差别 |
| ---- | ---- | ---- |
| if vs whether | I don't know **whether/if** he will come. / **Whether** he comes matters. | 主语从句、介词后通常用 whether |
| unless vs if not | Unless you hurry, you'll miss it. | unless 已含否定，不再加 not |
| in case vs if | Take a key in case I'm out. | in case 表预防 |

### 9.8 让步和对比

| 连接词 | 含义 | 例句 | 说明 |
| ------ | ---- | ---- | ---- |
| although | 虽然 | **Although** it was late, we stayed. | 标准让步 |
| though | 虽然；不过 | **Though** it was late, we stayed. | 可句尾：It was late, though. |
| even though | 尽管；即使事实如此 | **Even though** he was tired, he continued. | 强调事实让步 |
| even if | 即使假设如此 | I will go **even if** it rains. | 假设条件 |
| while | 虽然；而 | **While** I agree, I have concerns. | 书面让步/对比 |
| whereas | 而；相比之下 | Some agreed, **whereas** others refused. | 正式对比 |
| no matter + wh | 无论 | **No matter what** happens, stay calm. | = whatever 等 |

**although / but 不双连**：

| 不自然 | 推荐 |
| ------ | ---- |
| Although it was raining, but we went out. | Although it was raining, we went out. |
| Though he was tired, but he kept working. | He was tired, but he kept working. |

### 9.9 关联连词 Correlative Conjunctions

关联连词成对出现，连接平行结构。它们最容易出错的地方是结构不对称和主谓一致。

| 关联连词 | 含义 | 例句 |
| -------- | ---- | ---- |
| both...and | 两者都 | She is **both** smart **and** practical. |
| either...or | 要么……要么 | You can **either** stay **or** leave. |
| neither...nor | 既不……也不 | He **neither** called **nor** emailed. |
| not only...but also | 不仅……而且 | She is **not only** fast **but also** accurate. |
| whether...or | 是否……还是 | I don't know **whether** to stay **or** leave. |
| as...as | 和……一样 | It is **as** good **as** expected. |
| so...that | 如此……以至于 | It was **so** late **that** we left. |
| such...that | 如此……以至于 | It was **such** a mess **that** we stopped. |
| no sooner...than | 一……就 | **No sooner** had he arrived **than** it rained. |
| hardly/scarcely...when | 刚……就 | **Hardly** had I sat down **when** the phone rang. |

**平行结构**：

| 不平行 | 平行 |
| ------ | ---- |
| She is not only smart but also works hard. | She is not only smart but also hardworking. |
| Either you can call or email me. | You can either call me or email me. |
| He neither likes coffee nor tea. | He likes neither coffee nor tea. |

### 9.10 关联连词的主谓一致和倒装

| 结构 | 规则 | 例句 |
| ---- | ---- | ---- |
| both A and B | 通常复数 | Both Tom and Anna **are** here. |
| either A or B | 谓语常跟靠近的主语一致 | Either the manager or the employees **are** responsible. |
| neither A nor B | 谓语常跟靠近的主语一致 | Neither the employees nor the manager **is** available. |
| not only A but also B | 谓语常跟靠近的主语一致 | Not only the students but also the teacher **was** surprised. |
| not only 句首 | 前半句倒装 | Not only **did** he apologize, but he also paid. |
| no sooner 句首 | 倒装 + than | No sooner **had** I arrived than it started. |
| hardly/scarcely 句首 | 倒装 + when | Hardly **had** I sat down when the phone rang. |

### 9.11 连接副词不是并列连词

however, therefore, moreover 等连接副词表达逻辑关系，但语法上不是并列连词。连接两个独立句时，不能只用逗号。

| 关系 | 连接副词 | 例句 |
| ---- | -------- | ---- |
| 转折 | however, nevertheless, still | It was late; **however**, we stayed. |
| 结果 | therefore, thus, consequently | He was ill; **therefore**, he stayed home. |
| 补充 | moreover, furthermore, also | The method is cheap; **moreover**, it is fast. |
| 对比 | meanwhile, instead, in contrast | Some agreed; **in contrast**, others refused. |
| 顺序 | first, next, finally | **First**, check the data. |
| 例证 | for example, for instance | Many tools exist; **for example**, this one is free. |
| 总结 | in short, therefore, overall | **In short**, the plan failed. |

| 错误 | 正确 |
| ---- | ---- |
| It was late, however we stayed. | It was late; however, we stayed. |
| He was sick, therefore he left. | He was sick; therefore, he left. |
| The test is hard, moreover it is long. | The test is hard; moreover, it is long. |

### 9.12 逻辑连接速查

| 逻辑关系 | 常用连接 |
| -------- | -------- |
| 添加 | and, also, moreover, furthermore, in addition |
| 顺序 | first, then, next, finally, afterwards |
| 对比 | but, yet, while, whereas, however, in contrast |
| 让步 | although, though, even though, nevertheless, despite this |
| 原因 | because, since, as, for, because of, due to |
| 结果 | so, therefore, thus, consequently, as a result |
| 目的 | so that, in order that, in order to, so as to |
| 条件 | if, unless, as long as, provided that, in case |
| 例子 | for example, for instance, such as |
| 总结 | in short, in conclusion, overall, to sum up |
| 改述 | in other words, that is, namely |
| 强调 | indeed, in fact, above all |

### 9.13 标点规则

| 结构 | 标点 | 例句 |
| ---- | ---- | ---- |
| 独立句 + 并列连词 + 独立句 | 连词前常加逗号 | I was tired, but I continued. |
| 短并列成分 | 通常不用逗号 | tea and coffee |
| 三项以上列表 | 可用逗号；Oxford comma 依风格 | tea, coffee, and juice |
| 从属从句在前 | 从句后加逗号 | If it rains, we will cancel. |
| 从属从句在后 | 通常不用逗号 | We will cancel if it rains. |
| 连接副词连接独立句 | 分号/句号 + 连接副词 | It rained; therefore, we stayed. |
| 插入性连接词 | 两边逗号 | The plan, however, failed. |

### 9.14 常见错误速查

| 错误类型 | 不自然/错误 | 推荐表达 | 原因 |
| -------- | ----------- | -------- | ---- |
| because/so 双连 | Because it rained, so we stayed. | Because it rained, we stayed. / It rained, so we stayed. | 英语不用双重连接 |
| although/but 双连 | Although it was late, but we stayed. | Although it was late, we stayed. / It was late, but we stayed. | 同一让步关系不用双连 |
| comma splice | It was late, we left. | It was late, so we left. / It was late; we left. | 两个独立句不能只用逗号 |
| however 逗号拼接 | It was late, however we stayed. | It was late; however, we stayed. | however 不是并列连词 |
| 平行结构错误 | She likes reading, music, and to travel. | She likes reading, listening to music, and traveling. | 连接成分要平行 |
| either/or 位置错 | Either you can stay or leave. | You can either stay or leave. | either 应靠近第一个被连接成分 |
| neither/nor 多重否定 | He doesn't neither smoke nor drink. | He neither smokes nor drinks. | neither 已含否定 |
| unless 再否定 | Unless you don't hurry, you'll miss it. | Unless you hurry, you'll miss it. | unless = if not |
| 时间从句误用 will | When he will arrive, call me. | When he arrives, call me. | 时间/条件从句用现在表将来 |
| whether/if 混用 | It depends on if he agrees. | It depends on whether he agrees. | 介词后通常用 whether |
| so that / so 混用 | He was tired so that he slept. | He was tired, so he slept. | so that 表目的，不是普通结果 |
| despite 后接从句 | Despite he was tired, he worked. | Although he was tired, he worked. / Despite being tired, he worked. | despite 是介词 |

## 10. 从句系统（Clauses）

从句是带有主语和谓语的句法单位。英语从句最重要的判断问题有三个：它能不能独立成句、它在主句中充当什么成分、它由什么词引导。

| 层级 | 英文 | 能否独立成句 | 例子 |
| ---- | ---- | ------------ | ---- |
| 独立分句 | independent clause / main clause | 能 | **I know the answer**. |
| 从属分句 | subordinate clause / dependent clause | 不能 | **because I know the answer** |
| 名词性从句 | noun clause | 不能 | I know **that he is right**. |
| 定语从句 | relative clause | 不能 | the book **that I bought** |
| 状语从句 | adverbial clause | 不能 | I left **because it was late**. |
| 非限定从句 | non-finite clause | 通常不能 | I want **to leave**. / **Seen from here**, it looks small. |

### 10.1 从句速查地图

| 从句类型 | 在句中作用 | 常见引导词 | 典型例句 |
| -------- | ---------- | ---------- | -------- |
| 主语从句 | 作主语 | what, whether, that | **What he said** surprised me. |
| 宾语从句 | 作宾语 | that, if, whether, what, why | I know **that he left**. |
| 表语从句 | 作表语 | that, whether, what, why | The problem is **that we are late**. |
| 同位语从句 | 解释名词内容 | that, whether, why, how | The fact **that he left** shocked us. |
| 限制性定语从句 | 限定名词身份 | who, whom, whose, which, that, where, when, why | The book **that I bought** is useful. |
| 非限制性定语从句 | 补充说明名词 | who, whom, whose, which, where, when | My brother, **who lives in Boston**, called. |
| 状语从句 | 表时间、原因、条件等 | when, because, if, although, so that | I stayed home **because it rained**. |
| 条件从句 | 表真实或非真实假设 | if, unless, provided that | **If I were you**, I would wait. |

### 10.2 主句、从句与标点

| 结构 | 标点 | 例句 |
| ---- | ---- | ---- |
| 主句 + 从属从句 | 通常不用逗号 | I stayed home because it rained. |
| 从属从句 + 主句 | 从句后常加逗号 | Because it rained, I stayed home. |
| 限制性定语从句 | 不用逗号 | The people who arrived early got seats. |
| 非限制性定语从句 | 两边逗号 | My father, who is retired, lives alone. |
| 插入性从句 | 两边逗号 | The plan, I think, will work. |
| 两个独立句 | 不能只用逗号 | It rained; we stayed home. / It rained, so we stayed home. |

### 10.3 有限从句与非限定从句

有限从句有明确时态和主语；非限定从句用不定式、-ing 或过去分词形式，常常省略自己的主语。

| 类型 | 结构 | 例句 | 功能 |
| ---- | ---- | ---- | ---- |
| 有限从句 | 主语 + 限定动词 | I know **that he is tired**. | 名词/定语/状语 |
| to 不定式从句 | to + 动词原形 | I want **to leave**. | 名词、目的、补足语 |
| -ing 从句 | doing | **Walking home**, I saw her. | 状语、名词、定语 |
| 过去分词从句 | done | **Written in 1900**, the letter is valuable. | 被动/完成含义 |
| 无动词从句 | 形容词/名词短语 | **If necessary**, call me. | 省略式状语 |

| 完整表达 | 简化表达 | 说明 |
| -------- | -------- | ---- |
| When you are ready, call me. | When ready, call me. | 主语一致时可省略 |
| The man who is standing there is my uncle. | The man standing there is my uncle. | 现在分词简化定语从句 |
| The files that were deleted yesterday are gone. | The files deleted yesterday are gone. | 过去分词简化被动定语从句 |

### 10.4 名词性从句总览

名词性从句在句中相当于名词短语，可以作主语、宾语、表语、同位语或介词宾语。

| 功能 | 结构 | 例句 |
| ---- | ---- | ---- |
| 主语 | that/wh-/whether + 从句 | **Whether he agrees** matters. |
| 宾语 | 动词 + that/wh-/if/whether + 从句 | I don't know **where he lives**. |
| 表语 | be/seem/remain + 从句 | The point is **that we need evidence**. |
| 同位语 | 抽象名词 + that/whether/wh- + 从句 | the idea **that we should wait** |
| 介词宾语 | 介词 + wh-/whether 从句 | It depends on **whether he agrees**. |

### 10.5 that 从句

that 从句陈述一个事实、观点、判断或内容。that 本身通常不作从句成分，只起连接作用。

| 用法 | 例句 | that 能否省略 |
| ---- | ---- | ------------ |
| 宾语从句 | I think **that** he is right. | 口语常省略 |
| 主语从句 | **That he lied** is obvious. | 不省略 |
| 形式主语 it | It is obvious **that** he lied. | 不省略 |
| 表语从句 | The truth is **that** he lied. | 通常不省略 |
| 同位语从句 | the fact **that** he lied | 不省略 |
| 形容词补足语 | I am glad **that** you came. | 可省略但正式文体常保留 |

| 句型 | 例句 | 说明 |
| ---- | ---- | ---- |
| It + be + adjective + that | It is clear that we need more time. | 形式主语 |
| It + be + noun + that | It is a pity that you missed it. | 评价整个事实 |
| Verb + it + adjective + that | I find it strange that he left early. | it 作形式宾语 |
| be + adjective + that | I am sure that he will agree. | 形容词补足语 |

### 10.6 whether / if 从句

whether 和 if 都可表示“是否”，但 whether 的分布更广、更正式。

| 场景 | 推荐 | 例句 |
| ---- | ---- | ---- |
| 动词宾语 | whether / if 都可 | I don't know whether/if he will come. |
| 主语从句 | whether | Whether he will come is unclear. |
| 表语从句 | whether | The question is whether he will come. |
| 同位语从句 | whether | the question whether he will come |
| 介词宾语 | whether | It depends on whether he agrees. |
| 不定式前 | whether | I don't know whether to accept. |
| 与 or not 直接连用 | whether | I don't know whether or not he agrees. |

| 不自然/错误 | 推荐 | 原因 |
| ----------- | ---- | ---- |
| If he comes is unclear. | Whether he comes is unclear. | 主语从句通常不用 if |
| It depends on if he agrees. | It depends on whether he agrees. | 介词后用 whether |
| I don't know if to go. | I don't know whether to go. | 不定式前用 whether |

### 10.7 wh- 名词性从句与间接疑问句

wh- 从句由 what, who, whom, whose, which, when, where, why, how 引导。注意：间接疑问句使用陈述句语序。

| 引导词 | 功能 | 例句 |
| ------ | ---- | ---- |
| what | 什么；所……的事物 | I know **what he wants**. |
| who | 谁，作主语或表语 | Tell me **who called**. |
| whom | 谁，作宾语，正式 | I know **whom she invited**. |
| whose | 谁的 | I wonder **whose bag this is**. |
| which | 哪一个 | Tell me **which one you prefer**. |
| when | 何时 | I don't know **when he arrived**. |
| where | 何地 | Do you know **where she lives**? |
| why | 为什么 | I understand **why he left**. |
| how | 如何；多么 | Show me **how this works**. |

| 直接疑问句 | 间接疑问句 |
| ---------- | ---------- |
| Where does he live? | I don't know where he lives. |
| What did she say? | Tell me what she said. |
| Why is he angry? | I don't know why he is angry. |
| Can he help us? | I wonder whether/if he can help us. |

### 10.8 名词性从句的语序、时态和虚拟

| 问题 | 规则 | 例句 |
| ---- | ---- | ---- |
| 语序 | 用陈述句语序 | I don't know where he is. |
| that 省略 | 宾语从句口语可省，其他位置通常不省 | I think he is right. |
| 时态一致 | 主句过去时后，从句常作相应调整 | He said that he was tired. |
| 客观事实 | 真理或仍然成立的事实可用现在时 | She said that water boils at 100 C. |
| 要求/建议类虚拟 | demand, suggest, insist 等后用 should do 或动词原形 | They suggested that he leave early. |

| 常见动词/名词/形容词 | 从句形式 | 例句 |
| -------------------- | -------- | ---- |
| suggest, recommend, demand, insist, require | that + 主语 + 动词原形 | I suggest that she wait. |
| suggestion, demand, requirement, proposal | that + 主语 + 动词原形 | His suggestion that we wait is reasonable. |
| important, necessary, essential, vital | that + 主语 + 动词原形 | It is important that he be present. |

### 10.9 同位语从句与定语从句

同位语从句解释名词的内容；定语从句修饰名词本身。最常见的同位语先行名词包括 fact, idea, belief, claim, news, rumor, question, possibility, evidence, suggestion。

| 类型 | 例句 | 判断 |
| ---- | ---- | ---- |
| 同位语从句 | The idea **that we should leave early** is sensible. | that 后说明 idea 的内容 |
| 定语从句 | The idea **that he proposed** is sensible. | that 在从句中作 proposed 的宾语 |
| 同位语从句 | The news **that he had resigned** surprised us. | news 的内容是 he had resigned |
| 定语从句 | The news **that we heard yesterday** surprised us. | news 被 we heard yesterday 修饰 |

| 判断方法 | 同位语从句 | 定语从句 |
| -------- | ---------- | -------- |
| that 是否作成分 | 不作成分 | 作主语、宾语或表语 |
| 从句是否完整 | 通常完整 | 常缺一个成分 |
| 与名词关系 | 解释内容 | 限定或补充说明 |

### 10.10 定语从句总览

定语从句修饰名词或代词，被修饰的词叫先行词。限制性定语从句决定“是哪一个”；非限制性定语从句只是补充信息。

| 类型 | 标点 | that 是否可用 | 例句 |
| ---- | ---- | ------------ | ---- |
| 限制性定语从句 | 无逗号 | 可用 | The book **that I bought** is useful. |
| 非限制性定语从句 | 有逗号 | 不可用 | The book, **which I bought yesterday**, is useful. |
| 整句补充 | 逗号 + which | 不可用 that | He was late, **which annoyed everyone**. |

| 关系词 | 先行词 | 在从句中功能 | 例句 |
| ------ | ------ | ------------ | ---- |
| who | 人 | 主语 | The woman **who called** is my boss. |
| whom | 人 | 宾语，正式 | The man **whom I met** was kind. |
| whose | 人/物 | 所有格 | a writer **whose books sell well** |
| which | 物/事 | 主语/宾语 | the file **which contains the data** |
| that | 人/物 | 主语/宾语 | the team **that won** |
| where | 地点 | 地点状语 | the city **where I was born** |
| when | 时间 | 时间状语 | the year **when we met** |
| why | reason | 原因状语 | the reason **why he left** |

### 10.11 that / which / who / whom / whose

| 选择 | 常用场景 | 例句 | 注意 |
| ---- | -------- | ---- | ---- |
| who | 人，作主语 | The person who helped me left. | 口语和书面都常用 |
| whom | 人，作宾语 | The person whom I helped left. | 正式；口语常用 who |
| whose | 所属关系 | The student whose phone rang apologized. | 可指人或物 |
| which | 物，尤其非限制性 | The car, which is new, broke down. | 非限制性不用 that |
| that | 人或物，限制性 | The car that broke down is mine. | 不能用于非限制性 |

| 场景 | 常用 that | 例句 |
| ---- | --------- | ---- |
| 先行词含最高级 | the best book that I have read | 传统语法偏好 that |
| 先行词含序数词 | the first person that arrived | 常用 that |
| 先行词含 all, everything, nothing, anything | everything that matters | 常用 that |
| 先行词既有人又有物 | the people and things that I remember | 用 that 更自然 |

### 10.12 关系词省略与介词位置

关系代词作宾语时，在限制性定语从句中常可省略；作主语时不能省略。

| 结构 | 能否省略 | 例句 |
| ---- | -------- | ---- |
| 关系代词作主语 | 不能省略 | The man who called is here. |
| 关系代词作宾语 | 可省略 | The book I bought is useful. |
| 介词后关系代词 | 不能省略 | the person to whom I spoke |
| 非限制性定语从句 | 通常不省略 | My car, which I bought last year, is old. |

| 风格 | 例句 | 说明 |
| ---- | ---- | ---- |
| 正式 | the person **to whom** I spoke | 介词前置，whom |
| 普通 | the person **who** I spoke to | 介词后置，who |
| 口语 | the person I spoke to | 关系代词省略 |
| 物 | the issue **about which** we argued | 正式 |
| 物 | the issue we argued **about** | 普通 |

### 10.13 限制性与非限制性定语从句

| 对比 | 限制性 | 非限制性 |
| ---- | ------ | -------- |
| 信息作用 | 必要，决定是哪一个 | 附加，可删去 |
| 标点 | 不加逗号 | 加逗号 |
| that | 可用 | 不可用 |
| 翻译倾向 | “……的” | “……，他/它……” |

| 句子 | 含义 |
| ---- | ---- |
| My brother who lives in Tokyo is visiting. | 我有不止一个兄弟，住东京的那个要来 |
| My brother, who lives in Tokyo, is visiting. | 我兄弟要来；补充说明他住东京 |
| The students who passed the exam can leave. | 通过考试的学生可以离开 |
| The students, who passed the exam, can leave. | 这些学生都通过了考试，所以可以离开 |

### 10.14 关系副词 where / when / why

where, when, why 本质上相当于介词 + which，在从句中作状语。

| 关系副词 | 等价表达 | 例句 |
| -------- | -------- | ---- |
| where | in/at/on which | This is the house where I grew up. |
| when | at/on/in which | I remember the day when we met. |
| why | for which | Tell me the reason why you left. |

| 易错点 | 推荐 | 说明 |
| ------ | ---- | ---- |
| where 不能代替地点名词作主语 | The city that hosted the event is large. | hosted 缺主语，用 that/which |
| when 不能代替时间名词作主语 | The year that changed everything was 2020. | changed 缺主语 |
| reason why / reason that 都可 | the reason why he left / the reason that he left | why 作原因状语，that 可作连接词 |

### 10.15 状语从句总览

状语从句说明主句动作的时间、原因、条件、让步、目的、结果、方式、比较、地点等。

| 类型 | 常见引导词 | 例句 |
| ---- | ---------- | ---- |
| 时间 | when, while, before, after, until, since, as soon as | Call me when you arrive. |
| 原因 | because, since, as, now that | We stayed because it rained. |
| 条件 | if, unless, as long as, provided that | If it rains, we will cancel. |
| 让步 | although, though, even though, even if, while, whereas | Although it rained, we went out. |
| 目的 | so that, in order that, in case, lest | Speak clearly so that everyone can hear. |
| 结果 | so...that, such...that | It was so late that we left. |
| 方式 | as, as if, as though | Do it as I showed you. |
| 比较 | than, as...as, the more...the more | She is taller than I am. |
| 地点 | where, wherever | Sit where you like. |

### 10.16 时间状语从句

| 引导词 | 含义 | 例句 | 注意 |
| ------ | ---- | ---- | ---- |
| when | 当……时 | Call me when you arrive. | 点或段均可 |
| while | 当……期间；而 | I read while she cooked. | 强调持续或对比 |
| as | 当……时；随着 | As I was leaving, he arrived. | 动作同步 |
| before | 在……之前 | Finish this before you leave. | 从句现在表将来 |
| after | 在……之后 | We talked after the meeting ended. | 先后关系 |
| until/till | 直到 | Wait until I return. | 主句动作持续到终点 |
| since | 自从 | I have lived here since I was ten. | 主句常用完成时 |
| as soon as | 一……就 | I will call as soon as I know. | 从句现在表将来 |
| once | 一旦 | Once you understand it, it is easy. | 时间 + 条件 |

| 不自然 | 推荐 |
| ------ | ---- |
| I will call when I will arrive. | I will call when I arrive. |
| We will leave after he will come. | We will leave after he comes. |
| I have lived here since five years. | I have lived here for five years. / since 2019. |

### 10.17 原因、目的、结果状语从句

| 关系 | 引导词 | 例句 | 说明 |
| ---- | ------ | ---- | ---- |
| 直接原因 | because | I left because I was tired. | 最明确 |
| 已知原因 | since | Since you're here, let's start. | “既然” |
| 背景原因 | as | As it was late, we left. | 较弱、较书面 |
| 目的 | so that | I whispered so that no one would hear. | 常有 can/could/will/would |
| 正式目的 | in order that | He left early in order that he might arrive on time. | 正式 |
| 预防 | in case | Take a key in case I am out. | “以防” |
| 结果 | so...that | It was so cold that we stayed inside. | so + 形容词/副词 |
| 结果 | such...that | It was such a cold day that we stayed inside. | such + 名词短语 |

| 易错 | 推荐 | 原因 |
| ---- | ---- | ---- |
| Because it rained, so we stayed. | Because it rained, we stayed. / It rained, so we stayed. | because 和 so 不双连 |
| He was tired so that he slept. | He was tired, so he slept. | so that 表目的，不是普通结果 |
| In case it rains, we will cancel. | If it rains, we will cancel. | in case 是预防，不是普通 if |

### 10.18 条件与让步状语从句

| 类型 | 引导词 | 例句 | 说明 |
| ---- | ------ | ---- | ---- |
| 普通条件 | if | If it rains, we will cancel. | 最常见 |
| 否定条件 | unless | Unless you hurry, you'll be late. | = if not |
| 充分条件 | as long as | You can stay as long as you keep quiet. | “只要” |
| 正式条件 | provided that | You may leave provided that you sign out. | 较正式 |
| 让步事实 | although, though, even though | Although it rained, we went out. | 事实存在 |
| 让步假设 | even if | Even if it rains, I will go. | 假设也不改变结果 |
| 对比让步 | while, whereas | While I agree, I have concerns. | 书面语常见 |
| 无论 | no matter wh-, wh-ever | Whatever happens, stay calm. | 强调不受影响 |

| 易错 | 推荐 | 原因 |
| ---- | ---- | ---- |
| Although it rained, but we went out. | Although it rained, we went out. / It rained, but we went out. | although 和 but 不双连 |
| Unless you don't hurry, you'll be late. | Unless you hurry, you'll be late. | unless 已含否定 |
| Even though it rains tomorrow, I will go. | Even if it rains tomorrow, I will go. | 未来假设用 even if 更自然 |

### 10.19 条件句类型

条件句常由 if 从句 + 主句构成。真实条件通常用现在表将来；非真实条件使用过去形式或过去完成形式表达距离现实。

| 类型 | 含义 | if 从句 | 主句 | 例句 |
| ---- | ---- | ------- | ---- | ---- |
| 零条件句 | 普遍规律 | simple present | simple present | If water reaches 100 C, it boils. |
| 第一条件句 | 未来真实可能 | simple present | will/can/may + 动词原形 | If it rains, we will cancel. |
| 第二条件句 | 现在/未来非真实 | simple past | would/could/might + 动词原形 | If I were you, I would wait. |
| 第三条件句 | 过去非真实 | past perfect | would/could/might have + 过去分词 | If I had known, I would have helped. |
| 混合条件句 | 过去原因 + 现在结果 | past perfect | would + 动词原形 | If I had studied medicine, I would be a doctor now. |

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| unless | Unless it rains, we will go. | = if it does not rain |
| should 句首倒装 | Should you need help, call me. | = If you should need help |
| were 句首倒装 | Were I you, I would wait. | 正式 |
| had 句首倒装 | Had I known, I would have helped. | = If I had known |

### 10.20 比较、方式、地点状语从句

| 类型 | 引导词 | 例句 | 注意 |
| ---- | ------ | ---- | ---- |
| 比较 | than | She runs faster than I do. | 从句可省略重复部分 |
| 同级比较 | as...as | He is as tall as I am. | 否定：not as/so...as |
| 越……越…… | the more...the more | The more you practice, the better you get. | 两边都用比较级 |
| 方式 | as | Do it as I showed you. | 正式标准 |
| 仿佛 | as if / as though | He talks as if he knew everything. | 可用虚拟表达非真实 |
| 地点 | where | Put it where everyone can see it. | where 引导地点状语 |
| 任意地点 | wherever | Sit wherever you like. | “无论哪里” |

| 易错 | 推荐 |
| ---- | ---- |
| Do it like I told you. | Do it as I told you. |
| He is taller than me am. | He is taller than I am. / He is taller than me. |
| The more you read, you learn more. | The more you read, the more you learn. |

### 10.21 从句简化

当从句主语与主句主语一致，或从句结构可由分词/不定式表达时，英语常用简化从句。简化要避免悬垂结构。

| 完整从句 | 简化 | 例句 |
| -------- | ---- | ---- |
| 时间从句 | when/while + -ing/done | While waiting, I checked my email. |
| 原因从句 | -ing / done | Being tired, I went home early. |
| 条件从句 | if + adjective/done | If necessary, call me. |
| 让步从句 | though + adjective/done | Though tired, he continued. |
| 定语从句 | -ing / done / to do | the people waiting outside; the files deleted yesterday |

| 问题 | 不自然/错误 | 推荐 |
| ---- | ----------- | ---- |
| 悬垂分词 | Walking down the street, the rain started. | Walking down the street, I felt the rain start. |
| 主语不一致 | While reading, the phone rang. | While I was reading, the phone rang. |
| 被动误用主动 | The files deleting yesterday are gone. | The files deleted yesterday are gone. |

### 10.22 从句常见错误速查

| 错误类型 | 不自然/错误 | 推荐表达 | 原因 |
| -------- | ----------- | -------- | ---- |
| 间接疑问句倒装 | I don't know where is he. | I don't know where he is. | 名词性从句用陈述句语序 |
| 主语从句用 if | If he agrees is unclear. | Whether he agrees is unclear. | 主语从句通常用 whether |
| 介词后用 if | It depends on if he agrees. | It depends on whether he agrees. | 介词后用 whether |
| that 缺失导致歧义 | The fact he lied shocked us. | The fact that he lied shocked us. | 同位语从句 that 不省略 |
| 非限制性用 that | My car, that I bought last year, is old. | My car, which I bought last year, is old. | 非限制性不用 that |
| 关系词误选 | The city where hosted the event is large. | The city that hosted the event is large. | hosted 缺主语，不用 where |
| 时间从句用 will | I will call when I will arrive. | I will call when I arrive. | 时间/条件从句现在表将来 |
| because/so 双连 | Because it rained, so we stayed. | Because it rained, we stayed. | 英语不双连 |
| although/but 双连 | Although he was tired, but he continued. | Although he was tired, he continued. | 英语不双连 |
| comma splice | He was late, we left. | He was late, so we left. / He was late; we left. | 独立句不能只用逗号连接 |
| 条件句时态错误 | If I will see him, I will tell him. | If I see him, I will tell him. | 第一条件句 if 从句用现在时 |
| 悬垂分词 | Born in 1990, his family moved to Canada. | Born in 1990, he moved to Canada with his family. | 分词逻辑主语要清楚 |

## 11. 主谓一致（Subject-Verb Agreement）

主谓一致指谓语动词在人称和数上与真正的主语保持一致。英语主谓一致的难点通常不在简单句，而在主语被介词短语、定语从句、并列结构、数量表达或倒装结构隔开时。

| 主语 | 谓语 | 例句 |
| ---- | ---- | ---- |
| I | am / 动词原形 | I **am** ready. / I **work** here. |
| you / we / they / 复数名词 | are / 动词原形 | They **are** ready. / The books **belong** to me. |
| he / she / it / 单数名词 | is / 动词第三人称单数 | She **is** ready. / The book **belongs** to me. |
| 不可数名词 | 单数 | The information **is** useful. |
| 从句/动名词/不定式作主语 | 通常单数 | What he said **matters**. / Swimming **is** healthy. |

### 11.1 判断主谓一致的步骤

| 步骤 | 要问的问题 | 例子 |
| ---- | ---------- | ---- |
| 1 | 找谓语动词 | The list of names **is** long. |
| 2 | 找真正主语，不看介词短语 | The **list** of names is long. |
| 3 | 判断主语是单数、复数还是意义可变 | The list = 单数 |
| 4 | 处理特殊结构：and/or/none/there be/定语从句 | Either the manager or the employees are responsible. |
| 5 | 检查时态和助动词 | He does not know. / They do not know. |

| 易错干扰 | 真正主语 | 正确谓语 |
| -------- | -------- | -------- |
| The quality of the products | quality | **is** improving |
| A box of old letters | box | **was** found |
| The people in the room | people | **are** waiting |
| The data from the study | data | **are/is** important，依文体 |

### 11.2 基本一致规则

| 主语类型 | 谓语形式 | 例句 |
| -------- | -------- | ---- |
| 单数可数名词 | 单数 | The student **needs** help. |
| 复数可数名词 | 复数 | The students **need** help. |
| 不可数名词 | 单数 | The advice **was** helpful. |
| this / that | 单数 | This **is** important. |
| these / those | 复数 | These **are** important. |
| one / each / every | 单数 | Each answer **is** checked. |
| both / few / many / several | 复数 | Several answers **were** wrong. |

| 不自然/错误 | 推荐 |
| ----------- | ---- |
| The books is on the table. | The books are on the table. |
| The information are useful. | The information is useful. |
| Each student have a book. | Each student has a book. |

### 11.3 介词短语不决定谓语

介词短语常夹在主语和谓语之间，但通常不影响谓语单复数。判断时先忽略 of, with, along with, together with, as well as, including 等短语。

| 结构 | 真正主语 | 例句 |
| ---- | -------- | ---- |
| N + of + N | 前面的名词 | The **cost** of repairs **is** high. |
| N + with + N | 前面的名词 | The **teacher** with her students **is** here. |
| N + along with + N | 前面的名词 | The **manager**, along with the assistants, **was** late. |
| N + as well as + N | 前面的名词 | The **coach**, as well as the players, **is** responsible. |
| N + including + N | 前面的名词 | The **package**, including the books, **has** arrived. |

| 易错 | 正确 | 原因 |
| ---- | ---- | ---- |
| The list of names are long. | The list of names is long. | 主语是 list |
| The teacher with the students are here. | The teacher with the students is here. | with 短语不是并列主语 |
| The results of the test is surprising. | The results of the test are surprising. | 主语是 results |

### 11.4 and 连接的复合主语

and 连接两个真正的主语时，谓语通常用复数；如果两个词指同一人、同一物、同一概念或一道整体食物/活动，可用单数。

| 结构 | 谓语 | 例句 |
| ---- | ---- | ---- |
| A and B 表两个人/物 | 复数 | Tom and Anna **are** here. |
| A and B 表同一人 | 单数 | The writer and director **is** here. |
| the A and the B 表两个人 | 复数 | The writer and the director **are** here. |
| 固定整体概念 | 单数 | Bread and butter **is** simple food. |
| each/every + A and B | 单数 | Every boy and girl **was** invited. |

| 对比 | 含义 |
| ---- | ---- |
| The secretary and treasurer is absent. | 一个人兼任秘书和财务 |
| The secretary and the treasurer are absent. | 两个人都缺席 |
| Every teacher and student has a badge. | 每位老师和学生都有证件 |

### 11.5 or / nor / either...or / neither...nor

or, nor, either...or, neither...nor 连接主语时，谓语常与靠近谓语的主语一致。这叫就近一致。

| 结构 | 例句 |
| ---- | ---- |
| singular or singular | Either Tom or Anna **is** responsible. |
| plural or plural | Either the managers or the employees **are** responsible. |
| singular or plural | Either the manager or the employees **are** responsible. |
| plural or singular | Either the employees or the manager **is** responsible. |
| neither...nor | Neither the teacher nor the students **are** ready. |

| 不自然/错误 | 推荐 |
| ----------- | ---- |
| Neither my father nor my brothers is going. | Neither my father nor my brothers are going. |
| Either the students or the teacher are wrong. | Either the students or the teacher is wrong. |

### 11.6 不定代词作主语

很多不定代词语义上可指多人，但语法上按单数处理。

| 单数不定代词 | 例句 |
| ------------ | ---- |
| everyone, everybody | Everyone **is** here. |
| someone, somebody | Someone **has** called. |
| anyone, anybody | Does anyone **know**? |
| no one, nobody | Nobody **was** ready. |
| everything, something, anything, nothing | Nothing **seems** wrong. |
| each, either, neither | Neither **is** acceptable. |

| 复数不定代词 | 例句 |
| ------------ | ---- |
| both | Both **are** correct. |
| few / a few | Few **understand** the issue. |
| many | Many **were** invited. |
| several | Several **have** replied. |

| 可单可复 | 判断依据 | 例句 |
| -------- | -------- | ---- |
| all | 指不可数用单数；指复数用复数 | All of the water **is** gone. / All of the files **are** gone. |
| some | 看后面的名词 | Some of the money **is** missing. / Some of the books **are** missing. |
| most | 看后面的名词 | Most of the work **is** done. / Most of the students **are** here. |
| none | 可单可复；现代英语常看语义 | None of the money **is** left. / None of the tickets **are** left. |

### 11.7 each / every / either / neither

each, every, either, neither 作限定词或代词时通常触发单数谓语。

| 结构 | 谓语 | 例句 |
| ---- | ---- | ---- |
| each + 单数名词 | 单数 | Each student **has** a locker. |
| every + 单数名词 | 单数 | Every room **has** a window. |
| each of + 复数名词/代词 | 单数 | Each of the rooms **has** a window. |
| either/neither of + 复数名词/代词 | 单数较正式；口语偶见复数 | Neither of the answers **is** correct. |
| each 放在复数主语后 | 谓语跟主语 | The students each **have** a locker. |

| 易错 | 推荐 |
| ---- | ---- |
| Every students are ready. | Every student is ready. |
| Each of them have a key. | Each of them has a key. |
| The students each has a key. | The students each have a key. |

### 11.8 集合名词

集合名词表示一组人或组织。美式英语多按整体用单数；英式英语更容易按成员用复数。正式写作中要保持同一语境内一致。

| 集合名词 | 整体含义 | 成员含义 |
| -------- | -------- | -------- |
| team | The team **is** winning. | The team **are** arguing among themselves. |
| family | My family **has** a house. | My family **are** all doctors. |
| staff | The staff **is** small. | The staff **are** discussing their schedules. |
| committee | The committee **has** approved the plan. | The committee **are** divided. |
| government | The government **is** changing its policy. | The government **are** arguing among themselves. |

| 写作建议 | 例句 |
| -------- | ---- |
| 美式正式写作默认整体单数 | The company has announced its plan. |
| 强调成员时可改写为 members | The members of the team are arguing. |
| 避免代词前后不一致 | The team is proud of its result. / The players are proud of their result. |

### 11.9 数量、分数、百分比与量词

数量表达的谓语常由“数量所指的东西”决定，而不是只看数字本身。

| 结构 | 谓语 | 例句 |
| ---- | ---- | ---- |
| a number of + 复数名词 | 复数 | A number of students **are** absent. |
| the number of + 复数名词 | 单数 | The number of students **is** increasing. |
| a pair of + 复数名词 | 单数 | A pair of shoes **is** missing. |
| two pairs of + 复数名词 | 复数 | Two pairs of shoes **are** missing. |
| an amount of + 不可数名词 | 单数 | A large amount of money **was** spent. |
| amounts of + 不可数名词 | 复数 | Large amounts of money **were** spent. |
| a lot of / plenty of | 看后面的名词 | A lot of work **is** left. / A lot of people **are** here. |

| 表达 | 谓语 | 例句 |
| ---- | ---- | ---- |
| 分数 + 不可数名词 | 单数 | Half of the money **is** gone. |
| 分数 + 复数名词 | 复数 | Half of the students **are** absent. |
| 百分比 + 不可数名词 | 单数 | Fifty percent of the land **is** protected. |
| 百分比 + 复数名词 | 复数 | Fifty percent of the voters **are** undecided. |
| one of + 复数名词 | 单数 | One of the books **is** missing. |
| one of the + 复数名词 + that/who | 定语从句通常复数 | She is one of the students who **work** hard. |
| the only one of the + 复数名词 + that/who | 定语从句通常单数 | She is the only one of the students who **works** hard. |

### 11.10 时间、金钱、距离、重量作整体

表示时间、金钱、距离、重量、度量等的短语，如果被看作一个总量或整体，谓语通常用单数。

| 表达 | 例句 |
| ---- | ---- |
| 时间总量 | Ten years **is** a long time. |
| 金钱总额 | Fifty dollars **is** too much. |
| 距离总量 | Three miles **is** not far. |
| 重量总量 | Five kilograms **is** enough. |
| 算式 | Two and two **is/are** four. |

如果强调各个单位本身，则可用复数：

| 整体 | 个体 |
| ---- | ---- |
| Ten years is a long time. | The last ten years have changed him. |
| Fifty dollars is too much for this. | The fifty dollars were all marked bills. |

### 11.11 单复数形式特殊的名词

| 名词类型 | 谓语 | 例句 |
| -------- | ---- | ---- |
| 形式复数但意义单数的学科 | 单数 | Mathematics **is** difficult. |
| 形式复数但意义单数的疾病/游戏 | 单数 | Measles **is** contagious. |
| news | 单数 | The news **is** surprising. |
| economics / politics 作为学科 | 单数 | Economics **is** useful. |
| politics 表政治观点/活动 | 可复数 | His politics **are** conservative. |
| police | 复数 | The police **are** investigating. |
| people | 复数 | People **are** waiting. |
| cattle | 复数 | The cattle **are** grazing. |
| scissors, trousers, glasses | 复数 | These scissors **are** sharp. |
| a pair of scissors/trousers/glasses | 单数 | This pair of scissors **is** sharp. |

| data / media / criteria | 常见用法 |
| ----------------------- | -------- |
| data | 学术/技术写作常用复数：The data are clear. 普通语境中也常作集合单数：The data is useful. |
| media | 作“媒体机构整体”常复数或集合单数，依语境：The media are reporting it. |
| criteria | criterion 的复数，正式写作中用复数：The criteria are strict. |

### 11.12 标题、作品名、机构名与专有名词

专有名词的形式不一定决定谓语，要看它指一个整体还是多个实体。

| 主语 | 谓语 | 例句 |
| ---- | ---- | ---- |
| 书名、电影名、文章名 | 单数 | **Great Expectations** is a novel. |
| 国家名形式复数但指单一国家 | 单数 | The United States **is** a large country. |
| 公司/机构名 | 通常单数 | Google **is** expanding its services. |
| 体育队名 | 美式常单数，英式可复数 | Manchester United **is/are** playing tonight. |
| the + 形容词表示一类人 | 复数 | The rich **are** not always happy. |

### 11.13 there be / here be 与倒装

there be 和 here be 结构中，真正主语通常在动词后面，谓语要跟后面的名词一致。

| 结构 | 例句 |
| ---- | ---- |
| there is + 单数/不可数 | There **is** a problem. / There **is** water on the floor. |
| there are + 复数 | There **are** several problems. |
| here is + 单数 | Here **is** your key. |
| here are + 复数 | Here **are** your keys. |

| 注意 | 例句 |
| ---- | ---- |
| 口语中 there's + 复数常见，但正式写作用 there are | There are two reasons. |
| 并列名词时常与第一个名词一致 | There is a book and two pens on the desk. |
| 倒装句要找动词后的主语 | On the wall **hang** two paintings. / On the wall **hangs** a painting. |

### 11.14 定语从句中的主谓一致

定语从句的谓语要与关系词所指的先行词一致。

| 结构 | 例句 | 说明 |
| ---- | ---- | ---- |
| who/that 指单数 | The student who **works** hard passed. | who = student |
| who/that 指复数 | The students who **work** hard passed. | who = students |
| which 指单数 | The book which **contains** the map is old. | which = book |
| which 指复数 | The books which **contain** the maps are old. | which = books |
| one of + 复数名词 + who/that | She is one of the people who **know** the truth. | who = people |
| the only one of + 复数名词 + who/that | She is the only one of the people who **knows** the truth. | who = the only one |

### 11.15 主语从句、动名词和不定式作主语

一个从句、动名词短语或不定式短语作主语时，通常按单数处理；如果两个并列主语表达不同事情，则用复数。

| 主语 | 谓语 | 例句 |
| ---- | ---- | ---- |
| that 从句 | 单数 | That he lied **is** obvious. |
| wh- 从句 | 通常单数 | What he needs **is** time. |
| wh- 从句表示多个事物 | 可复数 | What we need **are** better tools. |
| 动名词短语 | 单数 | Reading books **is** useful. |
| 不定式短语 | 单数 | To leave now **would** be rude. |
| 两个并列短语 | 复数 | Reading and writing **are** different skills. |

### 11.16 主谓一致与助动词

一致不仅体现在 be 和普通动词 -s，也体现在 do/does, have/has 以及助动词后的动词形式。

| 主语 | 正确 | 错误 |
| ---- | ---- | ---- |
| he/she/it | She **does** not know. | She do not know. |
| I/you/we/they | They **do** not know. | They does not know. |
| he/she/it | He **has** finished. | He have finished. |
| I/you/we/they | They **have** finished. | They has finished. |
| 助动词后 | He **does not know**. | He does not knows. |
| 情态动词后 | She **can go**. | She can goes. |

### 11.17 意义一致与形式一致

英语有时按语法形式一致，有时按意义一致。正式写作中优先保持清晰和前后一致。

| 类型 | 形式一致 | 意义一致 |
| ---- | -------- | -------- |
| 集合名词 | The committee **is** meeting. | The committee **are** divided. |
| none | None of the money **is** left. | None of the tickets **are** left. |
| titles | The Birds **is** a film. | The birds **are** flying. |
| quantities | Ten dollars **is** enough. | The dollars **were** counted. |

### 11.18 常见错误速查

| 错误类型 | 不自然/错误 | 推荐表达 | 原因 |
| -------- | ----------- | -------- | ---- |
| 被 of 短语误导 | The list of names are long. | The list of names is long. | 主语是 list |
| 不可数名词误作复数 | The advice are useful. | The advice is useful. | advice 不可数 |
| each/every 误用复数 | Every student have a card. | Every student has a card. | every + 单数 |
| with 误作 and | The teacher with the students are here. | The teacher with the students is here. | with 不构成复合主语 |
| and 同一概念 | Bread and butter are my breakfast. | Bread and butter is my breakfast. | 整体概念可单数 |
| or/nor 就近错误 | Either the students or the teacher are wrong. | Either the students or the teacher is wrong. | 谓语跟近主语 |
| a number/the number 混淆 | The number of errors are small. | The number of errors is small. | the number 作单数 |
| there be 错误 | There is many reasons. | There are many reasons. | 真正主语是 reasons |
| 定语从句一致 | She is one of the students who works hard. | She is one of the students who work hard. | who 指 students |
| only one 例外 | She is the only one of the students who work hard. | She is the only one of the students who works hard. | who 指 the only one |
| 助动词后重复 -s | He doesn't knows. | He doesn't know. | does 已体现一致 |
| 复数形式单数意义 | The news are bad. | The news is bad. | news 是单数 |
| pair 结构 | These pair of glasses are new. | This pair of glasses is new. | 主语是 pair |
| 倒装误判主语 | On the wall hangs two paintings. | On the wall hang two paintings. | 主语是 paintings |

## 12. 感叹词与应答（Interjections and Responses）

感叹词和应答语通常不参与句子的主谓结构，但会强烈影响语气、礼貌程度和口语自然度。学习这一章不要只背“中文意思”，更要注意场景、强度和语域。

| 类型 | 功能 | 例子 | 注意 |
| ---- | ---- | ---- | ---- |
| 感叹词 | 直接表达情绪 | wow, ouch, ugh | 常独立成句 |
| 应答语 | 对别人话语作回应 | yes, sure, exactly | 体现态度和礼貌 |
| 填充词 | 争取思考时间 | well, um, uh | 正式演讲中少用 |
| 话语标记 | 组织话轮和语气 | actually, anyway, you know | 不是句子核心成分 |
| 警示/呼喊 | 立即提醒或求助 | watch out, help | 语气强，常用感叹号 |

### 12.1 感叹词的标点与语气

| 标点 | 语气 | 例子 |
| ---- | ---- | ---- |
| 感叹号 | 强烈、突然 | Wow! That's amazing. |
| 逗号 | 轻微插入 | Oh, I see. |
| 问号 | 惊讶、没听清、反问 | Huh? What did you say? |
| 句号 | 克制、冷淡或平静 | Well. That's unexpected. |
| 破折号/省略号 | 犹豫、停顿 | Um... I'm not sure. |

| 写作建议 | 说明 |
| -------- | ---- |
| 正式写作少用强烈感叹词 | 学术、商务报告中少写 Wow! |
| 对话可保留自然感叹词 | 小说、聊天、字幕中很常见 |
| 同一段不要连续滥用感叹号 | 多个感叹号会显得幼稚或情绪化 |
| 脏话、宗教表达要慎用 | damn, hell, God 等可能冒犯人 |

### 12.2 惊讶、赞叹与意外

| 表达 | 强度 | 语域 | 例句 |
| ---- | ---- | ---- | ---- |
| oh | 弱 | 通用 | Oh, I didn't know that. |

### 12.10 填充词与话语标记

| 表达 | 功能 | 例句 |
| ---- | ---- | ---- |

| like | 非正式填充或举例 | It was like a dream. |
| so | 开始话轮或总结 | So, what should we do? |

| -------------- | ------ |

## 14. 固定搭配、短语动词与习语（Collocations, Phrasal Verbs and Idioms）

固定搭配、短语动词和习语决定英语是否自然。它们不只是词汇问题，也涉及动词结构、宾语位置、介词选择、语域和可否按字面理解。

| 类型 | 核心问题 | 例子 | 学习重点 |
| ---- | -------- | ---- | -------- |
| 固定搭配 | 哪些词自然地一起出现 | make a decision, heavy rain | 词与词的组合 |
| 短语动词 | 动词 + 小品词形成新义 | give up, look up, run into | 宾语位置、是否可分 |
| 介词动词 | 动词 + 介词固定搭配 | depend on, listen to | 介词不能随便换 |
| 习语 | 整体意义不等于字面意义 | break the ice, under the weather | 语境和语域 |
| 固定句型 | 整个结构固定 | It is worth doing. | 结构整体记忆 |

### 14.1 固定搭配总览

| 搭配类型 | 结构 | 例子 |
| -------- | ---- | ---- |
| 动词 + 名词 | verb + noun | make a decision, take a risk |
| 形容词 + 名词 | adjective + noun | heavy rain, strong evidence |
| 副词 + 形容词 | adverb + adjective | highly likely, deeply concerned |
| 动词 + 副词 | verb + adverb | apologize sincerely, argue strongly |
| 名词 + 动词 | noun + verb | prices rise, a problem arises |
| 名词 + 介词 | noun + preposition | reason for, access to |
| 形容词 + 介词 | adjective + preposition | interested in, responsible for |
| 动词 + 介词 | verb + preposition | depend on, agree with |

**实用原则**：不要只记单词，要记“词块”。例如不要只记 decision，要记 make a decision, reach a decision, a difficult decision。

### 14.2 do / make / take / have / give / get

这些高频动词意义很宽，搭配固定，不能逐词翻译。

| 动词 | 常见搭配 | 例句 |
| ---- | -------- | ---- |
| do | do homework, do business, do research, do your best | She is doing research on climate. |
| make | make a decision, make progress, make a mistake, make money | We made a mistake. |
| take | take a break, take a risk, take responsibility, take notes | Take notes during the meeting. |
| have | have a look, have a conversation, have lunch, have trouble | We had a short conversation. |
| give | give advice, give a speech, give permission, give someone a chance | She gave a speech. |
| get | get a job, get permission, get ready, get better | He got permission to leave. |

| 中文意图 | 自然英文 | 不自然 |
| -------- | -------- | ------ |
| 做决定 | make a decision | do a decision |
| 犯错 | make a mistake | do a mistake |
| 做研究 | do research / conduct research | make research |
| 拍照 | take a photo | make a photo |
| 休息一下 | take a break / have a break | do a break |
| 取得进步 | make progress | get progress |

| 搭配 | 自然表达 | 不自然表达 |
| ---- | -------- | ---------- |

| 风大 | strong wind | heavy wind |

| 严重问题 | a serious problem | a heavy problem |
| 高度优先事项 | a high priority | a tall priority |
| 深切关心 | deep concern | strong concern 也可，但语气不同 |
| 浓茶 | strong tea | thick tea |
| 浓汤 | thick soup | strong soup |
| 高温 | high temperature | tall temperature |

| 形容词 | 常见名词搭配 |
| ------ | ------------ |
| strong | evidence, argument, wind, smell, coffee |
| heavy | rain, traffic, workload, burden, smoker |
| high | price, speed, temperature, priority, risk |
| deep | concern, understanding, sleep, water |
| serious | problem, injury, illness, mistake |
| major | issue, change, factor, problem |

### 14.6 短语动词总览

短语动词由动词加小品词构成。小品词看起来像介词或副词，但它常改变整个动词的意义。

| 类型 | 结构 | 例子 | 宾语位置 |
| ---- | ---- | ---- | -------- |
| 不及物短语动词 | verb + particle | The plane took off. | 无宾语 |
| 可分及物短语动词 | verb + object + particle / verb + particle + object | turn the light on / turn on the light | 代词必须放中间 |
| 不可分及物短语动词 | verb + particle + object | look after the child | 宾语放后面 |
| 三词短语动词 | verb + particle + preposition | put up with the noise | 通常不可分 |
| 介词动词 | verb + preposition | listen to music | 介词后接宾语 |

| 判断问题 | 例子 |
| -------- | ---- |
| 是否有宾语 | The car broke down. 无宾语 |
| 宾语能不能放中间 | Turn off the light. / Turn the light off. |
| 代词放哪里 | Turn it off. 不能说 turn off it |
| 是否可按字面理解 | look up a word 不是“向上看” |

### 14.7 可分与不可分短语动词

| 代词宾语必须在中间 | Turn it off. | Turn off it. |

| fill out | 填写 | Fill out the form. |
| look up | 查找 | Look it up. |
| throw away | 扔掉 | Throw it away. |
| write down | 写下 | Write it down. |

| 不可分短语动词 | 含义 | 例句 |
| -------------- | ---- | ---- |
| look after | 照顾 | She looks after her brother. |
| run into | 偶遇；撞上 | I ran into an old friend. |
| come across | 偶然发现 | I came across an old letter. |
| get over | 克服；恢复 | He got over the illness. |

### 14.10 短语动词与单词动词的语域差别

短语动词常更口语、更自然；拉丁来源的单词动词常更正式。两者不是简单替换，语气和搭配会变。

| 较口语 | 较正式 | 例句 |
| ------ | ------ | ---- |
| put off | postpone | We put off the meeting. / The meeting was postponed. |
| find out | discover | We found out the cause. |
| set up | establish | They set up a lab. |
| go up | increase | Prices went up. |
| go down | decrease | Costs went down. |
| carry out | conduct | They carried out a survey. |
| look into | investigate | The police are looking into it. |
| turn down | reject | She turned down the offer. |
| put up with | tolerate | I can't put up with the noise. |

| 写作建议 | 说明 |
| -------- | ---- |
| 日常口语优先自然短语动词 | Prices went up. |
| 学术或正式报告可用正式动词 | Prices increased. |
| 不要为了正式而生硬替换 | establish a meeting 不等于 set up a meeting |

### 14.11 习语总览

习语的整体意思通常不能从单词字面直接推出。使用习语要注意语域、场景和是否会让表达过于随意。

| 习语 | 含义 | 例句 |
| ---- | ---- | ---- |
| break the ice | 打破沉默；活跃气氛 | A joke helped break the ice. |
| under the weather | 身体不舒服 | I'm feeling under the weather. |
| once in a blue moon | 很少 | He calls once in a blue moon. |
| the ball is in your court | 该你行动了 | I've sent the proposal; the ball is in your court. |
| cost an arm and a leg | 非常贵 | The repair cost an arm and a leg. |
| hit the nail on the head | 说中要点 | You hit the nail on the head. |
| on the same page | 意见一致 | Let's make sure we're on the same page. |
| a blessing in disguise | 因祸得福 | Losing that job was a blessing in disguise. |
| get the hang of | 掌握窍门 | You'll get the hang of it. |
| cut corners | 偷工减料；走捷径 | Don't cut corners on safety. |

### 14.12 习语的语域和风险

| 场景 | 是否适合习语 | 建议 |
| ---- | ------------ | ---- |
| 朋友聊天 | 适合 | 可用常见习语 |
| 商务会议 | 可少量使用 | 用清楚、常见的表达 |
| 学术写作 | 通常不适合 | 用直接、精确表达 |
| 法律/技术文档 | 不适合 | 避免歧义 |
| 跨文化沟通 | 谨慎 | 优先透明表达 |
| 考试作文 | 可少量 | 不要堆砌冷僻习语 |

| 不推荐 | 推荐 |
| ------ | ---- |
| This policy is a double-edged sword, a blessing in disguise, and the ball is in our court. | This policy has both benefits and risks, so we need to act carefully. |
| The data opened a can of worms. | The data revealed several unexpected problems. |
| We should cut corners to save time. | We should simplify the process without reducing quality. |

### 14.13 固定句型和词块

| 句型 | 例句 | 注意 |
| ---- | ---- | ---- |
| be worth doing | This book is worth reading. | worth 后接 -ing |
| have difficulty doing | I had difficulty finding it. | 不说 difficulty to do |
| spend time doing | She spent two hours reading. | spend + 时间 + -ing |
| prevent someone from doing | The rain prevented us from leaving. | from 常保留 |
| be used to doing | I'm used to working late. | 习惯于 |
| used to do | I used to work late. | 过去常常 |
| would rather do | I'd rather stay home. | 后接动词原形 |
| had better do | You'd better leave now. | 后接动词原形 |
| make someone do | They made him apologize. | 主动中不带 to |
| be made to do | He was made to apologize. | 被动中恢复 to |

### 14.14 搭配学习方法

| 方法 | 做法 | 例子 |
| ---- | ---- | ---- |
| 以中心词扩展 | 从一个名词列动词和形容词 | decision: make, reach, final |
| 按语境记忆 | 记整个短句 | We reached an agreement. |
| 区分正式和口语 | 同义表达分层 | put off vs postpone |
| 记录介词 | 把介词作为词的一部分 | responsible for, access to |
| 查例句 | 看真实搭配 | strong evidence, heavy rain |
| 避免逐词翻译 | 先找英文惯用组合 | take a photo, not make a photo |

| 记忆单位 | 不推荐 | 推荐 |
| -------- | ------ | ---- |
| 单个词 | decision = 决定 | make a decision / reach a decision |
| 单个动词 | depend = 依靠 | depend on someone / depend on the result |
| 单个形容词 | interested = 感兴趣 | interested in history |
| 单个习语 | break the ice | use a joke to break the ice |

### 14.15 常见错误速查

| 错误类型 | 不自然/错误 | 推荐表达 | 原因 |
| -------- | ----------- | -------- | ---- |
| 逐词翻译 | do a decision | make a decision | decision 搭配 make |
| 动词搭配错 | make homework | do homework | homework 搭配 do |
| 名词搭配错 | strong rain | heavy rain | 雨大用 heavy |
| 形容词搭配错 | tall temperature | high temperature | 温度高用 high |
| 介词多余 | discuss about the issue | discuss the issue / talk about the issue | discuss 是及物动词 |
| 介词错误 | depend of | depend on | 固定介词 on |
| 双宾语错误 | explain me the rule | explain the rule to me | explain 不用 explain someone something |
| 可分短语动词代词位置错 | turn off it | turn it off | 代词宾语放中间 |
| 不可分短语动词拆开 | look the child after | look after the child | look after 不可分 |
| 三词短语动词拆开 | put it up with | put up with it | 三词短语通常不可分 |
| to 后误用原形 | I look forward to meet you. | I look forward to meeting you. | 这里 to 是介词 |
| used to 混淆 | I am used to work late. | I am used to working late. | be used to 后接 -ing |
| 习语堆砌 | The project is a piece of cake and a game changer and a win-win. | The project is simple and useful. | 习语过多显得不自然 |
| 习语语域不合 | The experiment was a piece of cake. | The experiment was straightforward. | 学术语境用直接表达 |
