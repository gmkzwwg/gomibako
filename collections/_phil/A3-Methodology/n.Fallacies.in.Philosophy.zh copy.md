## P1 什么样的推理才算真正支持了结论？

### 从信念到主张：论证在什么条件下才成为必要

人对自身、对周遭世界、对所感知到的实在持有大量思想、意见与信念。这些内容只有在被表述为`主张`（*claim*）之后，才进入可以被评价的范围。主张是陈述句、命题，或陈述句的一部分，至少包含一个主语名词短语与一个限定动词。它的决定性属性是具有真值：要么事情就是如此，要么并非如此。

主张彼此之间在**如何被确立**这一点上差别极大，而这一差别决定了论证在什么时候才成为必要。

有一类主张的真假可以被直接裁决。"有些蜘蛛是橙色的""多数婴儿出生时有两只手""撒切尔是英国首位女首相""月球上有环形山"——几乎无人对这些主张有异议，因为确立它们所需要的东西唾手可得。同样，"太阳是一颗立方体形状的恒星""动物细胞内含有该动物的微缩版本""比尔·盖茨写了《战争与和平》""一个人可以在同一时间、同一方面既站着又坐着"之所以被普遍判定为假，也是因为裁决手段现成可用。

另有一类主张，确立它们所需的证据远远超出"指着时空世界中的某物"这种做法所能提供的范围：灵魂是否在肉体死亡后继续存在、宇宙中的一切事件（包括人所引发的事件）是否都被决定要以其实际发生的方式发生、是否存在多个平行宇宙。还有一类主张更为特殊，其证据可能只对当事人有效——"我确实存在，因为我意识到自己在存在""我记得今天早上吃了鸡蛋""这个物体在我的视野中显现为绿色"。

**区别：** 真正的分水岭不在于主张的题材，而在于它是否"呼唤"一个理由。"撒切尔是英国首位女首相"可以凭历史记录直接判定真假；"撒切尔是英国最好的首相"则无法如此处置，它需要有人把理由摆出来并使他人信服。前者需要的是证据，后者需要的是论证。

**规范性主张几乎总是属于后者。** 任何传达"应当""理应""必须"做某事的主张，通常都要求一个论证。若有人说"不应当杀死家中见到的蜘蛛"，其论证大致是：

```
（1）蜘蛛在住宅的缝隙附近结网，捕食蚂蚁、蚊子这类一旦进入室内就会造成麻烦的昆虫。
（2）蜘蛛做这件事是好的，而它们必须活着才能做。
（3）应当做或促成好的事情，不应当做或促成坏的事情。
⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯
（4）因此，不应当杀死家中见到的蜘蛛。
```

*值得预先留意的是第（3）个前提。它是一个纯粹规范性的桥接前提，把前两个描述性前提与规范性结论连接起来。事实与规范之间是否存在这样一座桥、桥的承重如何，构成了一整组独立的问题。*

即使是看起来最稳固的那一类主张，也并非无懈可击。若干路人在街角目睹警车追逐并一致声称"被追的车是一辆红色 SUV"，警官通常有理由采信。但错觉是可能的，把并不存在的东西投射为存在也是可能的，甚至成群的人也曾如此。**因此论证并不是知识的常态，而是知识在某一点上遇到阻力时的产物。**

### 证据的七种形态及其各自的脆弱之处

`证据`（*evidence*）是为某一主张的真或假提供支持（确认、佐证、证实、证明）的事实或概念。支持的方式并非只有一种，而是至少有七种形态。以"埃菲尔铁塔"为例，可以看到它们如何层层递推：

1. **时空事物的直接感官证据**，通过视、听、触、味、嗅获得。亲自到巴黎看见铁塔，支持"埃菲尔铁塔在巴黎"为真。
2. **经由可靠校准的装置、机器或仪器获得的间接感官证据**，如放大镜、潜望镜、照相机、录像机、望远镜、显微镜、各类量具。从未到过法国，但看到铁塔的照片与影像，同样支持该主张。
3. **所信赖之人的证言**。从未到过法国，但父母去过并告知看见了铁塔。
4. **某一领域专家的证言**。铁塔的工程师古斯塔夫·埃菲尔告知其他工程师铁塔可以承载电梯系统，电梯工程师据此开工。
5. **科学中那样的权威性解释**。牛顿以来的研究者已经说明引力如何运作，这解释了为何铁塔这样的致密物体不会飘入大气层。
6. **逻辑或数学蕴涵**。若"铁塔位于巴黎"为真且"巴黎位于法国"为真，则凭借"位于"关系的`传递性`（*transitivity*），可以绝对确定地断定"铁塔位于法国"。
7. **论证本身充当证据**。`归谬法`（*reductio ad absurdum*）两千年来被用于证明某人的主张为假，其形式是：若你的主张 X 为真，则导致荒谬、矛盾或悖理的 Y；而 Y 不可接受；因此 X 为假。填入实质内容即为：若诺亚把每一物种的两只都装进了方舟，则方舟必须有澳大利亚那么大，这是荒谬的（何况也不是圣经所述——方舟约长 520 英尺、宽 86 英尺、高 52 英尺）；无法接受诺亚造了一艘澳大利亚大小的方舟；因此"诺亚装下了每一物种的两只"为假。

这七种形态与先前那批主张一一对应："有些蜘蛛是橙色的"依靠第一类；"多数婴儿出生时有两只手"依靠第四类（医生与研究者汇集的数据）；"撒切尔是首位女首相"依靠经由历史记录的第四类；"月球上有环形山"同时依靠第一类（肉眼可见）与第二类（自伽利略在十七世纪初开始的望远镜观察）。"太阳是立方体"之为假既依靠第一类，也依靠万有引力定律的一部分内容——恒星这类天体在旋转中被均匀地拉向其质心，从而形成球形而非立方体，这是第五类。"细胞内有微缩动物"之为假依靠显微镜，即第二类——细胞内只有细胞核、核糖体、线粒体等细胞器。"一个人可以同时同方面既站又坐"之为假则依靠逻辑中的`不矛盾律`，即第六类。

把这份清单摆出来，其价值不止于分类。**证据的每一种形态都有其特有的失效方式，而后文将要处理的大量推理错误，正是对某一种证据形态的误用或过度信赖。** 前两类涉及感官——无论是裸感官还是经由仪器的感官——其可靠性在知觉的建构性、主观验证与可得性误差那里会受到系统性的削弱。第三类与第四类涉及他人的话语，由此派生出不当诉诸权威、诉诸人民、无数赝品这一整组关于"证言能承担多少证明责任"的问题。第五类涉及科学共同体给出的权威解释，针对它的典型攻击方式是伽利略策略、年代势利与不可证伪主张。第六类是演绎推论本身，全部形式谬误正是它的失败面。第七类——论证充当证据——则把问题推到元层：既然论证可以是证据，那么"某个论证犯了谬误"这一发现本身能推出什么，就成了一个必须单独回答的问题。

### 前提、结论与推论：论证如何区别于解释和定义

当一个主张被当作从另一个或另几个已被认定为真的主张推出时，发生的是`推论`（*inference*）。"逻辑地跟随于"与"可以合法地从……推出"是同一件事的两种说法。

把这种关系呈现出来，就得到`论证`（*argument*）。论证由至少两个主张构成，其中一个充当`结论`（*conclusion*），其余充当`前提`（*premise*）。前提是被用来支持、支撑、辩护或给出接受结论之理由的主张；结论是被前提所支持、所辩护、被展示为由前提推出的主张。最简单的论证只需一个前提：

```
前提：弗兰克是单身汉。
⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯
结论：因此弗兰克是未婚男性。
```

通常论证有不止一个前提。把论证写成**标准形式**——前提在上，一条横线，结论在下——并非排版习惯，而是一项技术：横线的作用是让"结论是否真的跟随前提"成为一个可以在视觉上判定的问题。自然语言中的前提与结论则由指示词标记，前提指示词包括"因为""既然""鉴于""由于""理由是"，结论指示词包括"所以""因此""故而""这表明""由此可以推出"。

**区别：** 论证、解释与定义在语法上常常同形，但在功能上不同，而区分它们的依据不在句子内部。考虑：

```
（1）天主教徒是基督徒。
（2）基督徒信仰一神。
⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯
（3）因此天主教徒信仰一神。
```

这组命题只有在有人需要被说服"天主教徒信仰一神"时才是论证。稍加考察即可发现，按定义天主教徒是基督徒，又按定义基督徒信仰一神，因此并不存在需要被说服的余地——这是一次定义的展开。再考虑"车只有在电池工作时才能发动；电池不工作；因此车发动不了"。这完全可以是修车师傅对"我的车为什么发动不了"的回答，此时它是解释而非论证。同理，"路牌写着离芝加哥十英里；路牌由合格的公路人员设置；因此芝加哥很可能在十英里外"更像是对"还有多远"的说明。

**说服才是论证之所以存在的理由。** 彼得在看台上说"X 队今天很可能赢"，他希望所有人（包括他自己）相信这是真的。保罗不满足于此，他要求证明、要求被说服。彼得于是给出理由：X 队过去两年赢得冠军赛；X 队本赛季数据全联盟最好。这些理由即前提。保罗若接受前提为真，便也接受结论。论证的全部机制在此暴露无遗：它是一次以理由换取认同的交易。

*这一区分在后文有直接后果。把一个解释误读为一次辩护，是一类独立的错误：陈述某事为何发生，与主张某事因此正当，是两件事。*

### 必然支持与概率支持：演绎与归纳的三条分界

推理有两大类型，各自使用相应类型的论证。

`演绎论证`（*deductive argument*）具有三条特征。其一，结论被认为必然地（绝对地、无可置疑地）跟随前提。其二，若结论确实跟随前提，且所有前提确实为真，则结论不可能为假——结论必须为真。其三，前提蕴涵结论，也就是说，结论已经包含在前提之中；即便结论未被明白说出，它也隐含地在场，可以从前提中"读"出来。

`归纳论证`（*inductive argument*）在三条上都与之相反。其一，结论只是有可能地、大概地跟随前提，而非必然地跟随；这种支持是有程度的，可以设想为从 0.000…1（结论最不可能被推出）经 0.1、0.2……0.9 直到 0.999…（结论最有可能被推出）的连续标度。其二，即使所有前提为真，结论仍然可能为假。其三，前提不蕴涵结论——至少不以演绎论证中那种方式蕴涵。

对照两组实例即可看清差别。"去上班只有两条路，要么一号公路要么主街；一号公路因施工封闭；所以今天必须走主街"——若前提确实为真，结论是唯一可能的。"我以前的跑鞋是 X 牌真皮的，用了一年；我打算买的新鞋也是 X 牌真皮的；所以这双新鞋也能用一年"——新鞋完全可能撑不到一年，更妥当的措辞是"很可能能用一年"。

归纳论证对**证据数量**的敏感性在此已经显露。一个同类案例提供某种支持，一百个提供更多支持，一千个提供更多。反向亦然："袋里共有十颗豆，我不知道颜色；已经摸出的九颗都是红的；所以下一颗也是红的"——若第二个前提改为"已经摸出的五颗都是红的"，信心会下降；改为"两颗"，会进一步下降。这条敏感性是后文关于样本与概括的一整组问题的起点。

演绎领域内有两套推理系统。第一套处理**事物的范畴**，可追溯至亚里士多德，称为`范畴逻辑`（*categorical logic*），亦称传统逻辑、三段论逻辑或亚里士多德逻辑。**亚里士多德**（*Aristotle*，前 384—前 322）在《前分析篇》中铺陈的这套系统，主宰了西方与中东大部分地区的思想约两千年。第二套处理**主张本身**，称为`命题逻辑`（*propositional logic*），亦称语句逻辑。它在西方同样可追溯至亚里士多德，但第一次得到认真处理是在斯多亚派哲学家**克律西波**（*Chrysippus*，约前 280—前 205）那里。克律西波记录下的正确推理模式包括：

```
（A）如果第一，则第二。第一。因此第二。
（B）如果第一，则第二。并非第二。因此并非第一。
（C）要么第一要么第二。并非第一。因此第二。
```

前述"一号公路／主街"的例子正是（C）的实例；"若我的当事人作案，他当时会在芝加哥；但他不在芝加哥；因此他没有作案"则是（B）的实例。这两套系统各自的规则，以及违反规则所产生的失败模式，构成 P3 与 P4 的全部内容。

### 两步检验与四个评价词：有效、可靠、强、有力

评价（分析、批判）任何一个论证，都要走完一个两步程序：

```
第一步：确认结论确实从前提推出。
第二步：确认论证中所有前提都为真。
```

**顺序不可颠倒，而且第一步必须最先做。** 理由在于，未通过第一步的论证无论前提多真都无法成立，检查其前提是徒劳的。把论证写成标准形式的价值也正在于此：它让第一步成为可视的。

两步在两个推理领域中各有专名。在演绎领域，结论确实跟随前提意味着论证`有效`（*valid*），不跟随则`无效`（*invalid*）；严格地说，**演绎领域中一个无效的论证就是一个犯了形式谬误的论证**。当论证既有效、所有前提又为真时，称之为`可靠`（*sound*，亦译"健全"）；只要无效或有任一前提为假，即为`不可靠`。在归纳领域，结论很可能跟随前提意味着论证`强`（*strong*），不然则`弱`（*weak*）；**一个弱的论证就是一个犯了非形式谬误的论证**。当论证既强、所有前提又为真时，称之为`有力`（*cogent*）；只要弱或有任一前提为假，即为`无力`。

|  | 第一步通过 | 两步都通过 | 第一步失败 |
| --- | --- | --- | --- |
| 演绎 | 有效 | 可靠 | 犯了形式谬误 |
| 归纳 | 强 | 有力 | 犯了非形式谬误 |

两个领域中各有三种失败方式：第一步失败、有假前提、二者兼有。**四个诊断性范例必须成组来看，单看任何一个都不足以确立这套坐标。**

第一个范例展示第一步通过而第二步失败：

```
（1）太阳是一颗恒星。          ← 真
（2）所有恒星都是立方体形状的。 ← 假
⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯
（3）因此太阳是立方体形状的。   ← 确实跟随
```

结论绝对地跟随前提，而且除了它之外推不出别的东西。但第二个前提为假，因而结论也为假。这个论证有效但不可靠。**关键在于：它没有犯任何谬误。**

第二个范例展示第二步通过而第一步失败：

```
（1）计算机会计算。            ← 真
（2）人的心灵也会计算。        ← 真
⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯
（3）因此心灵是一台计算机。    ← 并不跟随
```

两个前提都绝对为真，但结论不跟随。这个论证无效，因而不可靠。

第三与第四个范例把同一对区分移入归纳领域。"在超过一百万项对照研究中，一贯显示人们采用每日五千卡路里的饮食一个月可减重百分之十；你下个月开始这一饮食；因此在其他条件相同的情况下，你很可能也会在一个月内减重百分之十"——没有犯谬误，结论确实很可能跟随，但第一个前提是凭空捏造的。这个论证强但无力。反过来，"他以会计为业；他认为全球变暖正在发生；因此全球变暖正在发生"——两个前提都真，但结论并不很可能跟随。这个论证弱，因而无力，它犯的是不当诉诸权威。

**方法：** "心灵是计算机"之所以看起来可信，是因为人工智能六十年来的进展给了它一层直觉外衣。要剥掉这层外衣，有一项可以反复使用的技术——构造一个**形式完全相同、但结论明显荒谬**的论证：

```
（1）鸟会飞。
（2）飞机也会飞。
⎯⎯⎯⎯⎯⎯⎯⎯
（3）因此飞机是鸟。
```

飞机不因为会飞就成了鸟。既然后一论证的结论不跟随，而前一论证与它形式相同，那么前一论证的结论同样不跟随。**这一技术之所以有效，恰恰因为演绎有效性只取决于形式：任何一个形式的反例都足以推翻该形式的全部实例。** 它在后文的中项不周延、弱类比、证明太多等处会被反复调用。

## P2 谬误是什么，这个范畴又是怎么来的？

### 谬误的定义：为什么它只针对两步检验的第一步

`谬误`（*fallacy*）是这样一种推理错误：某人提出一个论证，其中结论被当作已从前提得到恰当推出，而实际上该结论并不、也不应当从这些前提被推出。

这个定义的力量全部来自它所排除的东西。它把"论证坏在哪里"精确地锁定在两步检验的第一步上，因而带来两条不可放弃的限定。

**第一条：前提为假不构成谬误。** 前述"太阳是立方体"的论证前提有假、结论为假，是一个应当被拒绝的坏论证——但它没有犯任何谬误。它的推理完全正确，只是被喂入了错误的材料。

**第二条：结论为假不构成谬误，结论为真也不豁免谬误。** 考虑：

```
（1）如果亚特兰大是佐治亚州的首府，那么它在美国境内。
（2）亚特兰大在美国境内。
⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯
（3）因此亚特兰大是佐治亚州的首府。
```

这是一个无效论证，犯的是肯定后件的形式谬误。然而它的结论完全为真。真与假是主张的属性，谬误是推理的属性，二者互不蕴涵。**这一点后来将在元层上约束整本书：指出某人犯了谬误，绝不等于证明了他的结论为假。**

定义中同样不包含意图。提出谬误者可能全然没有意识到结论不跟随前提——人类历史上多数谬误大概属于这种情形，需要后来的思考者经分析才指出错误。另一些情形则相反，有人希望诱使他人以为结论跟随前提，政治宣传与商业推销中常见的正是这种操作。因此谬误的语言中往往兼有含混与歧义，有时还附带欺骗意图。但**是否构成谬误，与提出者的动机无关**。

这一界定之所以值得如此严格地守住，是因为谬误性思维的后果并不限于论辩桌面。它影响公共政策、民法，乃至世界各地被当作道德律的东西。以"圣经说上帝存在，因此上帝存在"这类循环论证为例，西方文明史上有多少不义、剥削与暴行曾以它为正当性来源？以"他们都是那样的"这类轻率概括为例，人类历史上又有多少奴隶制法律、宗教法律与选举法律以这个谬误性结论为基础？

### 形式与非形式：判定依据是结构还是内容

谬误大体分为两类。

`形式谬误`（*formal fallacy*）是这样一类：判定结论不跟随前提，只需**考察并理解论证的结构或形式**，而不必考察其内容。此处所需做的只是检查论证是否按照特定逻辑系统的原则被正确地搭建起来——若否，则论证是谬误的。若认为"如果下雨，人行道就是湿的"，接着看到"人行道是湿的"，于是断定"在下雨"，所犯的便是著名的肯定后件：

```
（1）R ⊃ S。            （1）R ⊃ S。
（2）R。                （2）S。
⎯⎯⎯⎯⎯⎯               ⎯⎯⎯⎯⎯⎯
（3）S。                （3）R。
   肯定前件                肯定后件
```

一旦把主张符号化，正确结构的正确性就变得显豁；同样，一旦看到正确结构被改动——R 与 S 换了位置——形式谬误的事实也随之显豁。人行道之所以是湿的，可能是洒水器、可能是水管破裂、可能是当天早些时候下过雨。

`非形式谬误`（*informal fallacy*）则相反：判定结论不跟随前提，必须考察论证的**内容**。而论证的内容由主张构成，主张又借语言表达，因此识别非形式谬误实际上是对所用语言——以及语言所指涉之物——的考察。它涉及的是对词语或语法的滥用与误用、因偏见或潜在预设而产生的误解、对事实或意见的错误陈述，以及思路上的非逻辑序列。

到此为止的划分是标准的。但还有一句常见的附加说法需要谨慎对待：形式谬误处于演绎推理领域，非形式谬误处于归纳推理领域。这句话作为粗略的定位有其道理——形式系统确实是演绎的，而大量非形式谬误确实出现在概率性推理中——**但它不能被当作判据**。理由可以由一个论证直接展示：

```
（1）中东冲突是无新闻（no news）。
（2）而无新闻是好新闻。
⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯
（3）所以中东冲突是好新闻。
```

直觉告诉人们，中东冲突不是好新闻，而且结论并不跟随前提。但为什么？此处发生的是`歧义词`（*equivocation*）：某个词项在一个句子、一段讨论、或如本例中的一个论证进行过程中改变了意义。"无新闻"在第一个前提中意为"为所有人或多数人所知"，在第二个前提中意为"没有什么引起注意的坏事发生"。

现在做两次符号化。第一次，**不诊断内容**，纯粹按表面形式处理，令 CME 代表中东冲突、NN 代表无新闻、GN 代表好新闻：

```
（1）CME 是 NN。
（2）NN 是 GN。
⎯⎯⎯⎯⎯⎯⎯⎯⎯
（3）所以 CME 是 GN。
```

从 CME 到 GN 的链路清清楚楚地经由 NN 建立起来，看上去完全有效。第二次，把两个"无新闻"的不同意义分别标出，令 KBA 代表"为所有人或多数人所知"、NBH 代表"没有坏事发生"：

```
（1）CME 是 KBA。
（2）NBH 是 GN。
⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯
（3）所以 CME 是 GN。
```

CME 与 GN 之间不再有任何链路。**此时即便纯粹从形式上看，该论证也是无效的。**

*这一演示给出的教训，比"歧义会破坏论证"更深一层。它表明：内容的诊断可以改变形式的判定。因此形式与非形式的真正分界不在于演绎与归纳，而在于——**判定该谬误是否只需检查结构**。形式谬误是那些结构本身已经暴露失败的情形；非形式谬误是那些必须先澄清内容、语境或意义，失败才会显形的情形。*

*一旦采用这一判据，若干原本令人困惑的编排就变得可理解。合成与分解处理的是部分与整体之间的演绎推论；蒙面人谬误涉及同一者不可分辨原则在信念语境中的失效，同样是演绎问题；水壶逻辑所涉的论证在形式上甚至是有效的——矛盾前提蕴涵一切——它的毛病在于必然不可靠而非无效；而存在谬误更是一个纯粹靠三段论形式即可判定的失败，却常被编入非形式的行列。这些并非分类失误，而是"演绎／归纳"这一判据本身不胜任的征兆。*

### 相关性、歧义、预设：非形式谬误三分法的判据

非形式谬误进一步分为三类。三类的名称容易记住，真正有用的是各自背后的**判据问题**——即为了判定某个论证属于哪一类，应当追问什么。

`相关性谬误`（*fallacy of relevance*，亦称不相干谬误）出现在这样的场合：论证的前提在逻辑上与结论不相干，却因为诉诸心理上或情感上的相干而**显得**相干。判据问题是：**若剥去全部情感、人际与修辞因素，这些前提是否仍对结论的真提供任何支持？** 典型成员包括针对人的论证、诉诸强力、不当诉诸权威、诉诸人民。

`歧义谬误`（*fallacy of ambiguity*）依赖于用词或措辞中的歧义（含混、晦涩、不明晰），其意义在论证进行过程中发生不同程度、有时极为微妙的偏移。判据问题是：**论证中是否有某个语词、结构或强调方式，在不同位置承担了不同意义？** 典型成员包括歧义词、双关、重音、合成、分解。

`预设谬误`（*fallacy of presumption*）出现在论证依赖某个隐藏假设之时——这个假设可能是某个未知因素、某个条件、某组情境、某种事态或某个观念——而一旦它不再隐藏，就会清楚地显示出它不足以支撑到结论。判据问题是：**把论证补全为完整形式后，是否浮现出一个既未被陈述、也未被论证的前提？** 典型成员包括假因、假两难、隐藏证据、复杂问句、轻率概括、丐题。

第三类的运作方式值得用一个最简单的例子看清楚。"每次我在凯西酒吧看我支持的球队比赛，他们都赢；明晚他们有比赛；因此我必须去凯西酒吧看，以确保他们再赢一次。"一场比赛的胜负牵涉无数原因、事件与事态，而在凯西酒吧观看与球队获胜之间的重合纯属巧合。此处被预设而未被陈述的前提是"两者之间存在因果联系"。**如果拥有关于每场比赛的全部原因与过程的知识——某种上帝视角——就会知道真正的原因是什么，而预设便无从藏身。** 隐藏性正是这一类谬误的定义特征。

*然而这套三分法既不互斥也不穷尽，这一点应当在一开始就说明，而不是留待后文发现。不相干结论一项常被称为"一切其他谬误之父"，理由是每一个谬误所得出的结论都与其前提不相干；若严格采纳这一说法，另外两类就会被吸收进相关性一类。反过来，歧义造成的失败往往同时可以描述为"预设了某语词意义的稳定性"。此外还有一批条目——确认偏误、可得性误差、知觉的建构性、主观验证等——被分散安置在相关性与预设两类之中，而它们所描述的其实是信念形成阶段的机制，与推论阶段的失效不在同一层级。三分法的恰当用法是作为定位工具，而非作为自然种类的划分。*

### 从"非三段论"到 Whately 的谬误表：一个历史范畴

上述分类之所以不整齐，有一个简单的原因：**"谬误"这份清单是历史累积的产物，而不是从统一理论中推导出来的。**

亚里士多德在《前分析篇》描述范畴三段论时，明确指出某些词项组合"不可能产生三段论""不产生三段论""无法构成三段论"。他并不称这些组合为谬误。阿弗罗狄西亚的亚历山大在其《前分析篇》注疏中称它们为"非三段论的"——这些命题组合根本不通向任何地方。在亚里士多德传统中，论证可以按质料与形式加以描述；而在这些后来被称作"形式谬误"的情形里，根本没有形式，因而根本不存在论证。中世纪思想家舍伍德的威廉在其《逻辑导论》中为三段论的正确构成立下规则，他把这类组合称为"无用的组合"。

那么当时什么才叫谬误？是基于歧义的推理错误，即亚里士多德在《辩谬篇》中处理、盖伦在《论谬误》中评注的那一类。**换言之，最初被称为谬误的恰恰是今天被归入"非形式"的那一支。**

把三段论规则的违反称为"谬误"，是相当晚近的做法。现代逻辑中这一传统真正始于**Whately**（*Richard Whately*）的《逻辑要义》（1826/27），该书是他为《大都会百科全书》所撰条目的扩充。Whately 自称最受其影响的著作是亨利·奥尔德里奇的《逻辑技艺纲要》（1691）；奥尔德里奇讨论了词项的不当处理与中项不周延这类问题，**却并未把它们收入其形式谬误附录**。在奥尔德里奇看来，形式谬误指的是任何违反同一律、不矛盾律或排中律的推理。只有在《逻辑要义》之后，标准的谬误表——即"某些前提组合为何无效"的理由清单——才开始包含大项或小项的不当周延，例如索利的《逻辑纲要》（1839）与尼尔的《推理的技艺》（1853）。

这段历史解释了这份清单的异质性。它实际上是**三股来源汇流**再加一条支线的产物。

第一股是古典与中世纪逻辑传统：亚里士多德《前分析篇》的三段论规则与《辩谬篇》的语言性谬误；克律西波的命题推理模式；亚历山大、舍伍德的威廉、布里丹、伯利对"无效组合"的规则化。

第二股是近现代批判性思维的教科书传统，自 Whately 确立谬误表之后，经索利、尼尔而至二十世纪的柯匹、赫尔利、达默等；在其上又叠加了当代`论辩理论`（*argumentation theory*）——伍兹与**沃尔顿**（*Douglas Walton*）贡献了两项关键工具：用一组程序性问题判定某个论证形式在具体实例中是否谬误的`批判性问题`（*critical questions*）方法，以及区分"该论证被驳倒"与"该论证可信度受损"的强读／弱读分析。

第三股是判断与决策心理学：特沃斯基与卡尼曼关于合取谬误、代表性启发与基础率忽略的实验；福勒关于主观验证的实验；以及知觉心理学与神经科学关于感官不可靠性的研究。

支线则来自具体哲学争论中被铸造出来的**学科专属指控**：**摩尔**（*G. E. Moore*）提出的自然主义谬误（弗兰肯纳 1939 年正是用"定义主义谬误"之名来指称它）；**威廉·詹姆斯**（*William James*）在《心理学原理》中命名的心理学家谬误；兰德与布兰登提出的被盗概念；巴菲尔德在二十年代首先描述、后经 C. S. 刘易斯推广的年代势利；弗卢命名的真苏格兰人；Jaynes 命名的心灵投射；费恩伯格提出的法律主义错误；来自文艺批评的意图谬误；以及**波普尔**（*Karl Popper*）的可证伪性判准所派生的不可证伪谬误。

**结论：** 这一百个条目处于不同层级。有的是形式系统内部的规则违反，其判定是机械的；有的是语言层面的意义偏移，需要语义与语用分析；有的是依赖对话语境、结论强度与论辩目的的论辩失败；有的根本不是推论错误，而是信念形成阶段的认知机制；还有的是在特定学术争论中被造出来的论战性标签，其"谬误"地位本身就是争论的一部分。**把它们当作同一层级的一百个并列项目来记忆，会造成系统性的误解。**

### 寄生性原理：谬误为什么总是长得像正确推理

前面已经确立了谬误是什么、如何分类、这一分类从何而来。剩下一个问题最为关键：既然谬误是推理的失败，为什么它们如此有效地说服了如此多的人？

答案是一条贯穿全部内容的原理：**几乎每一种谬误都与某种正确推理形式相似，而这种相似性正是其说服力的来源。** 这条原理在具体条目中被反复重述——赌徒谬误之所以盛行，是因为它类似于某种好的推理；中庸谬误之所以盛行，是因为它酷似一种非谬误的推理方式——把这些重述合并起来，就得到一条可以在每一处调用的总原则。

其配对关系大致如下：肯定后件寄生于肯定前件，否定前件寄生于否定后件，二者共享条件句这一形式外壳；肯定析取支寄生于析取三段论，二者共享"或"这个词；赌徒谬误寄生于大数法则；中庸谬误寄生于"真理常处于两极之间"这一在许多争论中确实成立的经验；诉诸人民寄生于共识所具有的某种归纳证据力；合成与分解寄生于同质整体中部分与整体之间确实成立的推论；诉诸无知寄生于沉默论证与否定性证据；针对人的论证寄生于对证言可信度的合法评估；代表性启发寄生于原型匹配这一在多数情况下高效的捷径——看到一只狂吠口吐白沫的狗便避开，是完全理性的；滑坡寄生于真实存在的因果链条；弱类比寄生于强类比；轻率概括寄生于合格的统计概括；实体化寄生于无害的隐喻性简称；稻草人寄生于对对手立场的合法重述。

**由此立即得到两个方法论后果。**

第一个后果是**救援条件模式**。既然谬误与其合法近邻共享形式，那么二者的差别往往不在形式而在一个被省略的前提。补上那个前提，推论就从失败转为成立。这一模式至少在四处以完全相同的方式运作：合成与分解在补入"该整体仅由单一种类材料构成"之后立即变为有效的推论；诉诸无知在补入"若 p 为真，则我们本应已经获得 p 的证据"这一`搜索深度前提`之后，立即转化为一个合法的否定后件式推理；肯定析取支在其析取确为排斥性时（"要么乔治·华盛顿死了，要么他活着"）就是无可挑剔的析取三段论；中庸谬误在补入支持居中判断的实际理由之后，就成为一个正常的论证。*这意味着相当一部分"谬误"更准确的描述是**省略**而非**错误**。它们之所以被归为谬误，是因为那个必需的前提既未被陈述，也无法被合理地默认为真。*

第二个后果是**语境依赖**，其最精确的形态是**强读与弱读的区分**。同一个论证形式，其结论可以有强弱两种读法：强读断言"该论证因此被驳倒"，弱读断言"该论证的可信度因此受损，需要独立证据支持"。在大量情形中，强读是谬误而弱读是合法的。指出某位证人曾犯伪证罪并不能证明他此刻所言为假——但它确实给出了不轻信其证词的理由，而在法庭语境中，后者往往已经足够。*这一区分将在 P6 中被完整地操作化，并推广到诉诸人民、不当诉诸权威、夸大分歧等处。它的一般形式是：判定一个论证是否谬误，必须同时确定它试图达到的结论有多强。*

**这三条原理合起来，改写了学习目标本身。** 掌握谬误不等于记住一百个名称，因为名称无法告诉人这个具体实例落在分界线的哪一侧。掌握谬误等于：对每一处，知道它寄生于哪一种正确推理，知道使它转为正确推理所需的那个条件是什么，知道它在多强的结论上失败、在多弱的结论上不失败。

最后一句警告与此直接相关。把"识别谬误"当作论辩中的攻击手段，本身就会滋生一种新的错误：认为既然对方的论证犯了谬误，对方的结论便因此为假。这一点在 P1 的评价坐标中已经被排除——谬误是推理的属性，真假是主张的属性——它将在 P17 作为对整套谬误理论的元层约束重新出现。


## P3 命题逻辑中的形式谬误

### 条件句的结构：前件、后件、充分条件与必要条件

命题逻辑处理的是主张的属性，以及主张彼此关联时所可能进行的推理。在其全部工具中，`条件句`（*conditional statement*）承担的推理负荷最重，它引发的推理错误也最多。

条件句是形如"如果……那么……"的句子，表达`前件`（*antecedent*，"如果"之后的部分）与`后件`（*consequent*，"那么"之后的部分）之间的某种联系。它的第一个关键特征是：**条件句既不断言前件，也不断言后件。** 它仅仅主张：若前件为真，则后件亦为真。

以一个最小模型为例。令 p = "索菲娅在双子城"，q = "她在明尼苏达"。条件句"如果索菲娅在双子城，那么她在明尼苏达"并没有说索菲娅在双子城，也没有说她在明尼苏达；它只说前者若成立则后者成立。这个模型之所以适合作为出发点，是因为双子城与明尼苏达之间的地理包含关系使方向性完全直观，不需要任何额外背景知识。

方向性正是全部问题所在。条件句在前件与后件之间建立的是一种**不对称**关系，而这种不对称由一对概念刻画。若某物是`充分条件`（*sufficient condition*），它保证另一件事；若某物是`必要条件`（*necessary condition*），它是另一件事所需要、所要求的。在上例中，身在双子城是身在明尼苏达的充分条件——身在双子城保证了身在明尼苏达；反过来，身在明尼苏达是身在双子城的必要条件——不在明尼苏达就绝不可能在双子城。但身在明尼苏达并不保证身在双子城，身在双子城对于身在明尼苏达也不是必要的。

一个条件句同时给出了这两条信息，**而两条信息指向相反的方向**：前件是后件的充分条件，后件是前件的必要条件。两种正确的推理各自利用其中一条：

```
肯定前件（modus ponens，"肯定的方式"）    否定后件（modus tollens，"取去的方式"）

（1）如果 p，那么 q。                      （1）如果 p，那么 q。
（2）p。                                  （2）并非 q。
⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯                          ⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯
（3）因此 q。                              （3）因此并非 p。
```

`肯定前件`（*modus ponens*）利用充分性：肯定了充分条件，被保证者随之成立。若索菲娅确实在双子城，她不可能不在明尼苏达。`否定后件`（*modus tollens*）利用必要性：否定了必要条件，需要它的那件事随之落空。若索菲娅不在明尼苏达，她不可能在双子城。两者都是有效的——前提为真便保证结论为真。

两种形式谬误则各自把方向弄反。它们与两种有效形式共享完全相同的外壳——同一个条件句、同一个第二前提位置、同一个结论位置——这正是`寄生性原理`在命题逻辑中的具体形态：说服力来自与有效形式的形式相似性。

### 肯定后件：把必要条件当成了充分条件

`肯定后件`（*affirming the consequent*）发生在命题三段论的小前提肯定了条件句的后件之时。

```
（1）如果索菲娅在双子城，那么她在明尼苏达。   （如果 p，那么 q）
（2）索菲娅在明尼苏达。                       （q）
⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯
（3）因此索菲娅在双子城。                     （p）
```

这个论证无效，因为若索菲娅在明尼苏达，她完全可能身处双子城之外的地方。明尼苏达的面积远大于双子城。

**失效的确切位置**在于：它假定"如果 p，那么 q"的**逆命题**"如果 q，那么 p"也为真。条件句并不给出这一信息。用充分与必要的语言说，肯定后件把一个必要条件当成了充分条件——**它混淆了必要条件与充分条件**。原条件句说的是"身在双子城保证身在明尼苏达"以及"身在明尼苏达是身在双子城所必需的"；它没有说、也不蕴涵"身在明尼苏达保证身在双子城"。

同一失败在日常推理中极为常见。认为"如果下雨，人行道就是湿的"，接着看到人行道是湿的，于是断定在下雨：

```
（1）如果在下雨，那么人行道是湿的。    （1）R ⊃ S。
（2）人行道是湿的。                    （2）S。
⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯       ⎯⎯⎯⎯⎯⎯
（3）因此在下雨。                      （3）R。
```

无法由此逻辑地、理性地断定在下雨，因为可能是洒水器造成的，可能是当地水管破裂，可能当天早些时候下过雨，也可能是其他任何使人行道变湿的原因。与之对照，"如果在下雨，那么人行道是湿的；在下雨；因此人行道是湿的"符号化为 R ⊃ S、R、∴S，是肯定前件，可以绝对地、毫无疑问地断定结论。

一旦把两者并列符号化，正确结构的正确性与被改动结构的失败就同时显豁：R 与 S 被放错了位置。"如果外面结冰，那么邮件会迟到；邮件迟到了；所以外面结冰了"是同一失败的另一实例——邮车可能爆胎，邮递员可能在前一站被耽搁。

**方法：** 检验的手段是 P1 中已经确立的同形反例法的一个变体——为 p 与 q 代入具体内容，然后追问：能否构造一个前提全真而结论为假的情形？能否为后件找到另一个可能的来源？若索菲娅在明尼苏达，她可能在双子城以外的地方吗？只要答案为是，该形式便无效。

### 否定前件：把充分条件当成了必要条件

`否定前件`（*denying the antecedent*）是镜像的失败：小前提否定了条件句的前件。

```
（1）如果索菲娅在双子城，那么她在明尼苏达。   （如果 p，那么 q）
（2）索菲娅不在双子城。                       （并非 p）
⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯
（3）因此索菲娅不在明尼苏达。                 （并非 q）
```

若索菲娅不在双子城，并不能推出她不在明尼苏达。她可以在明尼苏达的许多其他地方。

**失效的确切位置**在于：它假定前件一旦被否定，后件也必须被否定。而条件句只说前件为真时后件为真，对前件为假时后件如何只字未提。用充分与必要的语言说，否定前件把一个充分条件当成了必要条件：身在双子城对身在明尼苏达是充分的，但并非必要的。

**区别：** 把两对形式合起来看，可以得到一条统一的诊断。有效的两种推理各自沿着条件句所给出的**一个**方向前进——肯定前件沿充分性向前，否定后件沿必要性向后。两种谬误则各自试图沿着条件句**没有**给出的方向前进——肯定后件试图从必要条件反推，否定前件试图从充分条件的缺席反推。**四种形式的差别只是第二前提处理的是前件还是后件、是肯定还是否定；而其中两种成立、两种不成立，全部取决于条件句本身的不对称性。**

### 真值表如何把有效性变成可判定的

上述判断可以脱离直觉，交由一个机械程序完成。这正是`真值表`（*truth table*）的功能：它把"结论是否跟随前提"从一个需要想象力的问题，变成一个可以逐行核对的问题。

真值表首先刻画一个主张与其否定的关系：若 p 为真，则并非 p 必为假；若 p 为假，则并非 p 必为真。

| p | 并非 p |
| --- | --- |
| 真 | 假 |
| 假 | 真 |

条件句的真值表则穷尽了 p 与 q 真假组合的全部四种情形：

| p | q | 如果 p，那么 q |
| --- | --- | --- |
| 真 | 真 | 真 |
| 真 | 假 | **假** |
| 假 | 真 | 真 |
| 假 | 假 | 真 |

此处的每一行代表一种可能的世界状态。第一行：p 真且 q 真，条件句为真。第二行：p 真而 q 假，条件句为假——这是条件句唯一被推翻的情形，因为它恰恰主张了"p 真时 q 也真"。第三行与第四行：p 为假时，条件句无论 q 如何都为真，因为它对前件为假的情形没有作出任何承诺。

有了这张表，有效性获得了一个精确的判据：**一个论证有效，当且仅当不可能出现前提全真而结论为假的情形。** 于是判定程序变为：在全部行中寻找"所有前提为真且结论为假"的那一行；找到即无效，找不到即有效。

对肯定前件，两个前提是"如果 p，那么 q"与 p，结论是 q。只有第一行使两个前提同时为真，而该行中结论 q 也为真。不存在前提全真而结论假的行，因此肯定前件有效。

对肯定后件，两个前提是"如果 p，那么 q"与 q，结论是 p。**第三行是决定性的**：p 假、q 真，此时条件句为真、q 为真，两个前提全真；而结论 p 为假。存在这样一行，因此肯定后件无效。

对否定前件，两个前提是"如果 p，那么 q"与"并非 p"，结论是"并非 q"。同样是**第三行**：p 假、q 真，条件句为真、"并非 p"为真，两个前提全真；而结论"并非 q"为假。因此否定前件无效。

*两种谬误被同一行推翻，这并非巧合。p 假而 q 真，正是"后件有另一来源"这一情形的形式化表达——索菲娅在明尼苏达但不在双子城，人行道湿了但不是因为下雨。直觉上的反例与真值表上的那一行是同一件事的两种呈现。*

### 肯定析取支：包含性"或"与排斥性"或"的分歧

第三个命题逻辑的形式谬误不涉及条件句，而涉及"或"。它的形式极其简单：

|  | 例子 | 逻辑 |
| --- | --- | --- |
| 前提 1 | 麦迪逊喜欢猫，或者她喜欢狗。 | A 或 B。 |
| 前提 2 | 麦迪逊喜欢猫。 | A。 |
| 结论 | 麦迪逊不喜欢狗。 | 并非 B。 |

论证失败，因为它没有考虑到麦迪逊可能既喜欢猫又喜欢狗。

**这一谬误的全部根源在于英语中"或"的歧义**，而这种歧义因语境通常自动消解，以致很少被注意。"或"有两种截然不同的用法。

`包含性析取`（*inclusive or*）是经典逻辑所使用的那一种。命题"要么 A 要么 B"在三种情形下为真：A 真；B 真；A 与 B 都真。换言之，其后隐含着一句"或二者皆可"。搜索引擎使用的正是这一种：输入"苹果 or 香蕉"，返回的结果包含带"苹果"的、带"香蕉"的，以及同时带两者的。

`排斥性析取`（*exclusive or*）只在两种情形下为真：A 真；B 真。若 A 与 B 都真，排斥性析取命题为假。换言之，其后隐含着一句"但不能二者皆是"。

母亲对孩子说"要么你把蔬菜吃掉，要么你没有甜点"，孩子把它理解为一场交易——吃掉蔬菜就会有甜点——这一理解依赖于把该句读作排斥性析取。倘若母亲后来坚持自己使用的是包含性析取，那么"你吃了蔬菜**并且**你没有甜点"这第三种情形同样使她的话为真，她的陈述在字面上并未撒谎。

`肯定析取支`（*affirming a disjunct*）就发生在**误把包含性析取当作排斥性析取**之时。"对奥巴马你只有两种选择：要么相信他是基督徒，要么认为他是骗子"——这一断言忽略了第三种可能：某人可以认为他既是基督徒又是骗子。

**条件：** 并非每一个含"或"的陈述都会落入这一谬误。考虑：

```
（1）要么乔治·华盛顿死了，要么他活着。
（2）乔治·华盛顿死了。
⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯
（3）因此他不是活着的。
```

这是`析取三段论`（*disjunctive syllogism*），完全成立。差别在于：第一个前提中的"或"确实是排斥性的，它列出的两种可能性真正互斥——一个人死了就不活着，活着就没死。**这是救援条件模式在命题逻辑中的第一个实例：肯定析取支与析取三段论共享完全相同的形式，差别只在于析取本身的性质是否被确认为排斥性。** 若排斥性成立，推论合法；若未被确认而被默认，推论失败。

*这一点也揭示了形式谬误与语言问题之间并非截然分离。判定某个"或"是包含性还是排斥性，需要考察其内容与语境——而这正是 P2 中所说的、内容诊断可以改变形式判定的又一处证据。*

## P4 范畴逻辑中的形式谬误与周延概念

### A、E、I、O 与三段论的构件

人天生是分类者，把各种事物归入范畴，以便更好地理解、预测与控制实在。`范畴`（*category*）是包含若干共享某种特征之成员的类、组或集合。可以构造"狗"的范畴、"人"的范畴、"红色左脚鞋"的范畴、"尝起来甜且会飞之物"的范畴——原则上任何存在之物或可设想之物都能被归入某个范畴。

亚里士多德是最早为范畴之间的关系以及范畴推理立下规则的思想家之一，因而被视为范畴逻辑之父。他把范畴间的关系收摄为四种`范畴命题`，按传统记号称为 A、E、I、O：

- **A 命题**：所有 A 是 B。范畴 A 的全部成员都是范畴 B 的成员。"所有猫是哺乳动物""所有基督徒是一神论者""所有单身汉是未婚男性"。
- **E 命题**：没有 A 是 B。范畴 A 的成员没有一个是范畴 B 的成员。"没有猫是狗""没有基督徒是无神论者"。
- **I 命题**：有些 A 是 B。范畴 A 至少有一个成员是范畴 B 的成员。"有些猫是黑色的""有些基督徒是天主教徒"。
- **O 命题**：有些 A 不是 B。范畴 A 至少有一个成员不是范畴 B 的成员。"有些猫不是黑色的""有些基督徒不是天主教徒"。

四者沿两个维度排列：`质`（*quality*，肯定或否定）与`量`（*quantity*，全称或特称）。A 是全称肯定，E 是全称否定，I 是特称肯定，O 是特称否定。

这一系统中的推理工具是`三段论`（*syllogism*），亚里士多德在《前分析篇》24a19–22 中定义为：

> 三段论是这样一种论说：其中若干事物被陈述，某个不同于所陈述者的东西由于它们如此而必然地随之而来。所谓"由于此"，意指结论因它们而来；所谓"如此"，意指为使推论成为必然，不需要从外部引入任何进一步的词项。

最简形态的三段论由恰好两个前提与一个结论构成，其中的主张为 A、E、I、O 命题。三段论由**三个词项**组成，自亚里士多德以来分别称为`大项`、`小项`与`中项`。大项与小项也被称为三段论的"两端"，因为它们分列中项两侧。中项的标志是：它在两个前提中各出现一次，而在结论中消失。在全部可能的组合中，有十五个式是有效的，以下三例足以显示其运作：

```
（1）所有 A 是 B      所有猫是哺乳动物。
（2）所有 B 是 C      所有哺乳动物是温血动物。
⎯⎯⎯⎯⎯⎯⎯⎯⎯      ⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯
（3）所有 A 是 C      所有猫是温血动物。

（1）所有 A 是 B      所有基督徒是一神论者。
（2）没有 B 是 C      没有一神论者是多神论者。
⎯⎯⎯⎯⎯⎯⎯⎯⎯      ⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯
（3）没有 A 是 C      没有基督徒是多神论者。

（1）所有 A 是 B      所有狼是犬科动物。
（2）有些 A 是 C      有些狼是黑色的。
⎯⎯⎯⎯⎯⎯⎯⎯⎯      ⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯
（3）有些 C 是 B      有些黑色之物是犬科动物。
```

三段论之所以被亚历山大称为"最具强制力的辩护类型"，理由在于：当一部分由整体得到辩护时，凡适用于或成立于一个全称与总体者，必然也成立于包含于其中之物。**只要形式正确且前提为真，结论必然为真。** 范畴逻辑的形式谬误，就是这一必然性被切断的各种方式；每一个都是对某条构成规则的违反。这些违反直到 Whately 之后才被称作"谬误"，此前它们只是"不产生三段论"的组合。

### 周延：这个词项说到了它的全部外延吗

理解全部范畴谬误，需要先掌握一个概念。

`周延`（*distribution*，亦译"周延性"）描述的是一个词项的**外延**，即它在该命题中说到了多少个体。若说到了全部，该词项就是周延的。在"所有猫是蓝色的"中，"猫"是周延的——关于所有的猫，某件事被断言了。而"蓝色的"不是周延的，因为该陈述并未把所有蓝色之物纳入其中。可能还有别的蓝色之物，如天空；也可能所有且只有猫是蓝色的；但这个陈述并未告知究竟如何。

**威廉·尼尔**与**玛莎·尼尔**（*William and Martha Kneale*）把"周延"一词应用于词项的这一属性归功于中世纪逻辑学家：它后来被用来指称一个普遍词项在被用于指代它所适用的全部个体时被认为具有的属性。

四种范畴命题的周延情况可以直接从其量与质读出。A 命题"所有 A 是 B"周延主项而不周延谓项。E 命题"没有 A 是 B"两项皆周延——它把 A 的全部排除在 B 的全部之外。I 命题"有些 A 是 B"两项皆不周延。O 命题"有些 A 不是 B"不周延主项而周延谓项——说"有些 A 不是 B"即是把这些 A 排除在 B 的全部之外。

*把握这一点的最简办法是记住两条：全称命题周延主项，否定命题周延谓项。*

周延之所以成为范畴逻辑的枢纽，在于它刻画了**前提中的信息量**。一个词项若未被周延，关于它的全部就没有被说到任何事；而任何要求关于其全部的推论，都将超出前提所提供的内容。范畴逻辑的三条主要规则全都是这一约束的具体形态。

### 中项不周延：为什么"心灵是计算机"推不出来

中项的职能是连接两端。若中项在两个前提中都未被周延，连接便无从建立。这就是`中项不周延`（*undistributed middle*）。

以"实体"为中项、"动物"与"人"为两端：

```
（1）所有动物是实体。
（2）所有人是实体。
⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯
（3）……？
```

什么也推不出来。两个前提都未把实体的全部纳入考量，因此完全可能：是实体的那些动物，与是实体的那些人，并非同一批实体。亚历山大对此有精确的说明——中项是两端的谓项，因而相对于两者都是大项；它可以凭其一部分被述说于一端，凭另一部分被述说于另一端；若两端各自只与中项的不同部分相交，则两端彼此之间没有任何共享之物，而若要有三段论，两端必须共享同一个东西。

亚里士多德在《前分析篇》27a19 中给出了这条规则的原型：若 M 被述说于每一个 N 与每一个 O，则不可能有三段论；用以说明两端间肯定关系的词项是实体、动物、人，说明否定关系的是实体、动物、数。布里丹在《辩证法大全》中将其规则化为"第六结论：凡中项在两个前提中皆不周延者，皆非有效三段论"。

这正是 P1 中那个论证的诊断：

```
（1）计算机会计算。
（2）人的心灵也会计算。
⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯
（3）因此心灵是一台计算机。
```

中项是"会计算之物"，它在两个前提中都未被周延——前提只说计算机属于会计算之物的一部分，心灵也属于会计算之物的一部分，却从未把会计算之物的全部纳入。因而两者完全可能是该范畴中不同的部分。同形反例法给出同一结论："鸟会飞；飞机也会飞；因此飞机是鸟"具有完全相同的结构，而其结论明显为假。

**条件：** 中项周延是有效三段论的**必要而非充分条件**。并非所有中项周延的三段论都有效，但一个三段论必须中项周延才可能有效。修改上例，设想一个没有人是实体的世界：

```
（1）所有动物是实体。
（2）没有人是实体。
⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯
（3）因此没有人是动物。
```

此处可以得出结论，正是因为中项被周延了：人这一类与实体这一类互斥，意味着在某一点上实体的全部都被纳入了考量——实体的全部都被排除在人之外。

与之相关的另一条规则同样源于周延不足：**不能由两个特称前提得出有效结论。** "有些猫是蓝色的；有些猫是有毛的"推不出任何东西，因为没有任何词项被周延——关于猫的一般情况一无所知，关于蓝色之物的一般情况一无所知，关于有毛之物的一般情况也一无所知，甚至无法知道那些蓝色的猫与那些有毛的猫是不是同一批。

### 大项与小项的不当周延：结论不能比前提说得更多

第二条规则处理结论与前提之间的信息落差：**不能在结论中周延一个在前提中未被周延的词项。** 若前提只谈及某物的一部分，结论就不能转而谈及该物的全部。违反这一规则，依所涉词项之不同，构成`小项不当周延`或`大项不当周延`。

```
（1）所有猫是蓝色的。
（2）所有猫是有毛的。
⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯
（3）因此所有蓝色之物是有毛的。
```

前提中从未把蓝色之物的整个类扩展出来——"蓝色的"作为 A 命题的谓项不周延——因此结论不能就所有蓝色之物提出主张。这是小项的不当处理。大项的情形完全相同，只是被不当处理的是另一端：

```
（1）所有猫是蓝色的。
（2）所有猫是有毛的。
⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯
（3）因此所有有毛之物是蓝色的。
```

两个词项都不行。**可以得出的是**："有些有毛之物是蓝色的"——即那些是猫的有毛之物。这样就没有周延"有毛之物"，落差消失。

*不过这个补救本身牵出一个分歧：按亚里士多德的解释可以如此推出，而遵循布尔解释的人会认为这恰恰是一个存在谬误的实例。这一分歧的实质留待本部分最后一节处理。*

**区别：** 中项不周延与两端的不当周延处理的是同一约束的两侧。前者问：前提中是否有足够的信息把两端连接起来？后者问：结论所要求的信息是否超出了前提所给的？两条合起来可以概括为一句话——**可以在结论中不周延前提中已周延的词项，这完全没有问题；但绝不能在结论中周延前提中未周延的词项。**

### 排斥前提、四词与不当肯定：没有中项就没有推论

余下几条规则的共同主题是：**中项必须真正地充当连接。** 它可能因前提的质而失效，也可能因词项的数目而失效。

`排斥前提`（*exclusive premises*）发生在三段论具有两个否定前提之时。否定前提否认主项与谓项之间的联系。"没有猴子是猫"主张猴子这一集合与猫这一集合之间毫无联系；"有些猴子不是植物"主张猴子与植物之间不存在必然联系。否定前提通常（但不总是）含有"不"或"没有"。

```
（1）没有猴子是猫。
（2）没有猴子是植物。
⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯
（3）……？
```

两个陈述合起来什么也推不出。它们之间除了都提到猴子之外毫无关系——它们是**排斥的**。这两个前提合起来，关于猫与植物这两个集合之间的关系一无所言。亚历山大给出的理由最为精确：这一组合之所以推不出任何东西，是因为中项与两端都没有关系，**就好像中项根本没有被取用一样——而三段论依赖于中项**。亚里士多德在 26a9–13 与 27a21–23 中已经指出这一问题；用以说明肯定关系的词项是线、动物、人，说明否定关系的是线、动物、石头。这条规则从亚里士多德经中世纪直至近代从未被动摇：舍伍德的威廉写道"须注意，由两个否定命题或两个特称命题，什么也推不出来"；布里丹写道"第二结论：由两个否定命题不能有效地得出任何三段论"；伯利写道每个三段论无论何格何式都有两条通则，即必须有一个全称命题与一个肯定命题，因为由否定命题或特称命题什么也推不出来。

`四词`（*four terms*）则违反了构造有效三段论的第一条规则：**任何三段论必须恰好包含三个词项，不多不少。** 亚里士多德在 41b36–8 推出，每一个证明都将经由三个词项而非更多进行，除非同一结论由不同的命题对所确立；又在 42a30–35 说明理由：三个词项构成两个命题，而结论由两个命题而非更多得出。三是作出一个推论所需的最小数目——要形成有效三段论，至少必须能把两个不同的词项（大项与小项）关联到同一个词项（中项）上，从而得以作出关联大项与小项的有效推理。

若词项多于三个，结果只有两种。一种是实际上存在多个三段论：

```
（1）所有猫是可爱的。
（2）所有可爱之物是蓝色的。
（3）所有蓝色之物是有气味的。
⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯
（4）因此所有猫是有气味的。
```

把它化为恰当的三段论形式，需要显明一个隐含的结论——所有猫是蓝色的——于是该论证归约为两个各自有效的三段论。另一种是根本不存在三段论："所有猫是蓝色的；你妈妈闻起来很怪；因此……？"四个完全无关的词项之间无法建立任何合理的连接。

四词还有一种更隐蔽的犯法：**用一个实际上有两个意义的歧义词充当中项，而此处需要它只有一个意义。**

```
（1）所有驴（asses）吃干草。
（2）亚里士多德是头蠢驴（ass）。
⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯
（3）因此亚里士多德吃干草。
```

从赤裸的语言看，这像是一个有效三段论；但"ass"的意义在两个前提之间发生了偏移：在第一个前提中指马与驴所生的那种动物，在第二个前提中是比喻性的，指具有该动物某些品性的人。实际情况是，这又是一个两个前提毫无关联的伪三段论，因为**中项其实是两个词项**。

*这一案例是形式谬误与歧义谬误之间唯一的直接桥梁。它再次印证 P2 的判据：某些失败在纯粹的结构层面已经可见（词项数目为四），而使这一失败可见的前提是先在内容层面识破意义的偏移。*

反方向的限制同样存在：三段论也不能少于三个词项。舍伍德的威廉指出，命题不可能共享两个词项，否则它们就是同一个命题——因为一个命题中恰有两个词项，即主项与谓项，命题正是被分析为词项的。因此每个三段论中必有三个词项。

最后一条规则关涉质的传递。**一旦有一个否定前提，结论必须是否定的；若在有否定前提的情况下试图得出肯定结论，便犯了`不当肯定`**（亦称不当否定谬误，违反的是 Whately 的第六条三段论规则）。Whately 给出的理由是：在那个否定前提中，中项被宣告与一端不一致；而在另一个前提中（按前一条规则它当然是肯定的），中项与另一端一致；因此两端彼此不一致，结论为否定。同样可以证明其逆：**要证明一个否定结论，必有一个前提是否定的。** 亚里士多德在 41b27–30 中给出了更一般的表述：每个三段论中，两个前提或其中之一必须与结论同类——不仅在肯定或否定上如此，在必然、实然或或然上亦如此。

```
（1）所有猫是小丑。
（2）有些小丑不吸毒。
⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯
（3）因此有些猫吸毒。
```

由所给信息，关于猫的习性一无所知，什么也推不出来。再看一个把关系整个颠倒的版本：

```
（1）所有猫是小丑。
（2）没有猫吸毒。
⎯⎯⎯⎯⎯⎯⎯⎯⎯
（3）有些小丑吸毒。
```

由这两个前提确实能推出某些东西——有些小丑**不**吸毒。理由是：若所有猫是小丑，则有些小丑是猫；若没有猫吸毒，则那些身为小丑的猫不吸毒；因此有些小丑不吸毒。但绝无理由认为可以证明其反面。

### 存在谬误：全称命题是否承诺类中有成员

最后一个失败模式的判定同样只需检查三段论的形式，因而属于形式谬误，尽管它常被编入另一行列。

`存在谬误`（*existential fallacy*）发生在错误地预设某个类或组有成员之时。关于类或组的陈述可以为真，即便该类或组的成员并不存在。就"独角兽"这一类而言，可以说"独角兽有一只角"为真，但不必也不应因此认为独角兽的个体成员存在。

就三段论论证而言，这一失败的形式特征是：**前提在量上是全称的，而结论是特称的。** 前提可以用"所有"与"没有"陈述，且前提可以为真；然而前提之真并不必然带来关于其内容之"有些"的真，因为其内容可能并不存在。"所有人是有死的"为真，由此推出"有些人是有死的"——这一推论只有在人确实存在的条件下才成立。对人而言这一条件显然满足；对独角兽、对完美正义的城邦、对任何被定义却未被例示的类而言，则未必满足。

**这里存在一个真正的解释分歧，而非一方的错误。** 亚里士多德的解释预设全称命题的主项类非空，因而允许从全称推出特称；布尔解释不作这一预设，因而把同样的推论判为存在谬误。前一节中"所有猫是蓝色的；所有猫是有毛的；因此有些有毛之物是蓝色的"正落在这条分界线上：按亚里士多德可以推出，按布尔则不能，除非另行确认猫确实存在。

*康德关于"存在不是一个实在的谓词"的论点与此相关：当一个事物通过任意多的谓词被思考——哪怕是被彻底规定地思考——在此之上再设定这个事物"存在"，并不给这个事物增添分毫。对类的描述与对类之非空的断定，是两个层级的事情。*

**方法：** 由此可以提炼出一条可操作的要求。核实某物是否存在时，所使用的概念本身在规制这一核实——去哪里找、找什么，都由该概念决定。因此在寻求某个实体存在性的经验验证时，首先要确保对验证过程中所用的概念有恰当的理解。在三段论推理中，这条要求的具体形态是：**在由全称前提推出特称结论之前，先确认主项类的非空性是否已被确立，而不是被默认。**

## P5 相关性的伪装：心理相干与逻辑相干的分离

### 不相干结论：为什么它是一切谬误的母型

`相关性谬误`的定义已在 P2 给出：前提在逻辑上与结论不相干，却因诉诸心理或情感上的相干而显得相干。要理解这一整类，最好从其最纯粹的形态入手。

`不相干结论`（*irrelevant conclusion*，拉丁文 *ignoratio elenchi*，字面意为"对证明的无知"）指的是这样一种论证：其结论即便为真，也与该论证的前提不相干。以一组关于心脏病的概括为例（为论证起见假定它们为真）：

```
（1）日本人吃的脂肪少，心脏病发作少于美国人与英国人。
（2）法国人吃的脂肪多，心脏病发作少于美国人与英国人。
（3）意大利人喝很多酒，心脏病发作少于美国人与英国人。
（4）中国人喝酒很少，心脏病发作少于美国人与英国人。
⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯
（5）因此，杀死你的是说英语。
```

结论与前提之间不存在任何必然的连接。前提的数量无关紧要；哪怕再加上一千条同类概括，结论与它们的关系仍然是零。其一般形态可以写作：前提 1 + 前提 2 + 前提 3 + …… + 前提 n，结论 A，其中 A 与任何一条编号前提都无关。

这一谬误常被称为"一切其他谬误之父"，理由是：**每一个谬误所产生的结论，即便为真，也与其前提不相干。** 这句话既是一个洞见，也是一个危险。作为洞见，它指出了全部谬误共有的最低限度特征——若结论真的从前提推出，就不会有谬误可言。作为危险，它使"不相干结论"这一名称几乎不承载任何诊断信息：把某个论证判定为不相干结论，等于只说了"它犯了某种谬误"，而没有说明它是**如何**失败的。

*因此这一条目的恰当用法是作为母型而非作为诊断类别。当某个论证的失败方式无法被更精确地归类时，它才被单独使用；其余情形下，更有信息量的是指出前提与结论之间的不相干是通过哪一种伪装建立起来的。本部分其余各节处理的正是这些伪装。*

母型一旦确立，一条可操作的检验也随之确立：任何时候有人试图说服他人，或自己试图说服他人，都应当追问结论与前提之间是何种关系。**存在一个必然的、逻辑的连接，还是仅仅存在一个情感上的连接？** 前提是否真的支持结论，还是前提本身含混或可能被误解？不要仅仅因为某个东西被标为"结论"就接受它，而要确认它与那些据称支持它的命题之间确有连接。

### 转移注意力的三种技术：红鲱鱼、移动球门、冗长证明

前提与结论之间的不相干可以通过三种不同的操作被掩盖：把讨论引向别处、把讨论的终点挪动、把讨论淹没在体量之中。

第一种是`红鲱鱼`（*red herring*）。该名称的一个来源与警犬训练有关：训练者用气味强烈的红鲱鱼试图把狗从气味踪迹上引开，以辨别哪些是最好的追踪犬。一个红鲱鱼式的论证，正是用来把人从本该通向另一个更恰当结论的推理踪迹上引开的东西。其结构为三步：

```
第一步：人物一提出论证、议题或话题 A。
第二步：人物二引入论证、议题或话题 B。
第三步：A 被完全放弃，讨论在 B 上继续。
```

关键在于第三步。若 B 与 A 相关并最终导回 A，则发生的只是话题的扩展；只有当 A 被放弃而讨论者仍表现得像在回应 A 时，转移才构成谬误。被问及降雨情况却谈论上周的阳光，被问及五加五等于几却回答印度人发明了零——后者在事实上完全为真，却已经使提问者偏离了原问题。

第二种是`移动球门`（*moving the goalposts*）。它不转移话题，而是在话题内部改变成功的标准。其成立需要同时满足三个条件：

```
（1）甲要求乙达成某个目标 G。
（2）乙达成了 G。
（3）甲拒绝承认，并要求乙达成一个新目标 G′。
```

完成了全部要求却被告知奖赏又被移到更远处，这是其原型情境。移动球门与红鲱鱼的区别在于：红鲱鱼使论题被替换，移动球门使论题保持不变而**判定该论题已被解决的条件**被替换。其结果是对方永远无法满足要求，因为满足要求这件事本身被重新定义了。

*由此可以看出一条实践性的防范：论辩各方应当在开始之前明确成功标准，因为一旦某个标准被留作含混，一方就可能（而且往往会）利用这一含混。在规则明确的竞赛中，双方必须遵守同一套官方标准，例如球的充气压力必须达到规定值，正是为了避免一方获得不公平优势。*

第三种是`冗长证明`（*proof by verbosity*，亦称 *argumentum verbosium*、以恐吓为证）。它是一种修辞手段，试图以海量材料压倒听众，或使论证复杂到充满技术行话，从而使论证**听起来**言之成理。由此产生的论证如此繁复迂曲，以至于无人能够反驳，听众只好接受它，否则便须承认自己的无知。其极端形态是那类把日出日落、正午午夜说成在地球上印下"时间正方形"，进而推出单次自转中存在十六个角、九十六小时、四个同时的二十四小时日的文本——其内部术语与推演之密集，恰恰使得任何具体的反驳都无从下手。

**机制：** 三者共享同一个基础——它们都把论证的**说服负荷**从前提与结论之间的关系上移开，分别移向新话题、移向标准的可变性、移向听众承认无知的成本。而相干性的缺失在这个过程中从未被弥补，只是被遮蔽。

*冗长证明在复杂度维度上还有一个反向的对应物——过度简化，它通过忽略相干的复杂性而非制造多余的复杂性来伪造说服力。两者的对照留待语言层面的讨论处理。*

### 情绪作为前提：恐惧、怜悯、嘲弄与重复

情绪长期被视为可疑之物，因为它有压倒人的力量；柏拉图主张理性必须支配灵魂中的激情部分，而激情犯罪至今被认为比预谋暴力应受更轻的惩罚。在对话与论证的语境中，情绪同样扮演重要而强大的角色。恐惧可以使人瘫痪，也可以驱使人做出平常不会或不能做的事；在怜悯与同情的时刻，人往往放下戒备而向他人的需要敞开。正因其效果多样且对生活居于中心地位，情绪在论证中的位置必须被仔细考虑。

`诉诸强力或恐惧`（*appeal to force or fear*）是试图让听众因受到伤害的威胁或可能性而感到恐惧，从而接受某个结论。威胁或恐惧的唤起可以是直接的或间接的、身体的或心理的。"若本公司员工不同意减薪百分之二十五，公司可能被迫关门；因此本公司员工必须同意减薪百分之二十五"——恐惧在此被安放在前提的位置上。

**条件：** 但恐惧并非总是不相干。**当恐惧本身正是论题的一部分时，唤起恐惧可以是论证的合法组成部分。** 判定的关键在于所给出的理由是否与当下讨论的语境相干。考虑一位导师以继续留在项目中为条件向学生索取性关系的情形：若该情境中的"应当"意指"既然我们彼此吸引且有意"，那么没有理由认为这是谬误性的论证；然而实际发生的是，在权力不对等的语境中、以"要求"的措辞，"应当"的意义从前者被**转移**为"既然你显然想继续留在项目中"。鉴于关于性的恰当交换的伦理规范——性不应被胁迫——所给出的理由与"是否发生性关系"这一讨论语境不相干。**因此该论证是谬误性的，而其谬误性来自理由与语境的不相干，而非来自"涉及恐惧"这一事实本身。**

`诉诸怜悯`（*appeal to pity*）的结构为：提出者给出理由 x、y、z，其中一项或多项意在唤起怜悯；提出者据此断定 C 应当或不应当发生。判定其是否谬误，有两个必须回答的问题：

```
（1）结论究竟是什么？
（2）所理解的前提是什么？
```

两个对照案例足以显示这一程序的作用。一位家长向女儿细述姑妈蒂莉多年来的善意——关心她的福祉、记得她的重要日子、资助她的教育费用——以及姑妈当前的困顿、病弱、孤独与抑郁，最后说："你真的应该去看看蒂莉姑妈。"此处结论是一个关于应当如何对待长期善待自己之人的规范性判断，而所唤起的怜悯与这一判断直接相干。**这是一个合法的诉诸怜悯。** 反面案例是辩护律师陈述被告的悲惨经历，以求法官判其**无罪**：被告的经历完全不能推出他没有抢劫银行，即便法官关心的是改造而非报应。若辩护律师的用意是使法官为被告难过、使其认为被告已经受够了惩罚，那么这是一次谬误性的诉诸怜悯。同类的还有：某教师自去年丧妻后状态不佳，颁给他年度教师奖会振奋他的精神，而且他教得也不算太差——奖项的评定标准与"是否需要被振奋"之间不存在连接。

**区别：** 两个案例的差别不在于情绪的强度，而在于**结论的性质**。当结论是关于应当如何对待某人的规范性判断时，怜悯可能是相干的考虑；当结论是关于事实的断定（某人是否实施了某行为、某人是否符合某项标准）时，怜悯永远不相干。

`诉诸嘲弄`（*appeal to ridicule*）是把某个观点加以贬损或取笑，并以此作为论证的一部分。含有嘲弄的前提之所以不相干，是因为**取笑一个主张不能使它为假，一个观点听起来荒谬也可能仍然为真**。它与针对人的论证关系极近：后者通常直接攻击人（"你是个白痴"），前者则通过嘲弄其观点而间接攻击人（"这是我这周听过最愚蠢的话"）。说某人是傻瓜与说其意见愚蠢之间差别甚微；要嘲弄一个观点而不暗示同一描述适用于持有者本人，是困难的。它与情绪诉诸的相似之处则在于：两者都试图绕过对观点的理性评估，转而引发听众的情绪反应——可能是以他人为代价引发笑意，也可能是引发敌意，利用群体的恐惧与偏见。

*嘲弄的代价不止于单次论证的失败。与之对立的是`知性谦逊`——对自身认识处境有准确的评估，既不过高也不过低地看待自己。谦逊之所以是德性，在于人作为认识主体是有限的，必须依赖认识共同体中的他人来获得知识；谦逊促成真理的获取，它要求认真对待他人的观点，无论其听起来多么可笑，同时始终认识到自己或他人都可能弄错。嘲弄一个观点，就是不把他人当作认识主体来尊重。*

`重复论证`（*argument by repetition*，亦称 *ad nauseam*、*ad infinitum*）是反复使用同一词语、短语、故事或形象，指望重复本身带来说服。它是一种宣传手段：把同一件事一遍遍说，可以换不同的词，但要点相同；理论是说得足够多，人们最终就会相信。里根在 1976 年竞选中开始讲述的"福利女王"叙事——一个拥有八十个姓名、三十个地址、十二张社保卡，同时以每个身份领取医疗补助、食品券与福利金，免税现金收入超过十五万美元的芝加哥女人——在此后数十年间持续渗透关于政府福利项目的政治与社会话语。**重复论证不靠事实或逻辑说服听众，而靠重复的心理与情感力量；*ad nauseam* 正是指重复到令人厌倦乃至作呕的程度。** 其代价是，单一维度的叙事与刻板印象取代了对论题复杂性的考虑与承认。

### 诉诸不良后果：事实性结论与实践性结论的分叉

`诉诸不良后果`（*argument from adverse consequences*）具有如下一般形式：

```
（1）若 P 为真，则某种坏事会成立。
⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯⎯
（2）因此并非 P。
```

由于 P 的坏后果一般与 P 的真假不相干，这类论证通常犯相关性谬误。"如果必须向税务部门申报租金收入，那么我这六年的税都算错了，我得收集更多资料，还要担心往年被审计。所以我想我们并不真的需要申报租金收入。"又如，有人转述某社会学家通过据称文化中立的智商测验发现不同族群平均智力存在差异，回应者说："那她一定是弄错了。不同族群之间不存在平均智商差异，因为如果存在，偏执狂就可以据此为其种族主义辩护。"

**区别：** 这一谬误的判定有一个不可省略的步骤，即确定结论究竟是**事实性的**还是**实践性的**。主张"我们不应当公开讨论 X"或"不应当资助对 X 的研究"是关于行动的判断，而某个话题的恶劣后果对这类判断可以是完全相干的考虑。主张"X 因此为假"则是关于事实的断定，恶劣后果对它不提供任何支持。**同一段话在前一种读法下可能完全合理，在后一种读法下必定谬误。**

麻烦在于结论常被留作隐含。此时论证者尚未犯下谬误，但正处于犯下谬误的危险之中；有时论证者心中确有一个实践性结论而并未把它与事实性结论混同。丹宁勋爵对伯明翰六人案的判词即属此类模糊情形：若那六人胜诉，就意味着警方犯有伪证罪、暴力与威胁，供词是编造的且被不当采纳，定罪是错误的——"这是如此可怕的前景，以致全国每一个明理之人都会说这些诉讼不能再继续下去。"表面上这像是一个实践性结论。**但同时也很可能，他是在根据自己所相信的事实性陈述——例如警方并未伪证——来决定如何行动；而该情境之"可怕"（假定警方确实伪证等等）对那些事实性陈述几乎不提供支持，因此他很可能已经隐含地作出了一个诉诸不良后果的论证。**

### 诉诸传统与年代势利：时间位置为何不构成理由

最后一类相关性伪装利用的既非情绪也非注意力，而是**时间位置**。它有两个方向相反的形态。

`诉诸传统`（*appeal to tradition*）是无视应当改变的证据，理由是某事已经做了很久。从纯粹逻辑的角度看，它以"过去做过某事，通常还是有规律地做"作为"未来应当继续做"的理由——试图通过诉诸他人对某一传统的敬重或尊崇之情而非诉诸证据来说服，尤其是在有更重要的原则或论题处于危险之中的时候。它暗示传统之中有某种好东西，可以压倒任何其他考虑。

其危险在于阻止改变。诉诸传统长期被用来为人类耽溺其中的几乎每一种压迫行为辩护：奴隶制、剥夺妇女选举权、种族隔离都难以直接辩护，于是转而诉诸它们的历史长度。以校园午餐项目为例，一种典型的操作是承认孩子可能从免费或补贴午餐中受益，随即把这一点轻描淡写地带过，理由是与"美国传统"这一看似神圣的制度所受的损害相比，它无足轻重。**要留意的是，此处并非没有提及相干证据，而是相干证据被提及后被情感性的理由压倒。**

`年代势利`（*chronological snobbery*）走的是相反方向：预设后出时期的文化、哲学或科学观念必然优于更早时期的观念。这一名称由基督教学者巴菲尔德在二十年代首先描述，后经其友人与同事 C. S. 刘易斯推广。它以启蒙运动的"进步"概念为基础，源自这样一个假设——社会中不断增长的知识量（常因科技进步而来）自然而然且永久地取代一切过时之物。典型的表述是把宗教归入人类史前时期，说它来自人类物种啼哭而恐惧的婴儿期，是对知识以及慰藉、安心等幼稚需求的一种幼稚的满足方式，并断言今天受教育最少的孩子对自然秩序的了解也超过任何宗教创立者。

**结论：** 两者虽方向相反，失败机制完全相同：**一个观念被提出或被持有的时间位置，与该观念的真假不相干。** 切斯特顿对此的表述最为直接——现代论辩中兴起了一种愚蠢的习惯，说某某信条在一个时代可以持有而在另一个时代不能持有；据说某个教条在十二世纪可信而在二十世纪不可信。这就好比说某种哲学在星期一可以相信而星期二不能相信；就好比说某种宇宙观适合三点半而不适合四点半。**一个人能相信什么，取决于他的哲学，而不取决于钟表或世纪。**

*这一组同时构成对证据第五形态——科学中的权威性解释——的两种相反滥用：诉诸传统以时间长度对抗新证据，年代势利以时间新近取代论证。两者都把"何时"当成了"是否"。*

## P6 针对人的论证：何时合法，何时谬误

### 人身论证的统一结构与四个亚型

在人际交往中，品格应当获得多少分量？这个问题不能被简单地取消。一个人的品格可以相当合理地被视为其行动的源泉，因此在判断她所说之话的真实性与重要性时，留意其品格是完全正当的。若在考虑与某人深化友谊，了解他过去如何对待朋友是有帮助的；若一个可信赖的人质疑此人的品格，有理由重新考虑是否投入时间去加深这段关系。在政治语境中，尤其是高度公开的政治语境中，品格相当相干，因此那也是人们经常谈论品格的场合。

**正因为品格如此重要、评论他人品格具有如此大的影响力，何时以及如何评论必须极为审慎。**

`针对人的论证`（*ad hominem*，字面意为"对人的""朝向人的""针对人的"）就是一种介入他人品格的论证方式。它通过直接诉诸某人的某一负面方面，或间接地通过对其关系、过去或当下的行动、承诺、观点等作出某种负面主张，来质疑其品格、可信度与可信赖性。**正是对品格的直接或间接质疑，统一了针对人的论证的各种形态。**

三项结构特征贯穿全部亚型。其一，它发生在某种对话或交流的语境中，无论是真实的（面对面）还是设想的（与一个文本对话）。其二，它出现在对另一个人（`提出者`）所陈述的论证或立场作出回应之时，回应者称为`回应者`。其三，回应者不处理提出者的论证或立场，而处理提出者的品格，使其可信度受到质疑，从而质疑或驳倒其论证或立场。

四个亚型的差别在于介入品格的路径：

- **偏见型**：指控提出者因既得利益而有偏见，该偏见妨碍其公正地参与论辩。
- **处境型**：不直接攻击品格，而指出提出者的个人处境（其承诺）与其论证或立场的内容之间存在不一致，以此质疑其真诚或可信度。处境的范围相当宽泛，包括论证者当前或过去的行动、承诺、职业、关系、财产所有情况等等。
- **直接型**：直接针对人，尤其针对品格的某个方面。
- **你也一样型**（*tu quoque*）：当一方质疑另一方品格时，以"你也一样"作为回应，其目的大概是转移或削弱第一方指控的力量。

**许多教科书对针对人的论证处理得过于草率，常把这一论证形式当作通常乃至总是谬误的。** 事情并非如此简单。思考这一论证类型时最大的挑战之一，是找到区分谬误实例与非谬误实例的办法——而**同一个案例可能因读法不同、因回应者的结论不同而被判为谬误或合法**。

这一挑战之所以重要，是因为针对人的论证对提出者有意义地支持其立场的能力影响极大。谬误性的用法之所以有害，部分原因正在于极难有效地回应：一旦被描绘成坏人或伪君子，要从这样的指控中恢复过来是非常困难的。

### 批判性问题：一套可操作的判定程序

既然不能靠形式判定，就需要一套程序。**沃尔顿**提出的`批判性问题`方法正是为此。以偏见型为例，先确立其谬误形态的骨架：

```
回应者：主张论证或立场 x 的提出者有偏见。
回应者：主张提出者的偏见妨碍了她公正论辩的能力。
回应者：因此，提出者的品格与可信度不可信赖。
回应者：因此，论证或立场 x "不应当获得它在没有该偏见时本会获得的那么多可信度"。
```

使其成为谬误的，是**没有充分理由相信提出者的既得利益损害了她公正参与论辩的能力**。可能存在损害的情形，但**仅有偏见并不充分**；在偏见并无问题的情况下试图使他人转而反对提出者，是一种不正当的、谬误的手段，它非法地把论题从论证的主题转移到提出者的品格上。

要判定具体实例落在哪一侧，依次回答四个问题：

```
（1）有什么理由认为提出者有偏见？
（2）若提出者确有偏见，她是仅仅在"有既得利益"的意义上有偏见，还是该偏见也已经妨碍了她公正论辩的能力？
（3）关于提出者所谓偏见的细节，与所涉论证或立场、或与对话语境相干吗？
（4）回应者的结论是较弱的主张——提出者的论证或立场可疑、需要进一步支持——还是较强的主张——其论证或立场已被驳倒？
```

**条件：** 第二个问题指向一个容易被忽略的区分。偏见并非总是成问题的。对日本菜胜过墨西哥菜的偏好是一种偏见；推销员对自己产品的偏爱是一种偏见，而且是人们本就预期的。**偏见成为问题，是在那些目标为公正与尽可能不偏不倚地发现真理的语境中**；在这类语境中，偏见格外有害，因为它妨碍对话追求不偏不倚探究的目标，它涉及"在批判性怀疑恰当时压制批判性怀疑"。

第三个问题决定指控是否落到实处。以某位孟山都代表援引研究支持其立场、而回应者指控其有偏见为例：仅凭"他受雇于该公司"尚不足以作出判断，**相干的是那些研究本身的性质——谁出资？发表在什么期刊？** 若由孟山都出资并发表在类似《孟山都农业学刊》这样的刊物上，那就可能有理由认为存在成问题的偏见，因而该代表的可信度确实受损。

第四个问题则是全部程序的枢纽，值得单独处理。

### 强结论与弱结论：驳倒论证与削弱可信度的分界

**同一个针对人的论证，其结论可以有两种强度：**

```
强读：提出者的论证或立场因此被驳倒。
弱读：提出者的论证或立场因此可疑，需要来自不偏不倚一方的进一步证据。
```

**在大量情形中，强读是谬误的而弱读不是。** 以直接型为例：某位证人被指出曾犯伪证罪，是否因此可以认为其证词为假？做一个不可信赖的说谎者，并不意味着此人所说的一切都是假的；至多意味着此人不值得信赖，以及不加批判地接受其所言者是愚蠢的。**因此，若回应者主张该证词为假，则论证是谬误的；若回应者主张该证词不可被信赖，那么鉴于此人确为伪证犯，这一主张有理由被相信——在这一较弱的读法下，没有犯任何谬误。** 而由于这是一桩法庭案件，律师本就无须证明该证词为假，他只需表明有理由不信任它。**弱读在此不仅合法，而且已经足够。**

处境型的判定同样如此。以某人主张立即废除学校种族隔离、而自己却把儿子送进私立学校以避开所在社区的融合学校为例：真正的问题在于，回应者的主张是"提出者的论证或立场应被视为已被驳倒"，还是"提出者的可信度受到质疑，因而有理由怀疑其论证或立场"。若提出者的品格并未通过显示成问题之不一致的承诺而被真正质疑，那么回应者既未驳倒也未成功质疑其论证或立场，于是在两种读法下都给出了一个谬误性的处境型论证。

**区别：** "你也一样型"必须与两恶成善区分开来。沃尔顿强调，教科书处理"你也一样型"的最大问题在于，按其最常见的定义方式，它变得与两恶成善本质上是同一类论证。**使它不仅仅是后者、而是一个真正的针对人的论证的，是它以某种方式牵涉了双方的品格。** 公立学校教师主张提高公立学校教师的薪水，纳税人反驳说"当然啦，不难看出你为什么赞成加薪"，教师回应"我也可以这么说你，不难看出你为什么反对"——此处双方的品格都被卷入。而判定这一回应是否谬误，仍要回到相干性：回应者所预设的某种党派特征，是否会使提出者评估某个具体问题的可靠性降低？若二者之间难以看出连接，那么回应者的直接型攻击与提出者的直接型攻击并不真正相干，于是无论回应者是要人质疑提出者的品格进而间接质疑其论证，还是认为提出者的立场已被驳倒，都没有给出足够的理由——**在两种读法下，这都是一个谬误性的"你也一样型"论证。**

*强读与弱读的区分不限于针对人的论证。它是判定一大类相关性谬误的通用工具：诉诸人民、不当诉诸权威、夸大分歧在弱读下都可能提供某种程度的支持，而在强读下都失败。P7 将系统地运用这一工具。*

**局限：** 还有一种情形需要单独处理。上述全部讨论都预设提出者给出了论证，因而品格与论证的好坏之间存在距离。**若根本没有给出论证，而只有断言，那么提出者的品格就是是否采信其主张的核心。** 此时关于品格、处境与可信度对论证之有效性或强度不相干的说法并不适用——因为根本没有有效性或强度可言，只有证言的可信度问题。

### 井中投毒：在对方开口之前污染解释框架

`井中投毒`（*poisoning the well*）也是一种针对人而非其论证的攻击，但它与前述三种亚型在时间结构上不同。直接型、处境型与"你也一样型"通常是对对话者已经说出的主张的回应；**井中投毒则发生在对方尚未有机会为自己或自己的观点辩护之前**，以先发制人的一击或以关于论辩对手的不利信息，不正当地给听众预设立场。

其后果比单次论证的失败更深。它创造出一个概念框架，听众——甚至对话者本人——会按照这一框架把她的主张解读为"实现"并"确认"了埋藏在这一概念陷阱之中的预设。换言之，**它使对方此后所说的任何话都成为对指控的印证**：辩解被读作心虚，沉默被读作默认，反驳被读作恼羞成怒。

这一机制的极端历史形态出现在这样的处境中：任何对官方教义的质疑本身被预先定义为对权威的挑战，因而构成应受酷刑与死亡惩罚的重罪。在这种框架下，反对意见在被听取之前就已经被归类。

*井中投毒还有一个与其原初含义相邻但不同的用法，涉及那些狡猾的、不可证伪的陈述——它们无法被理性地或经验地证实，因而甚至不值得反驳。把这一类陈述也称作井中投毒，会损失一些术语的精确性，但两者确有共同之处：都使对手处于无论说什么都无法改善自身处境的位置。这一类陈述的机制本身在预设谬误处另行处理。*

### 起源、连坐与归谬于希特勒：从来源推断真值的三种形态

针对人的论证的核心错误可以被抽象为一句话：**由主张的来源推断主张的真值。** 这一错误有三种以不同方式实现的形态，它们不以品格为唯一中介。

`起源谬误`（*genetic fallacy*）是仅仅基于起源而为某个结论辩护。这是一个相关性——更确切地说是不相干性——的谬误，因为一个主张的起源可能与其真值无关。给出一个主张的发生学说明、它的历史或来源，可能是有信息量的、有帮助的；但这并不必然决定该主张的真值。**因此，当仅仅基于一个主张的起源而对其真值作出结论时，就可能犯了起源谬误。** 它有时被称为"疯子谬误"，因为这一谬误可以由一句俗语刻画：**就因为是疯子说的，并不意味着它不是真的。**

一个决定性的例子说明了为什么起源与真值必须分开。假设一群孩子相信不应触碰热炉子，理由是炉子里有个会咬手的邪恶精灵。**该信念之起源的虚假性，并不改变该主张的规范性价值**：即便炉子里没有邪恶精灵，也不意味着孩子们因此就应当把手放在热炉子上。在关于各种社会实践之建制的讨论中，结果的真值与它由之产生的手段之间存在明显的脱节。

`连坐`（*guilt by association*）则把来源替换为交往：因为某人或某物 A 与某人或某物 B 有关联，便认为 A 具有或接受 B 的全部性质。这一谬误渗透在社会各处——社交群体、政治竞选、商业关系、法院系统。在竞选中指控某位候选人"与恐怖分子厮混"，依据是他在九十年代曾认识一位在六十年代参与过国内恐怖组织的教授并与之共同参与过社区项目；附和者则说，若你与一个从未为轰炸五角大楼与国会大厦道歉、反而以之为傲的人来往，那就令人怀疑你的判断力。**失效的位置在于：当论证的对象变成某人"与谁厮混"，而不是此人本身时，连坐便已发生。** 犯下这类谬误性思考的人，把其"受害者"说成一维的、被简化的漫画形象，而非现实中的复杂个体。

`归谬于希特勒`（*reductio ad Hitlerum*）是针对人的论证这一属中的一个种。从逻辑上说，针对人的论证的各个种都可以由同一句话驳倒：**就因为 X 或某个 X 说了它，并不意味着它是假的。** 可以不喜欢杰斐逊拥有奴隶这一事实，但他拥有奴隶并不使他说过的一切因此为假；同样，若希特勒在某个星期二指出那天是星期二，不会有人说因为是希特勒说的，那天就一定不是星期二。

**条件：** 然而在某些语境中，这类主张可以是相干的。**一个主张的真值在多数情形下可以被理解为独立于作出该主张的人——但要排除某些类型的主张，即那些指涉作出该主张之人的主张。** 关于某人自身状态、承诺、意图的陈述，其真值与该人不可分离；关于世界的一般陈述则不然。此外，当所评价的不是某个陈述的真值而是某个行动的性质时，指涉行动者是必要的：若"为了政治利益而屠杀无辜者是恶的"这一前提成立，那么按多数标准，那些行动显然是恶的。

*针对这类论证在网络讨论中的泛滥，曾有人提出一条规则：凡在论辩中首先诉诸与希特勒或纳粹的比较者，论辩即视为结束，作出该比较者视为弃权。这条规则作为对话礼仪有其用处，但作为逻辑判据则过于粗糙——它取消了上述"某些语境中相干"的例外。*

### 伽利略策略：被主流嘲笑不是正确的证据

最后一种形态把针对人的论证**反转**过来：不是用他人的身份贬低其主张，而是用他人对自己的贬低来抬高自己的主张。

`伽利略策略`（*Galileo gambit*）由那些理论与主流科学共识相抵触的人所犯。这类理论常被嘲笑甚至讥笑；而对犯此谬误者而言，这恰恰成了认为自己理论为真的理由：主流曾嘲笑伽利略说太阳位于太阳系中心，那也违背了当时的常识，但结果证明他是对的；所以我的理论大概也是对的。**被嘲笑这一事实，被当作断定其为真的好理由。**

这个名称本身就不准确：伽利略并没有与科学共识相抵触，他抵触的是教会教义。不过确实有一些与科学共识相抵触而结果正确的例子——巴斯德与его病菌致病说、魏格纳与大陆漂移说、爱因斯坦与相对论。但由于犯此谬误者援引的是伽利略，这一名称便沿用下来。

**失效的位置**可以从若干方向指出，其中最直接的一个与证据的选择有关：犯此谬误者把注意力引向异见者最终正确的**那一个**案例，而忽略异见者最终错误的**无数**案例。这与确认偏误、可得性误差以及隐藏证据是同一类操作的不同侧面。

**条件：** 由此可以得出一条更强的结论。一个与既定观点相抵触的新理论，其提出者承担着证明它优于既定观点的初始工作；**仅仅是"我的理论与主流相反"这一事实是不够的——恰恰相反，这一事实意味着它很可能为假。** 若某位科学家在你尚未证明理论值得考虑之前就不予考虑，他并未表现出对既定智慧的不合理偏袒；他是在正确地评估你的理论为真的可能性，并据此合理地分配自己的时间。这一点可以被概括为：**要披上伽利略的外衣，仅仅被不友善的建制迫害是不够的——你还必须是对的。**

*伽利略策略、年代势利与不可证伪主张构成了对证据第五形态——科学中的权威性解释——的三种攻击路径：一个以被排斥为荣，一个以时代新旧取代论证，一个使主张脱离任何可能的检验。三者都不提供理论所缺的东西，即支持该理论优于竞争者的证据。*
